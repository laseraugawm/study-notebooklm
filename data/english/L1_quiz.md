- [ ] 13세 때 사이버불링 피해 소녀의 비극적인 기사를 접하고 개발을 결심했다.
- [ ] 사용자가 공격적인 메시지를 입력할 때 이를 감지하여 다시 생각해보도록 유도한다.
- [ ] 연구 결과에 따르면 청소년 사용자의 93%가 마음을 바꾸고 공격적 메시지를 게시하지 않았다.
- [x] 사이버불링 발생 즉시 경찰에 자동으로 신고하여 가해자를 처벌하는 기능을 제공한다.
