### 0. 프로그래밍과 개발 환경
- **프로그래밍**: 프로그래밍 언어를 이용해서 프로그램을 만드는 과정 (p.108)
- 파이썬은 이해가 쉽고 활용도가 높으며, 다양한 라이브러리를 제공해 데이터 분석·인공지능 작업도 할 수 있다. (p.108)
- **파이썬 IDLE**: 파이썬 프로그램을 설치하고 명령어를 입력한 뒤 Enter를 누르면 바로 실행 결과를 볼 수 있는 환경 (p.108)
- **구글 코랩(Google Colab)**: 프로그램을 따로 설치하지 않고 온라인상에서 파이썬으로 프로그래밍하고 바로 결과를 확인할 수 있는 통합 개발 환경 (p.108~109)

  2. 작업 창 구성: **코드 셀**(코드를 작성하고 실행 결과를 확인하는 공간), **텍스트 셀**(글과 이미지를 작성하는 공간) (p.109)
  3. 실행: [새 노트]의 코드 셀에 코드 작성 → (실행) 버튼 클릭 → 결과 확인 (p.109)

### 1. 변수
- **변수**: 프로그래밍에서 값을 저장하는 기억 공간. 등호(=)로 값을 저장하고, 저장된 값을 변경할 수 있다. (p.110)
- 형식: `변수명 = 변수에 저장할 값(상수, 변수, 수식 등)` (p.110)
- **변수명**: 기억 공간을 식별하기 위해 붙인 이름 (p.110)
- 변수명 지정 규칙 (p.110)
  1. 알파벳 대소문자, 한글, 언더 바(_), 숫자만 사용할 수 있다.
  2. if, for 같은 파이썬 예약어는 쓸 수 없다.
  3. 알파벳 대소문자를 구별한다.
  4. 첫 글자에 숫자가 올 수 없다.
- **파이썬 예약어** 예: True, False, and, or, not, return, for, while, if, else, elif, continue, break 등 (p.110)
- 변수의 역할을 나타내는 변수명을 쓰면 프로그램 이해와 수정이 쉽다. (p.110)
- `print( )`: 괄호 안의 값, 변수명, 수식 결과를 출력한다. (p.110)
- 활동 12: name = '김민지', age = 17, phone = '010-1234-5678' 처럼 정보를 변수에 저장 (p.110)

예제 5 (p.110)
```python
# a에 정수 10을 저장하기
a = 10
# b, c에 실수 2.5와 문자 ‘A’를 순서대로 저장하기 
b, c = 2.5, "A"
print(a, b, c)
# a에 저장된 값에 2를 곱하기
a = a * 2
print(a, b, c)
```
- `a = 10`: a에 정수 10 저장
- `b, c = 2.5, "A"`: 두 변수에 한 줄로 순서대로 저장
- 첫 `print` → `10 2.5 A`
- `a = a * 2`: a의 현재 값 10에 2를 곱해 다시 a에 저장(값 변경) → 두 번째 출력 `20 2.5 A`

### 2. 자료형
- **자료형**: 변수에 저장될 데이터가 어떤 유형인지 구분하는 것. 수치형, 불형, 문자열 등 (p.111)
  - **수치형**: 숫자. 정수형(int), 실수형(float) (p.111)
  - **불형(bool)**: 참(True)과 거짓(False) (p.111)
  - **문자열(str)**: 큰따옴표(" ")나 작은따옴표(' ')로 감싸서 표현 (p.111)
- `type( )`: 자료의 종류를 반환. 괄호 안에 변수·수식·값이 들어갈 수 있다. (p.111)
- **인덱스(index)**: 저장된 값(요소)의 위치 정보. 0부터 1씩 증가. 문자열·리스트에서 사용 (p.111, 120)

예제 6 결과 (p.111): `3 <class 'int'>`, `1.5 <class 'float'>`, `True <class 'bool'>`, `False <class 'bool'>`, `apple <class 'str'>`, `2025 <class 'str'>`
- `f = "2025"`는 따옴표로 감쌌으므로 숫자처럼 보여도 **문자열**이다.

예제 7 (p.111)
```python
a = "HAPPY BIRTHDAY!"
print(a[1])	# 1번 인덱스 출력하기
print(a[6:11])	# 6~10번 인덱스 출력하기
print(a[ : 5])	# 0~4번 인덱스 출력하기
print(a[11: ])	# 11~문자열 끝 출력하기
b = "2U"
print(a + b)	# a와 b 문자열 결합하기
print(b * 2)	# b 문자열 반복하기
```
- `a[1]` → `A` (H가 0번, A가 1번)
- `a[6:11]` → 6~10번 → `BIRTH` (끝 번호 11은 포함하지 않음)
- `a[ : 5]` → 처음~4번 → `HAPPY`
- `a[11: ]` → 11번~끝 → `DAY!`
- `a + b` → 문자열 결합 `HAPPY BIRTHDAY!2U`
- `b * 2` → 문자열 반복 `2U2U`
- 개발 과제: 문자열 a에서 HBD만 출력해 보기(H=0, B=6, D=11번 인덱스) (p.111)

### 3. 연산자
- **연산자**: 특정한 작업을 수행하려고 사용하는 기호. 값을 조작하거나 식을 계산 (p.112)
- 종류: 산술, 비교, 논리 연산자. 우선순위는 **산술 ＞ 비교 ＞ 논리** (p.112)
- **산술 연산자**: +, -, *, /(나눗셈), //(몫), %(나머지), **(거듭제곱) (p.112)
  - 우선순위: 괄호 먼저 → 곱셈·나눗셈이 덧셈·뺄셈보다 먼저 → 같은 순위면 왼쪽부터 (p.112)
  - 예제 8: `11 + 4 / 2` → 13.0, `25 // 2` → 12, `25 % 2` → 1, `2 ** 10` → 1024 (p.112)
- **비교 연산자**: 값을 비교해 True/False를 판단. >, <, >=, <=, ==(같다), !=(같지 않다) (p.112)
  - 예제 9 (n = 10): `n == 5` False, `n != 5` True, `n > 5` True, `n <= 5` False, `5 <= n < 10` False (p.112)
- 활동 13: 체질량 지수 bmi = 몸무게(kg) ÷ 키(m)². h = 1.7, w = 60. 정상 범위(18.5 이상 23 미만) 판정은 `18.5 <= bmi < 23` 형태로 True/False 출력 (p.112)
- **논리 연산자**: 논리식의 참과 거짓을 판단 (p.113)
  - **논리곱(and)**: a와 b 모두 참일 때 참
  - **논리합(or)**: 하나 이상이 참이면 참
  - **논리 부정(not)**: 참이면 거짓, 거짓이면 참

예제 10 (p.113)
```python
id = "Lee"
pw = "1234"
print(id == "Lee" and pw == "1234")
print(id == "Kim" and pw == "1234")
print(id == "Lee" or pw == "asdf")
print(id == "Kim" or pw == "asdf")
```
- 1번째: 둘 다 참 → `True`
- 2번째: id가 틀림 → and이므로 `False`
- 3번째: id가 맞음 → or이므로 `True`
- 4번째: 둘 다 틀림 → `False`
- 예제 11: `a = 10 > 5` → a는 True, `not a` → False (p.113)
- 활동 14(혈압 단계 구분, a=135, b=88) (p.113)

| 단계 | 수축기 | 연산자 | 이완기 |
|---|---|---|---|
| 정상 혈압 | 120 미만 | 그리고 | 80 미만 |
| 주의 혈압 | 120~129 | 그리고 | 80 미만 |
| 고혈압 전 단계 | 130~139 | 또는 | 80~89 |
| 고혈압 | 140 이상 | 또는 | 90 이상 |

  - 실행 결과: 정상 False, 주의 False, 고혈압 전 단계 True, 고혈압 False. "그리고"는 and, "또는"은 or로 바꾼다.

### 4. 표준입출력
- 프로그램은 데이터를 입력받아 처리하고 결과를 출력하는 단계로 진행된다. (p.114)
- **표준입출력**: 키보드 같은 표준 입력 장치로 입력받을 때 `input( )`, 모니터 같은 표준 출력 장치로 출력할 때 `print( )` (p.114)
- **input( )**: 키보드로 데이터를 입력받는 명령어. 입력값은 **문자열**로 처리된다. 형식 `변수명 = input( )` (p.114)
  - 지시어(안내 문구)를 넣을 수 있다: `b = input("연도: ")` (p.114)
- **형 변환**: input( )으로 받은 값은 문자열이므로 `int( )`, `float( )`로 바꿔야 한다. (p.114)
  - `int("2025")` → 정숫값 2025, `float("3.8")` → 실숫값 3.8, `int("3.8")` → **오류**(소수점이 있는 문자열은 정수형으로 바꿀 수 없음)
- 활동 15 (p.114): 5를 입력할 때
  - 프로그램 1 `n = input()` → `print(n + n)` : 문자열 합하기 → `55`
  - 프로그램 2 `n = int(n)` 후 `print(n + n)` : 덧셈 → `10`
- **print( )**: 모니터에 데이터를 출력. 형식 `print(값)`, `print(변수명)`, `print(수식)`, `print(값1, 값2, …)`(여러 값을 한 줄에) (p.115)
  - 예제 13 결과: `Python` / `10` / `6.5`(3 / 2 + 5) / `Hello 2025 Goodbye 2024` (p.115)
- 활동 16: 대인 50,000원·소인 30,000원, `int(input( ))`으로 정수 입력. 대인 2, 소인 2 → 160000 (p.115)

### 5. 파일입출력
- **파일입출력**: 파일 안의 데이터를 읽고 수정하고 저장하는 작업. 많은 양의 데이터를 빠르게 처리하고, 프로그램이 종료되어도 파일에 남아 있다. (p.116)
- **텍스트 파일**: 데이터가 모두 문자로만 구성된 파일. 메모장이나 코랩으로 작성 (p.116)
- **파일 객체**: 파일 경로를 가리키며 읽기·쓰기 작업을 할 수 있게 하는 대상 (p.116)
- 작성 과정 (p.116)
  1. 파일 열기: `파일 객체 = open('파일명', '접근 방식')` — r: 읽기, w: 쓰기, a: 추가하기
  2. 읽기·쓰기: `파일 객체.read( )`, `파일 객체.write( )`
  3. 파일 닫기: `파일 객체.close( )`
- 예제 14 (1): 코랩 왼쪽 (파일) 클릭 → 오른쪽 클릭 [새 파일] → '버킷리스트.txt' 이름 지정 후 더블 클릭해 놀이기구 목록 작성 → Ctrl + S로 저장 (p.116)

예제 14 (2) 파일 읽어 출력 (p.117)
```python
f = open("버킷리스트.txt", "r")	# 파일을 읽기( r ) 모드로 열기
data = f.read()	# 파일 내용 전체를 읽어 data에 저장하기   
print(data)	# data에 저장된 내용을 출력하기
f.close()	# 파일 닫기
```
- 결과: 롤러코스터 / 플룸라이드 / 바이킹 / 모노레일

한 줄씩 읽기 (p.117, 여기서 잠깐)
```python
f = open("버킷리스트.txt", "r")
for row in f :
  print(row, end = "")
f.close()
```
- f가 가리키는 파일에 접근해 한 줄씩 row에 넣어 출력한다.

예제 14 (3) 내용 비우고 새로 쓰기 (p.117)
```python
f = open("버킷리스트.txt", "w")	# 파일을 쓰기(w) 모드로 열기
f.write("회전목마")	# 파일에 있는 모든 내용을 지운 후 작성하기
f.close()	# 파일 닫기
```
- w 모드는 기존 내용을 **모두 지우고** 새로 쓴다 → 파일에 '회전목마'만 남는다.

예제 14 (4) 입력받아 추가하기 (p.117)
```python
data = input("타고 싶은 놀이기구는? ")	# 사용자로부터 놀이기구 입력받기
f = open("버킷리스트.txt", "a")	# 파일을 추가(a) 모드로 열기   
f.write("\n" + data)	# 입력받은 내용을 파일 끝에 추가하기
f.close()
```
- a 모드는 기존 내용 **끝에** 붙인다. `"\n"`은 줄바꿈 문자 → '범퍼카'가 새 줄에 추가된다.
- 쓰기(w)·추가하기(a) 모드는 파일이 없으면 지정한 위치에 **새로 생성**한다. (p.117)

활동 17 개인 정보 비식별화 (p.118)
- **비식별화**: 특정 개인을 알아볼 수 없도록 개인 정보의 일부나 전부를 삭제하거나 대체하는 작업
- **CSV(Comma Separated Values)**: 쉼표로 구분된 값을 저장하는 파일 형식, 다양한 프로그램에서 읽고 쓸 수 있다.
- 단계: ① 파일 수집('당첨자명단.csv' 다운로드) ② 코랩에 업로드(`from google.colab import files`, `uploaded = files.upload()`) ③ CSV 내용 확인 ④ 비식별화 처리
- 'utf8' 인코딩을 써야 한글이 깨지지 않는다.

단계 4 코드 (p.118)
```python
import csv	# 원본 파일 읽기
f1 = open("당첨자명단.csv", "r", encoding = "utf8")	# csv 파일을 읽기( r ) 모드로 열기
data1 = csv.reader(f1)  
f2 = open("비식별화처리.csv", "w", encoding = "utf8")	 # 결과 파일을 쓰기(w) 모드로 열기
data2 = csv.writer(f2)
for row in data1:
 row[0] = row[0].replace(row[0][1],'O')	 # 이름의 두 번째 글자를 'O'으로 변경하기 
 row[1] = row[1][-4:]	# 전화번호 뒷자리(4자리)만 잘라 내기
 data2.writerows([row])	# 변경한 행을 결과 파일에 추가하기
f1.close()
f2.close()
```
- `import csv`: csv 라이브러리 호출
- `csv.reader(f1)`: 원본 파일을 한 행씩 읽는 대상 생성 / `csv.writer(f2)`: 결과 파일에 쓰는 대상 생성
- `for row in data1`: 행마다 row = [이름, 전화번호]
- `row[0][1]`: 이름의 두 번째 글자 → `replace`로 'O'로 바꿈 (강감찬 → 강O찬)
- `row[1][-4:]`: 전화번호의 뒤 4자리만 (010-1234-5678 → 5678)
- `writerows([row])`: 바꾼 행을 결과 파일에 추가
- 결과: 강O찬,5678 / 김O신,2222 / 윤O주,3333

### 6. 다차원 데이터 구조
- 자료(문자·숫자·이미지·동영상 등)의 특성에 맞는 데이터 구조를 선택해야 한다. (p.119)
- **다차원 데이터 구조**: 데이터를 행과 열, 또는 여러 개의 차원으로 구성하여 저장하는 방법. 많은 양의 데이터를 효율적으로 처리·관리 (p.119)
- **차원(dimension)**: 데이터 구조를 구성하는 요소의 수. 2차원 = 행·열, 3차원 = 행·열·높이 (p.119)
- 예: 1차원 = 과목별 점수(국어 85, 수학 92, 정보 100, 영어 80), 2차원 = 번호×과목 점수표, 3차원 = 1반·2반·3반 점수표를 쌓은 것 (p.119)
- **컴퓨터 이미지 표현**: 흑백 이미지는 밝기만 필요 → 0~255 정숫값의 **2차원** 구조(0에 가까울수록 어둡고 255에 가까울수록 밝음). 컬러 이미지는 밝기에 빨강(R)·초록(G)·파랑(B) 색상 정보가 더해져 **3차원** 구조 (p.119)

#### 1차원 리스트
- **1차원 리스트**: 데이터들을 묶어서 하나의 이름으로 관리하는 방법 (p.120)
- 형식: `리스트명 = [값 1, 값 2, 값 3, …]`(생성), `리스트명[인덱스]`(요소 추출) (p.120)
- **요소(원소)**: 리스트를 구성하는 각각의 값. 모든 요소가 같은 자료형일 수도, 서로 다른 자료형일 수도 있다. (p.120)
- 예제 15: `a = [1, 3, 5]` → `[1, 3, 5] <class 'list'>` (p.120)
- 예제 16: `b = ["B", 1 > 0, 2.4]` → `['B', True, 2.4] <class 'list'>` (1 > 0이 True로 저장) (p.120)
- 다양한 생성: 빈 리스트 `c = [ ]` → `[ ]`, `d = [0] * 5` → `[0, 0, 0, 0, 0]` (p.120)
- **슬라이싱**(리스트의 부분 추출), a = [1, 3, 5, 7]: `a[1: 3]` → [3, 5], `a[1: ]` → [3, 5, 7], `a[ : 3]` → [1, 3, 5], `a[ : ]` → [1, 3, 5, 7] (p.120)

예제 17 (p.120)
```python
n = [10, 20, 30, 40, 50]           
print(n[0])	# 인덱스 0번에 위치한 값 
print(n[-1])	# 리스트 맨 뒤에 위치한 값 
n[0] = "hello"
print(n)
# 리스트값 연산하기
n[3] = n[1] + n[2]
print(n)
n[1] = n[2] > n[3]
print(n)
```
- `n[0]` → 10, `n[-1]` → 맨 뒤 값 50
- `n[0] = "hello"` → ['hello', 20, 30, 40, 50] (요소 값 변경, 자료형이 달라도 됨)
- `n[3] = n[1] + n[2]` → 20 + 30 = 50 → ['hello', 20, 30, 50, 50]
- `n[1] = n[2] > n[3]` → 30 > 50은 False → ['hello', False, 30, 50, 50]

#### 리스트 관련 명령어 (더 알기, p.121)
- `리스트명.append(값)`: 맨 뒤에 추가
- `리스트명.insert(인덱스, 값)`: 원하는 위치에 삽입(이후 데이터는 하나씩 뒤로 밀림)
- `리스트명.remove(값)`: 값과 일치하는 요소 삭제(같은 값이 여러 개면 **첫 번째**만 삭제)
- `리스트명.sort( )`: 오름차순 정렬
- `리스트명.pop( )`: 맨 뒤 데이터 삭제
- `len(리스트명)`: 데이터 개수 반환

플레이리스트 예 (p.121)
```python
# 나만의 플레이리스트 만들기
playlist = ['나비야', '작은별', '산토끼', '비행기']
print(playlist)
# 리스트 맨 뒤에 원소 추가하기
playlist.append('산토끼')
print(playlist)
# 리스트 맨 앞에 원소 추가하기
playlist.insert(0, '아기 상어')
print(playlist)
# 리스트에서 “산토끼” 삭제하기
playlist.remove(‘산토끼’)
print(playlist)
# 리스트 원소들을 오름차순으로 정렬하기
playlist.sort()
print(playlist)
# 리스트 맨 뒤에 있는 원소를 삭제하기
playlist.pop()
print(playlist)
# 리스트의 길이를 출력하기
print(len(playlist))
```
- append → ['나비야', '작은별', '산토끼', '비행기', '산토끼']
- insert(0, …) → 맨 앞에 '아기 상어'
- remove('산토끼') → 첫 번째 '산토끼'만 삭제 → ['아기 상어', '나비야', '작은별', '비행기', '산토끼']
- sort → ['나비야', '비행기', '산토끼', '아기 상어', '작은별']
- pop → 맨 뒤 '작은별' 삭제 → ['나비야', '비행기', '산토끼', '아기 상어']
- len → 4
- (교과서 인쇄본은 remove 괄호 안에 둥근 따옴표가 찍혀 있으나, 실제 입력은 일반 따옴표를 쓴다.)

#### 2차원 리스트
- **2차원 리스트**: 1차원 리스트가 겹쳐 쌓인 구조. 가로축(행)과 세로축(열)의 두 인덱스로 접근 (p.122)
- 형식: `리스트명 = [[값, 값, …], …, [값, 값, …]]`, `리스트명[행 인덱스][열 인덱스]` (p.122)

예제 18 (p.122)
```python
# 놀이기구 운행 정보를 2차원 리스트에 저장하기
a = [['놀이기구', '키 제한', '탑승 인원', '대기 시간(분)'],
   ['범퍼카', '110cm 이상', 30, 40],
   ['롤러코스터', '120cm 이상', 60, 100],
   ['플룸라이드', '140cm 이상', 8, 120]]
print(a)	# 리스트 전체 내용 출력하기
print(a[1])	# 1행에 저장된 놀이기구 정보 출력하기
print(a[2][3])	# 2행 3열에 저장된 값 출력하기
```
- `print(a)`: 리스트 전체 출력
- `a[1]` → 1행 전체 ['범퍼카', '110cm 이상', 30, 40] (0행은 제목 행)
- `a[2][3]` → 2행(롤러코스터) 3열(대기 시간) → 100

#### 선택 활동: 다차원 데이터 구조로 이미지 표현 (p.123)
- 흑백 이미지를 0·128·255 값의 7×7 2차원 리스트로 표현하고 `import matplotlib.pyplot as plt`, `plt.imshow(a, cmap = 'gray')`로 그림을 그린다.
- 컬러 이미지는 3차원 리스트: R = [255, 0, 0](빨강), G = [0, 255, 0](초록), B = [0, 0, 255](파랑), WT = [255, 255, 255](하양), BK = [0, 0, 0](검정)을 칸마다 넣고 `plt.imshow(a)`로 출력한다.

## 시험 함정 포인트
- 연산자 우선순위는 논리 > 비교 > 산술이 **아니라** 산술 > 비교 > 논리이다. (p.112)
- `11 + 4 / 2`의 결과는 7.5가 **아니라** 13.0이다(나눗셈이 먼저, /의 결과는 실수). (p.112)
- `//`는 나머지가 **아니라** 몫, `%`가 나머지이다. (p.112)
- `=`는 같다는 비교가 **아니라** 값 저장이고, 같은지 비교는 `==`이다. (p.110, 112)
- input( )으로 받은 값은 숫자를 넣어도 정수가 **아니라** 문자열이다 → 5를 넣고 n + n 하면 10이 아니라 55. (p.114)
- `int("3.8")`은 3이 **아니라** 오류이다. 소수점 문자열은 정수형으로 바로 바꿀 수 없다. (p.114)
- `"2025"`는 정수가 **아니라** 문자열(str)이다. (p.111)
- 인덱스는 1이 **아니라** 0부터 시작한다. `a[1]`은 두 번째 글자다. (p.111)
- 슬라이싱 `a[6:11]`은 11번을 포함하지 **않고** 6~10번이다. (p.111, 120)
- `n[-1]`은 오류가 **아니라** 맨 뒤 값이다. (p.120)
- w 모드는 내용을 덧붙이는 것이 **아니라** 모두 지우고 새로 쓴다. 덧붙이기는 a 모드이다. (p.117)
- w·a 모드에서 파일이 없으면 오류가 **아니라** 새로 생성된다. (p.117)
- remove( )는 같은 값을 모두 지우는 것이 **아니라** 첫 번째 것만 지운다. pop( )은 맨 앞이 **아니라** 맨 뒤를 지운다. (p.121)
- 변수명 첫 글자에 숫자는 올 수 없지만 한글과 언더 바(_)는 쓸 수 있다. 대소문자는 구별한다. (p.110)
- 흑백 이미지는 3차원이 **아니라** 2차원(밝기 0~255), 컬러 이미지는 RGB가 더해져 3차원이다. 0에 가까울수록 어둡다. (p.119)
- 2차원 리스트 a[2][3]은 2행 3열이며, 0행·0열부터 센다. (p.122)
