## 1. 핵심 개념 정리

### 1.1 컴퓨팅 시스템의 발달과 피지컬 컴퓨팅
*   **컴퓨팅 시스템의 발전 과정**: 
    1.  **정보 사회 초기**: 하드웨어와 소프트웨어 중심의 컴퓨팅 시스템으로 빠른 업무 처리.
    2.  **네트워크 및 인터넷**: 컴퓨팅 시스템 간 연결을 통한 전 세계 정보 공유.
    3.  **피지컬 컴퓨팅**: 현실 세계와 디지털 세계가 소통하는 장치 사용.
    4.  **사물 인터넷(IoT)**: 모든 사물을 인터넷으로 연결하여 사회 전 분야에 활용.
*   **피지컬 컴퓨팅**: 컴퓨터와 현실 세계를 연결하는 시스템으로 **센서**, **마이크로컨트롤러**, **액추에이터**로 구성됨.

#### [표 1] 피지컬 컴퓨팅의 3대 구성 장치 비교
| 장치명 | 역할 구분 | 주요 기능 및 정의 | 포함되는 기술/예시 |
| :--- | :--- | :--- | :--- |
| **센서** | 입력 장치 | 주변의 상황(온도, 밝기 등)이나 환경 데이터를 감지하고 측정 | 온도 센서, 압력 센서, 빛 센서, 가속도 센서 |
| **마이크로컨트롤러** | 처리 장치 | 센서로 얻은 정보를 처리하고 액추에이터를 제어 | 데이터 분석 및 제어 명령 전달 |
| **액추에이터** | 출력 장치 (구동기) | 마이크로컨트롤러의 제어에 의해 물리적으로 동작 | 물리적 동작 수행 장치 |

---

### 1.2 사물 인터넷(IoT)의 구성 및 동작 원리
*   **사물 인터넷의 4대 구성 요소**:
    1.  센서를 포함한 **사물(디바이스)**
    2.  사물끼리 연결하기 위한 **통신 장치**
    3.  데이터를 처리하고 저장하기 위한 **장치** (데이터베이스, 클라우드 등)
    4.  각 요소를 제어하고 활용할 수 있는 **소프트웨어**
*   **사물 인터넷의 동작 단계**:
    *   `데이터 수집 (센서)` $\rightarrow$ `데이터 전송 (네트워크)` $\rightarrow$ `데이터 처리 및 분석 (소프트웨어/DB)` $\rightarrow$ `서비스 제공`

#### [표 2] 스마트 홈 보안 시스템 동작 흐름 예시
| 단계 | 동작 내용 | 비고 (사례) |
| :--- | :--- | :--- |
| **1. 데이터 수집** | 동작 센서로 문 열림 감지 신호 발생 | 센서 기술 |
| **2. 데이터 전송** | 네트워크/인터넷을 통해 감지 신호 전송 | 네트워크 기술 |
| **3. 데이터 처리** | 보안 모드 상태 및 센서 신호를 분석하여 외부인 침입 가능성 판단 | 데이터 처리 및 분석 기술 |
| **4. 서비스 제공** | 침입 판단 시 가까운 경찰서에 자동 연결 | 서비스 및 소프트웨어 활용 |

### 1.3 사물 인터넷 구현 기술

| 기술 구분 | 기능 및 역할 | 관련 기술 및 세부 내용 |
| :--- | :--- | :--- |
| **센서 기술** | 주변 환경에서 데이터를 감지하고 측정하는 기술 | 온도, 압력, 빛, 가속도 센서 등 |
| **저장 기술** | 센서로 모은 데이터를 효율적으로 저장하고 관리하는 기술 | **데이터베이스** 기술, **클라우드 컴퓨팅** 기술 |

*   **데이터베이스**: 정보를 구조적으로 저장하고 관리하기 위한 시스템.

### 1.4 사물 인터넷과 블록체인 기술의 융합
*   **기존 IoT 데이터의 한계**: 보안 위험에 노출되어 있고, 데이터 위변조 검증이 불가능하여 완전히 신뢰하기 어려움.
*   **블록체인 적용 시 이점**: 데이터 위변조 원천 차단, 투명한 이력 관리, 정확성 및 보안성 강화.
*   **블록체인의 정의 및 작동 원리**:
    *   데이터를 **'블록'**이라는 작은 단위로 나누고 연결하여 **'체인'** 형태로 저장.
    *   네트워크에 연결된 다수의 컴퓨팅 시스템이 동시에 정보값을 유지하고 갱신.
    *   암호화된 인증을 사용하며 **서버에 집중되지 않음**(비단일 서버).
    *   연결된 모든 기기가 **동일한 복사본**을 가지고 있음.
*   **적용 사례**: 노후 건축물 안전 관리(기울기/균열 실시간 측정 및 위험 경보), 택배 보관함 키 관리, 가정용 도어록 보안.

#### [표 4] 기존 IoT vs 블록체인 적용 IoT 비교
| 구분 | 기존 IoT 시스템 | 블록체인 적용 IoT 시스템 |
| :--- | :--- | :--- |
| **보안성 및 신뢰성** | 보안 위험 노출, 데이터 위변조 검증 불가능 | 암호화 인증 사용, 데이터 위변조 원천 차단 |
| **데이터 저장 방식** | 중앙 서버 집중형 저장 구조 | 다수의 컴퓨팅 시스템이 동일한 복사본을 공유 및 동시에 갱신 |
| **이력 관리** | 데이터 신뢰도가 낮음 | 데이터의 투명한 이력 관리 가능 |

### 1.5 사물 인터넷으로 인한 사회 변화 (8대 핵심 분야)

1.  **스마트 그리드**: 정보 통신 기술(ICT)을 기존 전력망(grid)에 융합하여 전기 공급자와 소비자가 **실시간으로 전력 정보를 교환**함으로써 에너지를 더 효율적으로 생산하고 사용하는 전력망.
2.  **스마트 교육**: 스마트 기기를 활용해 학습자 수준에 맞는 학습 자료·문항 제공 및 피드백, 장소(교실, 집) 제약 없는 교육 제공.
3.  **스마트팜**: 온도, 습도 등 주변 환경을 자동으로 감지하여 농작물에 수분을 공급하거나 온도를 제어하여 **사람의 손을 거치지 않고 농작물을 재배**.
4.  **스마트 헬스케어**: 심박수, 심전도, 혈압 등 개인 건강 정보 실시간 모니터링/분석, **원격 진료**를 통한 질병 진단 및 처방.
5.  **스마트 홈**: 스마트폰/음성으로 기기 작동, 집 밖에서 원격 제어(냉난방기, 전등), 사용자의 상태에 따른 음악/레시피 제공.
6.  **스마트 빌딩**: 자동 출입 제어(보안), 전등/냉난방기 제어(에너지 절감), 스마트 주차 시스템(주차 공간 안내), 환경 감지(CO2/가스 측정, 화재 감지).
7.  **스마트 공장**: 생산 라인 관리 및 자동화를 통해 생산 과정을 모니터링하고 **비용 절감**.
8.  **스마트 교통**: 자율주행 자동차 제어, 교통 신호 체계 조정으로 **교통 흐름 개선 및 사고 감소**, 버스 위치 실시간 추적 전송.

## 2. 시험에서 헷갈리기 쉬운 함정 포인트

1.  **[함정 1] 피지컬 컴퓨팅 장치의 역할 혼동**
    *   **오답**: 액추에이터는 주변의 온도나 밝기를 감지하는 입력 장치이다.
    *   **정답**: 주변 환경을 감지하는 것은 **센서(입력 장치)**이다. **액추에이터**는 마이크로컨트롤러의 제어를 받아 물리적으로 움직이는 **출력 장치(구동기)**이다.
2.  **[함정 2] 블록체인의 데이터 저장 구조 (중앙 서버 유무)**
    *   **오답**: 블록체인 기술은 중앙 서버에 강력한 암호화 데이터를 집중 저장하여 안전하게 관리한다.
    *   **정답**: 블록체인은 **서버에 데이터가 집중되지 않으며**, 네트워크에 연결된 모든 기기(다수의 컴퓨팅 시스템)가 **동일한 복사본**을 가지고 동시에 정보값을 유지·갱신한다.
3.  **[함정 3] 스마트 그리드의 핵심 정의**
    *   **오답**: 스마트 그리드는 태양광이나 풍력 발전소에서 전기를 생산하는 친환경 발전 기술만을 의미한다.
    *   **정답**: 스마트 그리드의 핵심은 기존 전력망에 ICT를 융합하여 **전기 공급자와 소비자가 실시간으로 전력 정보를 교환**하여 효율성을 높이는 전력망 시스템이다.
4.  **[함정 4] 저장 기술의 범위**
    *   **오답**: 데이터베이스는 분석 기술에 속한다.
    *   **정답**: **데이터베이스**와 **클라우드 컴퓨팅**은 데이터를 모아 저장하기 위한 **저장 기술**에 해당한다. (분석 기술은 소프트웨어 기술 등을 활용하여 데이터를 처리하는 기술임)

## 4. 서술형 심화 문제 (Essay Prompts)

### [문제 1]
**노후 건축물 안전 관리 분야에서 기존 사물 인터넷(IoT) 시스템이 가졌던 한계점과 이를 해결하기 위해 '블록체인' 기술을 적용하였을 때의 동작 방식 및 이점을 서술하시오.**

*   **모범 답안**:
    기존 IoT 데이터는 보안 위험에 노출되어 있고 데이터 위변조 검증이 불가능하여 데이터를 완전히 신뢰하기 어렵다는 한계가 있었다. 
    이에 블록체인 기술을 적용하면 IoT 센서가 실시간으로 측정한 노후 건축물의 기울기 및 균열 데이터를 블록 단위로 나누어 체인 형태로 저장하게 된다. 블록체인은 데이터가 중앙 서버에 집중되지 않고 네트워크의 다수 컴퓨팅 시스템이 동일한 복사본을 보유하며 동시에 정보를 갱신하고 암호화된 인증을 사용한다.
    이로 인해 데이터 위변조가 원천 차단되고 투명한 이력 관리가 가능해지며, 검증된 분석 결과를 바탕으로 이상 변화 감지 시 건물 소유자에게 알림 문자를 전송하여 정확하고 신속한 재난 예방 조치를 할 수 있다.

### [문제 2]
**사물 인터넷이 사회 각 분야에 가져온 변화 중 '스마트 헬스케어'와 '스마트팜'의 동작 특징과 이를 통해 얻을 수 있는 이점을 각각 서술하시오.**

*   **모범 답안**:
    1.  **스마트 헬스케어**: 개인의 심박수, 심전도, 혈압 등의 건강 정보를 실시간으로 모니터링하고 분석한다. 이를 통해 개인은 건강 상태를 지속적으로 파악하여 건강한 생활을 유지할 수 있으며, 환자는 원격 진료를 통해 병원에 직접 가지 않고도 질병 진단 및 처방을 받을 수 있다.
    2.  **스마트팜**: 센서를 통해 온도, 습도 등 주변 환경을 자동으로 감지한다. 감지된 데이터에 따라 사람의 손을 직접 거치지 않고도 자동으로 농작물에 물을 공급하거나 온도를 제어하여 무인 상태에서도 효율적으로 농작물을 재배할 수 있다.

## 5. 핵심 용어 사전 (Glossary)

*   **피지컬 컴퓨팅 (Physical Computing)**: 센서, 마이크로컨트롤러, 액추에이터 등을 이용하여 컴퓨터와 현실 세계를 연결하고 소통하게 하는 시스템.
*   **센서 (Sensor)**: 온도, 밝기, 압력, 가속도 등 주변 환경이나 상황의 데이터를 감지하고 측정하는 입력 장치.
*   **마이크로컨트롤러 (Microcontroller)**: 센서로부터 수집된 정보를 분석·처리하고 액추에이터의 동작을 제어하는 처리 장치.
*   **액추에이터 (Actuator)**: 구동기라고도 하며, 마이크로컨트롤러의 제어 신호에 따라 물리적인 동작을 수행하는 출력 장치.
*   **사물 인터넷 (IoT, Internet of Things)**: 모든 사물을 인터넷으로 연결하여 데이터를 수집, 전송, 분석·처리하고 서비스를 제공하는 기술 및 환경.
*   **데이터베이스 (Database)**: 수집된 정보를 구조적으로 저장하고 효율적으로 관리하기 위한 시스템.
*   **데이터 보안 기술 (Data Security Technology)**: 데이터의 전송 및 저장 시 해킹을 방지하기 위한 기술로 암호화, 침입 탐지 시스템 등이 포함됨.
*   **블록체인 (Blockchain)**: 데이터를 블록 단위로 나누어 체인 형태로 저장하고, 다수의 기기가 동일한 복사본을 공유·갱신함으로써 데이터 위변조를 차단하고 투명성과 신뢰성을 높이는 기술.
*   **스마트 그리드 (Smart Grid)**: 정보 통신 기술(ICT)을 기존 전력망에 접목하여 전력 공급자와 소비자가 실시간으로 정보를 교환, 에너지를 효율적으로 생산 및 소비하도록 돕는 지능형 전력망.
