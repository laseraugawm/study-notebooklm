## Question 1

- [ ] 2025_year

## Question 2
파이썬 문자열 변수 `a = "HAPPY BIRTHDAY!"`에 대해 `print(a[6:11])`을 실행했을 때 출력되는 문자로 올바른 것은 무엇인가요?

- [ ] BIRTHDAY
- [x] BIRTH
- [ ] HAPPY
- [ ] DAY!

**Hint:** 슬라이싱 `a[m:n]`은 m번 인덱스부터 n-1번 인덱스까지의 문자열을 추출합니다. (0번 인덱스는 'H'입니다.)

## Question 3
다음 파이썬 수식의 실행 결과로 올바른 것은 무엇인가요?
`print(11 + 4 / 2)`

- [ ] 7.5
- [ ] 13
- [x] 13.0
- [ ] 15

**Hint:** 파이썬에서 곱셈과 나눗셈은 덧셈보다 우선순위가 높으며, 나눗셈(/) 연산 결과의 자료형은 실수형입니다.

## Question 4

- [x] 논리 연산자는 비교 연산자보다 연산 우선순위가 높다.
- [ ] not 연산자는 식이 참이면 거짓을, 거짓이면 참을 반환한다.
- [ ] 비교 연산의 결과는 참(True) 또는 거짓(False)의 불형(bool) 데이터이다.
- [ ] 논리곱(and)은 연산에 참여하는 두 식이 모두 참일 때만 참이 된다.

**Hint:** 산술, 비교, 논리 연산자 간의 연산 순서를 떠올려 보세요.

## Question 5

`n = int("3.8")`

## Question 6

## Question 8
1차원 리스트 `playlist = ['나비야', '작은별', '산토끼']`에 대해 다음 코드를 순서대로 실행한 후 `playlist`의 최종 상태로 올바른 것은 무엇인가요?
```python
playlist.append('비행기')
playlist.insert(0, '아기 상어')
playlist.remove('작은별')
```

- [x] ['아기 상어', '나비야', '산토끼', '비행기']
- [ ] ['나비야', '산토끼', '비행기', '아기 상어']
- [ ] ['아기 상어', '나비야', '작은별', '산토끼', '비행기']
- [ ] ['나비야', '작은별', '산토끼', '비행기']

**Hint:** `append()`는 맨 뒤 추가, `insert(인덱스, 값)`은 해당 위치 삽입, `remove(값)`은 지정 요소를 삭제합니다.

## Question 9

```python
    ['롤러코스터', '120cm 이상', 100],

]
```

- [x] '120cm 이상'
- [ ] '롤러코스터'
- [ ] 100
- [ ] '110cm 이상'
