# Ⅱ-03 빅데이터 개념과 분석
교과서 54-74쪽 · 정보

## 학습 목표
- 빅데이터 개념과 특징을 이해하고, 빅데이터가 활용되는 영역을 설명할 수 있다. (p.54)
- 빅데이터 분석 과정을 이해하고, 빅데이터 분석 도구를 활용해 문제 해결에 필요한 데이터를 수집·분석할 수 있다. (p.54)
- 학습 요소: 빅데이터, 정형 데이터, 비정형 데이터, 빅데이터 분석, 빅데이터 분석 도구, 시각화 (p.54)

## 핵심 개념

### 도입 — 축구 선수 장비에 빅데이터가?
- 유럽 프로 축구 5대 리그에서 쓰는 **전자 성능 추적 시스템(EPTS; Electronic Performance and Tracking System)**: GPS 기반 데이터를 수집하는 정보 기술 기기를 탑재한 조끼. 회전 운동 측정을 위한 가속도 센서, 심박 센서 등 내장 (p.54)
- 선수의 분당 이동 거리, 최고 속도, 활동량, 심박수 등 약 400가지 이상의 활력 징후 데이터와 경기력 데이터, 사소한 습관까지 실시간 확인 (p.54)
- 활용: 선수 장단점 파악 → 팀 전술·선수 운용, 실시간 피로도·부상 위험 예측 → 선수 관리 (1. 데이터 수집 → 2. 데이터 분석 및 활용) (p.54)

### 1. 빅데이터 개념 이해
- **빅데이터**: 수십 테라바이트 이상의 대규모 데이터. 최근에는 다양한 유형의 대규모 데이터를 효과적으로 저장하고 **통계, 컴퓨터 과학, 기계학습 등의 데이터 과학 기술로 가치를 추출하여 활용하는 포괄적인 개념**으로 사용한다. (p.55)
- 빅데이터 기술의 발전으로 방대하고 다양한 유형의 데이터까지 분석 → 다변화한 현대 사회를 더 효율적으로 예측하도록 돕는다. (p.55)
- **빅데이터 기술**: 빅데이터를 수집, 저장, 처리, 분석, 활용하기 위한 기술들. 예: 하둡 에코 시스템(Hadoop Eco System) (p.55)
- 인터넷에서 60초 동안 이루어지는 일(2023년 기준) 예: 241M 이메일 전송, 18M 문자 전송, 6M 온라인 회의, 2M 검색, 3M 스마트폰으로 사진 찍기, 69만 건 시청, 35만 건 트윗, 27만 건 다운로드, 2만 건 챗GPT 방문, 1만 건 가짜 계정 삭제 (p.55)

#### ① 빅데이터의 데이터 유형 (p.55)
- 스마트 기기와 **사물 인터넷(IoT)**의 확산으로 데이터를 생산하는 사물의 범위가 기하급수적으로 증가 → 다양한 유형의 디지털 데이터 급증
- **정형 데이터**: 고정된 형식과 구조에 맞게 저장된 데이터. 행과 열로 구별하는 **표**, 콤마(,)로 구별하는 **CSV 형식** 등 (예: ID, Name, AGE, SEX 표)
- **비정형 데이터**: 고정된 구조나 형태가 없는 데이터. **이미지, 소리, 보고서(문서)** 등

#### ② 빅데이터 특징 — 5V (p.55)
- 빅데이터는 양적인 특성뿐 아니라 **다양성과 복잡성** 때문에 '빅'으로 정의한다.
  1. **규모(Volume)**: 데이터의 규모가 크다.
  2. **속도(Velocity)**: 데이터 생성, 수집, 처리 속도가 빠르다.
  3. **다양성(Variety)**: 다양한 유형(정형, 비정형)의 데이터를 처리한다.
  4. **정확성(Veracity)**: 유용하고 신뢰할 수 있는 데이터를 다룬다.
  5. **가치(Value)**: 숨겨진 가치를 찾을 수 있다.
- 여기에 **가변성(Variability)**, **시각화(Visualization)** 특징이 추가되기도 한다.

### 2. 빅데이터 활용 분야
- 빅데이터는 정치, 사회, 경제, 의료 등 사회 전 영역에서 대량의 데이터 속 숨겨진 가치를 찾아 보여 주고 **합리적인 의사 결정**에 도움을 준다. (p.56)
- 사례 1 **정치와 사회**: 사회 안정, 복지, 에너지 자원 탐사 등 국가적 과제에 신속한 의사 결정 및 사전 대응 체계 지원 (p.56)
  - **부산광역시 침수 예측**: '도시 침수 예상도'와 '재해 정보 지도'를 바탕으로 기상청 강우 예보, 침수 감지 센서·강수량계·하천수위계 등의 실시간 데이터를 연계·분석해 **안전·주의·경계·위험 4단계** 침수 위험 정보 제공
  - **차세대 지능형 교통 시스템(C-ITS)**: 차량, 노면, 사고 등 데이터를 실시간 수집·분석, 교통 시설과 교통 정보·상황을 주고받아 사고 예방
- 사례 2 **의료와 보건**: 의료진의 진료를 도와 병을 진단해 적절한 치료법을 찾거나, 유행병을 예측해 예방책을 찾는 데 활용 (p.56)
  - **국민 건강 알람 서비스**: 국민 건강 정보와 식품의약품안전청, 기상청, 환경부, SNS 정보를 융합해 지역별 주요 질병 위험도 알람
  - **맞춤형 정밀 의료 서비스**: 진단 정보, 의료 영상, 유전체 정보, 생활 패턴 등 연계·분석 → 개인 맞춤형 질병 예측·진단·치료
- 사례 3 (경제·서비스) (p.57)
  - **음악 스트리밍 업체**: 운동, 수면, 상황, 취향, 기분, 날짜, 시간 등에 따른 맞춤형 음악 추천
  - **신용 카드**: 구매 이력·성향을 고려한 맞춤형 가맹점 할인 쿠폰 발행, 카드 이용 패턴 실시간 분석으로 **카드 부정 사용 사전 차단**
- 조사 과제: 식품 영양 서비스 사례, 사회 복지 시스템 개선 사례, 여행 플랫폼 사례 찾기 (p.56~57)
- 활동 3 — **공공 데이터 포털**(https://data.go.kr): 공공 기관의 데이터를 하나로 통합 관리·운영하여 다양한 정보를 제공하는 사이트. [데이터활용] - [공공데이터 활용사례]에서 분야별 사례 검색. 예: 분야 법률 / 활용 사례 형량 검색기 / 활용 데이터 헌법재판소_법령 정보 서비스 (p.57)

### 3. 빅데이터 분석
- 빅데이터는 규모와 유형의 복잡성 때문에 분석이 쉽지 않다 → 데이터 과학에서 많이 쓰는 **탐색적 데이터 분석**으로 분석 (p.58)
- **탐색적 데이터 분석(EDA)**: 데이터를 다양한 관점에서 관찰하고 이해하는 분석법. 통계적인 방법이나 그래프를 이용해 구조적 관계를 찾을 수 있다. (p.58)
- 분석 4단계: **문제 정의하기 → 데이터 수집하기 → 데이터 분석하기 → 공유 및 평가하기** (p.58~60, p.74)

#### ① 문제 정의하기 (p.58)
- 분석의 필요성, 요구 사항, 분석 범위 등을 정확히 파악하여 구체적인 문제의 분석 목적을 정의한다.

#### ② 데이터 수집하기 (p.58)
- 분석에 필요한 데이터를 수집하는 과정으로 **분석 결과에 가장 큰 영향**을 준다.
- 고려할 문제: 데이터양의 균형, 개인 정보 노출, **데이터 편향성**, 저작권 등
- **데이터 편향성**: 데이터가 특정 그룹이나 결과에 치우친 상태. 수집 시 인종, 성별 등의 편견이 반영되지 않았는지 주의
- 수집 방법: **자동화된 수집기** 사용, **인터넷 직접 검색**, **직접 수집**(설문 조사, 센서 실험 및 관찰)
- 데이터는 **합법적으로 정당하게** 수집해야 한다.
- **데이터 수집 프로그램**: 로그 수집기(정형 데이터), 크롤링(비정형 데이터), 오픈 소스 데이터 수집기(정형, 비정형 데이터)
- **웹 크롤러(web crawler)**: 웹 페이지를 방문하여 데이터를 자동적으로 수집하는 프로그램
- 데이터 수집 사이트 예
  - 공공 데이터 포털(https://www.data.go.kr): 공공 기관의 데이터 공유
  - 국가 통계 포털(https://kosis.kr): 국내외 통계 데이터 공유
  - 캐글(https://www.kaggle.com): **국외** AI 경진 대회 사이트, 분석용 데이터 공유
  - 데이콘(https://dacon.io): **국내** AI 경진 대회 사이트, 분석용 데이터 공유
  - 지표누리(https://www.index.go.kr/): 통계청에서 관리·운영하는 5종의 지표 체계 공유

#### ③ 데이터 분석하기 (p.59~60)
- 데이터를 시각화하여 다양한 각도에서 관찰하고 해석하는 과정. 수집된 데이터는 **전처리** 과정을 거쳐 다양한 형태로 **시각화**하여 분석한다.
- **⑴ 데이터 전처리하기**: 수집된 데이터를 전체적으로 살펴보고 분석에 적합한 형태로 가공. 평균, 중앙값, 최빈값 등 통계 지표로 정리·요약하고, **결측치, 중복값, 이상치**를 찾아 제거하거나 가공한다. (p.59)
  - **평균**: 모든 데이터를 더해 데이터의 개수로 나눈 값
  - **중앙값**: 데이터를 순서대로 나열했을 때 정가운데 있는 값
  - **최빈값**: 가장 자주 나타난 값
  - 탐색: [4, 4, 5, 7, 10]의 평균·중앙값·최빈값 → 풀이: 평균 6, 중앙값 5, 최빈값 4
  - **결측치**: 누락된 값 / **중복값**: 중복된 값 / **이상치**: 데이터 분포 범위에서 크게 벗어난 값
  - **박스 플롯**: 통계적 기준으로 데이터의 대략적인 분포와 개별적인 이상치를 동시에 보여 주는 시각화 기법. 박스 플롯의 최솟값~최댓값 범위를 벗어나는 값은 이상치로 파악
    - Q1: 하위 25%값, Q2: 중앙값(50%), Q3: 상위 25%값, IQR(Q1~Q3 구간)
    - 최솟값 `Q1 - 1.5×IQR`, 최댓값 `Q3 + 1.5×IQR`
  - 예: 2014~2023년 6, 7, 8월 서울 여름철 강수량(기상청 기상자료 개방 포털 [강수량 분석]) 30개 데이터, 최저 54.4mm ~ 최대 675.7mm, 결측치·중복값 없음. 평균 236mm, 중앙값 195mm. 박스 플롯 최댓값 오른쪽에 이상치 3개 → 공공 기관에서 **품질 검사 후 제공하는 데이터이므로 이상치가 없다고 판단하고 값을 그대로 유지**
- **⑵ 데이터의 시각화·분석하기**: 데이터를 명확하고 효과적으로 전달하기 위해 색채, 도형, 이미지 등으로 시각적으로 표현 → 데이터 간 흐름과 관계를 해석하고 패턴을 찾는다. (p.60)
  - **시간 시각화**: 시간에 따라 변하는 데이터의 추이. 선그래프, 막대그래프, 영역형 차트. 예: 우리나라 봄꽃 개화일 — 과거에 비해 기온은 오르고 매화·벚꽃 개화일이 빨라지고 있다.
  - **관계 시각화**: 데이터 간 연관성이나 관계. 버블 차트, 히스토그램, 산점도. 예: 2022년 취업자 현황 버블 차트(X축 청년 취업자, Y축 60세 이상 취업자, 버블 색은 지역, 버블 크기는 취업자 수) — 버블이 클수록 청년·60세 이상 취업자가 많다.
  - **비교 시각화**: 데이터 간 차이와 유사성을 한눈에 비교. 히트맵, 워드 클라우드, 방사형 차트. 예: 2022년 장마 기간 서울 경기 강수량 히트맵 — 6월 23일, 6월 30일, 7월 13일 비가 많이 내렸고, 인천·백령도·이천 외 지역은 6월 30일, 인천·백령도·이천은 7월 13일에 가장 많이 내렸다.
  - 이 밖에 **공간 시각화, 분포 시각화** 등이 있다.

#### ④ 공유 및 평가하기 (p.60)
- 분석 결과를 검토하고 평가하는 과정. 분석 목적에 맞게 데이터를 적절하게 수집·분석했는지, 분석 결과가 의사 결정에 도움을 줄 수 있는지 토의하고, 올바른 개선책 또는 해결책을 제시한다.

### 정보로 통하는 세상 — '전기와 물 먹는 하마' 데이터 센터 (p.61)
- 자율주행 차량, 인공지능(AI), 클라우드 등 최신 ICT 기술은 데이터 기반 → 수많은 서버를 한 곳에서 관리하는 **데이터 센터** 수요 증가
- **ICT**: 정보 기술과 통신 기술을 융합하여 정보를 주고받으며 운영, 관리하고 이용하기 위한 기술을 통틀어 이르는 말
- 데이터 센터는 365일 24시간 구동, 막대한 전기 사용, 열 발생 → 내부 온도 **20℃ 안팎**, 습도 **25% 안팎** 유지 위해 냉각 시설 사용(많은 전기, 냉각 유형에 따라 많은 담수 사용)
- 기업의 노력: 외부 냉기 활용, 신재생 에너지 이용(태양광, 해상 풍력 자체 발전소), 에너지 효율 개선, 폐열 재사용(수영장 난방, 실내 농업)
- **디지털 탄소 발자국**: 인간의 디지털 기기 사용으로 배출되는 온실가스 양
- 개인의 노력: 스트리밍 줄이기, 스마트폰 절전 및 밝기 조절, 메일함 자주 비우기, 사용하지 않는 노트북 전원 끄기, 스마트폰 자주 바꾸지 않기

### 실습 — 우리나라 해양 온난화 현황 분석하기 (융합: 지구 과학) (p.64~67)
- **해양 온난화**: 해양의 표면 온도가 상승하는 현상. 온실 효과(온실가스의 영향으로 대기 온도 상승)가 주요 원인
- **해양 열용량**: 해양에 얼마나 많은 열이 저장되어 있는지 나타내는 수치
- 단계1 문제 정의하기: CO₂(온실가스 중 배출량 최다) 농도 변화는? 우리나라 주변 바다의 열용량과 해수면 온도 변화는? 해양 온난화를 늦추기 위한 대책은? (p.64)
- 단계2 데이터 수집하기: 기상청 종합 기후 변화 감시 정보에서 '국내외 이산화 탄소 연평균농도' CSV(`co2_annual_new.txt`), '해역별 해양열용량 및 해수면 온도 비교' CSV(`hc_sst_year_avg.txt`) 다운로드. 저장 시 소속과 활용 목적을 확인해 정당하게 수집 (p.64)
- 단계3 데이터 분석하기 (p.65~67)
  - ⑴ 전처리: 메모장에서 두 파일을 'UTF-8' 인코딩으로 다시 저장('국내이산화탄소농도.txt', '해양열용량과 해수면온도.txt') → 코답 [새 문서]로 가져오기 → 이상치·결측치·중복값 확인, 비어 있는 마지막 속성 'attr' 삭제 → 케이스 카드로 요약 확인 → 테이블 보기로 복귀. 두 파일 모두 중복값·이상치는 없다고 판단, **결측치는 비워 둔다**.
  - 웹 기반 개발 환경에서는 문자 정보를 디지털로 변환하는 인코딩 방식으로 **UTF-8**을 사용하므로 저장 시 UTF-8을 선택해야 한다.
  - ⑵ 시각화·분석
    1. 이산화 탄소 연평균 농도: 두 테이블을 '연도' 속성으로 드래그해 합침 → x축 연도, y축 전지구·안면도·고산·울릉도 → [측정]-[연결 선]. 결과: 우리나라 CO₂ 농도는 매년 증가, **안면도(서쪽), 고산(남쪽), 울릉도(동쪽)** 순으로 높고, 세 지역 모두 전 지구 평균보다 높다.
    2. 해역별 해수면 온도: 결과: **남해, 동해, 서해** 순으로 높고 모든 해역 상승 추세. 2000년부터 **동해가 1.8℃** 올라 증가 폭이 가장 크고, 서해, 남해 순으로 증가 폭이 줄어든다.
    3. 해역별 해양 열용량: x축 연도, y축 해양열용량(동해·서해·남해) 그래프를 해석(탐색)
    4. CO₂ 농도와 해수면 온도의 관계: 안면도-서해, 고산-남해, 울릉도-동해 그래프에 [측정]-[최소 제곱선]. **최소 제곱선**은 데이터를 예측할 수 있는 추세선으로 r²이 1에 가까울수록 데이터를 잘 표현한다. 실세계 관측 데이터는 **r²이 0.4 이상이면 유의미**. 결과: 남해만 연관성이 조금 있어 보이고 다른 해역은 연관성이 보이지 않는다.
- 단계4 공유 및 평가하기 (p.67)
  - 정리: CO₂ 농도, 해수면 온도, 해양 열용량 모두 증가. **동해**에서 해수면 온도·해양 열용량 변화가 가장 큼. CO₂ 농도와 해수면 온도 간 **직접적인 연관성은 낮았다**. 기온 추이 비교, 동쪽 해역 생태계 변화로 확장 분석하면 좋겠다.
  - 토의: 연관성이 낮은 이유 → 해수면 온도는 대기 온도에 직접적 영향을 받기 때문 / 해수면 온도 상승으로 생길 문제 → 해수면 상승 / 늦추는 방안 → 탄소 중립 실천

### 창의·융합·코딩 — 스마트폰 센서로 나의 운동 활동 분석 (융합: 통합 과학) (p.72~73)
- 스마트폰은 내장된 동작, 환경, 위치 관련 센서로 기기의 움직임과 위치 정보를 모니터링하고 주변 환경 변화를 감지한다.
- 센서 종류: 제스처 센서(터치 없이 손 움직임 감지), RGB 센서(적·녹·청 측정해 광량 파악), 홀 센서(커버 덮힘 여부), 온습도 센서, 근접 센서(스마트폰과 신체 간 거리), 기압 센서(기압 변화로 현재 위치 높이 측정), 자이로 센서(회전 상태와 기울기), 가속도 센서(이동 상태 감지), 지자기 센서(자기장 세기로 방위 측정), 그 외 중력·터치·조도 센서
- 단계2: 'physics toolbox sensor suite' 앱 → [Linear Accelerometer] 설정에서 [Elapsed time], [Slowest] 선택 → 운동 시작 시 저장, 멈춤으로 CSV 저장. 들어 올리고 내리는 시간(측정 시작·끝)은 빼고 분석
- **리니어 가속도 센서**는 중력 가속도를 제외한 선형(x, y, z축) 가속도를 측정. **총 가속도**는 x, y, z축 가속도를 제곱하여 합한 값의 제곱근(`√(x² + y² + z²)`). 0에 가까우면 움직임 없음, 클수록 빠르게 움직임(달리기)
- 단계3: 코답에서 시간에 따른 총 가속도(atotal) 선그래프 → 가속도 0 움직임 없음, 낮음 걷는 중, 높음 달리는 중. 예시 결과: 운동하는 동안 걷거나 멈춰 있는 시간이 많다.
- 단계4: 효과적인 운동 방법 토의(예: 걷는 평균 속도를 높인다). 하나 더하기: 기압 센서(barometer)로 높은 곳 오르내리기 기압 변화 측정·시각화

### 대단원 마무리 (p.74~75)
- 개념 정리: 데이터 압축(손실/비손실, 런-렝스·렘펠-지브, BMP·GIF·PNG·JPEG, WAV·FLAC·MP3·AAC), 암호화(암호화·복호화, 평문·암호문·암호 알고리즘·키, 전치·치환, 현대 암호), 빅데이터(개념, 합리적 의사 결정, 분석 4단계)
- 실력 확인(풀이): 1 ㉠ 인코딩, ㉡ 디코딩 / 2 ① MP3는 손실 압축 / 3 ⑤ JPEG / 4 ④ 데이터 암호화 / 5 ① 키 / 6 ⑤ 카이사르 암호 / 7 ㉠ 해시 함수, ㉡ 공개키, ㉢ 대칭키 / 8 ③ CSV 파일(정형, 나머지는 비정형) / 9 빅데이터 / 10 ⑤ ㄷ(문제 정의) → ㄴ(수집) → ㄱ(분석) → ㄹ(공유 및 평가)
- 교과서 개념 정리와 2번 ③에는 'ACC'로 적혀 있으나 본문 표(p.45)의 형식 이름은 AAC다.

| 평균 | 모든 데이터 합 ÷ 개수 |
| 중앙값 | 순서대로 나열했을 때 정가운데 값 |
| 최빈값 | 가장 자주 나타난 값 |
| 결측치 | 누락된 값 |
| 중복값 | 중복된 값 |
| 이상치 | 분포 범위에서 크게 벗어난 값 |

### 빅데이터 활용의 문제 사례
| 사례 | 문제점 |
|---|---|
| 맞춤형 광고 | 프라이버시 및 개인 정보 자기 결정권 침해 |
| 아이스크림과 익사 | 상관관계를 인과 관계로 확대 해석 |
| 신용 카드 결제자 | 속성 하나가 다중 의미(구매 주체 ≠ 결제 주체) |

## 시험 함정 포인트
- 빅데이터는 양만으로 '빅'이 아니라 **다양성과 복잡성** 때문에도 '빅'으로 정의한다. (p.55)
- CSV 파일은 비정형이 아니라 **정형** 데이터다. 사진, 영상, PDF 문서, SNS 데이터는 비정형. (p.55, p.75)
- 5V의 Veracity는 '다양성'이 아니라 **정확성**, Variety가 **다양성**이다. (p.55)
- 분석 결과에 가장 큰 영향을 주는 단계는 분석하기가 아니라 **데이터 수집하기**다. (p.58)
- 분석 순서는 **문제 정의 → 수집 → 분석 → 공유 및 평가**이고, 전처리와 시각화는 '데이터 분석하기' 단계 안에 있다. (p.58~60)
- 이상치가 있다고 무조건 제거하지 않는다. 강수량 예는 공공 기관이 품질 검사 후 제공한 데이터라 **값을 그대로 유지**했다. (p.59)
- 박스 플롯에서 최솟값·최댓값은 데이터의 실제 최소·최대가 아니라 `Q1 - 1.5×IQR`, `Q3 + 1.5×IQR`이고 이를 벗어나면 이상치다. (p.59)
- 히스토그램은 비교 시각화가 아니라 **관계 시각화**의 예로, 히트맵·워드 클라우드가 **비교 시각화**다. (p.60)
- 캐글은 **국외**, 데이콘은 **국내** AI 경진 대회 사이트다. (p.58)
- 크롤링은 **비정형**, 로그 수집기는 **정형** 데이터 수집 프로그램이다. (p.58)
- 상관관계는 **인과 관계가 아니다**(아이스크림-익사 사례). (p.71)
- 해양 온난화 실습에서 CO₂ 농도와 해수면 온도의 직접적 연관성은 **낮았다**(r² 0.4 이상이 유의미, 남해만 조금). (p.67)
- 해수면 온도는 남해 > 동해 > 서해 순으로 높지만, 2000년 이후 증가 폭은 **동해**(1.8℃)가 가장 크다. CO₂ 농도는 안면도 > 고산 > 울릉도. (p.66)
- 리니어 가속도 센서는 **중력 가속도를 제외**한 가속도를 잰다. 총 가속도가 0에 가까우면 움직임이 없는 상태. (p.72)
- SDGs는 17개 목표와 **169개 세부 목표**, 5개 영역(인간, 지구, 번영, 평화, 파트너십)이다. (p.69)

|---|---|
| 빅데이터 | 다양한 유형의 대규모 데이터를 저장하고 데이터 과학 기술로 가치를 추출·활용하는 포괄적 개념(수십 테라바이트 이상) |
| 빅데이터 기술 | 빅데이터를 수집, 저장, 처리, 분석, 활용하기 위한 기술(예: 하둡 에코 시스템) |
| 사물 인터넷(IoT) | 확산으로 데이터를 생산하는 사물의 범위를 늘린 기술 |

| 5V | 규모, 속도, 다양성, 정확성, 가치 |
| EPTS | GPS 기반 데이터를 수집하는 전자 성능 추적 시스템 조끼 |

| 공공 데이터 포털 | 공공 기관 데이터를 통합 관리·운영해 제공하는 사이트 |
| 탐색적 데이터 분석(EDA) | 데이터를 다양한 관점에서 관찰·이해하는 분석법 |
| 데이터 편향성 | 데이터가 특정 그룹이나 결과에 치우친 상태 |
| 웹 크롤러 | 웹 페이지를 방문해 데이터를 자동 수집하는 프로그램 |
| 데이터 전처리 | 데이터를 분석에 적합한 형태로 가공하는 과정 |

| 결측치 / 중복값 / 이상치 | 누락된 값 / 중복된 값 / 분포에서 크게 벗어난 값 |

| 코답(CODAP) | 코딩 없이 쓰는 웹 기반 오픈 소스 데이터 분석 플랫폼 |
