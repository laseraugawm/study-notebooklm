## Question 4

## Question 5

- [x] 오름차순 정렬 시 기준 위치 이후의 데이터 중 최솟값을 찾아 기준 위치의 데이터와 교환한다.
- [ ] 비교할 때마다 즉시 교환이 일어나므로 버블 정렬보다 교환 횟수가 항상 많다.
- [ ] 정렬되지 않은 전체 데이터를 한 번에 모두 고정시키는 일괄 처리 방식이다.

**Hint:** 기준 위치를 지정한 다음, 나머지 데이터 중 가장 작은 값을 찾아서 위치를 바꾸는 과정을 떠올려 보세요.

## Question 6

- [ ] 버블 정렬과 선택 정렬 모두 비교 횟수와 교환 횟수가 동일하다.
- [ ] 선택 정렬이 버블 정렬에 비해 비교 횟수가 현저히 적어 정렬이 빠르다.
- [x] 선택 정렬은 최솟값을 찾아 매 단계 마지막에 교환하므로 버블 정렬보다 교환 횟수가 적어 빠르다.
- [ ] 버블 정렬은 데이터 쌍을 교환하지 않고 한 번에 정렬하므로 선택 정렬보다 빠르다.

**Hint:** 두 알고리즘의 총 비교 횟수는 같지만, 실제 값의 자리를 바꾸는 '교환 횟수'에서 차이가 발생합니다.

## Question 7

## Question 8

- [ ] 순차 탐색은 반드시 데이터가 사전 정렬되어 있어야만 적용할 수 있다.
- [x] 이진 탐색은 탐색을 수행하기 전에 데이터가 반드시 정렬되어 있어야 한다.
- [ ] 데이터의 개수가 매우 많아질수록 순차 탐색이 이진 탐색보다 훨씬 빠르게 찾아낸다.
- [ ] 이진 탐색은 첫 번째 데이터부터 차례대로 비교하므로 구조가 가장 단순하다.

**Hint:** 중앙값을 기준으로 왼쪽과 오른쪽 영역 중 어느 곳을 탐색할지 판단하기 위한 전제 조건이 무엇인지 떠올려 보세요.
