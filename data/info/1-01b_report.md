# 고1 정보 시험대비 핵심 요약집: 네트워크의 구성 및 사물 인터넷

---

## 1. 핵심 개념 정리

### 1.1 인터넷 네트워크 연결 및 IP 주소 (p.14)
*   **네트워크 연결의 필요성 및 방식 (p.14)**: 
    *   컴퓨팅 시스템으로 인터넷을 사용하기 위해서는 랜 카드에 선을 직접 연결하거나 와이파이를 사용해 무선으로 네트워크에 연결한 후 운영체제에서 제공하는 네트워크 환경을 설정해야 한다. (p.14)
    *   **유선 연결**: 랜 카드에 선을 직접 연결하여 구성. (p.14)
    *   **무선 연결**: 와이파이(Wi-Fi)를 사용하여 네트워크에 접속. (p.14)
    *   연결 후 운영체제(OS)의 네트워크 환경 설정을 통해 IP 주소 확인 및 와이파이 접속 관리가 가능함. (p.14)
*   **윈도(Windows) 운영체제에서의 네트워크 설정 (p.14)**:
    *   **네트워크 정보 확인**: `[설정]` $\rightarrow$ `[네트워크 및 인터넷]` $\rightarrow$ 이더넷의 `[속성]`을 클릭하여 연결 상태 및 **IP 주소** 확인. (p.14)
    *   **와이파이 연결**: 작업 표시줄 우측의 `[Wi-Fi]` 아이콘 클릭 $\rightarrow$ 와이파이 선택 $\rightarrow$ 보안 설정 시 비밀번호 입력. (p.14)
*   **IP 주소(IP Address) (p.14)**:
    *   **정의**: IP 주소는 인터넷에서 사용하는 주소를 의미한다. (p.14)
    *   주소 체계로 **IPv4**와 **IPv6**가 사용됨. (p.14)
    *   **IP 주소 확인 방법**:
        1. 인터넷 연결 후 윈도 검색창에 ‘What is my ip’ 검색. (p.14)
        2. 윈도 검색창에 `cmd` 입력 후, 커맨드창(명령 프롬프트)에서 `ipconfig` 명령 입력. (p.14)
        3. 스마트폰에서 IP 주소를 확인하는 방법은 교과서에 구체적 확인 방법이 서술되어 있지 않고 '찾아보고' 알아보는 탐구 활동으로 제시된다. (p.14)

### 1.2 네트워크에서의 자원 공유 및 클라우드 컴퓨팅 (p.15)
*   **네트워크 공유의 개념 및 장치 접근 (p.15)**: 
    *   네트워크를 사용하면 떨어져 있는 다양한 컴퓨터 시스템에 저장된 데이터(문서, 사진 등)에 접근할 수 있고, 프린터나 파일 서버 등과 연결된 장치에도 접근할 수 있다. (p.15)
    *   프린터 한 대에 여러 컴퓨팅 시스템을 연결해서 사용할 수 있으며 내 파일을 다른 사람들과 공유할 수 있다. (p.15)
*   **개인용 컴퓨터에서의 공유 (p.15)**:
    *   특정 폴더에 공유 설정을 하여 내부 파일 공유. (p.15)
    *   내 컴퓨터에 연결된 프린터를 네트워크상의 다른 사용자가 공동으로 사용. (p.15)
*   **클라우드 컴퓨팅(Cloud Computing)을 활용한 공유 (p.15)**:
    *   **정의**: 사용자들이 시간과 장소에 상관없이 네트워크로 연결된 컴퓨팅 자원을 사용할 수 있는 시스템으로, 연결된 장치의 저장 장소를 통해 데이터를 사용하거나 서버에서 제공하는 다양한 소프트웨어를 사용할 수 있다. (p.15)
    *   **특징**: 서버에서 동작하는 소프트웨어를 실행하거나 서버에 데이터를 저장 및 공유함. 장소에 구애받지 않고 여러 사람이 동시에 문서 공동 작업 가능. (p.15)
    *   **공유 절차 예시**: 클라우드 서비스(◯◯ 드라이브, N사 MYBOX 등) 업로드 $\rightarrow$ 파일 선택 후 `[링크 복사]` $\rightarrow$ `[액세스 관리]`에서 '링크가 있는 모든 사용자'로 권한 변경 후 링크 공유. (p.16)

### 1.3 무선 네트워크 기술 및 화면 미러링 (p.16)
*   **무선 네트워크 전송 기술 및 파일 전송 실습 (p.16)**:
    *   무선 네트워크 기술의 다양한 방법을 이용하여 친구에게 파일을 전송해 보고 각 방법의 특징을 적을 수 있다. (p.16)
    *   **무선 네트워크 기술의 예**: 와이파이 사용, 블루투스 사용, 모바일 기기의 공유 기능 사용(에어드롭, 퀵셰어). (p.16)
*   **화면 미러링(Mirroring) (p.16)**:
    *   태블릿, 노트북, 스마트폰의 화면을 교실 TV 등 외부 디스플레이에 연동하여 출력하는 기술. (p.16)
    *   **미러링 방법(에어플레이 예시)**: 에어플레이는 미러링 아이콘을 클릭하고 TV를 선택하여 연결한다. (p.16)
    *   **모드별 차이**: 확장 모드, 복제 모드 등 제공. (p.17)
    *   **화면 방향에 따른 차이**: 스마트폰 세로/가로 모드 전환 시 미러링 화면 크기가 변하며, 가로 모드 시 전체 화면 표시 가능. (p.16)

### 1.4 사물 인터넷(IoT) 및 피지컬 컴퓨팅 (p.17-18)
*   **사물 인터넷(IoT; Internet of Things) (p.17)**:
    *   **정의**: 일상생활 속에서 다양한 물건이 인터넷에 연결되어 데이터를 주고받을 수 있는 시스템. (p.17)
    *   **구성 요소**: 사물(컴퓨터, 태블릿 등 컴퓨팅 기기 + 스피커, 냉장고, 전등, TV 등 일상의 구체적·개별적 물건), 센서, 통신 장치, 인터넷, 소프트웨어. (p.17)
    *   **특징**: 사물과 사물, 또는 사물과 사람이 인터넷 네트워크로 서로 연결된 환경을 구축함. (p.17)
*   **피지컬 컴퓨팅(Physical Computing) 동작 원리 예시 (p.18)**:
    *   **화재 감지기 사례**: 센서(화재 감지) $\rightarrow$ 컴퓨터(상황 판단) $\rightarrow$ 인터넷/하드웨어(화재 경보 울림). (p.18)

## 2. 분류 및 비교 정리

### 2.1 개인용 컴퓨터 공유 vs 클라우드 컴퓨팅 공유 (p.15)
| 구분 | 개인용 컴퓨터에서의 공유 | 클라우드 컴퓨팅을 활용한 공유 |
| :--- | :--- | :--- |
| **자원 위치** | 개인이 소유한 단말기(PC, 로컬 저장장치) | 네트워크로 연결된 중앙 서버 및 연결된 장치의 저장 장소 |
| **접근성** | 해당 PC가 켜져 있고 네트워크에 연결되어야 함 | 시간과 장소에 상관없이 네트워크만 연결되면 접근 가능 |
| **주요 활용** | 지정된 폴더 파일 공유, 로컬 연결 프린터 공유 | 서버 소프트웨어 실행, 대용량 파일 링크 공유, 실시간 공동 문서 작성 |

### 2.2 피지컬 컴퓨팅 주요 센서 및 입력 장치 (p.18)
| 센서/장치명 | 주요 기능 및 감지 대상 |
| :--- | :--- |
| **동작 감지 센서** | 사람이나 동물 등의 움직임을 감지 |
| **기울기 센서** | 물체의 기울어짐 정도를 감지 |
| **조도 센서** | 주변의 밝기를 측정 |
| **터치 센서** | 장치에 대한 접촉 여부를 감지 |
| **거리 센서** | **초음파**를 이용하여 거리를 측정 |
| **버튼** | 버튼이 눌렸는지 여부(눌림)를 감지 |
| **온습도 센서** | 주변의 온도와 습도를 측정 |
| **레이저 센서** | **레이저**를 이용하여 물체의 거리, 위치, 속도 등을 측정 |

## 3. 시험 출제 포인트 및 함정(Trap) 분석

*   **함정 1: IP 주소 명령어 및 확인 경로의 혼동**
    *   *오답 유도*: 윈도 검색창에 직접 `ipconfig`를 입력하면 IP가 출력된다? (X)
    *   *정답 분석*: 윈도 검색창에는 `cmd`를 입력하여 커맨드창을 연 후, 커맨드창 내부에서 `ipconfig`를 입력해야 한다. 윈도 검색창에 직접 입력할 때는 ‘What is my ip’를 검색해야 한다.
*   **함정 2: IP 주소 소유 기기 대상의 오해**
    *   *오답 유도*: IP 주소는 데스크톱 컴퓨터에만 부여된다? (X)
    *   *정답 분석*: 인터넷에 연결되는 스마트폰, 태블릿 등 모든 네트워크 기기는 IP 주소를 할당받는다.
*   **함정 3: 사물 인터넷(IoT)에서 ‘사물’의 범주**
    *   *오답 유도*: IoT의 사물에는 일반 가전제품만 포함되며 기존의 컴퓨터나 태블릿은 제외된다? (X)
    *   *정답 분석*: IoT의 '사물'은 스피커, 냉장고, 전등, TV 등 일상 물건뿐만 아니라 컴퓨터, 태블릿 등 기존의 컴퓨팅 기기까지 모두 포함하는 개념이다.
*   **함정 4: 거리 측정 센서의 종류 구별**
    *   *오답 유도*: 초음파를 이용해 물체의 속도와 위치까지 측정하는 센서는 거리 센서이다? (X)
    *   *정답 분석*: **초음파**를 이용해 단순히 거리를 측정하는 것은 **거리 센서**이다. 반면 **레이저**를 이용하여 거리뿐만 아니라 **위치, 속도**까지 측정하는 것은 **레이저 센서**이다.

## 4. 단답형 실전 퀴즈

**Q1. 윈도 운영체제 커맨드창(cmd)에서 내 컴퓨터의 IP 주소를 확인하기 위해 입력해야 하는 명령어는 무엇인가?**
*   *정답*: `ipconfig`

**Q2. 현재 인터넷 주소 체계로 주로 사용되고 있는 두 가지 주소 방식을 쓰시오.**
*   *정답*: IPv4, IPv6

**Q3. 사용자들이 시간과 장소에 상관없이 네트워크로 연결된 컴퓨팅 자원 및 서버 소프트웨어를 활용할 수 있는 시스템을 무엇이라 하는가?**
*   *정답*: 클라우드 컴퓨팅 (Cloud Computing)

**Q4. 초음파를 이용하여 물체와의 거리를 측정하는 피지컬 컴퓨팅 센서의 명칭은 무엇인가?**
*   *정답*: 거리 센서

**Q5. 일상생활 속에서 다양한 물건에 센서와 통신 장치를 탑재하여 인터넷에 연결하고 데이터를 주고받는 시스템을 나타내는 약어(영어)는 무엇인가?**
*   *정답*: IoT (Internet of Things)

## 5. 서술형 대비 평가 문제

### 문제 1. 클라우드 컴퓨팅을 활용하여 공유를 진행할 때, 개인용 컴퓨터(PC) 단독 공유 방식과 비교하여 얻을 수 있는 장점을 '접근성'과 '협업' 측면에서 서술하시오.
*   **모범 답안**:
    클라우드 컴퓨팅은 네트워크 중앙 서버를 활용하므로, 개인용 컴퓨터 공유 방식과 달리 특정 PC가 켜져 있지 않아도 **시간과 장소에 상관없이** 데이터에 접근할 수 있는 높은 접근성을 가진다. 또한, 서버에서 동작하는 소프트웨어를 이용하여 멀리 떨어져 있는 여러 사람이 동시에 접속해 문서를 함께 완성하는 등 **실시간 협업**이 가능하다는 장점이 있다.

### 문제 2. 사물 인터넷(IoT) 시스템이 동작하기 위해 필요한 구성 요소들을 화재 감지기 사례를 들어 설명하시오.
*   **모범 답안**:
    사물 인터넷 시스템은 사물, 센서, 통신 장치, 인터넷, 컴퓨팅 시스템(하드웨어 및 소프트웨어)으로 구성된다. 화재 감지기 사례의 경우, **센서**가 주변의 화재 발생을 감지하여 데이터를 수집하고, **인터넷 네트워크**를 통해 이 데이터를 **컴퓨터(컴퓨팅 시스템)**로 전달한다. 컴퓨터는 전달받은 데이터를 판단하여 화재 상태임을 인식한 후, 경보를 울리는 **하드웨어 동작**을 수행하게 된다.

## 6. 핵심 용어 사전 (Glossary)

*   **IP 주소 (IP Address)**: 인터넷에 연결된 컴퓨팅 시스템 및 기기들이 서로를 식별하고 통신하기 위해 사용하는 독자적인 인터넷 주소 체계(IPv4, IPv6).
*   **클라우드 컴퓨팅 (Cloud Computing)**: 사용자들이 시간과 장소에 상관없이 네트워크로 연결된 컴퓨팅 자원을 사용할 수 있는 시스템으로, 연결된 장치의 저장 장소를 통해 데이터를 사용하거나 서버에서 제공하는 다양한 소프트웨어를 사용할 수 있다.
*   **사물 인터넷 (IoT; Internet of Things)**: 컴퓨팅 기기를 포함하여 일상의 다양한 사물에 센서와 통신 기능을 내장하여 인터넷에 연결하고, 사물끼리 혹은 사람과 사물 간에 데이터를 주고받는 환경.
*   **화면 미러링 (Mirroring)**: 스마트폰, 태블릿, 노트북 등 모바일 기기의 화면을 TV나 대형 디스플레이에 동일하게(또는 확장하여) 실시간으로 출력해 주는 연동 기술 (예: 에어플레이 등).
*   **피지컬 컴퓨팅 (Physical Computing)**: 센서를 통해 현실 세계의 물리적인 정보(빛, 온도, 움직임 등)를 입력받아 컴퓨터가 처리한 후, 결과물을 물리적 장치(경보기, 모터 등)로 출력하는 컴퓨팅 시스템.
*   **조도 센서**: 주변 환경의 빛의 양(밝기)을 측정하여 감지하는 센서.
*   **동작 감지 센서**: 사람이나 동물의 이동 및 움직임을 센싱하는 피지컬 컴퓨팅 센서.
