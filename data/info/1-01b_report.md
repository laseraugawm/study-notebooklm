# 고1 정보 시험대비 핵심 요약집: 네트워크의 구성 및 사물 인터넷

## 1. 핵심 개념 정리

### 1.1 인터넷 네트워크 연결 및 IP 주소 (p.14)
*   **네트워크 연결의 필요성 및 방식 (p.14)**: 
    *   네트워크 환경을 구성하면 인터넷으로 컴퓨팅 시스템을 연결하는 것은 물론 다양한 자원을 공유할 수 있다. (p.14)
    *   컴퓨팅 시스템으로 인터넷을 사용하기 위해서는 랜 카드에 선을 직접 연결하거나 와이파이를 사용해 무선으로 네트워크에 연결한 후 운영체제에서 제공하는 네트워크 환경을 설정해야 한다. (p.14)
    *   운영체제에서 제공하는 네트워크 관련 설정을 선택하면 연결된 기기의 IP 주소를 확인하거나 현재 위치에서 접속할 수 있는 와이파이를 확인할 수 있다. (p.14)
*   **윈도(Windows) 운영체제에서의 네트워크 설정 (p.14)**:
    *   **내 컴퓨터의 네트워크 정보 알아보기**: 윈도 운영체제의 경우 `[설정]` $\rightarrow$ `[네트워크 및 인터넷]` $\rightarrow$ 이더넷의 `[속성]`을 클릭하여 내 컴퓨터의 네트워크 연결 상태와 IP 주소 등 네트워크 정보를 알 수 있다. (p.14)
    *   **컴퓨터에 와이파이 연결하기**: 윈도 운영체제의 경우 작업 표시줄 오른쪽의 `[Wi-Fi]` 아이콘을 클릭하고 연결할 와이파이를 선택하여 무선 네트워크를 연결할 수 있다. 이때 보안 설정이 된 경우 비밀번호를 입력해야 한다. (p.14)
*   **IP 주소(IP Address) (p.14)**:
    *   **정의**: 인터넷에서 사용하는 주소를 의미하며, 인터넷 주소 체계로 IPv4와 IPv6가 사용되고 있다. (p.14)
    *   **IP 주소 확인 방법**:
        1. 내 컴퓨터의 IP 주소 알아보기 (실습): 커맨드창에서 `ipconfig` 명령 입력 등 확인. (p.14)
        2. 스마트폰에서 IP 주소를 확인하는 방법을 찾아보고 내 스마트폰의 IP 주소를 알아보는 탐구 활동이 제시되어 있다. (p.14)
        3. 인터넷 연결 후 윈도 검색창에 ‘What is my ip’를 검색하면 연결된 기기의 IP 주소를 쉽게 확인할 수 있다. (p.14)
        4. 윈도 검색창에 ‘cmd’를 입력하고 커맨드창에서 ‘ipconfig’ 명령을 입력하여 IP 주소를 확인할 수 있다. (p.14)

### 1.2 네트워크에서의 자원 공유 및 클라우드 컴퓨팅 (p.15)
*   **네트워크에서의 공유 (p.15)**: 
    *   네트워크를 사용하면 떨어져 있는 다양한 컴퓨터 시스템에 저장된 문서나 사진 등의 데이터에 접근할 수 있고, 프린터나 파일 서버 등과 연결된 장치에도 접근할 수 있다. (p.15)
    *   프린터 한 대에 여러 컴퓨팅 시스템을 연결해서 사용할 수도 있고 내 파일을 다른 사람들과 공유할 수도 있다. (p.15)
    *   특히 클라우드 컴퓨팅을 활용하면 장소에 상관없이 저장된 데이터를 이용하여 여러 사람이 함께 문서를 완성할 수도 있다. (p.15)
*   **개인용 컴퓨터에서의 공유 (p.15)**:
    *   컴퓨터에 공유 설정을 하면 지정된 폴더의 파일을 공유하거나 내 컴퓨터에 연결된 프린터를 다른 사람이 사용할 수 있다. (p.15)
*   **클라우드 컴퓨팅을 활용한 공유 (p.15)**:
    *   **정의**: 사용자들이 시간과 장소에 상관없이 네트워크로 연결된 컴퓨팅 자원을 사용할 수 있는 시스템으로 연결된 장치의 저장 장소를 통해 데이터를 사용하거나 서버에서 제공하는 다양한 소프트웨어를 사용할 수 있다. (p.15)
    *   **활용 방법**: 클라우드 컴퓨팅을 활용하면 서버에서 동작하는 소프트웨어를 사용할 수 있고 서버에 데이터를 저장하고 사용하는 등 다양한 방법으로 공유할 수 있다. (p.15)
    *   **공유 실습 예시**: 클라우드 컴퓨팅에 가입한 후 사진이나 문서를 친구들과 공유 (예: ◯◯ 드라이브, N사 MYBOX 등에서 사진 파일 선택 후 [링크 복사]를 클릭하여 친구에게 링크 보내기, [액세스 관리]에서 ‘링크가 있는 모든 사용자’로 권한 변경). (p.16)

### 1.3 무선 네트워크 기술 및 화면 미러링 (p.16)
*   **무선 네트워크 기술 및 파일 전송 (p.16)**:
    *   무선 네트워크 기술의 다양한 방법을 이용하여 친구에게 파일을 전송해 보고 각 방법의 특징을 적어 볼 수 있다. (p.16)
    *   **무선 네트워크 기술의 예**: 와이파이 사용, 블루투스 사용, 모바일 기기의 공유 기능 사용(에어드롭, 퀵셰어). (p.16)
*   **화면 미러링 (Mirroring) (p.16)**:
    *   태블릿, 노트북, 스마트폰의 화면을 교실의 TV에 미러링해 보고 기기별로 미러링하는 방법을 적어 보는 활동이 제시된다. (p.16)
    *   **미러링 방법 예시**: 에어플레이는 미러링 아이콘을 클릭하고 TV를 선택하여 연결한다. (p.16)
    *   **모드별 차이**: 확장, 복제 등 미러링 모드가 있는 경우 각각의 모드가 어떻게 다른지 경험한 후 기록하는 활동이 제시되어 있다. (p.16)
    *   **화면 방향에 따른 특징**: 스마트폰을 가로로 들었을 때와 세로로 들었을 때 TV에 미러링되는 화면의 크기가 다르게 표시되며, 가로 모드에서는 전체 화면 표시가 가능하다. (p.16)

### 1.4 사물 인터넷(IoT) 및 피지컬 컴퓨팅 (p.17-18)
*   **사물 인터넷 (IoT; Internet of Things) (p.17)**:
    *   일상생활 속에서 다양한 물건이 인터넷에 연결되어 데이터를 주고받을 수 있는 시스템을 의미한다. (p.17)
    *   컴퓨터뿐만 아니라 각종 사물에 센서와 통신 장치가 있어서 사물과 사물 또는 사물과 사람이 인터넷 네트워크로 서로 연결된 환경을 의미한다. (p.17)
    *   **사물의 의미**: 사물 인터넷에서 의미하는 사물은 컴퓨터, 태블릿 등 컴퓨팅 기기를 포함하여 스피커, 냉장고, 전등, TV 등 주변에서 쉽게 만날 수 있는 구체적이며 개별적인 존재를 통틀어 이른다. (p.17)
*   **피지컬 컴퓨팅 (Physical Computing) (p.17-18)**:
    *   학습 요소로 제시되며, 센서로 화재를 감지하고 컴퓨터가 판단해서 화재 경보를 울리게 하는 화재 감지기 사례를 제시한다. (p.17-18)

## 2. 분류 및 비교 정리

### 2.1 개인용 컴퓨터 공유 vs 클라우드 컴퓨팅 공유 (p.15)
| 구분 | 개인용 컴퓨터에서의 공유 | 클라우드 컴퓨팅을 활용한 공유 |
| :--- | :--- | :--- |
| **자원 위치** | 개인이 소유한 단말기(PC, 로컬 저장장치) | 네트워크로 연결된 중앙 서버 및 연결된 장치의 저장 장소 |
| **접근성** | 해당 PC가 켜져 있고 네트워크에 연결되어야 함 | 시간과 장소에 상관없이 네트워크만 연결되면 접근 가능 |
| **주요 활용** | 지정된 폴더 파일 공유, 로컬 연결 프린터 공유 | 서버 소프트웨어 실행, 대용량 파일 링크 공유, 실시간 공동 문서 작성 |

### 2.2 피지컬 컴퓨팅 주요 센서 및 입력 장치 (p.18)
| 센서/장치명 | 주요 기능 및 감지 대상 |
| :--- | :--- |
| **동작 감지 센서** | 사람이나 동물 등의 움직임을 감지한다. |
| **기울기 센서** | 물체의 기울어짐 정도를 감지한다. |
| **조도 센서** | 주변의 밝기를 측정한다. |
| **터치 센서** | 장치에 접촉 여부를 감지한다. |
| **거리 센서** | 초음파를 이용하여 거리를 측정한다. |
| **버튼** | 버튼의 눌림을 감지한다. |
| **온습도 센서** | 주변의 온도와 습도를 측정한다. |
| **레이저 센서** | 레이저로 물체의 거리, 위치, 속도 등을 측정한다. |

## 3. 시험 출제 포인트 및 함정(Trap) 분석

*   **함정 1: IP 주소 명령어 및 확인 경로의 혼동**
    *   *오답 유도*: 윈도 검색창에 직접 `ipconfig`를 입력하면 IP가 출력된다? (X)
    *   *정답 분석*: 윈도 검색창에는 `cmd`를 입력하여 커맨드창을 연 후, 커맨드창 내부에서 `ipconfig`를 입력해야 한다. 윈도 검색창에 직접 입력할 때는 ‘What is my ip’를 검색해야 한다. (p.14)
*   **함정 2: IP 주소 소유 기기 대상의 오해**
    *   *오답 유도*: IP 주소는 데스크톱 컴퓨터에만 부여된다? (X)
    *   *정답 분석*: 교과서는 내 컴퓨터의 IP 주소 확인과 스마트폰에서 IP 주소를 확인하는 방법을 찾아보는 탐구 활동을 제시한다. (p.14)
*   **함정 3: 사물 인터넷(IoT)에서 ‘사물’의 범주**
    *   *오답 유도*: IoT의 사물에는 일반 가전제품만 포함되며 기존의 컴퓨터나 태블릿은 제외된다? (X)
    *   *정답 분석*: IoT에서 의미하는 사물은 컴퓨터, 태블릿 등 컴퓨팅 기기를 포함하여 스피커, 냉장고, 전등, TV 등 주변에서 쉽게 만날 수 있는 구체적이며 개별적인 존재를 통틀어 이른다. (p.17)
*   **함정 4: 거리 측정 센서의 종류 구별**
    *   *오답 유도*: 초음파를 이용해 물체의 속도와 위치까지 측정하는 센서는 거리 센서이다? (X)
    *   *정답 분석*: 거리 센서는 초음파를 이용하여 거리를 측정하며, 레이저 센서는 레이저로 물체의 거리, 위치, 속도 등을 측정한다. (p.18)

## 5. 서술형 대비 평가 문제

### 문제 1. 클라우드 컴퓨팅을 활용할 때 얻을 수 있는 장점에 대해 교과서 내용을 바탕으로 서술하시오.
*   **모범 답안**:
    클라우드 컴퓨팅을 활용하면 장소에 상관없이 저장된 데이터를 이용하여 여러 사람이 함께 문서를 완성할 수 있고, 서버에서 동작하는 소프트웨어를 사용할 수 있으며 서버에 데이터를 저장하고 사용하는 등 다양한 방법으로 공유할 수 있다. (p.15)

### 문제 2. 사물 인터넷의 개념과 교과서에 제시된 화재 감지기 사례를 연계하여 설명하시오.
*   **모범 답안**:
    사물 인터넷은 일상생활 속에서 다양한 물건이 인터넷에 연결되어 데이터를 주고받을 수 있는 시스템을 의미하며, 컴퓨터뿐만 아니라 각종 사물에 센서와 통신 장치가 있어서 사물과 사물 또는 사물과 사람이 인터넷 네트워크로 서로 연결된 환경을 의미한다. 교과서의 화재 감지기 사례는 센서로 화재를 감지하고 컴퓨터가 판단해서 화재 경보를 울리게 하는 피지컬 컴퓨팅 시스템의 예시로 볼 수 있다. (p.17-18)

## 6. 핵심 용어 사전 (Glossary)

*   **IP 주소 (p.14)**: 인터넷에서 사용하는 주소를 의미하며, 인터넷 주소 체계로 IPv4와 IPv6가 사용되고 있다.
*   **클라우드 컴퓨팅 (p.15)**: 사용자들이 시간과 장소에 상관없이 네트워크로 연결된 컴퓨팅 자원을 사용할 수 있는 시스템으로 연결된 장치의 저장 장소를 통해 데이터를 사용하거나 서버에서 제공하는 다양한 소프트웨어를 사용할 수 있다.
*   **사물 인터넷(IoT; Internet of Things) (p.17)**: 일상생활 속에서 다양한 물건이 인터넷에 연결되어 데이터를 주고받을 수 있는 시스템을 의미하며, 컴퓨터뿐만 아니라 각종 사물에 센서와 통신 장치가 있어서 사물과 사물 또는 사물과 사람이 인터넷 네트워크로 서로 연결된 환경을 의미한다.
*   **화면 미러링(Mirroring) (p.16)**: 교과서는 태블릿, 노트북, 스마트폰의 화면을 교실의 TV에 미러링해 보고 기기별 미러링 방법과 확장·복제 등 모드별 차이를 경험하도록 제시하며, 에어플레이는 미러링 아이콘을 클릭하고 TV를 선택하여 연결하는 예시로 제시된다.
*   **피지컬 컴퓨팅 (p.17-18)**: 교과서는 피지컬 컴퓨팅을 학습 요소로 제시하고, 센서로 화재를 감지하고 컴퓨터가 판단해서 화재 경보를 울리게 하는 화재 감지기 사례를 제시한다.
*   **조도 센서 (p.18)**: 주변의 밝기를 측정한다.
*   **동작 감지 센서 (p.18)**: 사람이나 동물 등의 움직임을 감지한다.
