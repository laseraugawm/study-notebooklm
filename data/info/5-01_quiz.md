## Question 1

- [x] 디지털 콘텐츠를 실제 공간에 구현하여 사용자가 가상 환경과 상호작용하거나 전문가와 실시간 소통하도록 돕는 기술이다.
- [ ] 대량의 비구조화 데이터를 분석하여 기업의 의사 결정 및 예측 모델 구축을 전담하는 기술이다.
- [ ] 분산 네트워크를 통해 거래 정보를 암호화하고 개인 정보의 무단 유출을 방지하는 보안 기술이다.
- [ ] 사용자 명령어를 음성으로 인식하여 가정 내 모든 전자제품의 제어를 자동화하는 기술이다.

**Hint:** 디지털 콘텐츠를 현실 세계의 장소에 겹쳐 나타내어 소통하는 방식을 생각해 보세요.

- [x] 블록체인 기술을 활용해 고객의 신용카드 번호를 안전한 디지털 기록으로 대체하고 이상 거래를 탐지한다.
- [ ] 음성 인식 기술과 접목하여 가전제품을 제어하고 이상 상황을 실시간 감지한다.

- [ ] 3D 프린터를 활용하여 주문부터 배송까지 제품 생산 공정을 전체 자동화한다.

**Hint:** 신용 정보 보호, 신원 증명, 거래 내역의 안전한 디지털 기록 보관과 관련된 기술을 찾아보세요.

## Question 3
다양한 분야에 디지털 기술이 접목된 사례에 대한 설명으로 올바르지 않은 것은?

- [ ] 요식업 분야에서는 로봇이 튀김 작업을 수행함으로써 균질한 맛을 내고 요리사의 화상이나 호흡기 질환 위험을 줄여준다.
- [ ] 스포츠 분야에서는 선수들의 달리기 속도, 공의 회전수 등 데이터 분석을 통해 선수 컨디션을 측정하고 경기 전략을 수립한다.
- [ ] 의료 분야에서는 캡슐 내시경을 활용해 소화관 내부를 확인하며, 가상 현실(VR) 기술을 ADHD나 약물 중독 치료에 활용한다.
- [x] 제조 분야에서는 작업자가 증강 현실(AR) 기술로 부품과 도면을 확인하지만, 자동차 구조 검토는 반드시 실물 시제품 제작을 통해서만 이루어진다.

**Hint:** 자동차 디자인 검토 단계에서 가상 환경 기술이 어떻게 쓰이는지 확인해 보세요.

## Question 4

- [x] 데이터 과학자 - 대량의 데이터를 수집·분석하여 기업이나 조직의 의사 결정에 도움을 준다.
- [ ] 사물 인터넷 개발자 - 클라우드 컴퓨팅 환경에서 작동하는 서비스의 설계, 구축 및 유지·보수를 담당한다.
- [ ] 클라우드 서비스 기술자 - 실제 세계와 디지털 세계를 혼합하여 사용자가 가상 환경에서 경험할 수 있는 시스템을 개발한다.
- [ ] 가상(증강) 현실 설계자 - 사물 간의 인터넷 연결과 통신을 관리하는 애플리케이션 및 시스템을 개발한다.

**Hint:** 빅데이터 수집 및 분석을 통한 의사 결정 지원 업무를 주도하는 직무를 떠올려 보세요.

- [ ] 모든 상담 업무가 인공지능으로 완전 대체되어 사람 상담원이라는 직무 자체가 전면 폐지된다.
- [x] 단순 반복적인 상담은 인공지능이 담당하고, 사람은 고도화된 판단과 복잡한 문제 해결을 요구하는 상담에 집중한다.

**Hint:** AI 시스템과 사람 상담원이 각각 어떤 난이도의 업무를 분담하는지 생각해 보세요.

## Question 6

- [x] 타인의 얼굴이 명확히 드러나지 않더라도 신체적 특징으로 많은 사람이 알아볼 수 있다면 허락 없는 영상 업로드는 초상권 침해가 될 수 있다.
- [ ] 탈퇴한 쇼핑몰이라 하더라도 사용자가 기존에 작성한 구매 내역이 남아있다면 광고 메시지 수신에 동의한 것으로 간주된다.
- [ ] 개인적인 야외 촬영 도중 불특정 다수의 얼굴이 우연히 촬영된 경우에는 초상권 보호 대상에서 완전히 제외된다.
- [ ] 개인정보 처리자는 회원 탈퇴 이후에도 향후 재가입을 고려하여 만료된 개인정보를 지속적으로 보유해야 한다.
