## 핵심 개념

### 1. 기계학습의 이해
- 인공지능, 기계학습, 딥러닝의 관계 (p.180)
  - **인공지능**: 인간이 가진 지적 능력을 컴퓨터로 구현한 기술
  - **기계학습**: 컴퓨터 스스로 학습하는 알고리즘을 연구하고 구현하는 기술
  - **딥러닝**: 인간의 뉴런과 비슷한 인공 신경망으로 스스로 정보를 처리, 학습할 수 있는 인공지능 기술
  - 포함 관계: 인공지능 ⊃ 기계학습 ⊃ 딥러닝
- **기계학습(machine learning, 머신러닝)**: 사람의 학습 능력을 컴퓨터로 구현하는 인공지능 기술로서, 컴퓨터가 수많은 데이터로 학습하여 **모델**을 만들고 이 모델에 새로운 데이터를 적용하여 새로운 예측과 같은 지능적인 판단을 할 수 있다. (p.180)
- 활용 분야: 기상 예측, 수요 예측, 주가 예측, 스팸 메일 분류, 의료 영상 분석으로 질병 진단, 신용 카드 부정 거래 탐지, 상품 추천, 지능형 게임 로봇 등 (p.180)
- 기계학습은 **사람이 직접 알고리즘을 설계하기 어려운 분야**에 활용된다. (p.180)
- 활용 사례 (p.180)
  - 북극 해빙 면적 예측: 인공위성 데이터로 학습하여 미래의 북극 해빙 면적을 예측
  - 추천 시스템: 사용자 선호도를 지능적으로 판단하여 맞춤형 콘텐츠 추천
  - 게임 AI: 이용자의 수준에 맞게 난이도를 조절하고 캐릭터가 이용자와 다양하게 상호 작용
- 데이터 기반 기계학습의 예: 여러 가지 자동차 데이터로 다양한 자동차를 학습 → 실생활에서 자동차 구분에 활용 (p.180)
- **모델**: 현실 세계의 시스템이나 현상을 단순화하여 표현한 것. 수학적 모델, 컴퓨터 모델, 시뮬레이션 데이터 모델, 인공지능 모델 등이 있다. (p.181)

### 2. 기계학습의 유형
- 데이터로 학습하는 **지도학습**과 **비지도학습**, 반복적인 경험을 통해 학습하는 **강화 학습**이 있다. (p.181)

#### ① 지도학습
- **지도학습**: 주어진 입력과 그것에 대한 **정답 데이터**로 학습한다. (p.181)
- 학습을 위해 입력하는 속성 = **특징**, 정답 = **레이블** (p.181)
- 수많은 예시 데이터를 사용해 데이터 간의 관계와 패턴을 인식하고 이해하도록 한다. 학습이 완료되면 모델은 **레이블이 없는 새로운 데이터**에 대해 정확한 예측이나 분류를 할 수 있다. (p.181)
- 그림 예: 정답이 있는 데이터(거북, 물고기)를 학습 → "수많은 거북과 물고기 데이터를 보니까 거북과 물고기를 구분할 수 있을 것 같아." (p.181)
- 활용 예: 날씨 예측, 주택 가격 예측, 스팸 메일 분류, 질병 유무 판단 (p.181)

#### ② 비지도학습
- **비지도학습**: 레이블(정답)이 없는 데이터를 스스로 학습하면서 데이터 안의 패턴이나 구조를 스스로 찾아내어 **비슷한 것들을 그룹으로 묶거나 주요 특징을 추출**하는 등의 작업을 한다. (p.181)
- 명확한 답이 없는 데이터를 다룰 때 유용하며, 스스로 학습하여 **알려져 있지 않은 유용한 정보를 발견**하는 데 도움이 된다. (p.181)
- 그림 예: 정답 정보 없이 학습 → "비슷한 색상끼리 모아 볼까?"(노란색·회색·갈색), "이 데이터에는 어떤 특징이 숨어 있는지 찾아볼까?", "생물의 비슷한 특징을 모아 보면 새로운 사실을 알 수 있지 않을까?" (p.181)
- 활용 예: 신용 카드 이상 사용 탐지, 고객 세분화 마케팅, 도서 추천 시스템 (p.181)

#### ③ 강화 학습
- **강화 학습**: 사람이 시행착오를 겪으며 점점 나은 행동을 학습해 가는 방법과 비슷한 인공지능의 학습 방법 (p.182)
- 시행착오 과정에서 어떤 행동에 대한 **'보상'** 이 주어지면, 이 보상을 **최대화**하는 방향으로 학습이 진행되어 점점 더 나은 행동을 하게 된다. (p.182)
- 주어진 데이터나 환경에 대한 **사전 지식 없이** 스스로 학습하고 적응하는 방법으로, 로봇의 자율 제어, 컴퓨터 게임 캐릭터 등에 적용된다. (p.182)
- 예 (p.182)
  - 2족 보행 로봇: 목표 "직선으로 걷도록 로봇 훈련시키기". 로봇이 넘어지지 않고 자율적으로 걸으면 **긍정의 보상 신호**를 제공하여 스스로 바르게 걷는 방법을 학습하게 한다. ("로봇을 걷게 하려면 어떤 순서의 움직임이 필요할까?" — 로봇 움직임 시뮬레이션)
  - 게임 캐릭터: 주어진 환경에서 어떤 동작을 했을 때 보상(점수)이 최대화되는지를 여러 번의 시행착오로 학습
  - **알파고**: 인간 챔피언과 바둑 대결에서 **4 : 1**로 이겼다. 강화 학습으로 **수백만 번의 연습 경기를 스스로 진행**하여 승리할 수 있었다.
- 활용 예: 게임 AI의 캐릭터, 알파고, 걷는 로봇 (p.182)

### 3. 재미 솔솔 이야기 — 기계학습으로 파피루스 안쪽에 감춰진 문자를 읽어 내다 (p.182)
- 서기 79년 베수비오 화산 폭발로 사라진 폼페이에서 발견된 파피루스 두루마리의 비밀이 인공지능 덕분에 풀리기 시작했다.
- 두루마리는 불에 타거나 검게 그을려 손을 대면 부스러질 위험이 컸고, 엑스레이(X-ray)로 판독하려 했으나 종이가 겹겹이 말려 있어 어려웠다.
- 프랑스 학사원이 대회를 개최 → 컴퓨터 공학과 국제 연합 팀이 두루마리 사진에서 **잉크를 식별해 내는 기계학습 알고리즘**을 개발해 '보라색'이라는 뜻의 그리스 문자를 읽어 냈다(두 번째 줄의 첫 번째 단어).
- 이 기계학습은 잉크가 파피루스 표면에 일으키는 변화를 알아내도록 학습되었다.
- 참가자들은 각자의 코드를 **오픈 소스**로 공개하면서 판독 기술을 서로 공유하고 개선해 나가고 있다.

### 5. (다음 소단원 도입) 기계학습의 다양한 모델 (p.184)
소스 마지막 쪽에는 03 기계학습의 모델과 구현의 첫 부분이 실려 있다.
- 03 학습 목표: 지도학습과 비지도학습의 모델별 개념을 이해할 수 있다 / 기계학습을 활용하여 해결할 수 있는 문제와 그렇지 않은 문제를 구분할 수 있다 / 기계학습을 활용하여 사회 문제 해결에 적용할 수 있다. 학습 요소: 기계학습, 분류, 회귀, 군집화, 문제 해결 (p.184)
- 데이터로 학습한 기계학습은 지도학습과 비지도학습으로 나눈다. (p.184)
  - 지도학습: 성적이나 온도 예측 등 **연속적인 값**을 예측하는 **회귀** 모델 / 영상 인식, 스팸 메일 등 **몇 가지 범주로 구분**하는 **분류** 모델
  - 비지도학습: 비슷한 특징끼리 모으는 **군집화**, 데이터의 관련성을 찾는 **연관 규칙** 등
- **회귀**: 연속적인 수치형 데이터를 예측하는 지도학습 방법. 입력값과 결괏값의 관계를 잘 나타내는 함수를 만들고 새로운 값이 입력되면 이 함수를 이용해 예측한다. 선형 형태의 함수 모델을 쓰면 **선형 회귀** (p.184)
- 선형 회귀 활용: 광고비 지출에 따른 판매량 예측, 면적에 따른 주택 가격 예측, 거리에 따른 택시비 예측 (p.184)
- 회귀의 활용 예: 미래의 강우량 예측, 운행 거리에 따른 중고차 판매 가격 예측, 원유 가격 예측, 시간별 지하철 이용 승객 예측 (p.184)
- 학습 시간에 따른 성적 예측 회귀 모델: (10시간, 70점), (12, 76), (15, 85), (20, 92), (25, 93)을 좌표에 표시하고 두 속성의 관계를 나타내는 직선(회귀 모델)을 그려 **30시간 공부할 때의 성적**을 예측할 수 있다. (p.184)

## 시험 함정 포인트
- 강화 학습은 데이터(정답)로 학습하는 것이 아니라 **반복적인 경험(시행착오)과 보상**으로 학습한다. 데이터로 학습하는 것은 지도·비지도학습이다. (p.181~182)
- 지도학습에서 입력 속성은 레이블이 아니라 **특징**, 정답이 **레이블**이다. (p.181)
- 학습이 끝난 지도학습 모델은 레이블이 있는 데이터가 아니라 **레이블이 없는 새로운 데이터**를 예측·분류한다. (p.181)
- 신용 카드 이상 사용 탐지·고객 세분화 마케팅·도서 추천은 지도학습이 아니라 **비지도학습** 활용 예다. (p.181)
- 스팸 메일 분류·질병 유무 판단은 비지도학습이 아니라 **지도학습** 활용 예다. (p.181)
- 강화 학습은 보상을 최소화가 아니라 **최대화**하는 방향으로 학습한다. (p.182)
- 강화 학습은 주어진 데이터나 환경에 대한 **사전 지식 없이** 학습한다. (p.182)
- 알파고는 인간 챔피언에게 5 : 0이 아니라 **4 : 1**로 이겼다. (p.182)
- 기계학습은 사람이 알고리즘을 쉽게 설계할 수 있는 분야가 아니라 **직접 설계하기 어려운 분야**에 활용된다. (p.180)
- 회귀는 범주 구분이 아니라 **연속적인 수치형 값** 예측, 범주 구분은 **분류**다. 둘 다 지도학습. (p.184)
- 군집화·연관 규칙은 지도학습이 아니라 **비지도학습** 모델이다. (p.184)
- 파피루스 판독에서 기계학습은 엑스레이 사진이 아니라 두루마리 사진에서 **잉크를 식별**하도록(잉크가 표면에 일으키는 변화) 학습되었다. (p.182)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 기계학습(머신러닝) | 컴퓨터가 수많은 데이터로 학습해 모델을 만들고 새 데이터에 적용해 예측 등 지능적 판단을 하는 인공지능 기술 (p.180) |
| 딥러닝 | 인간의 뉴런과 비슷한 인공 신경망으로 스스로 정보를 처리·학습하는 인공지능 기술 (p.180) |
| 모델 | 현실 세계의 시스템이나 현상을 단순화하여 표현한 것 (p.181) |
| 지도학습 | 입력과 정답 데이터로 학습하는 기계학습 (p.181) |
| 특징 | 학습을 위해 입력하는 속성 (p.181) |
| 레이블 | 정답 (p.181) |
| 비지도학습 | 레이블 없는 데이터에서 패턴·구조를 스스로 찾아 그룹으로 묶거나 특징을 추출하는 학습 (p.181) |
| 강화 학습 | 시행착오 속에서 보상을 최대화하는 방향으로 더 나은 행동을 학습하는 방법 (p.182) |
| 보상 | 강화 학습에서 어떤 행동에 대해 주어지는 신호(점수 등) (p.182) |
| 알파고 | 강화 학습으로 수백만 번의 연습 경기를 스스로 진행해 인간 챔피언에게 4 : 1로 이긴 바둑 인공지능 (p.182) |
| 알파 제로 | 바둑·장기·체스 등 게임의 규칙을 스스로 터득하는 게임 AI (p.183) |
| 오픈 소스 | 코드를 공개해 기술을 공유·개선하는 방식(파피루스 판독 대회 사례) (p.182) |
| 회귀 | 연속적인 수치형 데이터를 예측하는 지도학습 방법 (p.184) |
| 선형 회귀 | 선형 형태의 함수 모델을 사용하는 회귀 (p.184) |
| 분류 | 몇 가지 범주로 구분하는 지도학습 모델 (p.184) |
| 군집화 | 비슷한 특징끼리 모으는 비지도학습 모델 (p.184) |
| 연관 규칙 | 데이터의 관련성을 찾는 비지도학습 모델 (p.184) |

## 자기점검 질문
1. 기계학습의 정의는? — 컴퓨터가 수많은 데이터로 학습해 모델을 만들고, 새 데이터에 적용해 예측 같은 지능적 판단을 하는 인공지능 기술
2. 인공지능·기계학습·딥러닝의 포함 관계는? — 인공지능 ⊃ 기계학습 ⊃ 딥러닝
3. 지도학습에서 '특징'과 '레이블'은 각각 무엇인가? — 특징: 입력하는 속성, 레이블: 정답
4. 비지도학습이 유용한 경우는? — 명확한 답이 없는 데이터를 다룰 때, 알려지지 않은 유용한 정보를 발견할 때
5. 강화 학습에서 학습 방향을 정하는 것은? — 보상, 보상을 최대화하는 방향
6. 걷는 로봇을 강화 학습시키는 방법은? — 넘어지지 않고 자율적으로 걸으면 긍정의 보상 신호를 준다
7. 고객 세분화 마케팅은 어떤 유형의 활용 예인가? — 비지도학습
8. 불량 감귤 선별 AI는 어떤 유형으로 볼 수 있는가? — 지도학습(정상·불량 정답이 있는 이미지로 학습해 분류)
9. 회귀와 분류의 차이는? — 회귀는 연속적인 값 예측, 분류는 몇 가지 범주로 구분
10. 비지도학습 모델 두 가지는? — 군집화, 연관 규칙
11. 기계학습의 세 유형 중 데이터로 학습하지 않는 것은? — 강화 학습(반복적인 경험으로 학습)
