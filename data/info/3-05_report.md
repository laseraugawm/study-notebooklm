### 1. 함수
- **함수(function)**: 특정 기능을 수행하기 위해 여러 명령문을 작은 단위의 코드로 묶은 것. 반복해서 쓰는 부분을 함수로 만들고 필요할 때 호출하면 프로그램을 효율적으로 작성·관리할 수 있다. (p.139)
- 파이썬 함수의 종류 (p.139)
  - **내장 함수**: 파이썬 설치 시 함께 제공('python built-in functions'로 검색해 종류 확인)
  - **외장 함수**: 파이썬 라이브러리 모듈에 포함. 모듈을 import해서 사용 (예: `import math`, `math.gcd(3,18)`)
  - **사용자 정의 함수**: 사용자가 필요할 때 직접 만들어 사용
- **함수 정의**: 특정 기능을 수행하는 함수를 미리 만들어 두는 것 / **함수 호출**: 필요할 때 정의된 함수를 불러 실행 (p.139)
- 함수의 실행 과정 (p.139)
  1. 특정 기능을 수행하는 함수를 작성(`def F(매개 변수) :` … `return 반환값`)
  2. 프로그램 실행 중 함수를 호출
  3. 함수를 호출한다.
  4. 함수로 정의된 코드를 실행한다.
  5. 함수를 호출했던 곳으로 복귀한다.
- 함수명 작성 규칙 (p.139)
  - 숫자, 한글, 알파벳, 언더 바(_) 사용 가능 → `turn_left( )` O
  - 공백 사용 불가 → `turn right( )` X
  - 키워드 사용 불가 → `if( )`, `and( )` X
  - 숫자로 시작 불가 → `123abcd( )` X

### 2. 다양한 사용자 정의 함수 (p.140~141)
- 호출할 때 인수가 있거나 없을 수 있고, 반환값도 있거나 없을 수 있다.
- **매개 변수**: 함수 호출 시 전달된 값을 받는 변수 / **인수**: 함수 호출 시 보내는 값 / **반환값**: 함수의 결과를 호출한 곳으로 전달하는 값(return문 사용). 셋 다 **필수 요건은 아니다**. (p.140)
- **return**: 함수를 호출한 위치로 특정 값을 전달하고 함수 실행을 종료 (p.140)

방법 1 인수와 반환값이 없는 경우 (p.140)
```python
def f() :	# 함수 정의
	print("Hello world")

f()	 	# 함수 호출
```
- 마지막 줄에서 인수 없이 f( )를 호출 → 함수 안에서 Hello world 출력 → 호출한 곳으로 복귀 후 종료

방법 2 인수가 없고 반환값이 있는 경우 (p.140)
```python
def f() :	# 함수 정의    
	a = "Hello world"
	return a	# a값 반환하기  

b = f()	# 함수 호출: 함수 f( )의 반환값을 b에 저장하기 
print(b)    
```
- f( ) 호출 → a에 문자열 저장 → return으로 a 값을 가지고 복귀 → b에 저장 → b 출력(Hello world)

### 3. 지역 변수와 전역 변수 (p.142)
- 변수가 선언된 위치에 따라 사용할 수 있는 범위가 달라진다.
- **지역 변수(local variable)**: 함수와 같은 특정 지역에서만 사용. 함수 내부에서만 값을 읽고 변경
- **전역 변수(global variable)**: 함수 외부에서 생성되어 프로그램 전체에서 사용. 프로그램 전역에서 값을 변경할 수 있지만 함수 내부에서는 (그냥은) 값을 변경할 수 없다.
- 함수 내부에서 전역 변숫값을 바꾸려면 `global 전역 변수`로 선언

예제 35 (p.142)
```python
count = 20	# 전역 변수
def func() :
 count = 10	# 지역 변수 
 print("함수 내부 변수: ", count)   

func()
print("함수 외부 변수: ", count) 
```
- 함수 밖 count = 20은 전역 변수
- 함수 안 count = 10은 함수 안에서만 쓰는 새 지역 변수 → 내부 출력 10
- 함수가 끝난 뒤 바깥 출력은 전역 변수 → 20

global 사용 예 (p.142)
```python
count = 0
def add(a, b) :
    global count
    c = a + b
    print(a,"+", b,"=", c)
    count + = 1

add(3, 5)
add(10, 14)
print("덧셈 횟수", count)
```
- `global count`로 함수 안에서 전역 변수 count를 사용·변경
- 호출할 때마다 덧셈 결과를 출력하고 count 1 증가 → 3 + 5 = 8, 10 + 14 = 24, 덧셈 횟수 2
- (인쇄본에 `count + = 1`로 띄어 찍혀 있으나 연산자는 `+=`이다.)

활동 23 순차 탐색 함수 (p.142)
```python
count = 0	# 탐색 횟수 초기화 
def L_search(a, target) :	# 순차 탐색 함수 정의 
 global count	# 전역 변수 count 사용
 n = len(a)	# a 개수 저장하기
 for i in range(n) :	# i를 0부터 n-1까지 반복하기
   count += 1	# 탐색 횟수 증가하기
   if a[i] == target :	# a[ i ]가 target과 같은가?
      return i	# 같으면 위치 [ i ]를 반환하고 함수 종료하기
 return -1	# traget이 a에 없으면 –1을 반환하기
 	
a = [3, 5, 7, 8, 9, 10, 14]	# a 리스트 생성하기
target = 14	# 찾을 값 설정하기
result = L_search(a, target)	 # 순차 탐색 함수 호출
print("탐색 위치: ", result)
print("탐색 횟수: ", count)
```
- 앞에서부터 하나씩 비교하며 탐색할 때마다 count 증가
- 찾으면 위치 i를 반환하고 함수 종료, 끝까지 없으면 -1 반환
- 14는 6번 위치, 7번 비교 → 탐색 위치 6, 탐색 횟수 7

활동 24 이진 탐색 함수 (p.143)
```python
count = 0	# 탐색 횟수 초기화
def B_search(a, target) :	# 이진 탐색 함수 정의
 global count	# 전역 변수 count 사용
 left, right = 0, len(a) - 1	 # 왼쪽 끝 인덱스와 오른쪽 끝 인덱스 설정하기
 while left <= right :	# 왼쪽 끝 인덱스가 오른쪽 끝 인덱스를 지나치면 중지하기
    mid = (left + right) // 2	 # 중간 인덱스 설정하기
    count += 1	# 탐색 횟수 증가하기
    print("left-", left, "mid-", mid, "right-", right) # 왼쪽-중간-오른쪽 인덱스 출력하기
    if a[mid] == target :	# 중간값이 target과 같으면 인덱스 반환하기
       return mid
    elif a[mid] > target :	# 중간값이 target보다 크면 왼쪽 부분 탐색하기
       right = mid - 1
    else :	# 중간값이 target보다 작으면 오른쪽 부분 탐색하기
       left = mid + 1
 return –1	# target을 찾지 못한 경우 -1 반환하고 함수 종료하기

a = [7, 14, 3, 9, 8, 5, 10]	# 탐색할 리스트 저장하기
a.sort()	# a 리스트를 오름차순으로 정렬하기
target = 14	# 탐색값을 target에 저장하기
result = B_search(a, target)	# B_search( ) 함수 호출하기
print("탐색 위치: ", result)
print("탐색 횟수: ", count)
```
- 이진 탐색은 사전에 데이터가 **정렬**되어야 하므로 `a.sort()`로 [3, 5, 7, 8, 9, 10, 14]로 만든다.
- left·right로 범위를 잡고 가운데 mid = (left + right) // 2와 비교
- 중간값이 크면 왼쪽 절반(right = mid - 1), 작으면 오른쪽 절반(left = mid + 1)으로 범위를 줄임
- 실행: left 0·mid 3·right 6 → left 4·mid 5·right 6 → left 6·mid 6·right 6 → 탐색 위치 6, **탐색 횟수 3** (순차 탐색은 7)

### 4. 모듈과 라이브러리
- 파이썬은 **함수**(특정 작업 수행) ⊂ **모듈**(관련 함수·변수를 모아 놓은 것) ⊂ **라이브러리**(여러 모듈을 모아 놓은 것)로 구성 (p.144)
- **모듈(module)**: 특정 기능을 수행하도록 만든 파일로 변수, 함수, 클래스 등을 모아 놓은 파일(파이썬 파일) (p.144)
- 형식: `import 모듈명 [as 별명]`(모듈 불러오기), `모듈명.함수( )`(함수 사용) (p.144)
- 모듈의 별명: `import math as m` → `m.sqrt(121)` 처럼 편리하게 사용 (p.144)
- 모듈의 함수 찾기: `import 모듈명` 후 `dir(모듈명)` → math는 acos, acosh, asin, asinh … (p.144)
- 도트(.)로 포함 관계 표현: `상위 개념.하위 개념` 예) `matplotlib.pyplot`(matplotlib의 pyplot 모듈) (p.144)
- 예제 36: `import math`, `print(math.gcd(15, 18))` → 최대공약수 3 (p.144)
- 활동 25: `math.sqrt(121)` → 11.0 (제곱근) (p.144)
- **라이브러리**: 모듈을 모아 놓은 것 (p.145)
  - **표준 라이브러리**: 파이썬이 공식 제공, 파이썬과 함께 설치
  - **외부 라이브러리**: 표준 라이브러리가 지원하지 않는 추가 기능 제공
    - **판다스(pandas)**: 표 형태 데이터를 쉽게 조작·분석
    - **넘파이(numpy)**: 다차원 배열을 다루며 수치 계산에 효율적
    - **맷플롯립(matplotlib)**: 그래프·차트 등 데이터 시각화
- **random.sample(리스트 또는 문자열, 샘플의 개수)**: 샘플 개수만큼 요소를 랜덤하게 선택 (p.145)
  - 활동 26 청소 당번: `c = list(range(1, a+1))`로 1~학급 인원수 리스트 생성 후 `random.sample(c, b)` → 30명 중 8명 랜덤 선택

- '2024-01-01'에서 5번 인덱스부터 → '01-01'(연도를 빼고 월-일만) (p.149)

```python
# df 데이터프레임에서 temp(최저기온) 열의 최솟값을 찾아 일치하는 행의 day(일시) 열만 출력하기
df[df["temp"] == df["temp"].min()]["day"]
```
- temp 최솟값과 같은 행을 골라 day만 출력 → 1월 25일이 가장 추운 날 (p.149)
- `df[df["temp"] == df["temp"].max()]["day"]` → 최댓값 행 → 1월 13일이 가장 따뜻한 날 (p.149)
- 정렬: `df.sort_values(by = "temp")` 오름차순, `df.sort_values(by = "temp", ascending = False)` 내림차순. by는 정렬할 열, ascending = True 오름차순 / False 내림차순, **생략하면 오름차순** (p.150)
- 더하기 하나 (p.150)
  - `df["temp"].min()` → temp 열의 최솟값 -14.0
  - `df["temp"] == df["temp"].min()` → 행마다 True/False
  - `df[df["temp"] == df["temp"].min()]` → 최솟값과 일치하는 행(22번, 01-23, -14.0)
- `df[df["temp"] >= 0]` → 최저 기온이 영상인 날 → 4번 (p.151)
- 막대그래프: `import matplotlib.pyplot as plt`, `plt.figure(figsize = (40, 10))`(그래프 가로세로 크기), `plt.bar(df["day"], df["temp"])`(x축 day, y축 temp) → 가장 따뜻한 날·추운 날을 쉽게 알 수 있다. (p.151)
- 단계 4 문제 해결: 분석 결과 정리, 겨울 기온 변화가 미치는 영향 정리 (p.151)
- 모둠 활동 평가 요소: 문제 정의하기, 데이터 수집하기, 데이터 분석하기, 문제 해결하기, 협업하기 (p.151)

## 시험 함정 포인트
- 매개 변수는 호출할 때 보내는 값이 **아니라** 받는 변수이다. 보내는 값은 인수이다. (p.140)
- 매개 변수·인수·반환값은 반드시 있어야 하는 것이 **아니다**(필수 요건 아님). (p.140)
- return은 값만 전달하는 것이 **아니라** 함수 실행도 종료한다. (p.140, 142)
- 외장 함수는 그냥 쓸 수 있는 것이 **아니라** 모듈을 import해야 쓴다. 설치와 함께 바로 쓰는 것은 내장 함수이다. (p.139)
- 함수명에 공백·키워드를 쓸 수 없고 숫자로 시작할 수 없지만, 한글·언더 바는 쓸 수 있다. (p.139)
- 예제 35에서 함수 안 count = 10이 전역 변수를 바꾸는 것이 **아니라** 새 지역 변수를 만든다 → 바깥 출력은 20. (p.142)
- 함수 안에서 전역 변수를 바꾸려면 global 선언이 필요하다. (p.142)
- 이진 탐색은 정렬되지 않은 자료에 바로 쓰는 것이 **아니라** 먼저 정렬해야 한다. (p.143)
- 모듈이 라이브러리를 포함하는 것이 **아니라**, 라이브러리가 여러 모듈을 포함한다. (p.144)
- math.ceil(3.14)는 3이 **아니라** 4(올림), math.floor(3.56)은 4가 **아니라** 3(내림)이다. (p.141)
- math.sqrt(121)의 결과는 11이 **아니라** 11.0이다. (p.144)
- pandas·numpy·matplotlib는 표준 라이브러리가 **아니라** 외부 라이브러리이다. (p.145)
- sort_values에서 ascending을 생략하면 내림차순이 **아니라** 오름차순이다. (p.150)
- 데이터프레임은 1차원이 **아니라** 행과 열로 된 2차원 구조이다. (p.148)
