# 정보보안 퀴즈

## Question 1
개인 정보 비식별 조치 기술 중 '익명 정보'에 대한 설명으로 가장 적절한 것은?

- [x] 특정인을 알아볼 수 있는 핵심 식별 정보를 완전히 제거하여 상업적 목적으로도 자유롭게 활용이 가능하다.
- [ ] 이름이나 연락처의 일부를 가린 정보로, 학술 연구나 통계 작성 등의 목적으로만 한정하여 사용된다.
- [ ] 개인이 자신의 정보 소유권을 가지며 금융기관 등에 직접 선별하여 제공하는 데이터 분석 방식이다.
- [ ] 정보 주체의 사전 동의가 있어야만 제3자에게 유상으로 제공하거나 매매할 수 있는 정보이다.

**Hint:** 식별 정보의 완전한 제거 수준과 활용 가능한 목적 범위(상업적 이용 포함 여부)를 생각해 보세요.

## Question 2
정보 보안의 3요소 중 하나인 '무결성(Integrity)'을 위협받은 상황으로 가장 적절한 것은?

- [ ] 인가되지 않은 사용자가 시스템의 아이디와 비밀번호를 알아내 무단으로 접속하여 개인 정보를 열람하였다.
- [ ] DDoS 공격으로 인해 서버가 과부하되어 정작 필요한 시점에 정상적인 사용자가 서비스를 이용하지 못했다.
- [x] 악의적인 해커가 시스템 내부 서버에 침입하여 원본 데이터 파일의 수치와 저장 내용을 무단으로 수정하였다.
- [ ] 반려동물용 IP 카메라인 사물 인터넷 기기가 해킹되어 집 내부 영상이 외부 네트워크로 유출되었다.

**Hint:** 정보가 허가 없이 변경되거나 변조되지 않고 정확성과 완벽함을 유지해야 한다는 원칙에 주목해 보세요.

## Question 3
사용자 인증 기술의 분류 중 '소유 기반 인증' 수단에만 해당하는 조합은 무엇인가?

- [ ] 패스워드, PIN 번호, 패턴
- [ ] 지문, 홍채, 정맥 인식
- [x] 공인 인증서, 보안 토큰, OTP 카드
- [ ] 얼굴 인식, 스마트 카드, 패스워드

**Hint:** 사용자가 물리적 형태나 데이터 형태로 직접 소지하고 가지고 다니는 인증 매체를 찾으세요.

## Question 4
네트워크 보안 기술 중, 트래픽을 복사하여 이상 징후를 탐지하고 로그 파일 수집 및 분석을 수행하는 시스템은 무엇인가?

- [x] 침입 탐지 시스템 (IDS)
- [ ] 침입 방지 시스템 (IPS)
- [ ] 방화벽 (Firewall)
- [ ] 블록체인 보안 (Blockchain)

**Hint:** 실시간 직접 차단 동작보다는 패킷 감시 및 경고, 로그 수집에 중점을 둔 탐지 전용 시스템을 떠올려 보세요.

## Question 5
다음 중 보호해야 할 '개인 정보'의 종류와 예시가 올바르게 연결되지 않은 것은 무엇인가?

- [ ] 인적 사항 - 이름, 주민등록번호, 주소, 연락처
- [ ] 신체적 정보 - 얼굴, 홍채, 지문, 의료 기록
- [x] 정신적 정보 - 학력, 병역 정보, 전과 기록, 과태료 납부 내역
- [ ] 재산적 정보 - 월급, 신용카드 번호, 계좌 번호, 소유 주택

**Hint:** 학력이나 병역, 전과 기록 등 사회생활 과정에서 생성되는 정보의 정확한 명칭을 확인해 보세요.

## Question 6

- [ ] 소스 코드가 공개되어 있으므로 누구나 무료로 이용할 수 있다.
- [x] 허가된 사용자에 한해서만 코드를 수정할 수 있고 재배포는 원천적으로 금지된다.
- [ ] 다수의 개발자가 개발에 참여하고 검토하여 코드의 안정성을 높일 수 있다.
- [ ] 민간 기업이나 개인의 공동 프로젝트 진행 및 지식 확장에 도움을 준다.

**Hint:** 오픈 소스의 기본 정의인 코드 수정 및 다시 배포하는 행위의 자유로움에 관해 떠올려 보세요.

## Question 7
모바일 기기 및 개인 컴퓨팅 시스템의 보안을 유지하기 위한 올바른 실천 방법은 무엇인가?

- [ ] 비밀번호 관리를 편하게 하기 위해 가입된 모든 사이트의 암호를 동일하게 설정한다.
- [ ] 새로운 앱을 설치할 때 필수 권한 여부와 상관없이 요구하는 모든 권한을 항상 동의한다.
- [x] 웹 브라우저를 사용할 때 주소창 시작 부분이 'https'인지 확인하고 자물쇠 모양 아이콘을 점검한다.
- [ ] 네트워크 연결 속도를 향상하기 위해 무선 공유기에 설정된 암호를 제거하고 개방한다.

**Hint:** 보안이 적용된 웹 사이트의 주소 시작 방식 및 브라우저 상단의 안전 표시 기호를 기억해 보세요.
