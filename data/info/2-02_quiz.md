# 디지털암호화 퀴즈

## Question 1
디지털 데이터 암호화 기술에서 암호화 키와 복호화 키의 관계에 대한 설명으로 가장 옳은 것은?

- [ ] 대칭키 암호화는 암호화 키와 복호화 키가 서로 다르다.
- [ ] 공개키 암호화는 통신하는 두 사람이 서로 동일한 비밀 키를 미리 공유해서 사용한다.
- [ ] 대칭키 암호화는 공개된 키로 데이터를 암호화하고 개인만 가진 키로 복호화한다.
- [x] 공개키 암호화는 암호화할 때 사용하는 키와 복호화할 때 사용하는 키가 서로 다르다.

**Hint:** 대칭키와 공개키를 구분하는 핵심 기준은 암호화 키와 복호화 키의 동일 여부입니다.

## Question 2
고대 암호 기법인 스키테일 암호와 카이사르 암호에 대한 설명으로 옳은 것은?

- [ ] 스키테일 암호는 평문의 알파벳을 다른 알파벳으로 교체하여 암호문으로 만드는 치환 암호이다.
- [ ] 카이사르 암호는 평문 문자의 위치를 무작위로 섞어서 암호문으로 만드는 전치 암호이다.
- [x] 스키테일 암호는 굵기와 길이가 같은 나무 막대를 이용해 글자의 순서를 바꾸는 전치 암호이다.
- [ ] 카이사르 암호와 스키테일 암호는 모두 암호화 키와 복호화 키가 서로 다른 공개키 암호 알고리즘이다.

**Hint:** 문자의 원래 위치(순서)를 바꾸는 방식인지, 글자 자체를 다른 글자로 바꿔치기하는 방식인지를 떠올려 보세요.

## Question 3
제2차 세계 대전 시기 독일에 의해 사용된 근대 기계식 암호기인 '에니그마(Enigma)'에 대한 설명으로 옳지 않은 것은?

- [ ] 키보드로 문자를 입력하면 가장 먼저 배전반에 연결된 문자로 1차 치환된다.
- [ ] 1차 치환된 문자는 회전자들을 통과하면서 2차로 알파벳이 치환된다.
- [ ] 에니그마의 회전자 1개당 발생할 수 있는 경우의 수는 총 $676$개($26 \times 26$)이다.
- [x] 전치 암호 방식만을 단독으로 사용하여 입력된 글자의 순서만 정교하게 재배열한다.

**Hint:** 근대 암호 장치는 고대 암호의 두 가지 주요 방식(전치, 치환)을 어떻게 조합하여 발전했는지 생각해 보세요.

## Question 4
사용자 패스워드를 서버에 저장할 때 사용되는 '해시 함수(Hash function)'의 특성으로 올바르지 않은 것은?

- [ ] 입력되는 패스워드의 길이에 관계없이 고정된 길이의 해시값을 출력한다.
- [ ] 암호화된 해시값이 유출되더라도 이를 다시 원래의 평문 패스워드로 복원할 수 없다.
- [ ] 동일한 패스워드를 입력할 경우 적용된 규칙에 따라 항상 동일한 해시값이 출력된다.
- [x] 비밀번호를 안전하게 관리하기 위해 암호화 및 복호화 과정에서 사용자 본인의 개인키를 필수적으로 활용한다.

**Hint:** 해시 함수는 대칭키나 공개키 암호화와 달리 '키(key)'의 존재 여부와 '복호화 가능 여부'에서 큰 차이가 있습니다.

## Question 5
네트워크 환경에서 송신자의 신원을 증명하기 위해 활용되는 '디지털 서명'의 과정으로 옳은 것은?

- [ ] 송신자는 수신자의 공개키로 해시값을 암호화하고, 수신자는 자신의 개인키로 복호화한다.
- [x] 송신자는 송신자의 개인키로 해시값을 암호화하고, 수신자는 송신자의 공개키로 이를 복원해 검증한다.
- [ ] 송신자와 수신자가 공유한 대칭키를 이용하여 서명을 암호화하고 복호화한다.
- [ ] 수신자는 송신자의 개인키를 직접 전달받아 송신자가 보낸 서명 문서를 복구한다.

**Hint:** 디지털 서명은 기밀성 유지 목적의 일반 공개키 암호화와 비교할 때 키(공개키/개인키)의 활용 순서가 반대로 적용됩니다.

## Question 6
웹 브라우저와 웹 사이트 간에 데이터를 암호화하여 안전하게 통신하는 'HTTPS' 기술에 관한 설명으로 옳은 것은?

- [ ] 안전한 웹 사이트인지 검증할 때 대칭키 암호화를 사용하고, 실제 데이터를 주고받을 때 공개키 암호화를 사용한다.
- [x] 외부 인증 기관이 인정한 사이트인지 확인에 공개키 암호화를 사용하고, 전송 데이터 암호화에 대칭키 암호화를 사용한다.
- [ ] 복호화가 불가능한 해시 함수만을 통신 전체 구간에 적용하여 송수신 데이터의 비밀을 유지한다.
- [ ] 안전한 암호 통신이 적용되어 있음을 확인하기 위해서 사이트 주소가 'http'로 시작하는지 점검해야 한다.

**Hint:** HTTPS는 사이트 신원 검증(인증) 단계와 실제 대용량 데이터 전송 단계에서 서로 다른 암호화 방식을 조합하여 성능과 보안을 모두 확보합니다.

## Question 7

- [x] VHFUHW
- [ ] PBZOBQ

## Question 8
고대 카이사르 암호의 한계점을 극복하기 위해 등장한 '비즈네르 암호'에 대한 설명으로 가장 적절한 것은?

- [ ] 하나의 암호화 키(숫자)를 사용하여 전체 알파벳을 항상 동일하게 평행 이동시키는 방식이다.
- [x] 암호화 키 단어에 따라 각 위치의 문자가 서로 다른 이동 수(알파벳)로 암호화된다.
- [ ] 알파벳 자체는 변경하지 않고 글자의 순서와 배치 위치만을 교환하는 전치 암호이다.
- [ ] 해시 함수를 활용하여 키가 없이도 암호문을 자동으로 해독할 수 있게 만든 근대 암호 장치이다.

**Hint:** 카이사르 암호는 특정 문자가 항상 동일한 문자로 바꾸어 출력되어 알파벳 '출현 빈도 분석'으로 해독되기 쉬웠습니다. 비즈네르 암호는 이를 어떻게 보완했을까요?

## Question 9
디지털 데이터 암호화의 필요성 및 구성 용어에 대한 설명으로 올바른 것은?

- [ ] 평문(Plaintext)이란 권한이 없는 사람만 읽을 수 있도록 변환된 상태의 데이터를 말한다.
- [ ] 복호화(Decryption) 과정은 평문을 읽을 수 없는 암호문으로 교체하는 과정이다.
- [x] 데이터 암호화를 통해 보안 위협을 줄이고 유출 시 복구에 소요되는 컴퓨팅 자원을 절약할 수 있다.
- [ ] 복호화 키를 분실하더라도 올바른 암호 알고리즘의 이름만 알면 누구나 원문을 즉시 해독할 수 있다.

**Hint:** 암호화, 복호화, 평문, 키(key)의 정의와 데이터 암호화의 효율성 및 보안적 이점을 검토해 보세요.
