# 디지털데이터 퀴즈

## Question 1
디지털 데이터 압축 과정에서 인코딩(encoding)과 디코딩(decoding), 그리고 압축 방식(손실/비손실)에 대한 설명으로 옳은 것은?

- [x] 인코딩은 데이터의 비트 수를 줄이기 위해 다른 형태로 변환하는 과정이고, 압축 해제 후 입력 데이터와 출력 데이터가 완전히 동일하면 비손실 압축에 해당한다.
- [ ] 디코딩 과정은 암호화 또는 부호화라고도 불리며, 입력 데이터의 크기를 줄이는 역할을 담당한다.
- [ ] 손실 압축은 디코딩 결과가 원본 데이터와 달라지므로, 문자 데이터처럼 정확해야 하는 영역에는 적용할 수 없다.
- [ ] 인코딩된 데이터를 원래 형태의 데이터로 복원하는 과정을 인코딩이라 하고, 비트 수를 줄이는 과정을 디코딩이라고 한다.

**Hint:** 데이터 변환 방향과 복원 후 원본과의 일치 여부를 파악해 보세요.

## Question 2
문자열 비손실 압축 알고리즘인 런-렝스(Run-Length) 인코딩과 렘펠-지브(Lempel-Ziv) 인코딩에 대한 설명으로 옳은 것은?

- [x] 렘펠-지브 인코딩은 떨어져 있는 같은 패턴도 상대적 위치와 패턴의 길이를 이용해 치환하므로 반복 패턴이 많은 긴 문자열에서 압축 효율이 높다.
- [ ] 런-렝스 인코딩은 연속 반복 문자가 적고 무작위 문자가 길게 이어질수록 압축 효율이 더 높아진다.
- [ ] 렘펠-지브 인코딩은 오직 바로 인접하여 연속으로 중복되는 문자만 처리할 수 있다는 제한이 있다.
- [ ] 런-렝스 인코딩 시 반복 없는 단일 문자는 문자 앞에 반복 횟수 '1'을 반드시 표기해야 압축이 정상 수행된다.

**Hint:** 연속된 반복 문자를 줄이는 알고리즘과 떨어진 패턴의 상대 위치/길이를 활용하는 알고리즘의 차이를 비교하세요.

## Question 3
원본 문자열에 숫자가 포함되어 있는 경우, 런-렝스 인코딩을 적용할 때 숫자 데이터와 문자의 반복 횟수 표기를 구분하기 위한 방법으로 옳은 것은?

- [x] 출현 빈도가 적은 문자를 탈출 문자(escape character)로 지정하여 반복 문자 개수와 구분하여 압축한다.
- [ ] 문자열 내의 모든 숫자를 16진수 코드로 일괄 변환하여 압축 문자열의 맨 뒤로 이동시킨다.
- [ ] 숫자가 포함된 문자열은 런-렝스 인코딩이 불가능하므로 반드시 손실 압축 알고리즘으로 변환해야 한다.
- [ ] 숫자 데이터 자체를 삭제하고 문자의 연속 반복 횟수만 적는 방식으로 데이터 용량을 줄인다.

**Hint:** 숫자와 반복 개수가 섞이지 않도록 구분할 때 사용하는 특별한 문자를 떠올려 보세요.

## Question 4
비트맵 이미지의 색상 표현 비트 수 및 파일 형식에 대한 설명으로 옳은 것은?

- [x] 24비트 트루 컬러(True Color)는 RGB 각각의 색상 조합을 통해 총 $2^{24}$가지(약 1,677만 가지)의 색을 표현할 수 있다.
- [ ] 8비트 색상 표현 방식은 총 $2^8 = 512$가지의 색상을 지원하여 고품질 사진 저장에 적합하다.
- [ ] BMP 파일은 화소 정보를 고율로 손실 압축하여 인터넷 전송 및 공유가 매우 빠른 것이 장점이다.
- [ ] 1비트 색상 표현 방식은 흑, 백, 적, 록의 4가지 기본 색상을 표현할 수 있다.

**Hint:** 비트 수에 따른 표현 가능 색상 수 계산 공식($2^n$)과 무압축 파일 형식의 특징을 점검하세요.

## Question 5
이미지 압축 파일 형식(PNG, GIF, JPEG)의 특징에 대한 설명으로 가장 올바른 것은?

- [x] GIF는 256색 이하의 이미지를 압축할 때는 손실이 없지만, 256색을 초과하는 이미지는 지원 가능한 색으로 변환되므로 이미지 손실이 발생한다.
- [ ] PNG 파일은 최대 256색까지만 지원하며 사람이 인식하지 못하는 영역의 색 차이를 제거하는 손실 압축을 수행한다.
- [ ] JPEG 파일은 비손실 압축 방식을 사용하여 압축률은 낮지만 원본 이미지를 100% 완전하게 복원할 수 있다.
- [ ] PNG, GIF, JPEG 세 가지 파일 형식 모두 트루 컬러(24비트)를 기본 지원하여 압축 효율과 해상도가 동일하다.

**Hint:** GIF 파일이 지원하는 256색을 초과하는 이미지를 압축할 때 일어나는 현상에 유의하세요.

## Question 6
아날로그 소리 신호를 디지털 데이터로 변환하는 3단계 과정의 올바른 순서와 설명으로 옳은 것은?

- [x] 표본화(아날로그 파형을 일정 간격으로 나누어 측정) $\rightarrow$ 양자화(소리 크기를 가까운 정숫값으로 표현) $\rightarrow$ 부호화(각 정수를 0과 1의 디지털값으로 표현)
- [ ] 부호화(소리 파형을 정수로 변환) $\rightarrow$ 표본화(일정 시간 간격 나누기) $\rightarrow$ 양자화(0과 1의 2진수로 변환)
- [ ] 양자화(0과 1의 디지털 신호 작성) $\rightarrow$ 부호화(측정된 소리의 크기를 정수화) $\rightarrow$ 표본화(아날로그 연속 파형 측정)
- [ ] 표본화(가까운 정숫값 매핑) $\rightarrow$ 양자화(일정 시간 간격 분할) $\rightarrow$ 부호화(아날로그 파형 복원)

**Hint:** 연속적인 신호를 일정 간격으로 나누는 것부터 시작하여 최종적으로 이진 코드로 만드는 순서를 생각하세요.

## Question 7
CD 음원 사양인 $44.1\text{ kHz}$ 샘플링 주파수와 $16\text{ bit}$ 표현, 2채널(스테레오) 조건에서 소리 데이터 1초 분량의 저장 용량을 구하는 계산식으로 옳은 것은?

- [x] 샘플 수 $\times$ 비트 수 $\times$ 채널 수 $= 44,100 \times 16 \times 2 = 1,411,200\text{ bit} \approx 176,400\text{ byte}$
- [ ] 샘플 수 $\div$ 비트 수 $\times$ 채널 수 $= 44,100 \div 16 \times 2 = 5,512.5\text{ bit} \approx 689\text{ byte}$
- [ ] 샘플 수 $\times$ 비트 수 $\div$ 채널 수 $= 44,100 \times 16 \div 2 = 352,800\text{ bit} \approx 44,100\text{ byte}$
- [ ] 샘플 수 $\times$ 비트 수 $= 44.1 \times 16 = 705.6\text{ bit} \approx 88.2\text{ byte}$

**Hint:** 초당 추출 샘플 수, 샘플당 비트 수, 채널 수를 모두 곱해야 합니다.

## Question 8
소리 압축 파일 형식(FLAC, MP3, AAC)에 대한 설명 중 옳은 것은?

- [x] AAC는 사람이 잘 듣지 못하는 대역의 신호를 제거하는 손실 압축 방식이지만, 동일한 비트 전송률에서 MP3보다 음질이 더 뛰어나다.
- [ ] FLAC은 소리 데이터의 가청 주파수를 일부 삭제하여 용량을 대폭 줄이는 대표적인 손실 압축 형식이다.
- [ ] MP3 파일은 비트 전송률(bitrate)을 아무리 낮게 설정하여도 압축 전 음원과 동일한 최고 음질을 유지한다.
- [ ] WAV 파일은 무음과 반복 구간을 수식으로 예측 압축하여 용량을 $0.16\text{ MB}$ 수준으로 절감한 비손실 압축 표준 형식이다.

**Hint:** MP3와 AAC의 압축 방식 공통점과 음질 측면에서의 차이점을 떠올려 보세요.

## Question 9
디지털 데이터 암호화 및 분산 기술인 '블록체인(Blockchain)'과 'NFT'에 대한 설명으로 올바른 것은?

- [x] 블록체인은 거래 기록을 중앙 서버 대신 네트워크 참여자 모두에게 분산 공유 및 대조하는 기술이며, NFT는 토큰에 고윳값을 부여해 최초 사용자의 소유권을 증명한다.
- [ ] 블록체인은 중앙 집중형 단일 서버 한 곳에만 모든 거래 기록을 보관하여 데이터 관리 절차를 단순화한 기술이다.
- [ ] NFT는 디지털 자산을 동일한 가치를 지닌 다른 토큰과 자유롭게 1:1 교환 및 복제할 수 있도록 만든 대체 가능 토큰이다.
- [ ] 데이터 암호화 기술은 블록체인이나 NFT와 상관이 없으며 런-렝스 인코딩과 동일하게 복호화 과정 없이 원본 데이터를 노출시키는 기술이다.

**Hint:** 중앙 서버의 부재(분산 저장)와 토큰 고유성에 의한 소유권 증명 개념을 확인하세요.

## Question 10
디지털 데이터 압축의 필요성과 이점에 대한 설명으로 가장 적절하지 않은 것은?

- [x] 압축을 수행하면 데이터의 전체 비트 수가 증가하지만 계산 속도가 향상되어 컴푸팅 시스템 자원을 절약할 수 있다.
- [ ] 데이터를 압축하면 동일한 네트워크 환경에서 데이터를 전송할 때 걸리는 시간을 줄일 수 있다.
- [ ] 한정된 디지털 저장 공간에 데이터를 더 효율적으로 기록하기 위하여 다른 형태로 변환하여 기록한다.
- [ ] 대량의 데이터 용량을 압축하고 효율적으로 관리함으로써 디지털 탄소 중립 실천에 기여할 수 있다.

**Hint:** 압축 과정에서 전체 비트 수의 변화와 저장 공간 및 전송 속도에 미치는 영향을 검토하세요.
