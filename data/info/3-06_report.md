### 1. 객체지향 프로그래밍의 이해
- **객체지향 프로그래밍**: 현실 세계의 사물을 추상화하여 객체로 표현하고, 객체 간의 상호 작용을 통해 프로그램으로 구현하는 방법. 객체(object), 클래스(class), 인스턴스(instance)의 개념을 이해해야 한다. (p.153)
- **객체**: 고유한 속성과 기능을 가지는 데이터. 프로그램 동작의 주체가 되는 요소 (p.153)
  - 사물: 자동차, 책상, 블록
  - 개념적인 것: 학생, 교사
  - 프로그램 요소: 버튼, 체크 박스, 게임 캐릭터, 주사위, 이미지
- **클래스**: 객체를 만들기 위한 **설계도**. 객체들의 공통된 속성과 메소드를 정의 (p.153)
  - **속성**: 클래스가 가진 특성
  - **메소드**: 클래스가 가진 기능
  - 예: 클래스 Dice — 속성 value(주사위 숫자 저장), 메소드 roll( )(주사위 굴리는 함수)
- **인스턴스**: 클래스로 생성된 각각의 객체. 클래스를 한 번 정의하면 많은 인스턴스를 만들 수 있고, 인스턴스는 클래스의 속성과 메소드를 가진다. (p.153)
  - 예: Dice 클래스로 dice1, dice2 … 를 만들면 각각 속성 value와 메소드 roll( )을 가진다.
- 객체와 인스턴스의 차이: 종종 혼용하지만, 인스턴스는 **클래스와 객체의 관계를 중심으로** 설명할 때 주로 쓴다. 즉 어떤 클래스의 구체적인 실체를 표현할 때 인스턴스라고 한다. (p.153)

### 2. 실습 1: 이미지 처리 프로그래밍 (융합: 미술, p.154~155)
- **PIL(Python Imaging Library)**: 이미지 분석 및 처리 라이브러리. 이미지를 인스턴스로 생성하고 속성·메소드로 처리
  - 속성: 크기(size), 모드(mode)
  - 메소드: 좌우 반전 transpose, 회전 rotate, 필터 처리 filter
- 단계 1 이미지 파일 업로드: `from google.colab import files`, `uploaded = files.upload()`로 'lighthouse.jpg' 업로드 (p.154)

```python
from PIL import Image		# PIL의 Image 모듈 불러오기
img = Image.open("lighthouse.jpg")	# img 인스턴스 생성하기
print(img.size)		# img.size: 이미지 크기
print(img.mode)		# img.mode: 이미지 모드
img			# img 인스턴스를 화면에 나타내기
```
- PIL에서 Image 모듈을 불러옴
- Image 클래스의 open 메소드로 이미지 파일을 열어 인스턴스 img 생성
- 속성 size 출력 → (1200, 797): 가로 1200, 세로 797 픽셀
- 속성 mode 출력 → RGB
- 마지막 줄: img를 화면에 표시

단계 3 이미지 메소드 사용 (p.155)
```python
img.rotate(50).save("lighthouse_r.jpg")  
x = Image.open("lighthouse_r.jpg")
x
```
- `rotate(50)`: 50° **왼쪽**으로 회전, 오른쪽 회전은 `rotate(-50)`처럼 음수 사용
- `.save(…)`: 회전한 이미지를 새 파일로 저장 → 다시 열어 x로 표시
- 좌우 반전: `img.transpose(Image.FLIP_LEFT_RIGHT)`
- 위아래 반전(참고): `img.transpose(Image.FILP_TOP_BOTTOM)` (교과서 인쇄 표기 그대로)

단계 4 이미지 필터 적용 (p.155)
```python
from PIL import ImageFilter
img.filter(ImageFilter.BLUR)	# BLUR 속성 적용하기
```
- **필터(filter)**: 사진을 찍을 때 렌즈 앞에 부착해 영상에 특수한 효과를 주는 도구. PIL의 ImageFilter 모듈로 이미지 객체에 적용
- **BLUR 속성**: 픽셀과 주변 픽셀들의 평균값을 구해 자신의 픽셀로 대체 → 이미지를 뿌옇게
- **SHARPEN 속성**: 픽셀 간 차이를 강조. 주변 픽셀 가중치를 음수로 하여 차이가 클수록 변화가 두드러지게 → 더 선명하게
- **CONTOUR 속성**: 이미지 경계를 추출해 테두리를 그리고 나머지는 흰색으로 처리

### 3. 객체지향 프로그래밍의 구현 (p.156)
- 객체와 클래스를 중심으로, 클래스의 속성과 메소드를 정의하고 인스턴스를 생성해서 사용하는 방식
- 클래스 정의: 속성은 **변수**로, 메소드는 **사용자 정의 함수** 형태로 표현하고, 첫 매개 변수는 **self**로 시작
- **생성자**: 인스턴스를 생성하면서 속성값을 초기화하는 명령어. `__init__( )`으로 만들고 첫 매개 변수는 self. 인스턴스 생성 시 전달받는 속성값이 있으면 self 옆에 매개 변수를 추가
- **self**: 인스턴스 자신을 참조한다는 의미
- 클래스 첫 문자는 일반적으로 **대문자**
- 클래스 정의 형식
```
class 클래스명 :
  def __init__(self) :	# def __init__(self, 매개 변수) : 
      초기화할 속성 
      ⋮
  def 메소드명(self) :
      명령문
      ⋮
```
- 인스턴스 생성 형식
```
인스턴스명 = 클래스명( )	# 인스턴스 생성하기
인스턴스명.속성	# 인스턴스의 속성 불러오기
인스턴스명.메소드명( )	# 인스턴스의 메소드 불러오기
```

### 4. 예제 38: 주사위 두 개 (p.157)
- 클래스와 인스턴스 구성: 클래스명 Dice, 생성자 `__init__( )`, 속성 value(주사위 숫자값), 메소드 roll( )(값 임의로 구하기)·get_value( )(값 반환하기), 인스턴스 dice1, dice2

단계 1 클래스 정의
```python
import random
class Dice :	# 주사위 클래스
  def __init__(self) :	# 주사위 인스턴스 생성자
    self.value = 0	# value 속성 0으로 초기화하기
  def roll(self) :	# 주사위 값을 임의로 구하는 메소드
    self.value = random.randint(1, 6)
  def get_value(self) :	# 주사위 값을 반환하는 메소드
    return self.value
```
- random 모듈 불러오기
- `class Dice :` 주사위 클래스 정의
- 생성자에서 `self.value = 0` → 인스턴스가 만들어질 때 value 속성을 0으로 초기화
- roll 메소드: value에 1~6 임의의 정수 저장
- get_value 메소드: 현재 value 반환

단계 2 인스턴스 생성
```python
dice1 = Dice()	# 주사위 인스턴스 2개 생성하기(dice1, dice2)
dice2 = Dice()
dice1.roll()	# 각각의 주사위 인스턴스에서 임의의 값을 구하는 메소드
dice2.roll()
```
- 한 클래스로 인스턴스 2개 생성 → 각자 value를 따로 가짐
- 각각 roll( )을 호출해 서로 다른 임의의 값 저장

단계 3 값 출력
```python
print("주사위1의 값: ", dice1.get_value())
print("주사위2의 값: ", dice2.get_value())
```
- get_value( )로 각 인스턴스의 값을 얻어 출력 (예: 6, 4 — 임의의 값)
- 개발 과제: 주사위 개수를 입력받아 주사위들의 숫자 합을 구하는 객체지향 프로그램 구현 (p.157)

### 5. 선택 활동: 틀린 그림 찾기 (p.158~159)
- 비슷하지만 다른 이미지 두 개(left.jpg, right.jpg)를 비교해 **픽셀값이 다른 부분을 빨간색으로 표시**
- 클래스 ImageComparator 구성: 생성자 `__init__( )` — 이미지 인스턴스 생성(img1: left.jpg, img2: right.jpg, new_img: 새 이미지) / 메소드 compare( ) — 같은 위치의 다른 픽셀값을 빨간색으로 표시
- 단계 1: `from google.colab import files`, `uploaded1 = files.upload()`, `uploaded2 = files.upload()`로 두 이미지 업로드 (p.159)

단계 2 이미지 비교 클래스 정의 (p.159)
```python
from PIL import Image
class ImageComparator :
# 생성자: 이미지 인스턴스 생성하기
  def _ _init_ _(self, img1_path, img2_path) : 
    self.img1 = Image.open(img1_path)	 # img1 인스턴스 생성
    self.img2 = Image.open(img2_path)	 # img2 인스턴스 생성
    self.new_img = Image.new(self.img1.mode, self.img1.size, color = 'white')

  def compare(self) :
# 메소드: img1, img2 픽셀값 비교하기
    for x in range(self.img1.width) :
      for y in range(self.img1.height) :
        if self.img1.getpixel((x, y)) != self.img2.getpixel((x, y)) : 
          self.new_img.putpixel((x, y), (255, 0, 0)) 
    return self.new_img
```
- 생성자: 매개 변수로 두 이미지 경로를 받아 img1, img2 인스턴스 생성
- 7행: img1과 같은 모드·크기의 **흰색** 이미지 인스턴스 new_img 생성
- 9~14행 compare 메소드: 중첩 for문으로 가로(width)·세로(height) 모든 좌표를 돈다.
- 12행 `getpixel((x, y))`: (x, y) 좌표의 픽셀값을 가져오는 메소드 → 두 이미지 값이 다르면
- 13행 `putpixel((x, y), (255, 0, 0))`: 그 좌표를 빨간색으로 저장
- 14행: 표시가 끝난 new_img 반환
- (인쇄본은 `_ _init_ _`로 띄어 찍혀 있으나 생성자 이름은 밑줄 두 개씩 붙인 `__init__`이다.)

단계 3 인스턴스 생성 및 비교 결과 출력 (p.159)
```python
comp = ImageComparator("left.jpg", "right.jpg") # comp 인스턴스 생성하기
comp.compare()	# compare 메소드 호출하여 실행하기
```
- 두 파일 경로로 comp 인스턴스 생성(생성자 실행)
- compare( ) 호출 → 다른 픽셀을 빨간색으로 표시한 new_img 반환·표시

## 시험 함정 포인트
- 클래스는 실제 객체가 **아니라** 객체를 만들기 위한 설계도이다. 실제로 만들어진 것은 인스턴스이다. (p.153)
- 클래스 하나로 인스턴스를 하나만 만드는 것이 **아니라** 여러 개 만들 수 있다. (p.153, 157)
- 객체는 눈에 보이는 사물만이 **아니라** 학생·교사 같은 개념적인 것, 버튼·이미지 같은 프로그램 요소도 포함한다. (p.153)
- 속성은 기능이 **아니라** 특성(변수)이고, 기능은 메소드(함수)이다. (p.153, 156)
- 생성자는 아무 이름이나 쓰는 것이 **아니라** `__init__( )`으로 만들며, 첫 매개 변수는 self이다. (p.156)
- self는 클래스 자체가 **아니라** 인스턴스 자신을 참조한다. (p.156)
- 생성자는 인스턴스를 생성하면서 속성값을 **초기화**하는 명령어이다(Dice는 value = 0으로 시작). (p.156~157)
- rotate(50)은 오른쪽이 **아니라** 왼쪽으로 50° 회전한다. 오른쪽은 음수(rotate(-50)). (p.155)
- BLUR는 이미지를 선명하게 하는 것이 **아니라** 뿌옇게 만든다. 선명하게는 SHARPEN이다. (p.155)
- 객체와 인스턴스는 완전히 다른 것이 **아니라** 혼용되기도 하며, 인스턴스는 클래스와의 관계를 강조할 때 쓴다. (p.153)
- 틀린 그림 찾기의 new_img는 검은색이 **아니라** 흰색으로 만들고, 다른 픽셀만 빨간색 (255, 0, 0)으로 칠한다. (p.159)

## 보완 노트 (외부 리뷰 1차 · deepseek)
- **빠진 내용** 객체지향 프로그래밍의 정의 — 객체지향 프로그래밍은 현실 세계의 사물을 추상화하여 객체로 표현하고 객체 간의 상호 작용을 통해 프로그램으로 구현하는 방법이다. (p.152)
- **빠진 내용** 객체의 정의(프로그램 동작의 주체) — 객체는 프로그램 동작의 주체가 되는 요소로 속성과 기능을 가지고 있다. (p.152)
- **빠진 내용** 클래스 정의 시 속성은 변수, 메소드는 사용자 정의 함수, 첫 매개 변수 self — 클래스에서 속성은 변수로, 메소드는 사용자 정의 함수 형태로 표현하고, 첫 매개 변수는 self로 시작한다. (p.156)
- **빠진 내용** 생성자의 정의와 형식 — 클래스를 정의할 때 인스턴스를 생성하면서 속성값을 초기화하는 명령어를 생성자라고 하며, __init__( )으로 만들고 첫 매개 변수는 self로 시작한다. (p.156)
- **빠진 내용** self의 의미 — self는 객체지향 프로그래밍에서 인스턴스 자신을 참조한다는 의미이다. (p.156)
- **빠진 내용** 클래스 첫 문자 대문자 관례 — 일반적으로 클래스 첫 문자는 대문자를 사용한다. (p.156)
- **빠진 내용** 인스턴스 생성 및 속성·메소드 호출 형식 — 인스턴스명 = 클래스명( ), 인스턴스명.속성, 인스턴스명.메소드명( )의 형식으로 인스턴스를 생성하고 속성과 메소드를 불러온다. (p.156)
- **빠진 내용** PIL의 정의와 속성·메소드 — PIL(Python Imaging Library)은 이미지 분석 및 처리 라이브러리로, 이미지를 인스턴스로 생성하고 크기(size)·모드(mode) 속성과 좌우 반전(transpose)·회전(rotate)·필터 처리(filter) 메소드를 이용해 이미지를 처리한다. (p.153)
- **빠진 내용** 이미지 인스턴스 생성 및 속성 출력 결과 — Image 클래스의 open 메소드로 이미지 파일을 열어 인스턴스 img를 생성하고, size는 (1200, 797), mode는 RGB임을 확인한다. (p.153)
- **빠진 내용** rotate 회전 방향 — rotate(50)은 50° 왼쪽으로 회전하는 메소드로, 오른쪽 회전은 rotate(-50)과 같이 음수를 사용한다. (p.155)
- **빠진 내용** transpose 좌우/위아래 반전 — img.transpose(Image.FLIP_LEFT_RIGHT)로 좌우 반전, img.transpose(Image.FILP_TOP_BOTTOM)으로 위아래 반전한다. (p.155)
- **빠진 내용** 필터와 ImageFilter 속성 — 필터는 사진을 찍을 때 카메라 렌즈 앞에 부착하여 영상에 특수한 효과를 주는 도구로, PIL의 ImageFilter 모듈의 BLUR·SHARPEN·CONTOUR 속성을 이미지 객체에 적용할 수 있다. (p.155)
- **빠진 내용** BLUR/SHARPEN/CONTOUR 속성 설명 — BLUR는 픽셀과 주변 픽셀들의 평균값으로 대체해 뿌옇게, SHARPEN은 픽셀 간 차이를 강조해 선명하게, CONTOUR는 이미지 경계를 추출해 테두리를 그리고 나머지는 흰색으로 처리한다. (p.155)
- **빠진 내용** 예제 38 Dice 클래스 구성 — Dice 클래스는 생성자 __init__( ), 속성 value, 메소드 roll( )·get_value( )로 구성되며, dice1·dice2 인스턴스를 생성해 각각 roll( )과 get_value( )를 호출한다. (p.157)
- **빠진 내용** 개발 과제(주사위 개수 입력 후 합 구하기) — 주사위의 개수를 입력받아 주사위들의 숫자 합을 구하는 객체지향 프로그램을 구현해 보자. (p.157)
- **빠진 내용** 틀린 그림 찾기 활동 개요 — 비슷하지만 다른 두 이미지 파일 left.jpg, right.jpg를 비교하여 픽셀값이 다른 부분을 빨간색으로 표시한다. (p.158)
- **빠진 내용** ImageComparator 클래스 구성 — ImageComparator 클래스는 생성자 __init__( )에서 이미지 인스턴스를 생성하고, compare( ) 메소드에서 두 이미지의 같은 위치의 다른 픽셀값을 빨간색으로 표시한다. (p.158)
- **빠진 내용** getpixel/putpixel 설명 — getpixel((x, y))은 (x, y) 좌표에 있는 픽셀값을 가져오는 메소드이고, putpixel((x, y), (255, 0, 0))은 (x, y) 좌표에 픽셀값을 빨간색으로 저장하는 메소드이다. (p.159)
- **빠진 내용** new_img 생성(흰색, img1과 동일 모드·크기) — 인스턴스 img1의 동일한 모드, 크기로 흰색의 이미지 인스턴스(new_img)를 생성한다. (p.159)
- **빠진 내용** compare 메소드의 중첩 반복 구조 — compare( )는 img1의 width와 height 범위를 중첩 for문으로 돌며 같은 위치의 픽셀값을 비교한다. (p.159)
