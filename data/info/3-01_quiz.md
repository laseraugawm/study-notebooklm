# 추상화 퀴즈

## Question 1
컴퓨터를 이용한 문제 해결 과정에서 복잡한 문제를 단순화하는 '추상화(Abstraction)' 과정에 포함되는 3가지 주요 단계의 조합으로 가장 적절한 것은?

- [x] 문제 분해, 핵심 요소 추출, 모델링
- [ ] 문제 분석, 알고리즘 설계, 프로그래밍
- [ ] 현재 상태 정의, 목표 상태 정의, 제약 조건 설정
- [ ] 표 작성, 트리 생성, 그래프 표현

**Hint:** 복잡한 문제를 작게 나누고, 중요한 요소를 뽑아, 이를 단순하게 표현하는 연속적 절차를 생각해 보세요.

## Question 2

- [x] 주어진 문제 환경에서 반드시 따라야 하거나 넘지 말아야 할 제한 사항
- [ ] 문제 해결이 시작되기 전 문제의 최초 상황이나 주어진 초기 데이터
- [ ] 문제를 완전히 해결했을 때 도달해야 하는 결과나 최종 목적

**Hint:** 문제 해결 과정에서 자유롭게 행동하는 것을 제한하는 규칙이나 한계 항목을 찾아보세요.

## Question 3
$3 \times 3$ 크기의 격자 공간에서 로봇이 시작 좌표 $(1, 1)$에 위치해 있다. 로봇에게 'D, R, R, U, L, D'의 이동 명령을 순서대로 내렸을 때, 로봇의 최종 좌표는 어디인가? (단, 로봇은 상(U), 하(D), 좌(L), 우(R)로 1칸씩 이동하며, 격자 공간을 벗어나는 이동은 무시된다. 행 좌표는 위에서부터 1~3, 열 좌표는 왼쪽부터 1~3이다.)

- [x] (2, 2)
- [ ] (3, 2)
- [ ] (2, 3)
- [ ] (1, 2)

**Hint:** 시작 위치 (1, 1)부터 각 방향 명령에 따라 행과 열의 변화를 차례대로 추적해 보세요.

## Question 4
복잡한 문제를 해결하기 쉽게 작은 문제로 나누는 '문제 분해' 과정에 대한 설명으로 가장 올바른 것은?

- [x] 분해된 작은 단위 문제들 사이의 관계나 처리 순서를 고려하여 해결 순서를 잡아야 한다.
- [ ] 문제 해결 능력을 높이기 위해 분해된 문제는 항상 무한히 작게 나누어야 한다.
- [ ] 문제 분해를 완료하면 문제 해결에 불필요한 모든 데이터가 자동으로 삭제된다.
- [ ] 작은 단위 문제들을 독립적으로 해결하면 원래 전체 문제의 목적과 상관없이 해결된다.

**Hint:** 작은 문제들 간의 연관성과 선후 관계를 고려해야 전체 문제를 정상적으로 풀 수 있음을 떠올려 보세요.

## Question 5

- [x] 손님의 이름 및 개인 연락처
- [ ] 손님이 선택한 메뉴명

- [ ] 각 메뉴별 정가(가격)

**Hint:** 메뉴 가격 계산에 직접적인 영향을 주지 않는 정보를 찾아보세요.

## Question 6
여러 정보나 데이터의 관계를 정리할 때 사용하는 '표(Table)' 구조 모델링에 대한 설명으로 가장 적절한 것은?

- [x] 데이터를 가로축(행)과 세로축(열)으로 나누어 주어진 조건이나 항목을 한눈에 비교·평가하기 좋다.
- [ ] 최상위 노드에서 시작해 하위 노드로 뻗어 나가는 계층적 데이터 구조이다.
- [ ] 노드와 간선으로 구성되며 사이클(순환 구조)을 허용하는 복합적인 네트워크 형태이다.
- [ ] 데이터 간에 상위-하위 관계가 명확하여 순환이 절대로 불가능한 구조이다.

**Hint:** 행(가로)과 열(세로)을 통해 여러 조건을 대조하고 정리하는 특성을 생각해 보세요.

## Question 7
트리(Tree) 구조의 특징에 관한 설명 중 옳지 않은 것은?

- [x] 특정 노드에서 시작하여 간선을 지나 다시 출발했던 노드로 돌아오는 사이클(순환 구조)을 허용한다.
- [ ] 상위 노드가 없는 최상위 노드를 루트 노드(Root node)라고 부른다.
- [ ] 상위 노드에서 하위 노드 방향으로만 연결 관계가 존재하는 계층적 구조이다.
- [ ] 컴퓨터의 디렉터리(폴더) 구조나 조직도, 생물 분류 체계 등이 트리의 대표적 사례이다.

**Hint:** 트리 구조에서는 시작점으로 다시 돌아오는 순환선(loop)이 존재하는지 여부를 생각해 보세요.

## Question 8

- [x] 데이터 항목을 나타내는 노드와 이들 간의 관계를 나타내는 간선으로 이루어지며, 사이클을 가질 수 있다.
- [ ] 상위 노드와 하위 노드가 엄격히 구분되어 부모가 없는 노드가 반드시 하나만 존재해야 한다.
- [ ] 간선에는 절대로 방향성이나 가중치(거리, 비용 등)를 표시할 수 없다.
- [ ] 데이터를 가로축과 세로축에 나열하여 일대일로 비교하는 2차원 격자 형태이다.

**Hint:** 네트워크 형태처럼 연결되어 자유롭게 이동할 수 있고 출발점으로 재돌아올 수도 있는 구조를 생각해 보세요.

## Question 12

- [ ] 모델링이 완료된 후 문제의 불필요한 요소를 찾아 삭제하는 과정을 추상화라고 부른다.

- [ ] 추상화와 모델링은 서로 연관성이 없으며 실 생활 문제 해결에서는 모델링만 선택적으로 사용한다.

**Hint:** 추상화라는 커다란 울타리 안에 문제 분해, 핵심 요소 추출, 모델링이 포함된다는 관계를 떠올려 보세요.
