## 핵심 개념

### 0. 생활 속 제어 구조 (p.124)
- 혈압 측정 상황: "10분이 지났는가?"를 확인하며 휴식을 계속하는 것은 **반복 구조**, 측정한 수치로 정상·주의·고혈압 전 단계를 나누는 것은 **선택 구조**
- 혈압 분류: 정상(최고 < 120 그리고 최저 < 80), 주의(120~129 그리고 < 80), 고혈압 전 단계(130~139 또는 80~90)

### 1. 조건문
- **조건문**: 주어진 조건에 따라 명령을 수행하는 구문 (p.125)
- **들여쓰기**: 코드 블록을 구분하는 데 사용하며 프로그램 구조를 명확하게 만든다. 참일 때 실행되는 명령문들은 들여쓰기 해야 한다. (p.125)

#### 단순 조건문 ① if문 (p.125)
- 가장 단순한 조건문. 조건식이 참(True)일 때만 특정 명령문 실행
```
if 조건식 :    
  명령문 1
명령문 2
```
- 참이면 명령문 1 실행 후 명령문 2 실행. 거짓이면 명령문 1은 건너뛰고 명령문 2 실행. **명령문 2는 조건과 상관없이 무조건 실행**

예제 19 (p.125)
```python
speed = int(input())
if speed > 30 : 
 print("과속입니다.")
print("시속 30km를 유지하세요.")
```
- 1행: 입력값을 정수로 바꿔 speed에 저장
- 2행: speed가 30 초과인지 검사
- 3행: 참일 때만(들여쓰기) "과속입니다." 출력
- 4행: 들여쓰기가 없으므로 항상 실행
- 34 입력 → 과속입니다. / 시속 30km를 유지하세요.
- 활동 18: `height = float(input("키: "))`, `if height < 140 :` 이면 "더블스핀 놀이기구 탑승 불가" (121.5 입력 시 출력) (p.125)

#### 단순 조건문 ② if~else문 (p.126)
- 조건식이 참일 때와 거짓일 때 실행하는 명령문이 다른 구조
```
if 조건식 :   
  명령문 1
else : 
  명령문 2
```
예제 20 (p.126)
```python
road = input("어린이 보호 구역은 a, 일반 도로는 다른 문자를 입력하세요. ")
if road == "a" :
  print("어린이 보호 구역은 시속 30km입니다.")
else : 
  print("일반 도로는 시속 50km입니다.")
```
- road가 "a"이면 30km 안내, 그 외 모든 문자는 else로 50km 안내 (b 입력 → 일반 도로는 시속 50km입니다.)
- 활동 19: 18세 이하는 40,000원, 성인은 50,000원 → 빈칸은 `if age <= 18 :` 형태의 조건 (p.126)

#### 중첩 조건문 (p.127)
- **중첩 조건문**: 조건문 안에 또 다른 조건문을 포함하는 구조. if문 안에도, else문 안에도 if문이 들어갈 수 있다.
```
if 조건식 1 :
    if 조건식 2 :  
      명령문 1
    else : 
      명령문 2
else :
      명령문 3
```
- 조건식 1 참·조건식 2 참 → 명령문 1 / 조건식 1 참·조건식 2 거짓 → 명령문 2 / 조건식 1 거짓 → 명령문 3

예제 21 (p.127)
```python
a = input("고속 도로/일반 도로? ")
if a == "고속 도로" :
    limit = 100
else :
    b = input("어린이 보호 구역(있음/없음)? ")
    if b == "있음" :
       limit = 30
    else :
       limit = 50
print("제한 속도는", limit, "km/h")
```
- 고속 도로면 limit = 100 (어린이 보호 구역 질문을 하지 않음)
- 아니면 else 안에서 다시 어린이 보호 구역 여부를 묻고, "있음"이면 30, 아니면 50
- 마지막 줄은 들여쓰기 없이 항상 실행 → <예시 1> 100 km/h, <예시 2>(일반 도로, 있음) 30 km/h

#### 다중 조건문 if~elif~else (p.128)
- **다중 조건문**: 선택 사항이 여러 개일 때, 여러 조건식에 따라 명령을 다르게 실행
- if~else 사이에 elif를 넣는다. **elif에는 반드시 조건식**이 있어야 한다. else 없이 여러 elif로만 만들 수도 있다.
- 조건식 1 참 → 명령문 1 후 if문을 벗어남 / 거짓이면 조건식 2 검사, 참이면 명령문 2 후 벗어남 / 모두 거짓이면 명령문 3

예제 22 (p.128)
```python
n = int(input())
if n >= 80 : 
   print("A")
elif n >= 60 :
   print("B")
else : 
   print('C')
```
- 80 이상 A, 60 이상 80 미만 B, 60 미만 C. 75 입력 → 첫 조건 거짓, 둘째 조건 참 → B
- elif에 `n < 80`을 따로 쓰지 않아도 되는 이유: 위의 if가 거짓일 때만 elif를 검사하기 때문
- 활동 20(키 탑승 조건): 100 미만 탑승 불가, 100 이상 130 미만 보호자 동행 시 탑승 가능, 130 이상 195 미만 탑승 가능, 195 이상 탑승 불가 → 127 입력 시 "보호자 동행 시 탑승 가능" (p.128)

### 2. 반복문
- **반복문**: 특정 명령문을 반복해서 실행해야 할 때 사용. 종류는 for문, while문 등 (p.129)
- 예: "회전목마 1번째 바퀴 운행" ~ "20번째"를 하나씩 쓰는 대신 "회전목마를 20바퀴 운행하시오(범위 + 반복할 명령)" (p.129)
- 1~100의 합: 반복문 없이 `t += 1` … `t += 100`을 100줄 나열 vs 반복문으로 4줄 (p.129)
```python
t = 0
for a in range(1, 101) :
    t += a  # 덧셈 100번 하기
print(t)
```
- `t = 0`: 합계 변수 초기화
- `range(1, 101)`: 1부터 100까지 정수 생성
- a에 1~100을 차례로 넣으며 `t += a`(= `t = t + a`)를 100번 실행
- 반복 후 합계 출력
- 회전목마 예: `for i in range(1, 21) :` → `print("회전목마 ", i, "번째 바퀴 운행하시오.")` (p.129)

#### for문 (p.130)
- 주로 **범위를 정해 놓고** 특정 명령문을 반복하는 구조. 단순 for문과 중첩 for문
- **단순 for문**: for문 한 개. 범위에 리스트, 문자열, range( ) 함수 사용
  - 형식 1 `for 변수 in 리스트[값, 값, …] :`
  - 형식 2 `for 변수 in 문자열 :`
  - 형식 3 `for 변수 in range(시작값, 종룟값, 증감값) :` — 변수는 시작값~(종룟값 - 1)까지 증감값만큼 변함. 시작값 0, 증감값 1이면 생략 가능. `range(1, 6, 1)`과 `range(1, 6)`은 같다(1~5).
- 주의: for문 범위 뒤에 반드시 **콜론(:)**, 반복할 명령문은 **같은 위치의 들여쓰기** (p.130)
- **range( ) 함수**: 데이터 범위를 한번에 지정, 주로 for문과 함께 사용. 형식 `range([시작값], 종룟값, [증감값])`. 범위는 시작값~종룟값 전의 값. 생략 시 시작값 0, 증감값 1 (p.130)
  - `range(0, 3, 1)`, `range(0, 3)`, `range(3)` 모두 0, 1, 2
- 예제 23: `for a in [1, 2, 3] :` → 1, 2, 3 (리스트 요소를 차례로 a에 할당) (p.130)
- 예제 24: `for a in "hello" :` → h, e, l, l, o 한 글자씩 (p.131)
- 예제 25: `for a in range(1, 4) :` → 1, 2, 3 (p.131)

예제 26 타이머 (p.131)
```python
import time 
for i in range(5, 0, -1) :
  print(i, "초 남았습니다.")
  time.sleep(1)
print("종료")
```
- `import time`: time 모듈 불러오기
- `range(5, 0, -1)`: 5에서 시작해 1씩 감소, 0 전까지 → 5, 4, 3, 2, 1
- `time.sleep(1)`: 1초 동안 일시 정지(일정 시간 동작을 정지시키는 명령)
- 반복이 끝나면 "종료"
- 예제 27 구구단: `d = int(input("몇 단? "))`, `for i in range(1, 10)`, `a = d * i`, `5 * 1 = 5` … `5 * 9 = 45` 형태로 출력 (p.131)

#### 중첩 for문 (p.132)
- **중첩 for문**: for문 안에 또 다른 for문. **내부 for문이 끝나면 외부 for문**을 실행
```python
for i in range(2) :	# i를 0~1까지 반복하기
  for j in range(3) :	# j를 0~2까지 반복하기
     print("i = ", i, "j = ", j)	# i, j값 출력하기
```
- i = 0일 때 j = 0, 1, 2 → 3번, i = 1일 때 다시 j = 0, 1, 2 → 3번, 총 6번 출력

예제 28 구구단 2~9단 (p.132)
```python
for i in range(2, 10) :	# 외부 for문
  for j in range(1, 10) :	# 내부 for문
     print(i, "*", j, "=", i * j)
```
- 외부 i가 단(2~9), 내부 j가 1~9로 곱함 → `2 * 1 = 2` … `9 * 9 = 81`

예제 29 세트 메뉴 조합 (p.132)
```python
popcorn_options = ["기본", "카라멜", "어니언"]	# 팝콘과 음료의 옵션
drink_options = ["생수", "탄산음료"]
for popcorn in popcorn_options :	# 모든 세트 메뉴 조합 출력
    for drink in drink_options :
         print("세트 메뉴: ", popcorn, "팝콘,", drink)
```
- 팝콘 3종 × 음료 2종 = 6가지 조합 출력 (기본-생수, 기본-탄산음료, 카라멜-생수 …)

#### while문 (p.133)
- **while문**: 조건식이 **참인 동안만** 내부 명령문을 반복하고, 거짓이면 반복문을 벗어난다.
```
변수 초기화
while 조건식 : 
   반복 명령문
```
- 내부에서 조건식의 변숫값을 증감하며 반복 횟수를 조절하기도 한다. 조건식 변수는 **미리 초기화**하는 경우가 많다.
- 주의: 조건식에 쓰는 변수는 미리 초기화, 반복 명령문은 같은 위치의 들여쓰기

예제 30 (p.133)
```python
a = 1	# 조건식 변수 초기화
while a <= 5 :	# 조건식  
   print(a)	# a값 출력하기
   a = a + 1	# a값을 1씩 증가하기
```
- a = 1부터 a <= 5인 동안 출력 후 1 증가 → 1~5 출력, a가 6이 되면 종료
- for문으로는 `for a in range(1, 6) :` `print(a)`
- **무한 반복**(더 알기): 특정 명령을 무한히 반복. while 조건식에 True나 1을 쓰거나 조건식이 항상 참이 되게 만든다. 벗어나려면 강제 종료하거나 내부에 break문 사용. 예: `while True :`, `while 1 :` (p.133)

#### 반복문의 제어 (p.134)
- 반복문에서 프로그램 흐름을 제어하는 명령문: break문, continue문
- **break문**: 반복문 실행 중 **강제로 반복문을 벗어날** 때 사용
- **continue문**: 특정 명령문을 **건너뛰고 처음으로 돌아가** 반복문을 계속 실행할 때 사용

예제 31 break (p.134)
```python
while 1 :	# 무한 반복 
   n = input("프로그램을 벗어나려면 q 또는 Q를 입력하세요. ")
   if n == 'q' or n == 'Q' :	# 'q' 또는 'Q'를 입력하면 
      print("프로그램 나가기")	# '프로그램 나가기' 출력하기
      break	# while문 탈출하기
```
- `while 1`: 무한 반복
- a, b 입력 시 계속 반복, q 입력 → 조건 참 → "프로그램 나가기" 출력 후 break로 탈출

예제 32 continue (p.134)
```python
total = 0	# total 변수에 0으로 초기화하기
for i in range(1, 101) :	# i 변숫값을 1부터 100까지 반복하기
   if i % 5 != 0 :	# i가 5의 배수가 아닌가?
      continue	# 5의 배수가 아니라면 for문으로 돌아가기
   total += i	# i가 5의 배수라면, total 변수에 i값 더하기
print(total)	# 반복문이 종료되면 total값 출력하기
```
- 5로 나눈 나머지가 0이 아니면(5의 배수 아님) continue로 아래 덧셈을 건너뜀
- 5의 배수만 더해짐 → 1050

### 3. 제어 구조 프로그래밍 (p.135~136)
- **모듈**: 특정 기능을 수행하는 파이썬 코드의 집합. 불러오면 모듈 안의 모든 코드를 사용할 수 있다. (p.135)
- **random 모듈**: 무작위로 값을 구하거나 값을 섞는 함수들이 저장됨. `random.randint(1, 5)` → 1~5 중 임의의 정수 (p.135)

예제 33 업-다운 숫자 맞히기 (p.135)
```python
import random	# random 모듈 불러오기
num = random.randint(1, 10)	# 1부터 10 사이의 숫자를 랜덤으로 생성하기
guess = int(input("1부터 10 사이의 숫자 입력: "))	 # 숫자 입력하기
for i in range(10) : 	# 10회 반복하기
   if guess == num :	# 입력한 숫자가 랜덤으로 생성된 숫자와 같은가?
    print("정답: ", num)	# 숫자가 같은 경우 정답을 출력하고
    break	# for문 종료하기
   elif guess < num :	# 랜덤으로 생성된 숫자가 입력한 숫자보다 큰가?
    print(guess, "보다 업!")
   else :	# 랜덤으로 생성된 숫자가 입력한 숫자보다 작은가?
    print(guess, "보다 다운!")
   guess = int(input("다시 숫자 입력: "))	# 새로운 숫자 입력하기
```
- num에 1~10 임의 정수, guess에 첫 입력
- 최대 10회 반복하며 같으면 정답 출력 후 break
- guess가 작으면 "업!", 크면 "다운!" 출력 후 새 숫자 입력
- 랜덤 숫자가 6일 때: 5 → 업!, 8 → 다운!, 6 → 정답: 6

예제 34 영어 타자 게임 (p.136)
```python
import random	# random 모듈 불러오기 
# capital(수도) 리스트 만들기
capital = ["Beijing", "Seoul", "Kathmandu", "Tokyo", "Paris"]
correct = 0	# 정답 수를 저장하는 변수
for i in range(3) :	# 3회 반복하기
  print("*** problem", i + 1, "***")
  a = random.randint(0, 4)	# 0~4 중 랜덤값 생성하기
  word = capital[a]	# 랜덤 숫자에 해당되는 도시의 수도를 가져오기
  print(word)	# 도시의 수도 출력하기
  user = input()	# 도시의 수도 입력하기
  if user == word :	# 입력한 도시의 수도가 정답과 같은가?
    print("- pass -")	# 같으면 “- pass -” 출력하기
    correct += 1	# 정답 수 1 증가하기 
  else :	# 입력한 도시의 수도가 정답과 다르면 
    print("- fail -")	# “- fail -” 출력하기
success = round(correct / 3, 2)	# 소수점 이하 셋째 자리에서 반올림하기
print("success rate", success)	 # 성공률 출력하기 
```
- 3회 반복: 0~4 임의 인덱스로 리스트에서 단어를 골라 보여 주고 입력과 비교
- 같으면 pass, correct 1 증가(= correct = correct + 1), 다르면 fail
- `round(correct / 3, 2)`: 성공률을 소수점 이하 둘째 자리까지 → Soul(fail), Tokyo(pass), Pari(fail) → 0.33
- **round( ) 함수**(더 알기): 지정한 자릿수로 반올림. 파이썬은 5로 끝나는 수를 반올림할 때 **앞자리가 홀수면 올림, 짝수면 내림** (p.136)
  - `round(3.141592)` → 3, `round(3.141592, 3)` → 3.142, `round(0.5)` → 0, `round(1.5)` → 2

### 4. 선택 활동: 정렬 알고리즘 구현 (p.137)
- 버블 정렬과 선택 정렬을 구현해 초기 데이터 8, 4, 2, 1의 **교환 횟수**를 비교

버블 정렬
```python
a = [8, 4, 2, 1]
print("초기: ", a)
n = len(a)	# 리스트 요소 수
count = 0	# 교환 횟수 
for i in range(0, n - 1) :	
  for j in range(0, n – i - 1) :
    if a[j] > a[j + 1] :	# 왼쪽 수가 오른쪽 수보다 큰가?
      a[j], a[j + 1] = a[j + 1], a[j] # 크면 두 수 교환하기
      count += 1	# 교환 횟수 증가하기
  print(a)	
print("교환 횟수: ", count)	# 교환 횟수 출력하기
```
- 외부 for: n - 1 = 3회전, 내부 for: 회전마다 비교 범위가 1씩 줄어듦
- 이웃한 두 수를 비교해 왼쪽이 크면 교환하고 count 증가
- 회전별: [4, 2, 1, 8] → [2, 1, 4, 8] → [1, 2, 4, 8], **교환 횟수 6**

선택 정렬
```python
a = [8, 4, 2, 1]
print("초기: ", a)
n = len(a)                   	 # 리스트 요소 수
count = 0                   	# 교환 횟수
for i in range(0, n - 1) :	
   min_index = i            	# 최솟값의 위치를 i로 초기화하기
   for j in range(i + 1, n) :	
     if a[min_index] > a[j] :	# 최솟값이 a[ j ]보다 큰가?
       min_index = j	# 크면 최솟값의 위치를 j로 변경하기
   if  min_index != i :	# 최솟값의 위치가 처음과 다른가?
       a[i], a[min_index] = a[min_index], a[i]	# 다르면 최솟값과 a[ i ]값 교환하기
       count += 1	# 교환 횟수 1 증가하기
   print(a)
print("교환 횟수: ", count)	# 최종 교환 횟수 출력하기
```
- 회전마다 i 이후에서 최솟값 위치를 찾고, i 위치와 다를 때만 한 번 교환
- 회전별: [1, 4, 2, 8] → [1, 2, 4, 8] → [1, 2, 4, 8](교환 없음), **교환 횟수 2**
- (교과서 인쇄본 버블 정렬 6행의 `n – i - 1`에는 긴 대시 기호가 찍혀 있다. 실제 입력은 빼기 기호 -이다.)

| 중첩 조건문 | if 안에 if | 조건식 1 참·2 참/거짓, 1 거짓으로 3갈래 |
| if~elif~else | 여러 조건식 | 처음으로 참인 곳만 실행하고 벗어남 |

| 구분 | for문 | while문 |
|---|---|---|

| 1~5 출력 | for a in range(1, 6) : | a = 1, while a <= 5 : … a = a + 1 |

## 시험 함정 포인트
- if문에서 들여쓰기 없는 다음 명령문(명령문 2)은 조건이 거짓일 때만이 **아니라** 조건과 상관없이 항상 실행된다. (p.125)
- elif에는 조건식을 생략할 수 **없다**. 반드시 조건식이 있어야 한다. else는 생략할 수 있다. (p.128)
- 다중 조건문은 참인 조건을 모두 실행하는 것이 **아니라** 처음 참인 명령만 실행하고 if문을 벗어난다(75점 → B만 출력). (p.128)
- range(1, 6)은 1~6이 **아니라** 1~5이다. 종룟값은 포함되지 않는다. (p.130)
- range(3)의 시작값은 1이 **아니라** 0이다(0, 1, 2). (p.130)
- 중첩 for문은 외부가 먼저 다 돈 뒤 내부가 도는 것이 **아니라**, 외부 1회마다 내부 for문이 끝까지 돈다. (p.132)
- while문은 조건이 거짓인 동안이 **아니라** 참인 동안 반복한다. (p.133)
- continue는 반복문을 끝내는 것이 **아니라** 건너뛰고 처음으로 돌아가 계속한다. 끝내는 것은 break이다. (p.134)
- round(0.5)는 1이 **아니라** 0이다(앞자리가 짝수면 내림). round(1.5)는 2이다. (p.136)
- 8, 4, 2, 1 정렬 시 교환 횟수는 버블 정렬 6, 선택 정렬 2로 같지 **않다**. (p.137)
- for문 범위 뒤 콜론(:)은 생략할 수 **없다**. (p.130)
- 예제 32의 결과 1050은 1~100 전체 합이 **아니라** 5의 배수의 합이다. (p.134)
