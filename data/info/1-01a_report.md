# 고1 정보 시험대비 학습 가이드: 유·무선 네트워크의 특성과 무선 기술

본 학습 가이드는 고등학교 정보 교과서(천재교육, 김현철 저) Ⅰ. 컴퓨팅 시스템 단원의 **‘네트워크의 구성 ① 유선·무선 네트워크의 특성과 무선 기술’(교과서 7~13쪽)** 내용을 바탕으로 작성되었습니다. 시험에 출제되는 핵심 개념, 비교표, 함정 포인트, 단답형 및 서술형 연습 문제, 핵심 용어 사전이 모두 포함되어 있습니다.

---

## 1. 핵심 개념 정리

### 1.1 네트워크의 이해 및 구성 요소
*   **컴퓨터 네트워크**: 네트워크는 서로 다른 기기들이 연결된 통신망이며, 다양한 컴퓨팅 기기가 유선 또는 무선 통신망으로 연결된 것을 컴퓨터 네트워크라고 한다 (p.11).
*   **네트워크 환경 구성 요소**:
    *   **물리적 환경**: 컴퓨팅 시스템, 통신을 위한 네트워크 장비 등 (p.12).
    *   **소프트웨어 환경**: 네트워크 장비 설정 및 관리, 보안과 같이 물리적인 환경을 제어하기 위한 소프트웨어도 필요하다 (p.12).

---

### 1.2 유선 네트워크 vs 무선 네트워크 비교

| 구분 | 유선 네트워크 | 무선 네트워크 |
| :--- | :--- | :--- |
| **연결 방식** | 광 케이블, 이더넷 케이블 등 **각종 케이블(선)**을 사용 | **공간의 무선 주파수**를 사용 |
| **장소의 제약** | 물리적 연결이 필요하여 **장소의 제약을 받음** | 케이블이 없어 **장소의 제약 없이 자유롭게 사용** |
| **전송 특성** | **안정적이고 빠르게** 데이터를 전송함 | 무선 네트워크는 장소의 제약을 받지 않고 자유롭게 기기들을 사용할 수 있는 장점이 있으며, 센서와 통신 기능이 내장된 사물과도 연결되어 사물 인터넷을 가능하게 하는 중요한 역할을 한다 (p.12). |
| **주요 사용 환경**| 회사, 학교 등 **고정된 공간**에서 작업할 때 사용 | 이동 중이거나 다양한 컴퓨팅 기기 및 주변 장치 연결 시 사용 |

#### [유선 케이블 종류]
*   **광 케이블**: 광 케이블은 고속의 데이터 전송, 원거리 전송이 가능하여 다양한 분야에 활용한다 (p.11).
*   **이더넷 케이블**: 이더넷 케이블은 저렴한 구축 비용과 유연성으로 주로 LAN 구축에 사용된다 (p.11).

---

### 1.3 주요 네트워크 장비 및 역할

| 장비명 | 주요 역할 및 특징 |
| :--- | :--- |
| **허브 및 스위치** | · 여러 대의 컴퓨팅 시스템과 주변 장치를 연결하여 하나의 네트워크를 형성함.<br>· 네트워크 내부에서 데이터를 전송할 수 있게 함 (스위칭 기능) (p.11). |
| **라우터** | · 서로 다른 네트워크(내부 네트워크와 외부 네트워크)를 연결해 줌.<br>· 외부 네트워크로 데이터가 전송되는 **경로를 지정**함 (p.11). |
| **무선 AP (액세스 포인트)**| · 유선 랜과 무선 랜을 연결해 주는 장치.<br>· **와이파이(WiFi) 기술**을 사용하여 인터넷을 이용할 수 있도록 지원함 (p.12). |
| **방화벽** | · 외부로부터의 불법 접근이나 악의적인 공격을 막아 **보안을 유지**함 (p.12). |

---

### 1.4 무선 네트워크 기술의 종류 및 특징

| 기술명 | 통신 거리 | 주요 특징 및 내용 | 적용 사례 |
| :--- | :--- | :--- | :--- |
| **전자 태그 (RFID)** | 다양한 거리 | 전자 태그(RFID)는 소형 반도체 칩이 내장된 태그나 라벨, 카드 등에 저장된 데이터를 무선 주파수로 읽어 상품을 식별하거나 관련 데이터를 읽어 내는 인식 시스템이다 (p.13). | 교통카드, 고속도로 하이패스, 상품 정보 인식 |
| **근거리 무선 통신 (NFC)**| **10cm 이내** | · **RFID 기술 중 하나**.<br>· 전자 태그(RFID) 기술 중 하나로 10cm 내의 가까운 거리에서 접촉하지 않고도 데이터를 주고받을 수 있는 무선 통신 기술이다 (p.13). | 스마트폰 비용 지불, 비접촉식 결제, 티켓 발매, 출입 통제 |
| **블루투스 (Bluetooth)** | **10m 이내** | 블루투스는 10m 이내에서 무선으로 데이터를 주고받을 수 있는 무선 기술이다 (p.13). | 무선 이어폰 연결, 인공지능(AI) 스피커 연결 |
| **와이파이 (WiFi)** | 사용 거리 제한 있음 | 와이파이는 가까운 거리에서 노트북이나 휴대 전화 등으로 데이터를 주고받을 수 있도록 랜을 무선화한 기술로, 사용 거리에 제한이 있지만 휴대 전화를 이용한 이동 통신 네트워크보다 비용이 저렴하고 전송 속도가 빨라 많은 사람이 사용한다 (p.13). | 외부 업무, 과제 수행, 무선 인터넷 접속 |
| **디스플레이 공유 기술** | - | · 서로 다른 기기의 화면을 그대로 전송하여 공유함 (**미러링**).<br>· 주요 기술: **미라캐스트(miracast)**, **DLNA** | 교사 모니터 화면을 학생 PC로 연결, 영화/사진 화면 전송 |

## 2. 시험에서 헷갈리기 쉬운 함정 포인트

###  함정 1: NFC와 RFID는 완전 별개의 기술이다?
*   **Fact**: **NFC는 RFID 기술 중 하나**입니다. 차이점은 RFID는 하이패스처럼 더 넓은 범위에서 사용될 수 있는 반면, NFC는 **10cm 이내**의 극근거리 비접촉 통신에 특화되어 있다는 점입니다.

###  함정 2: 허브/스위치와 라우터의 기능 혼동
*   **허브 및 스위치**: **동일한 네트워크 내부**에서 여러 기기를 묶어주고 데이터를 전송합니다.
*   **라우터**: **서로 다른 네트워크(내부 ↔ 외부)**를 연결하며, 데이터가 나아갈 **‘경로(Route)를 지정’**합니다. "경로 지정"이라는 키워드가 나오면 반드시 라우터입니다.

###  함정 3: 광 케이블과 이더넷 케이블의 특징 반대로 기억하기
*   **광 케이블**: 고속 전송, **원거리** 전송 가능.
*   **이더넷 케이블**: 저렴한 비용, 유연함, **LAN(근거리 통신망)** 구축에 주로 사용.

###  함정 4: 무선 네트워크 기술 간 전송 속도 및 거리 비교
*   **속도 비교**: 와이파이가 블루투스보다 전송 속도가 빠릅니다. (블루투스는 와이파이보다 속도가 느림)
*   **거리 비교**: NFC는 **10cm 이내**, 블루투스는 **10m 이내**입니다. 치수를 바꾸어 오답을 유도할 수 있으니 단위와 숫자를 명확히 외워야 합니다.

###  함정 5: 네트워크 환경 구축 시 물리적 장비만 있으면 된다?
*   **Fact**: 네트워크 환경을 구성하려면 물리적인 컴퓨팅 시스템 및 통신 장비뿐만 아니라, 이를 제어하고 보안을 유지하기 위한 **소프트웨어(설정, 관리, 보안 소프트웨어 등)**가 반드시 함께 필요합니다.

## 3. 단답형 연습 문제

**Q1. 컴퓨팅 기기들이 유선 또는 무선 통신망으로 연결되어 데이터를 주고받을 수 있도록 구성된 통신망을 무엇이라고 하는가?**
> **정답**: 컴퓨터 네트워크 (또는 네트워크)

**Q2. 유선 케이블 중 구축 비용이 저렴하고 유연하여 사무실이나 주택 등의 LAN 구축에 주로 사용되는 케이블은 무엇인가?**
> **정답**: 이더넷 케이블

**Q3. 네트워크 장비 중 내부 네트워크와 외부 네트워크 사이를 연결하고, 데이터가 전송될 경로를 지정해 주는 장비의 명칭을 쓰시오.**
> **정답**: 라우터 (Router)

**Q4. 외부로부터의 불법적인 접근이나 악의적인 공격을 막아 네트워크의 보안을 유지해 주는 기술은 무엇인가?**
> **정답**: 방화벽

**Q5. 무선 랜과 유선 랜을 연결하여 사용자가 와이파이(WiFi) 기술을 통해 무선 인터넷을 사용할 수 있도록 돕는 장비는 무엇인가?**
> **정답**: 무선 AP (액세스 포인트)

**Q6. RFID 기술의 한 종류로, 10cm 이내의 가까운 거리에서 비접촉으로 데이터를 주고받는 무선 통신 기술은 무엇인가?**
> **정답**: 근거리 무선 통신 (NFC)

**Q7. 블루투스(Bluetooth) 기술에서 두 개의 기기를 무선으로 서로 연결하는 과정을 뜻하는 용어는 무엇인가?**
> **정답**: 페어링 (pairing)

**Q8. 한 기기에서 보여지는 화면(영화, 사진 등)을 다른 기기에 그대로 전송하여 공유하는 기술을 무엇이라고 하는가?**
> **정답**: 미러링 (mirroring)

**Q9. 소형 반도체 칩이 내장된 태그나 라벨 등에 저장된 데이터를 무선 주파수로 읽어 상품을 식별하는 기술로, 고속도로 하이패스 등에 활용되는 기술은 무엇인가?**
> **정답**: 전자 태그 (RFID)

**Q10. 디스플레이 화면 공유 기술의 대표적인 예시 2가지를 제시하시오.**
> **정답**: 미라캐스트 (miracast), DLNA

## 4. 서술형 평가 대비 문제

### 서술형 Q1. 유선 네트워크와 무선 네트워크의 특성을 (1) 전송 매체(연결 방식), (2) 장소 제약 여부, (3) 전송의 안정성 측면에서 비교하여 서술하시오.
*   **모범 답안**:
    유선 네트워크는 광 케이블이나 이더넷 케이블 등 물리적인 선을 전송 매체로 사용하여 데이터를 전송하므로 장소를 이동하거나 기기를 배치할 때 장소의 제약을 받지만, 데이터 전송이 매우 안정적이고 빠르다는 장점이 있습니다. 반면 무선 네트워크는 공간의 무선 주파수를 전송 매체로 사용하므로 물리적 케이블이 필요 없어 장소의 제약 없이 자유롭게 기기를 사용할 수 있습니다.

### 서술형 Q2. 내부 네트워크(LAN)에 속한 PC가 외부 인터넷망으로 데이터를 안전하게 송수신하고자 할 때, 거치게 되는 주요 네트워크 장비(허브 및 스위치, 라우터, 방화벽)의 역할을 데이터 이동 순서와 함께 서술하시오.
*   **모범 답안**:
    교과서는 허브 및 스위치(하나의 네트워크 내 데이터 전송), 라우터(서로 다른 네트워크 연결 및 외부 전송 경로 지정), 방화벽(외부 불법 접근·악의적 공격 차단)의 역할을 각각 설명할 뿐, 데이터가 거치는 구체적 순서를 제시하지 않는다 (p.11-12).

## 5. 핵심 용어 사전 (Glossary)

*   **네트워크 (Network)**: 서로 다른 기기들이 연결되어 데이터를 주고받을 수 있도록 구축된 통신망.
*   **LAN (근거리 통신망)**: 사무실, 주택 등 일정한 제한된 범위 안에서 기기들이 연결된 네트워크.
*   **광 케이블**: 광 케이블은 고속의 데이터 전송, 원거리 전송이 가능하여 다양한 분야에 활용한다 (p.11).
*   **이더넷 케이블**: 저렴한 구축 비용과 유연성을 특징으로 하여 주로 LAN 환경 구축에 쓰이는 유선 케이블.
*   **허브 및 스위치**: 여러 대의 컴퓨팅 시스템과 주변 장치를 연결해 하나의 내부 네트워크를 만들고 데이터를 전송하는 장비.
*   **라우터 (Router)**: 서로 다른 네트워크를 연결하며, 데이터가 외부 네트워크로 전송되는 최적의 경로를 지정해 주는 장비.
*   **방화벽 (Firewall)**: 외부의 불법적 접근이나 악의적 공격을 차단하여 네트워크 보안을 유지하는 시스템/기술.
*   **무선 AP (Access Point)**: 유선 랜과 무선 랜을 연결하여 와이파이를 통해 무선 인터넷 접속을 가능하게 하는 장치.
*   **사물 인터넷 (IoT)**: 생활 속 다양한 물건이 인터넷에 연결되어 데이터를 주고받고 원격 제어가 가능하도록 하는 시스템.
*   **전자 태그 (RFID)**: 소형 반도체 칩이 내장된 태그의 데이터를 무선 주파수를 이용하여 읽어내는 식별 시스템.
*   **근거리 무선 통신 (NFC)**: RFID 기술의 일종으로, 10cm 이내의 가까운 거리에서 비접촉으로 데이터를 송수신하는 기술.
*   **블루투스 (Bluetooth)**: 10m 이내의 근거리에서 기기 간 무선 데이터 송수신을 지원하는 기술.
*   **페어링 (Pairing)**: 블루투스 통신을 위해 두 개의 무선 장치를 서로 연결하는 과정.
*   **와이파이 (WiFi)**: 근거리에서 랜(LAN)을 무선화한 기술로, 빠르고 저렴하게 무선 인터넷을 이용할 수 있게 함.
*   **미러링 (Mirroring)**: 한 정보 기기의 디스플레이 화면을 다른 기기의 화면에 그대로 전송하여 동일하게 공유하는 기술.
*   **생체 인증 시스템**: 지문 등 개인의 생체 정보를 인식하여 본인 인증 및 보안 관리를 수행하는 시스템.
