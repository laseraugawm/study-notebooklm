# Ⅲ-02-1 02. 합리적 선택과 경제 주체의 역할 합리적 선택의 의미와 한계는 무엇일까?
교과서 69-72쪽 · 통합사회

## 학습 목표
- 합리적 선택의 의미를 이해하고, 그 한계로 인해 나타나는 시장 실패를 파악할 수 있다. (p.69)

## 핵심 개념

### 1. 자원의 희소성과 선택 (p.69)
- **자원의 희소성**: 인간의 욕구는 **무한**한 데 비해 이를 충족해 줄 자원의 양이 **상대적으로 부족**한 상태
- 자원의 희소성 때문에 경제활동을 하면서 수많은 **선택**의 상황에 놓인다.

### 2. 편익, 비용, 기회비용 (p.69)
- 합리적으로 선택하려면 선택에 따른 **편익**과 **비용**을 고려해야 한다.
- **편익**: 어떤 선택을 함으로써 얻는 이익이나 만족감 등
- **비용**: 어떤 선택에 대해 지불하는 대가 → 이때 비용은 **기회비용**을 뜻함
- **기회비용** = **명시적 비용** + **암묵적 비용**
  - 명시적 비용: 어떤 것을 선택할 때 **실제로 지출하는 비용**
  - 암묵적 비용: 선택으로 **포기한 대안들의 가치 중 가장 큰 가치**
- **합리적 선택**: 여러 대안 중 **최선의 대안**을 고르는 것 → **편익에서 기회비용을 뺀 순편익이 가장 큰** 대안을 선택해야 함
  - `순편익 = 편익 − 기회비용`

### 3. 읽기 자료 — 합리적 선택과 매몰 비용 (이준구 외, 『경제학 들어가기』, p.69)
- 호텔 주방장 갑: 월급 **5백만 원**, 직장을 그만두고 음식점을 열려 함
  - 1년 예상 수입 **3억 원**, 예상 비용(명시적 비용) **2억 5천만 원** → 겉보기 이윤 5천만 원
  - 직장을 그만두면 연간 **6천만 원**의 소득을 포기(암묵적 비용)
  - 총비용(기회비용) = 2억 5천만 원 + 6천만 원 = **3억 1천만 원** → 음식점 운영 시 **1천만 원 손해** → **합리적 선택이 아니다**
- **매몰 비용**: 일단 지출한 뒤에는 어떤 선택을 하든지 **다시 회수할 수 없는 비용**
  - 어떤 행위를 할지 결정할 때 매몰 비용은 **고려 대상으로 삼지 말아야** 합리적 선택을 할 수 있다.
  - 들인 돈이 아까워 매몰 비용을 고려해 판단을 그르치는 경우가 많다.
  - 예: 비싼 돈을 내고 음악회에 간 사람이 연주가 시시하다고 느끼면서도 **본전을 뽑기 위해** 그대로 앉아 있는 것 → 합리적이지 않음
- 확인 문제 사례(p.75): 영국과 프랑스가 공동 개발한 초음속 여객기 **콩코드** — 소음·대기 오염 문제가 심각하고 탑승객이 100여 명에 그쳐 수익성도 낮았으나, **막대한 투자 비용을 회수하고자** 상업 운항을 강행하여 큰 손실 → 매몰 비용을 고려한 비합리적 선택의 교훈

### 4. 합리적 선택의 한계와 시장 실패 (p.70)
- 합리적 선택으로 경제적 목표를 효율적으로 달성할 수 있다.
- 시장경제 체제의 관점: 경제 문제의 해결을 시장에 맡기면 개인이 합리적으로 선택하여 사익을 추구하고, 그 과정에서 자연스럽게 **효율적인 자원 배분** → 사회 전체의 이익도 증가
- 그러나 때로는 시장에서 자원이 효율적으로 배분되지 못해 사회 전체의 이익이 커지지 않는 경우가 발생 → **시장 실패**
- 시장 실패의 유형: ① **독과점의 폐해** ② **공공재의 부족** ③ **외부 효과의 발생**

### 5. 시장 실패 ① 독과점의 폐해 (p.70)
- **독점 시장**: 하나의 기업이 시장을 지배 → 공급자가 이윤을 늘리려고 가격과 생산량을 **임의로 결정**
- **과점 시장**: 소수의 기업이 시장을 지배 → 공급자 간 **담합**하여 가격과 생산량 조절
- **담합**: 비슷한 재화나 서비스를 생산하는 기업들이 경쟁할 때보다 더 높은 이익을 얻으려고 생산량과 가격을 **사전에 협의**하여 결정하는 행위
- 독과점 시장의 공급자는 **생산량을 줄여 가격을 올림**으로써 이윤 극대화 → 소비자는 시장 가격보다 높은 가격에 구매할 수밖에 없음(다른 대안이 없어 손해)
- 결과: 재화나 서비스가 사회적으로 적정한 수준만큼 공급되지 않아 **자원의 비효율적 배분**
- 그림: "사전에 약속한 대로 닭고기 생산량을 줄여 높은 가격에 상품을 팔았더니 더 많은 이윤을 얻을 수 있었어요." / "다들 같은 가격에 판매하니 비싸지만 살 수밖에 없어."

### 6. 시장 실패 ② 공공재의 부족 (p.70~71)
- 일반 재화·서비스: **대가를 지불한 사람만** 사용 가능, 한 사람이 소비한 만큼 다른 사람의 몫이 **줄어든다**.
- **공공재**: 국방 및 치안 서비스, 가로등, 공원, 등대 등 → **대가를 지불하지 않아도** 누구든지 소비할 수 있으며, 한 사람이 소비해도 다른 사람의 몫이 **줄어들지 않는다**.
- 공공재에는 가로등 같은 **재화**뿐 아니라 국방 같은 **서비스**도 포함된다.
- **무임승차자 문제**: 아무런 대가를 지불하지 않고 공공재를 사용하려는 데 따르는 문제점
- 기업이 공공재를 생산하면 **이윤을 얻을 수 없어** 생산을 줄이거나 포기 → 시장에만 맡기면 사회가 필요로 하는 양만큼 충분히 공급되지 않음
- 사례: **등대** — 배들을 일일이 찾아가 비용을 받는 것은 사실상 불가능, 어떤 배가 불빛을 본다고 다른 배가 볼 불빛이 줄지 않음 → 무임승차자 발생 → 사회적으로 필요한 수준보다 **적게 생산** ("이용료를 내지 않는다고 불빛을 못 보는 것도 아니니 일단 모르는 척해야지.")

### 7. 시장 실패 ③ 외부 효과의 발생 (p.71)
- **외부 효과**: 아무런 경제적 대가를 주고받지 않는 상황에서 어떤 경제 주체의 행위가 다른 경제 주체에게 (의도하지 않은 이익이나 피해의) 영향을 주는 현상
- 결과: 재화나 서비스가 사회적으로 적정한 수준보다 **많거나 적게** 생산되어 자원이 비효율적으로 배분
- **부정적 외부 효과**: 의도하지 않은 **피해**를 주는데도 경제적 대가를 **치르지 않는** 상태 → 사회적으로 적정한 수준보다 **많이** 나타남
  - 예: **대기 오염 물질 배출** ("생산에 필요한 비용을 생각하면 이 정도가 적정한 생산량이야." vs "대기 오염 물질의 배출로 발생하는 사회적 비용도 생각해야지.")
- **긍정적 외부 효과**: 의도하지 않은 **이익**을 주는데도 경제적 대가를 **받지 않는** 상태 → 사회적으로 적정한 수준보다 **적게** 나타남
  - 예: **예방 접종** ("난 면역력이 좋으니 굳이 비싼 돈을 내고 예방 접종을 할 필요는 없어." vs "모두 나처럼 예방 접종을 하면 사람들이 독감에 걸릴 확률도 낮아질 텐데…….")

### 8. 창의·융합 — 경제, 심리학과 만나다 (행동 경제학, p.72)
- 노벨 경제학상을 수상한 심리학자 **허버트 사이먼**: 인간을 합리적 존재로 보는 주류 경제학과 달리 인간은 **제한적으로 합리적**이며 때로는 **감정적으로 선택**하는 경향이 있다고 전제하는 **행동 경제학** 주창
- **닻 내림 효과(Anchoring Effect)**: 처음 입력된 정보가 정신적 닻 역할을 하여 이후 판단에 계속 영향을 주는 현상 (대니얼 카너먼, 『생각에 관한 생각』)
  - 사례: 대형 할인점 음료수 **10% 할인** 행사에서 구매량 제한이 없는 안내판 → 평균 **3개**, 구매량에 제한을 둔 안내판 → 평균 **7개** 구매. 제한 개수가 닻이 되어 그만큼 사도록 유도
- **프레이밍 효과(Framing Effect)**: 질문을 제시하는 방식(프레임, 틀)의 변화에 따라 판단이나 선택이 달라지는 현상 (도모노 노리오, 『행동 경제학』)
  - 사례: 방치하면 600명이 사망하는 질병
    - 제1집단: (가) 200명 생존 / (나) 모두 생존할 확률 1/3, 모두 사망할 확률 2/3 → 대부분 **(가)** 선택
    - 제2집단: (다) 400명 사망 / (라) 아무도 사망하지 않을 확률 1/3, 모두 사망할 확률 2/3 → 대부분 **(라)** 선택
  - 사실 (가)=(다)(200명 생존), (나)=(라)(생존 확률 1/3, 사망 확률 2/3)로 같은 선택지
  - 이유: 사람들은 **긍정적** 인식의 틀에서는 불확실한 이득보다 **확실한 이득**을, **부정적** 인식의 틀에서는 확실한 손실보다 **불확실한 손실**을 선호

## 비교·정리표

### 표 1. 기회비용의 구성 (p.69)
| 구분 | 명시적 비용 | 암묵적 비용 |
|---|---|---|
| 의미 | 선택할 때 실제로 지출하는 비용 | 선택으로 포기한 대안들의 가치 중 가장 큰 가치 |
| 주방장 갑 사례 | 음식점 운영 비용 2억 5천만 원 | 포기한 연봉 6천만 원 |
| 합계 | 기회비용 3억 1천만 원 → 수입 3억 원보다 커서 1천만 원 손해 | |

### 표 2. 기회비용 vs 매몰 비용
| 구분 | 기회비용 | 매몰 비용 |
|---|---|---|
| 의미 | 명시적 비용 + 포기한 대안 중 가장 큰 가치 | 지출한 뒤 어떤 선택을 해도 회수할 수 없는 비용 |
| 합리적 선택에서 | 반드시 고려 | 고려하지 말아야 함 |
| 사례 | 주방장 갑의 포기한 연봉 | 시시한 음악회 표값, 콩코드 투자 비용 |

### 표 3. 시장 실패의 세 유형
| 유형 | 원인 | 결과 | 사례 |
|---|---|---|---|
| 독과점의 폐해 | 독점 기업의 임의 결정, 과점 기업의 담합 | 생산량 감소·가격 상승, 적정 수준보다 적게 공급 | 닭고기 생산량 담합 |
| 공공재의 부족 | 대가 없이 소비 가능, 몫이 줄지 않음 → 무임승차자 | 이윤이 없어 필요한 양보다 적게 공급 | 등대, 국방·치안, 가로등, 공원 |
| 외부 효과 | 대가를 주고받지 않고 다른 주체에 영향 | 적정 수준보다 많거나 적게 생산 | 부정적: 대기 오염(과다) / 긍정적: 예방 접종(과소) |

### 표 4. 긍정적 외부 효과 vs 부정적 외부 효과 (p.71)
| 구분 | 긍정적 외부 효과 | 부정적 외부 효과 |
|---|---|---|
| 영향 | 의도하지 않은 이익 | 의도하지 않은 피해 |
| 대가 | 받지 않음 | 치르지 않음 |
| 생산·활동 수준 | 적정 수준보다 적음 | 적정 수준보다 많음 |
| 예 | 예방 접종 | 대기 오염 물질 배출 |

## 시험 함정 포인트
- 기회비용은 실제 지출만이 아니라 **명시적 비용 + 암묵적 비용(포기한 대안 중 가장 큰 가치)**이다. 포기한 대안들의 가치를 **모두 합친 것이 아니라 가장 큰 것 하나**이다. (p.69)
- 합리적 선택은 편익이 가장 큰 대안이 아니라 **순편익(편익 − 기회비용)이 가장 큰** 대안이다. (p.69)
- 주방장 갑은 회계상 5천만 원 이윤처럼 보이지만 포기한 연봉 6천만 원을 넣으면 **1천만 원 손해**이다. (p.69)
- 매몰 비용은 이미 지출해 회수할 수 없으므로 의사 결정 때 **고려하지 않아야** 합리적이다. (p.69)
- 시장 실패는 정부의 잘못이 아니라 **시장에서 자원이 효율적으로 배분되지 못하는 것**이다. (p.70)
- 독과점 기업은 생산량을 **늘리는 것이 아니라 줄여서** 가격을 올린다. (p.70)
- 공공재는 대가를 지불하지 않아도 소비할 수 있고 **한 사람이 소비해도 다른 사람의 몫이 줄지 않는다**. 국방 같은 **서비스**도 공공재이다. (p.71)
- 부정적 외부 효과는 적정 수준보다 **많이**, 긍정적 외부 효과는 적정 수준보다 **적게** 나타난다(반대로 외우지 않기). (p.71)
- 프레이밍 효과에서 긍정적 틀에서는 **확실한 이득**, 부정적 틀에서는 **불확실한 손실**을 선호한다. (p.72)
- 행동 경제학을 주창한 허버트 사이먼은 인간이 **제한적으로 합리적**이라고 보았다(완전히 합리적 X). (p.72)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 자원의 희소성 | 인간의 욕구는 무한한 데 비해 자원의 양이 상대적으로 부족한 상태 (p.69) |
| 편익 | 어떤 선택을 함으로써 얻는 이익이나 만족감 (p.69) |
| 비용 | 어떤 선택에 대해 지불하는 대가(기회비용) (p.69) |
| 기회비용 | 실제로 지출하는 비용과 포기한 대안의 가치 중 가장 큰 것을 합친 것 (p.69) |
| 명시적 비용 | 선택할 때 실제로 지출하는 비용 (p.69) |
| 암묵적 비용 | 선택으로 포기한 대안들의 가치 중 가장 큰 가치 (p.69) |
| 합리적 선택 | 여러 대안 중 순편익(편익 − 기회비용)이 가장 큰 최선의 대안을 고르는 것 (p.69) |
| 매몰 비용 | 일단 지출한 뒤에는 어떤 선택을 하든 회수할 수 없는 비용 (p.69) |
| 시장 실패 | 시장에서 자원이 효율적으로 배분되지 못해 사회 전체 이익이 커지지 않는 경우 (p.70) |
| 독점 시장 | 하나의 기업이 시장을 지배하는 시장 (p.70) |
| 과점 시장 | 소수의 기업이 시장을 지배하는 시장 (p.70) |
| 담합 | 기업들이 더 높은 이익을 얻으려고 생산량과 가격을 사전에 협의하여 결정하는 행위 (p.70) |
| 공공재 | 대가 없이 누구나 소비할 수 있고 한 사람의 소비가 다른 사람의 몫을 줄이지 않는 재화·서비스 (p.71) |
| 무임승차자 문제 | 대가를 지불하지 않고 공공재를 사용하려는 데 따르는 문제 (p.71) |
| 외부 효과 | 경제적 대가 없이 어떤 경제 주체의 행위가 다른 경제 주체에게 영향을 주는 현상 (p.71) |
| 긍정적 외부 효과 | 의도하지 않은 이익을 주고도 대가를 받지 않는 상태 (p.71) |
| 부정적 외부 효과 | 의도하지 않은 피해를 주고도 대가를 치르지 않는 상태 (p.71) |
| 행동 경제학 | 인간이 제한적으로 합리적이며 감정적으로 선택하기도 한다고 전제하는 경제학 (p.72) |
| 닻 내림 효과 | 처음 입력된 정보가 이후 판단에 계속 영향을 주는 현상 (p.72) |
| 프레이밍 효과 | 질문 제시 방식(프레임)에 따라 판단이나 선택이 달라지는 현상 (p.72) |

## 자기점검 질문
1. 자원의 희소성이란? — 욕구는 무한한데 자원은 상대적으로 부족한 상태
2. 기회비용의 두 구성 요소는? — 명시적 비용, 암묵적 비용
3. 합리적 선택의 기준은? — 편익에서 기회비용을 뺀 순편익이 가장 큰 대안 선택
4. 주방장 갑의 음식점 개업이 합리적이지 않은 이유는? — 포기한 연봉 6천만 원을 포함한 기회비용이 3억 1천만 원으로 수입 3억 원보다 커서 1천만 원 손해
5. 매몰 비용을 의사 결정에서 어떻게 다뤄야 하는가? — 회수할 수 없으므로 고려하지 않는다
6. 시장 실패의 세 유형은? — 독과점의 폐해, 공공재의 부족, 외부 효과의 발생
7. 독과점 기업이 이윤을 극대화하는 방법은? — 생산량을 줄여 가격을 올림(과점은 담합)
8. 공공재가 시장에서 부족하게 공급되는 이유는? — 무임승차자 문제로 기업이 이윤을 얻을 수 없어 생산을 줄이거나 포기
9. 예방 접종은 어떤 외부 효과이며 사회적 수준과 비교해 어떻게 나타나는가? — 긍정적 외부 효과, 적정 수준보다 적게
10. 프레이밍 효과의 예에서 (가)와 (다)의 관계는? — 같은 선택지(200명 생존 = 400명 사망)
