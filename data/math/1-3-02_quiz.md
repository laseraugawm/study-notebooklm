# 대칭이동 퀴즈

## Question 1
점 $P(a, b)$를 $y$축에 대하여 대칭이동한 점을 $P_1$, 점 $P_1$을 다시 직선 $y=x$에 대하여 대칭이동한 점을 $P_2$라 할 때, 점 $P_2$의 좌표는?

- [x] $(b, -a)$
- [ ] $(-b, a)$
- [ ] $(-a, b)$
- [ ] $(-b, -a)$

**Hint:** $y$축 대칭이동은 $x$좌표의 부호를 바꾸고, 직선 $y=x$ 대칭이동은 $x$좌표와 $y$좌표의 위치를 바꿉니다.

## Question 2
직선 $y = 3x - 2$를 직선 $y=x$에 대하여 대칭이동한 직선의 기울기와 $y$절편의 합은?

- [x] $1$
- [ ] $-1$
- [ ] $\frac{1}{3}$
- [ ] $5$

**Hint:** 직선 $y=x$에 대하여 대칭이동할 때는 $x$와 $y$의 위치를 서로 바꾸어 방정식을 정돈합니다.

## Question 3
원 $(x+2)^2 + (y-3)^2 = 9$를 원점에 대하여 대칭이동한 후, 다시 $x$축에 대하여 대칭이동한 원의 중심의 좌표는?

- [x] $(2, 3)$
- [ ] $(-2, -3)$
- [ ] $(2, -3)$
- [ ] $(-2, 3)$

**Hint:** 원점에 대하여 대칭이동하면 $x, y$ 부호가 모두 바뀌고, $x$축 대칭이동은 $y$의 부호만 바뀝니다.

## Question 4
직선 $ax - 2y + 4 = 0$을 직선 $y=x$에 대하여 대칭이동한 후, $x$축에 대하여 대칭이동하였더니 점 $(1, -2)$를 지났다. 이때 상수 $a$의 값은?

- [x] $-1$
- [ ] $1$
- [ ] $-3$
- [ ] $2$

**Hint:** 대칭이동 단계별로 변수를 바꾼 후, 주어진 점의 좌표를 대입하여 식을 성립시킵니다.

## Question 5
두 점 $A(-1, 4)$와 $B(5, 2)$가 있다. $x$축 위의 점 $P$에 대하여 $AP + PB$의 값이 최소가 되도록 하는 점 $P$의 $x$좌표는?

- [x] $3$
- [ ] $2$
- [ ] $1$
- [ ] $4$

**Hint:** 한 점을 $x$축에 대하여 대칭이동한 후 다른 점과 직선으로 연결할 때 거리의 합이 최소가 됩니다.

## Question 6
방정식 $f(x, y) = 0$이 나타내는 도형을 $y$축에 대하여 대칭이동한 후, 원점에 대하여 대칭이동한 도형의 방정식으로 옳은 것은?

- [x] $f(x, -y) = 0$
- [ ] $f(-x, -y) = 0$
- [ ] $f(-x, y) = 0$
- [ ] $f(y, x) = 0$

**Hint:** $y$축 대칭이동은 $x$ 대신 $-x$를, 원점 대칭이동은 $x, y$ 대신 각각 $-x, -y$를 대입합니다.

## Question 7
기울기가 $m$ ($m \ne 0$)이고 $y$절편이 $n$인 직선 $y = mx + n$을 여러 대칭이동을 하였을 때의 설명으로 옳은 것만을 [보기]에서 있는 대로 고른 것은?

[보기]
ㄱ. $y$축에 대하여 대칭이동하면 기울기의 부호가 바뀐다.
ㄴ. 원점에 대하여 대칭이동하면 기울기가 변하지 않는다.
ㄷ. 직선 $y=x$에 대하여 대칭이동하면 기울기는 기존 기울기의 역수 $\frac{1}{m}$이 된다.

- [x] ㄱ, ㄴ, ㄷ
- [ ] ㄱ, ㄴ
- [ ] ㄴ, ㄷ
- [ ] ㄱ, ㄷ

**Hint:** 각 대칭이동 규칙을 직선 $y = mx + n$의 방정식에 적용한 후 기울기의 변화를 확인해보세요.

## Question 8
원 $C_1: (x-3)^2 + (y+1)^2 = 16$을 직선 $y=x$에 대하여 대칭이동한 원을 $C_2$라 하자. 두 원 $C_1$과 $C_2$의 중심 사이의 거리는?

- [x] $4\sqrt{2}$
- [ ] $4$
- [ ] $2\sqrt{2}$
- [ ] $8$

**Hint:** 직선 $y=x$에 대칭이동된 원 $C_2$의 중심 좌표를 구한 뒤, 두 점 사이의 거리 공식을 사용합니다.

## Question 9
점 $P(2, 5)$를 직선 $y=x$에 대하여 대칭이동한 점을 $Q$라 할 때, 선분 $PQ$의 중점의 좌표는?

- [x] $\left(\frac{7}{2}, \frac{7}{2}\right)$
- [ ] $\left(\frac{3}{2}, \frac{3}{2}\right)$
- [ ] $(7, 7)$
- [ ] $(2, 5)$

**Hint:** 직선 $y=x$에 대칭인 두 점을 잇는 선분의 중점은 항상 직선 $y=x$ 위에 존재합니다.

## Question 10
좌표평면 위에 두 점 $A(1, 4)$와 $B(5, 2)$가 있다. 직선 $y=x$ 위의 점 $P$에 대하여 $AP + PB$의 최솟값은?

- [x] $\sqrt{2}$
- [ ] $2\sqrt{2}$
- [ ] $2$
- [ ] $\sqrt{10}$

**Hint:** 두 점 중 하나를 직선 $y=x$에 대하여 대칭이동한 후 다른 점까지의 선분 길이를 구합니다.
