# Ⅱ-2-01 명제와 조건
교과서 83~87쪽 · 공통수학2

## 학습 목표
- 명제와 조건의 뜻을 알고, '모든', '어떤'을 포함한 명제를 이해하고 설명할 수 있다. (p.83)

## 핵심 개념

### 1. 명제와 조건
- 생각 틔우기: 참, 거짓을 명확하게 판별할 수 있는 문장 찾기 (p.83)
  - '3과 4의 합은 7보다 크다.' → 판별 가능(거짓)
  - '제주도는 대한민국 땅이다.' → 판별 가능(참)
  - '백두산은 높은 산이다.' → '높다'의 기준이 불분명하여 판별 불가
  - 'x는 5의 배수이다.' → x의 값에 따라 참, 거짓이 달라짐
- **명제**: 참, 거짓을 명확하게 판별할 수 있는 문장이나 식 (p.83)
  - 예: '2는 소수이다.'는 참, 식 '√2 + √3 = √5'는 거짓 → 둘 다 명제 (p.83)
- **조건**: 변수를 포함하는 문장이나 식 중에서 변수의 값에 따라 참, 거짓을 명확하게 판별할 수 있는 것 (p.83)
  - 예: `x + 3 = 5`
- 일반적으로 명제와 조건은 알파벳 소문자 p, q 등으로, 조건 p, q의 진리집합은 대문자 P, Q 등으로 나타낸다. (p.83)

### 2. 진리집합
- **진리집합**: 전체집합 U의 원소 중에서 조건 p가 참이 되게 하는 모든 원소의 집합 P (p.83)
- 보기: `U = {x | x는 자연수}` 에서 조건 'p: x는 10의 약수이다.'의 진리집합 `P = {1, 2, 5, 10}` (p.83)
- 특별한 말이 없으면 전체집합 U는 실수 전체의 집합이다. (p.84)

### 3. 부정 (~p)
- **부정**: 명제 또는 조건 p에 대하여 'p가 아니다.'를 p의 부정이라 하고 `~p` 로 나타낸다. (p.83)
- 명제 p가 참이면 ~p는 거짓, p가 거짓이면 ~p는 참 (p.83)
- `~(~p)` 는 p이다. (p.83)
- 조건 p의 진리집합이 P이면 부정 ~p의 진리집합은 `Pᶜ` (p.83)
- 보기 (p.83)
  1. '13은 소수이다.'는 참, 그 부정 '13은 소수가 아니다.'는 거짓
  2. `U = {1, 2, 3, 4, 5}`, 'p: x는 4의 약수이다.' → `P = {1, 2, 4}`, ~p의 진리집합 `Pᶜ = {3, 5}`

### 4. '또는'과 '그리고'의 부정 (역량 키우기, p.85)
- 'x(x − 1) = 0'의 부정은 'x(x − 1) ≠ 0'
  - x(x − 1) = 0 은 'x = 0 또는 x = 1'
  - x(x − 1) ≠ 0 은 'x ≠ 0 그리고 x ≠ 1'
  - 따라서 'x = 0 또는 x = 1'의 부정은 'x ≠ 0 그리고 x ≠ 1'
- 일반적으로 조건 'p 또는 q'의 부정은 조건 '~p 그리고 ~q' (p.85)
- 적용하기: ① 'x = 1 그리고 x = 3'의 부정 ② 'x ≤ 1 또는 x ≥ 3'의 부정 말하기

### 5. 명제 p → q, 가정과 결론
- 두 조건 'p: x = 3', 'q: x + 2 = 5'에 대하여 문장 'x = 3이면 x + 2 = 5이다.'는 참, 거짓을 판별할 수 있으므로 명제이다. (p.84)
- 두 조건 p, q로 이루어진 명제 'p이면 q이다.'를 `p → q` 로 나타내고 **p를 가정, q를 결론**이라 한다. (p.84)
- 보기: 'x = 1이면 x² = 1이다.'에서 'x = 1'은 가정, 'x² = 1'은 결론 (p.84)

### 6. 명제 p → q의 참, 거짓과 진리집합 (p.84)
- P ⊂ Q 이면 조건 p가 참이 되는 모든 경우에 q가 참이 되므로 p → q는 참
- P ⊄ Q 이면 p는 참이지만 q는 거짓인 원소가 있으므로 p → q는 거짓
- 정리: 두 조건 p, q의 진리집합을 각각 P, Q라고 할 때
  1. `P ⊂ Q` 이면 p → q는 참이고, p → q가 참이면 `P ⊂ Q`
  2. `P ⊄ Q` 이면 p → q는 거짓이고, p → q가 거짓이면 `P ⊄ Q`
- **반례**: 명제 p → q가 거짓임을 보일 때, 가정 p는 만족시키지만 결론 q는 만족시키지 않는 예. 하나라도 있으면 된다. (p.84)

### 7. 예제 1 (p.84) — 진리집합으로 참, 거짓 판별
- (1) 'x + 1 > 4이면 x > 2이다.'
  - p: x + 1 > 4, q: x > 2 → `P = {x | x > 3}`, `Q = {x | x > 2}`
  - 수직선에서 P(3 초과)가 Q(2 초과)에 들어가므로 P ⊂ Q → **참**
- (2) 'x² − 5x = 0이면 x = 5이다.'
  - p: x² − 5x = 0, q: x = 5 → `P = {0, 5}`, `Q = {5}`
  - P ⊄ Q → **거짓**. [반례] x = 0일 때 x² − 5x = 0이지만 x ≠ 5
- 답: (1) 참 (2) 거짓

### 8. '모든'이나 '어떤'을 포함한 명제
- '모든 자연수 x에 대하여 x > 0이다.', '어떤 실수 x에 대하여 x² = −1이다.'는 변수 x를 포함하지만 참, 거짓을 판별할 수 있으므로 **명제**이다. (p.86)
- '모든 x에 대하여 p이다.', '어떤 x에 대하여 p이다.'는 조건 p의 진리집합으로 참, 거짓을 판별한다. (p.86)
- 함께 완성하기: `U = {1, 2, 3, 4}` (p.86)

| 명제 | 조건 p | 진리집합 P | =, ≠ | 참, 거짓 |
|---|---|---|---|---|
| 모든 x에 대하여 x > 0이다. | x > 0 | {1, 2, 3, 4} | P = U | 참 |
| 모든 x에 대하여 x > 1이다. | x > 1 | {2, 3, 4} | P ≠ U | 거짓 |
| 어떤 x에 대하여 x > 3이다. | x > 3 | {4} | P ≠ ∅ | 참 |
| 어떤 x에 대하여 x > 4이다. | x > 4 | ∅ | P = ∅ | 거짓 |

(첫 줄만 교과서에 채워져 있고 나머지는 빈칸 활동이다.)

- 정리: 전체집합 U에 대하여 조건 p의 진리집합을 P라고 할 때 (p.86)
  1. '모든 x에 대하여 p이다.'는 P = U이면 참, P ≠ U이면 거짓
  2. '어떤 x에 대하여 p이다.'는 P ≠ ∅이면 참, P = ∅이면 거짓
- '어떤 x에 대하여 p이다.'는 'p인 x가 존재한다.'는 것과 같다. (p.86)

### 9. '모든', '어떤'을 포함한 명제의 부정 (p.86)
- U가 실수 전체의 집합일 때
  - '모든 x에 대하여 x = 3이다.'의 부정 → 'x = 3이 아닌 실수 x가 있다.' 즉 '어떤 x에 대하여 x ≠ 3이다.'
  - '어떤 x에 대하여 x² = 2이다.'의 부정 → 'x² = 2인 실수 x가 없다.' 즉 '모든 x에 대하여 x² ≠ 2이다.'
- 일반적으로
  - '모든 x에 대하여 p이다.'의 부정은 '어떤 x에 대하여 ~p이다.'
  - '어떤 x에 대하여 p이다.'의 부정은 '모든 x에 대하여 ~p이다.'
- 진리집합으로: P = U의 부정은 P ≠ U, 즉 Pᶜ ≠ ∅ / P ≠ ∅의 부정은 P = ∅, 즉 Pᶜ = U (p.86)

### 10. 스스로 익히기·역량 키우기 문제 유형
- p.85

  2. 부정 말하고 참, 거짓: (1) 5는 소수이다. (2) 9 < 7
  3. `U = {x | x는 10 이하의 자연수}`, 'p: x² − 7x + 10 = 0', 'q: x는 소수이다.'의 진리집합 (1) p (2) q (3) ~p (4) ~q
  4. (예제 1 연계) 진리집합으로 판별: (1) x가 4의 배수이면 x는 8의 배수이다. (2) x = −2이면 x² = 4이다. (3) x² < 1이면 x < 1이다.
- p.87
  1. (1) 모든 실수 x에 대하여 |x| ≥ 0이다. (2) 어떤 실수 x에 대하여 x² + x + 1 = 0이다.
  2. `U = {0, 1, 2, 3, 4}` 에서 (1) 모든 x에 대하여 x³ − x = 0이다. (2) 어떤 x에 대하여 2x − 1 = 3이다. — 참, 거짓과 까닭
  3. 부정과 참, 거짓: (1) 모든 정수 x에 대하여 x² > 0이다. (2) 어떤 실수 x에 대하여 x − 3 = 0이다.
  - 역량 키우기(실생활 및 타 교과와 연결하기): 예 '모든 액체는 1기압일 때 100 ℃에서 끓는다.'(거짓), '어떤 나라의 화폐 단위는 유로(€)이다.'(참)

## 비교·정리표

### 명제 vs 조건
| 구분 | 뜻 | 예 | 참·거짓 |
|---|---|---|---|
| 명제 | 참, 거짓을 명확하게 판별할 수 있는 문장이나 식 | 2는 소수이다. / √2 + √3 = √5 | 하나로 정해짐 |
| 조건 | 변수를 포함하고 변수의 값에 따라 참, 거짓이 정해지는 것 | x + 3 = 5 | x의 값에 따라 달라짐 |
| 둘 다 아님 | 기준이 불분명한 문장 | 백두산은 높은 산이다. / 12는 작은 수이다. | 판별 불가 |

### 진리집합과 참, 거짓 판별
| 명제 꼴 | 참일 조건 | 거짓일 조건 |
|---|---|---|
| p → q | P ⊂ Q | P ⊄ Q (반례 존재) |
| 모든 x에 대하여 p | P = U | P ≠ U |
| 어떤 x에 대하여 p | P ≠ ∅ | P = ∅ |

### 부정 만들기
| 원래 | 부정 | 진리집합 |
|---|---|---|
| p | ~p | P → Pᶜ |
| p 또는 q | ~p 그리고 ~q | — |
| x = 0 또는 x = 1 | x ≠ 0 그리고 x ≠ 1 | — |
| 모든 x에 대하여 p | 어떤 x에 대하여 ~p | P = U ↔ Pᶜ ≠ ∅ |
| 어떤 x에 대하여 p | 모든 x에 대하여 ~p | P ≠ ∅ ↔ Pᶜ = U |

## 시험 함정 포인트
- 거짓인 문장도 명제다. '√2 + √3 = √5'는 거짓이지만 참, 거짓을 판별할 수 있으므로 명제이다. 명제는 "참인 문장"이 아니다. (p.83)
- '백두산은 높은 산이다.', '12는 작은 수이다.'처럼 기준이 불분명한 문장은 명제가 아니다. (p.83, p.85)
- 변수가 있으면 무조건 조건인 것이 아니다. '모든 자연수 x에 대하여 x > 0이다.'는 변수 x를 포함하지만 참, 거짓이 정해지므로 명제이다. (p.86)
- p → q가 참인 것은 Q ⊂ P가 아니라 **P ⊂ Q**일 때이다. 가정의 진리집합이 결론의 진리집합에 포함되어야 한다. (p.84)
- 반례는 결론을 만족시키지 않는 아무 예가 아니라, **가정은 만족시키면서** 결론은 만족시키지 않는 예이다. x² − 5x = 0이면 x = 5에서 반례는 x = 0. (p.84)
- '모든 x에 대하여 p'의 부정은 '모든 x에 대하여 ~p'가 아니라 '어떤 x에 대하여 ~p'이다. '모든 ↔ 어떤'을 바꾸고 p도 부정해야 한다. (p.86)
- 'p 또는 q'의 부정은 '~p 또는 ~q'가 아니라 '~p 그리고 ~q'이다. (p.85)
- '어떤 x에 대하여 p'가 참이려면 P ≠ ∅, 즉 만족하는 x가 하나라도 있으면 된다. 모두 만족할 필요는 없다. (p.86)
- 부정의 부정은 원래대로: ~(~p)는 p이다. (p.83)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 명제 | 참, 거짓을 명확하게 판별할 수 있는 문장이나 식 |
| 조건 | 변수를 포함하는 문장이나 식 중 변수의 값에 따라 참, 거짓을 판별할 수 있는 것 |
| 진리집합 | 전체집합 U의 원소 중 조건 p가 참이 되게 하는 모든 원소의 집합 |
| 부정 (~p) | 'p가 아니다.' |
| p → q | 명제 'p이면 q이다.' |
| 가정 | 명제 p → q에서 p |
| 결론 | 명제 p → q에서 q |
| 반례 | 가정은 만족시키지만 결론은 만족시키지 않는 예 |
| '모든 x에 대하여 p' | P = U이면 참인 명제 |
| '어떤 x에 대하여 p' | 'p인 x가 존재한다.'와 같은 뜻, P ≠ ∅이면 참 |

## 자기점검 질문
1. '√2 + √3 = √5'는 명제인가? — 거짓이지만 참, 거짓을 판별할 수 있으므로 명제
2. U가 자연수 전체일 때 'p: x는 10의 약수이다.'의 진리집합은? — {1, 2, 5, 10}
3. U = {1, 2, 3, 4, 5}, 'p: x는 4의 약수이다.'일 때 ~p의 진리집합은? — Pᶜ = {3, 5}
4. 명제 p → q가 참일 조건을 진리집합으로 말하면? — P ⊂ Q
5. 'x² − 5x = 0이면 x = 5이다.'의 반례는? — x = 0
6. 'x + 1 > 4이면 x > 2이다.'가 참인 이유는? — P = {x | x > 3} ⊂ Q = {x | x > 2}
7. '어떤 x에 대하여 p이다.'가 거짓일 조건은? — P = ∅
8. '모든 x에 대하여 x = 3이다.'의 부정은? — 어떤 x에 대하여 x ≠ 3이다.
9. 'x = 0 또는 x = 1'의 부정은? — x ≠ 0 그리고 x ≠ 1
10. U = {1, 2, 3, 4}에서 '모든 x에 대하여 x > 1이다.'는? — P = {2, 3, 4} ≠ U 이므로 거짓
