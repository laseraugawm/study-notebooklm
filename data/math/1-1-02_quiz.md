# 직선방정식 퀴즈

## Question 1
점 $(x_1, y_1)$을 지나고 기울기가 $m$인 직선의 방정식 및 직선의 성질에 대한 설명으로 옳은 것은?

- [x] 기울기가 $0$이고 점 $(x_1, y_1)$을 지나는 직선의 방정식은 $y = y_1$이다.
- [ ] $x_1 = x_2$인 서로 다른 두 점 $(x_1, y_1), (x_2, y_2)$를 지나는 직선의 기울기는 $0$이다.
- [ ] $x$축에 평행하거나 $x$축과 일치하는 직선의 기울기는 $1$이다.
- [ ] $y$축에 평행하고 점 $(x_1, y_1)$을 지나는 직선의 방정식은 $y = x_1$이다.

**Hint:** $x$축에 평행한 직선의 기울기와 점의 좌표 변화에 따른 직선 형태를 떠올려 보세요.

## Question 2
$x$절편이 $a$, $y$절편이 $b$ (단, $ab \neq 0$)인 직선의 방정식을 바르게 나타낸 것은?

- [x] $\frac{x}{a} + \frac{y}{b} = 1$
- [ ] $ax + by = 1$
- [ ] $\frac{x}{b} + \frac{y}{a} = 1$
- [ ] $\frac{x}{a} - \frac{y}{b} = 1$

**Hint:** 두 점 $(a, 0)$과 $(0, b)$를 지나는 직선의 방정식을 구하는 식을 생각해 보세요.

## Question 3
두 일차방정식 $ax + by + c = 0$과 $a'x + b'y + c' = 0$ ($abc \neq 0, a'b'c' \neq 0$)이 나타내는 두 직선이 서로 평행하기 위한 조건으로 옳은 것은?

- [x] $\frac{a}{a'} = \frac{b}{b'} \neq \frac{c}{c'}$
- [ ] $\frac{a}{a'} = \frac{b}{b'} = \frac{c}{c'}$
- [ ] $aa' + bb' = 0$
- [ ] $\frac{a}{a'} \neq \frac{b}{b'}$

**Hint:** 평행 조건은 두 직선의 기울기가 같고 $y$절편은 달라야 한다는 점을 계수의 비로 나타내 보세요.

## Question 4
두 직선 $ax + by + c = 0$과 $a'x + b'y + c' = 0$ ($ab \neq 0, a'b' \neq 0$)이 서로 수직일 때, 계수 사이의 관계식으로 항상 성립하는 것은?

- [x] $aa' + bb' = 0$
- [ ] $aa' - bb' = 0$
- [ ] $ab' + a'b = 0$
- [ ] $aa' + bb' = -1$

**Hint:** 두 직선의 기울기의 곱이 $-1$임을 이용하여 식을 정리해 보세요.

## Question 5
점 $(3, -2)$를 지나고 직선 $y = \frac{1}{2}x + 5$에 수직인 직선의 방정식은?

- [x] $y = -2x + 4$
- [ ] $y = 2x - 8$
- [ ] $y = -\frac{1}{2}x - \frac{1}{2}$
- [ ] $y = -2x - 2$

**Hint:** 두 직선이 수직이면 두 기울기의 곱이 $-1$입니다.

## Question 6
평행한 두 직선 $3x + 4y - 2 = 0$과 $3x + 4y + 8 = 0$ 사이의 거리는?

- [x] $2$
- [ ] $\frac{6}{5}$
- [ ] $10$
- [ ] $\frac{10}{\sqrt{7}}$

**Hint:** 한 직선 위의 임의의 한 점을 잡고, 그 점에서 다른 직선까지의 거리를 구하는 공식을 적용해 보세요.

## Question 7
점 $(1, -2)$와 직선 $2x - y + 5 = 0$ 사이의 거리는?

- [x] $\frac{9\sqrt{5}}{5}$
- [ ] $\sqrt{5}$
- [ ] $\frac{9}{5}$
- [ ] $3$

**Hint:** 점 $(x_1, y_1)$과 직선 $ax + by + c = 0$ 사이의 거리 공식 $d = \frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}$를 활용하세요.

## Question 8
실수 $k$의 값에 관계없이 일차방정식 $3x - y - 5 + k(x + y - 3) = 0$이 나타내는 직선이 항상 지나는 정점의 좌표는?

- [x] $(2, 1)$
- [ ] $(1, 2)$
- [ ] $(3, -5)$
- [ ] $(2, -1)$

**Hint:** 실수 $k$의 값에 관계없이 항상 성립하도록 하는 $k$에 대한 항등식 개념을 적용하세요.

## Question 9
원점 $O(0, 0)$과 두 점 $A(x_1, y_1)$, $B(x_2, y_2)$를 꼭짓점으로 하는 삼각형 $OAB$의 넓이 $S$를 나타내는 공식으로 옳은 것은?

- [x] $S = \frac{1}{2}|x_1 y_2 - x_2 y_1|$
- [ ] $S = \frac{1}{2}|x_1 y_1 - x_2 y_2|$
- [ ] $S = |x_1 y_2 - x_2 y_1|$
- [ ] $S = \frac{1}{2}(x_1 y_2 + x_2 y_1)$

**Hint:** 원점을 한 꼭짓점으로 하는 삼각형 넓이는 두 점 좌표의 엇갈린 곱의 차에 절댓값을 씌우고 $2$로 나눕니다.

## Question 10
점 $(a, 2)$를 지나고 직선 $3x - y + 4 = 0$에 평행한 직선이 점 $(2, 5)$를 지날 때, 실수 $a$의 값은?

- [x] $1$
- [ ] $-1$
- [ ] $3$
- [ ] $\frac{5}{3}$

**Hint:** 평행한 직선의 기울기를 파악한 뒤, 점 $(2, 5)$를 지나는 직선의 방정식을 먼저 완성해 보세요.
