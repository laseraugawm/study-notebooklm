# Ⅰ-3-02 대칭이동
교과서 48-51쪽 · 수학(공통수학2)

## 학습 목표
- 원점, x축, y축, 직선 y = x 에 대한 대칭이동을 탐구하고, 실생활과 연결하여 문제를 해결할 수 있다. (p.48)

## 핵심 개념

### 1. 대칭이동의 뜻 (p.48)
- **준비하기**: 직선 x + 3y − 2 = 0 을 x축의 방향으로 1만큼, y축의 방향으로 −2만큼 평행이동한 직선 → (x − 1) + 3(y + 2) − 2 = 0, 즉 x + 3y + 3 = 0
- **생각 틔우기(수학·한문)**: 규모가 큰 저택의 모습을 본떠 만든 한자 '버금 아(亞)'를 좌표평면 위에 나타냄. 점 P(14, 6)과 x축, y축, 원점에 대하여 대칭인 점 → (14, −6), (−14, 6), (−14, −6)
- **대칭이동**: 좌표평면 위의 도형을 한 점 또는 한 직선에 대하여 대칭인 도형으로 옮기는 것을 각각 그 점 또는 그 직선에 대한 대칭이동이라고 한다. (p.48)
- 인물: **뇌터**(Noether, A. E., 1882~1935) — 질량이나 에너지 보존과 같은 물리학 문제를 수학의 대칭의 관점으로 해결한 독일의 수학자 (p.48)

### 2. 점의 대칭이동 (p.48~49)
- 점 P(x, y)를
  - x축에 대하여 대칭이동 → (x, −y)
  - y축에 대하여 대칭이동 → (−x, y)
  - 원점에 대하여 대칭이동 → (−x, −y)
- **직선 y = x 에 대한 대칭이동** 유도 (점 P(x, y)가 y = x 위에 있지 않을 때, 대칭점 P′(x′, y′))
  1. 직선 PP′은 직선 y = x 에 **수직** → `(y′ − y)/(x′ − x) = −1`, 즉 x′ + y′ = x + y ……①
  2. 선분 PP′의 **중점** `((x + x′)/2, (y + y′)/2)` 은 직선 y = x 위 → `(y + y′)/2 = (x + x′)/2`, 즉 x′ − y′ = −x + y ……②
  3. ①, ②에서 x′ = y, y′ = x
  4. 따라서 P(x, y)를 y = x 에 대하여 대칭이동한 점은 **P′(y, x)**
- **점의 대칭이동 정리** (p.49): 좌표평면 위의 점 (x, y)를
  1. x축 → (x, −y)
  2. y축 → (−x, y)
  3. 원점 → (−x, −y)
  4. 직선 y = x → (y, x)
- 보기: 점 (3, 2)를 x축, y축, 원점, 직선 y = x 에 대하여 대칭이동 → 각각 **(3, −2), (−3, 2), (−3, −2), (2, 3)**

### 3. 도형의 대칭이동 (p.49~50)
- x축 대칭 유도
  1. f(x, y) = 0 위의 점 P(x, y)를 x축에 대하여 대칭이동한 점 P′(x′, y′): x′ = x, y′ = −y
  2. x = x′, y = −y′ 를 f(x, y) = 0 에 대입 → f(x′, −y′) = 0
  3. 따라서 구하는 도형의 방정식은 **f(x, −y) = 0**
- 같은 방법으로 y축, 원점, 직선 y = x 에 대하여 대칭이동한 도형의 방정식은 각각 **f(−x, y) = 0, f(−x, −y) = 0, f(y, x) = 0** (p.49 그림: 각 대칭이동의 그래프)
- **도형의 대칭이동 정리** (p.50): 방정식 f(x, y) = 0 이 나타내는 도형을
  1. x축에 대하여 대칭이동 → f(x, −y) = 0
  2. y축에 대하여 대칭이동 → f(−x, y) = 0
  3. 원점에 대하여 대칭이동 → f(−x, −y) = 0
  4. 직선 y = x 에 대하여 대칭이동 → f(y, x) = 0

### 4. 예제 1 — 원의 대칭이동 (p.50)
- 문제: 원 (x − 1)² + (y − 2)² = 4 를 x축, y축, 원점, 직선 y = x 에 대하여 대칭이동한 원의 방정식
- 풀이
  - x축: `(x − 1)² + (−y − 2)² = 4`, 즉 **(x − 1)² + (y + 2)² = 4**
  - y축: `(−x − 1)² + (y − 2)² = 4`, 즉 **(x + 1)² + (y − 2)² = 4**
  - 원점: `(−x − 1)² + (−y − 2)² = 4`, 즉 **(x + 1)² + (y + 2)² = 4**
  - 직선 y = x: `(y − 1)² + (x − 2)² = 4`, 즉 **(x − 2)² + (y − 1)² = 4**
- 확인: 중심 (1, 2)가 각각 (1, −2), (−1, 2), (−1, −2), (2, 1)로 옮겨지고 반지름 2는 그대로

### 5. 예제 2 — 대칭이동을 이용한 최단 거리 (p.50)
- 문제: 캠핑장에서 수연이가 A 지점(−2, 3)에 있는 반려견을 개울가(x축)로 데리고 가서 물을 먹인 후 텐트가 있는 B 지점(3, 2)로 가려고 할 때 반려견의 최소 이동 거리
- 풀이 흐름
  1. 개울가 위의 임의의 점을 P, 점 B를 x축에 대하여 대칭이동한 점을 B′(3, −2)라 하면 PB = PB′
  2. `AP + PB = AP + PB′ ≥ AB′`
  3. `AB′ = √((3 + 2)² + (−2 − 3)²) = 5√2`
  4. 답: **5√2**
- 원리: 꺾인 경로를 대칭이동으로 **한 직선(선분 AB′)** 으로 펴면 그 길이가 최솟값이다.

### 6. 스스로 익히기 (p.51)
1. x축, y축, 원점, 직선 y = x 에 대하여 대칭이동한 점: ⑴ (2, −5) → (2, 5), (−2, −5), (−2, 5), (−5, 2) ⑵ (−3, 0) → (−3, 0), (3, 0), (3, 0), (0, −3)
2. (예제 1 유형) x축, y축, 원점, 직선 y = x 에 대하여 대칭이동한 도형의 방정식
   - ⑴ 3x − 2y + 5 = 0 → 3x + 2y + 5 = 0, 3x + 2y − 5 = 0, 3x − 2y − 5 = 0, 2x − 3y − 5 = 0
   - ⑵ x² + y² + 4x − 8y − 5 = 0 → x² + y² + 4x + 8y − 5 = 0, x² + y² − 4x − 8y − 5 = 0, x² + y² − 4x + 8y − 5 = 0, x² + y² − 8x + 4y − 5 = 0
3. 직선 ax + y + 5 = 0 을 직선 y = x 에 대하여 대칭이동한 다음 y축에 대하여 대칭이동하였더니 점 (−3, 2)를 지남 → x + ay + 5 = 0 → −x + ay + 5 = 0, (−3, 2) 대입: 3 + 2a + 5 = 0, a = −4
4. (예제 2 유형) 두 도서관 A(−4, 3), B(1, 4)와 도로변인 직선 y = x 위에 거리의 합이 최소가 되도록 무인 도서관 P 설치 (건물 크기는 무시)
   - A를 y = x 에 대하여 대칭이동한 A′(3, −4), 직선 A′B: y = −4x + 8 과 y = x 의 교점 → P(8/5, 8/5)
- 계산 결과는 교과서 해설 쪽(148쪽)이 소스에 없어 직접 계산한 값이다(A, B 좌표는 그림의 점선 눈금에서 읽음).

### 7. 역량 키우기(추론·원리 탐구하기) (p.51)
- 직선 y = mx + n (m ≠ 0)을 x축, y축, 원점, 직선 y = x 에 대하여 대칭이동할 때 표 완성 (x축 행은 교과서에 채워져 있음)

| 대칭 | 대칭이동한 직선 | 기울기 | 기울기의 변화 |
|---|---|---|---|
| x축 | y = −mx − n | −m | 부호가 바뀐다. |
| y축 | y = −mx + n | −m | 부호가 바뀐다. |
| 원점 | y = mx − n | m | 변하지 않는다. |
| 직선 y = x | y = (1/m)x − n/m | 1/m | 역수가 된다. |

- y축, 원점, y = x 행은 대칭이동 공식으로 직접 채운 값이다.

## 비교·정리표

### 표 1. 점과 도형의 대칭이동
| 대칭의 기준 | 점 (x, y) → | 도형 f(x, y) = 0 → | 보기: 점 (3, 2) (p.49) |
|---|---|---|---|
| x축 | (x, −y) | f(x, −y) = 0 | (3, −2) |
| y축 | (−x, y) | f(−x, y) = 0 | (−3, 2) |
| 원점 | (−x, −y) | f(−x, −y) = 0 | (−3, −2) |
| 직선 y = x | (y, x) | f(y, x) = 0 | (2, 3) |

### 표 2. 평행이동 vs 대칭이동 (도형의 방정식)
| 이동 | 대입 규칙 | 원의 중심 (1, 2) 의 변화 | 반지름 |
|---|---|---|---|
| 평행이동 (a, b) | x → x − a, y → y − b | (1 + a, 2 + b) | 그대로 |
| x축 대칭 | y → −y | (1, −2) | 그대로 |
| y축 대칭 | x → −x | (−1, 2) | 그대로 |
| 원점 대칭 | x → −x, y → −y | (−1, −2) | 그대로 |
| y = x 대칭 | x ↔ y | (2, 1) | 그대로 |

### 표 3. 최단 거리 문제 (대칭이동 활용)
| 문제 | 대칭 기준 | 대칭점 | 결과 |
|---|---|---|---|
| 예제 2 캠핑장 (p.50) | x축(개울가) | B(3, 2) → B′(3, −2) | 최소 거리 AB′ = 5√2 |
| 스스로 익히기 4 도서관 (p.51) | 직선 y = x(도로) | A(−4, 3) → A′(3, −4) | 직선 A′B 와 y = x 의 교점이 P |

## 시험 함정 포인트
- x축 대칭은 x좌표가 아니라 **y좌표의 부호**가 바뀐다: (x, y) → (x, −y). 이름과 바뀌는 좌표를 반대로 외우기 쉽다. (p.48)
- 직선 y = x 대칭은 부호를 바꾸는 것이 아니라 **x와 y를 서로 바꾸는** 것이다: (3, 2) → (2, 3). (p.49)
- y = x 대칭점 유도의 두 조건은 ① **PP′ ⊥ y = x (기울기 곱 −1)**, ② **PP′의 중점이 y = x 위** 이다. 둘 중 하나만으로는 정해지지 않는다. (p.48)
- 도형의 y = x 대칭은 f(y, x) = 0 이다. 대입 후 **x에 대한 식으로 다시 정리**해야 한다: (y − 1)² + (x − 2)² = 4 → (x − 2)² + (y − 1)² = 4. (p.50)
- 원을 대칭이동하면 중심만 대칭이동하고 **반지름은 그대로**이다. (p.50 예제 1)
- 원점 대칭은 x축 대칭과 y축 대칭을 **모두** 한 것: (−x, −y). 직선의 기울기는 원점 대칭에서 **변하지 않는다**. (p.51 역량 키우기)
- 최단 거리 문제는 A, B 중 **한 점만** 대칭이동한다. 두 점을 모두 대칭이동하면 안 된다. (p.50 예제 2)
- 최단 거리는 `AP + PB = AP + PB′ ≥ AB′` 이므로 최솟값은 AB′ 이지 AB 가 아니다. (p.50)
- 두 번 연속 대칭이동하는 문제는 **순서대로** 한 번씩 대입한다(y = x 대칭 후 y축 대칭). (p.51 스스로 익히기 3)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 대칭이동 | 도형을 한 점 또는 한 직선에 대하여 대칭인 도형으로 옮기는 것 (p.48) |
| x축에 대한 대칭이동 | (x, y) → (x, −y), f(x, y) = 0 → f(x, −y) = 0 (p.49~50) |
| y축에 대한 대칭이동 | (x, y) → (−x, y), f(−x, y) = 0 (p.49~50) |
| 원점에 대한 대칭이동 | (x, y) → (−x, −y), f(−x, −y) = 0 (p.49~50) |
| 직선 y = x 에 대한 대칭이동 | (x, y) → (y, x), f(y, x) = 0 (p.49~50) |
| 중점 | 선분 PP′의 가운데 점, y = x 대칭에서 y = x 위에 있음 (p.48) |
| 뇌터 | 물리학 문제를 수학의 대칭의 관점으로 해결한 독일 수학자(1882~1935) (p.48) |
| 최소 이동 거리 | 대칭점을 이용해 꺾인 경로를 선분으로 펼 때의 길이 (p.50) |
