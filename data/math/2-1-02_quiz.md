# 집합 연산 퀴즈

## Question 1
두 집합 $A, B$에 대한 설명으로 옳은 것은?

- [x] 두 집합 $A$와 $B$에 공통인 원소가 하나도 없을 때, $A$와 $B$는 서로소라고 한다.
- [ ] $A \cap B = \{x \mid x \in A \text{ 또는 } x \in B\}$이다.
- [ ] $A \cup B = \{x \mid x \in A \text{ 그리고 } x \in B\}$이다.
- [ ] 두 집합 $A, B$가 서로소이면 $A$와 $B$ 중 적어도 하나는 공집합이어야 한다.

**Hint:** 합집합과 교집합을 나타내는 조건제시법의 연결어('또는', '그리고')와 서로소의 정의를 떠올려 보세요.

## Question 2
집합 $A = \{2, 3, 7\}$과 집합 $B$가 서로소이고 $A \cup B = \{1, 2, 3, 4, 5, 6, 7\}$일 때, 집합 $B$의 모든 원소의 합은?

- [x] 16
- [ ] 12
- [ ] 28
- [ ] 14

**Hint:** 두 집합이 서로소라는 것은 공통인 원소가 없음을 의미하므로, $A \cup B$에서 $A$의 원소를 제거하여 $B$를 구합니다.

## Question 3
어느 학급에서 플랫폼 A를 이용하는 가구 수는 14, 플랫폼 B를 이용하는 가구 수는 8, 플랫폼 A 또는 플랫폼 B를 이용하는 가구 수는 20이다. 플랫폼 A와 플랫폼 B를 모두 이용하는 가구 수는?

- [x] 2
- [ ] 6
- [ ] 4
- [ ] 12

**Hint:** 합집합의 원소 개수 공식인 $n(A \cup B) = n(A) + n(B) - n(A \cap B)$를 활용해 보세요.

## Question 4
세 집합 $A, B, C$에 대해 집합의 연산 법칙 중 분배법칙이 올바르게 적용된 것은?

- [x] $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$
- [ ] $A \cup (B \cap C) = (A \cup B) \cup (A \cup C)$
- [ ] $(A \cup B) \cup C = A \cup (B \cup C)$
- [ ] $A \cap (B \cup C) = (A \cap B) \cap (A \cap C)$

**Hint:** 수학의 곱셈 분배와 비슷하게, 괄호 밖의 연산 기호가 괄호 안의 각 집합으로 적용되고 중간 연산 기호가 바뀐다는 점에 주의하세요.

## Question 5
두 집합 $A, B$에 대하여 $A \cup (A \cap B)$를 간단히 나타낸 것은?

- [x] $A$
- [ ] $B$
- [ ] $A \cap B$
- [ ] $A \cup B$

**Hint:** $A \cap B$가 집합 $A$의 부분집합이라는 것을 벤 다이어그램으로 떠올려 보세요.

## Question 6
전체집합 $U$의 두 부분집합 $A, B$에 대하여 차집합 $A - B$의 조건제시법 표현으로 옳은 것은?

- [x] $\{x \mid x \in A \text{ 그리고 } x \notin B\}$
- [ ] $\{x \mid x \in A \text{ 또는 } x \notin B\}$
- [ ] $\{x \mid x \in U \text{ 그리고 } x \notin A\}$
- [ ] $\{x \mid x \in B \text{ 그리고 } x \notin A\}$

**Hint:** 차집합 $A - B$는 '$A$에는 포함되면서 동시에 $B$에는 포함되지 않는 원소'들의 집합입니다.

## Question 7
전체집합 $U$의 두 부분집합 $A, B$에 대하여 차집합 $A - B$와 항상 동일한 연산식은?

- [x] $A \cap B^C$
- [ ] $A^C \cap B$
- [ ] $A \cup B^C$
- [ ] $(A \cup B)^C$

**Hint:** 차집합은 앞 집합과 뒤 집합의 '여집합'의 '교집합'으로 바꿀 수 있습니다.

## Question 8
전체집합 $U$의 두 부분집합 $A, B$에 대한 여집합과 차집합의 성질 중 옳지 않은 것은?

- [x] $U^C = U$
- [ ] $(A^C)^C = A$
- [ ] $A \cup A^C = U$
- [ ] $A \cap A^C = \emptyset$

**Hint:** 전체집합 $U$에 속하지 않는 원소들로 이루어진 집합이 무엇일지 생각해 보세요.

## Question 9
두 집합 $A = \{2, 3, 6\}$, $B = \{1, 2, 4, 8\}$일 때, 차집합의 원소의 개수 $n(A - B)$의 값은?

- [x] 2
- [ ] -1
- [ ] 3
- [ ] 1

**Hint:** $n(A - B)$는 집합 $A$의 원소 개수에서 두 집합의 공통 원소 개수 $n(A \cap B)$를 빼서 구합니다.

## Question 10
자연수 $k$에 대하여 $A_k = \{x \mid x\text{는 } k\text{의 배수인 100 이하의 자연수}\}$라 할 때, $n(A_2 \cap A_3)$의 값은?

- [x] 16
- [ ] 50
- [ ] 33
- [ ] 67

**Hint:** 2의 배수의 집합과 3의 배수의 집합의 교집합은 공배수의 집합, 즉 최소공배수의 배수 집합이 됩니다.

## Question 11
전체집합 $U$의 두 부분집합 $A, B$에 대하여 $n(U)=50$, $n(A)=7$, $n(B)=16$, $n(A \cup B)=21$일 때, $n(A^C \cap B^C)$의 값은?

- [x] 29
- [ ] 27
- [ ] 43
- [ ] 34

**Hint:** $A^C \cap B^C$는 드모르간 법칙에 의해 $(A \cup B)^C$와 같음을 이용해 보세요.
