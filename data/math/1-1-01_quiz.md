# 도형의방정식 퀴즈

## Question 1
수직선 위의 두 점 $A(-8)$과 $B(-3)$ 사이의 거리를 구하는 올바른 식과 그 계산 결과는?

- [x] $|-3 - (-8)| = 5$
- [ ] $|-8 - (-3)| = -5$
- [ ] $-8 - (-3) = -5$
- [ ] $(-8) + (-3) = -11$

**Hint:** 수직선 위 두 점 사이의 거리는 두 좌표의 차에 절댓값을 씌운 값입니다.

## Question 2
좌표평면 위의 두 점 $A(-2, 3)$과 $B(4, -5)$ 사이의 거리는?

- [x] $10$
- [ ] $2\sqrt{5}$
- [ ] $\sqrt{10}$
- [ ] $2\sqrt{7}$

**Hint:** 좌표평면 위 두 점 $(x_1, y_1)$과 $(x_2, y_2)$ 사이의 거리는 피타고라스 정리에 기초한 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$ 공식을 사용합니다.

## Question 3
세 점 $A(1, 4)$, $B(-2, 0)$, $C(2, -3)$을 꼭짓점으로 하는 삼각형 $ABC$는 어떤 삼각형인가?

- [x] $\angle B = 90^\circ$인 직각이등변삼각형
- [ ] $\angle A = 90^\circ$인 직각이등변삼각형
- [ ] 정삼각형
- [ ] $\angle C = 90^\circ$인 직각삼각형

**Hint:** 세 변 $AB$, $BC$, $CA$의 길이를 각각 구한 후 피타고라스 정리와 변의 길이 관계를 확인해 보세요.

## Question 4
수직선 위의 두 점 $A(x_1)$과 $B(x_2)$를 이은 선분 $AB$를 $m : n\ (m>0, n>0)$으로 내분하는 점 $P$의 좌표 $x$를 구하는 공식으로 옳은 것은?

- [x] $x = \frac{mx_2 + nx_1}{m+n}$
- [ ] $x = \frac{mx_1 + nx_2}{m+n}$
- [ ] $x = \frac{mx_2 - nx_1}{m-n}$
- [ ] $x = \frac{x_1 + x_2}{m+n}$

**Hint:** 내분점 좌표를 구할 때 비율 $m$은 엇갈려서 점 $B$의 좌표 $x_2$에 곱하고, $n$은 점 $A$의 좌표 $x_1$에 곱합니다.

## Question 5
좌표평면 위의 두 점 $A(-3, 6)$과 $B(2, -4)$를 이은 선분 $AB$를 $3 : 2$로 내분하는 점 $P$의 좌표는?

- [x] $(0, 0)$
- [ ] $(-1, 2)$
- [ ] $(1, -2)$
- [ ] $(-\frac{1}{2}, 1)$

**Hint:** $x$좌표와 $y$좌표에 각각 내분점 공식 $\left(\frac{mx_2+nx_1}{m+n}, \frac{my_2+ny_1}{m+n}\right)$을 적용합니다.

## Question 6
두 점 $A(3, a)$와 $B(-5, 4)$를 이은 선분 $AB$를 $1 : 3$으로 내분하는 점이 $x$축 위에 있을 때, 상수 $a$의 값은?

- [x] $-\frac{4}{3}$
- [ ] $\frac{4}{3}$
- [ ] $-12$
- [ ] $-4$

**Hint:** 점이 $x$축 위에 있다는 것은 그 점의 $y$좌표가 $0$임을 의미합니다.

## Question 7
세 점 $A(x_1, y_1), B(x_2, y_2), C(x_3, y_3)$을 꼭짓점으로 하는 삼각형 $ABC$의 무게중심 $G$의 좌표를 구하는 과정에 대한 설명 중 옳은 것은?

- [x] 변 $BC$의 중점 $M$에 대하여 점 $G$는 선분 $AM$을 $2 : 1$로 내분하는 점이다.
- [ ] 변 $BC$의 중점 $M$에 대하여 점 $G$는 선분 $AM$을 $1 : 2$로 내분하는 점이다.
- [ ] 변 $AB$의 중점 $M$에 대하여 점 $G$는 선분 $CM$을 $3 : 1$로 내분하는 점이다.
- [ ] 세 꼭짓점에서 대변에 내린 수선의 교점이다.

**Hint:** 무게중심은 꼭짓점과 대변의 중점을 연결한 선분(중선)을 몇 대 몇으로 내분하는지 생각해 보세요.

## Question 8
세 점 $A(-2, 2)$, $B(1, -7)$, $C(4, -1)$을 꼭짓점으로 하는 삼각형 $ABC$의 무게중심 $G$의 좌표는?

- [x] $(1, -2)$
- [ ] $(3, -6)$
- [ ] $(-1, 2)$
- [ ] $(\frac{1}{2}, -4)$

**Hint:** 삼각형의 무게중심 좌표는 세 꼭짓점의 $x$좌표의 평균과 $y$좌표의 평균으로 구합니다.

## Question 9
삼각형 $ABC$에서 변 $BC$의 중점을 $M$이라 할 때, $AB^2 + AC^2 = 2(AM^2 + BM^2)$이 성립함을 좌표평면을 이용하여 증명하려고 한다. 직선 $BC$를 $x$축으로, 점 $M$을 원점으로 정하고 점 $A(a, b)$, 점 $B(-c, 0)$이라 할 때, 점 $C$의 좌표는? (단, $c > 0$)

- [x] $(c, 0)$
- [ ] $(0, c)$
- [ ] $(-c, b)$
- [ ] $(2c, 0)$

**Hint:** 점 $M(0,0)$은 변 $BC$의 중점이며, 점 $B$와 점 $C$는 모두 $x$축 위에 있습니다.

## Question 10
좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$를 이은 선분 $AB$의 중점 $M$의 좌표에 대한 설명 중 옳은 것은?

- [x] 선분 $AB$를 $1 : 1$로 내분하는 점의 좌표와 같다.
- [ ] 선분 $AB$를 $2 : 1$로 내분하는 점의 좌표와 같다.
- [ ] 두 점의 $x$좌표와 $y$좌표의 차를 $2$로 나눈 값이다.
- [ ] 원점 $O(0, 0)$과 점 $A$ 사이의 거리의 절반이다.

**Hint:** 중점은 선분을 반으로 나누는 점으로, 내분비 $m:n$에서 $m=n=1$인 특수한 경우입니다.
