# Ⅱ-1-01 집합의 뜻과 포함 관계
교과서 65~69쪽 · 공통수학2

## 학습 목표
- 집합의 개념을 이해하고, 집합을 표현할 수 있다. (p.65)
- 두 집합 사이의 포함 관계를 판단할 수 있다. (p.65)

## 핵심 개념

### 1. 집합의 뜻과 원소
- **집합**: 주어진 기준에 의하여 그 대상을 분명하게 정할 수 있을 때, 그 대상들의 모임 (p.65)
- **원소**: 집합을 이루는 대상 하나하나 (p.65)
- 판단 기준은 "대상을 분명하게 정할 수 있는가"이다.
  - '10의 약수의 모임' → 대상을 분명하게 정할 수 있으므로 집합, 원소는 1, 2, 5, 10 (p.65)
  - '큰 수의 모임' → '큰 수'의 기준이 명확하지 않아 집합이 아니다. (p.65)
- 특별한 언급이 없으면 약수와 배수는 자연수의 범위에서 생각한다. (p.65)
- 일반적으로 집합은 알파벳 대문자 A, B, C, …, 원소는 알파벳 소문자 a, b, c, …로 나타낸다. (p.65)
- 생각 틔우기: 학교 안전 교육 주제(화재 발생 시 안전 수칙, 고카페인 식품 폐해, 태풍 발생 시 대처 요령, 스마트폰 중독 예방, 직업 안전 의식) 중 '재난 안전 영역' 주제는 기준이 분명하지만 '체험형으로 진행하기 쉬운 주제'는 사람마다 다를 수 있음을 비교해 보는 활동 (p.65)

### 2. 원소와 집합의 관계: ∈, ∉
- a가 집합 A의 원소일 때 **a는 집합 A에 속한다**고 하며 `a ∈ A` 로 나타낸다. (원소 ∈ 집합) (p.65)
- b가 집합 B의 원소가 아닐 때 **b는 집합 B에 속하지 않는다**고 하며 `b ∉ B` 로 나타낸다. (p.65)
- 보기: 홀수의 집합을 A라고 하면 `3 ∈ A`, `4 ∉ A` (p.65)
- 기호 ∈의 유래가 되는 영어 단어를 찾아보는 활동이 있다(교과서는 답을 제시하지 않음). (p.65)

### 3. 집합을 나타내는 방법
1. **원소나열법**: { } 안에 집합의 원소를 모두 나열하여 나타내는 방법 (p.66)
   - 8의 약수의 집합: `A = {1, 2, 4, 8}`
   - 원소를 나열하는 **순서는 달리해도 되지만**, 같은 원소를 **중복하여 쓰지는 않는다**. (p.66)
   - 원소의 개수가 많고 원소 사이에 일정한 규칙이 있을 때는 '…'를 사용하여 원소의 일부를 생략하기도 한다. (p.66)
2. **조건제시법**: 집합의 모든 원소가 가진 공통된 성질을 기준으로 제시하여 나타내는 방법 (p.66)
   - `A = {x | x는 8의 약수}`
   - 세로선 왼쪽 x = 원소를 대표하는 문자, 오른쪽 = 원소들이 갖는 공통된 성질 (p.66)
3. **벤 다이어그램**: 집합을 나타내는 그림 (p.66)
   - `A = {1, 2, 4, 8}` 을 원 안에 1, 2, 4, 8을 적어 나타낸다.
   - 벤(Venn, J., 1834~1923): 벤 다이어그램을 고안한 영국의 논리학자 (p.66)
- 보기: 100 이하의 홀수의 집합 B → `B = {1, 3, 5, …, 99}` 또는 `B = {x | x는 100 이하의 홀수}` (p.66)

### 4. 유한집합, 무한집합, 공집합, n(A)
- **유한집합**: 원소가 유한개인 집합 (p.66)
- **무한집합**: 원소가 무수히 많은 집합 (p.66)
- **n(A)**: 집합 A가 유한집합일 때 집합 A의 원소의 개수 (p.66)
- **공집합**: 원소가 하나도 없는 집합, 기호 ∅. 원소가 없으므로 `n(∅) = 0` (p.66)
- 보기 (p.66)
  - `A = {6, 7, 8, 9, 10}` → n(A) = 5
  - `B = {x | x는 2보다 작은 소수}` → 2보다 작은 소수가 없으므로 B = ∅, n(B) = 0

### 5. 부분집합
- 생각 틔우기: 독도 생태 탐사대가 5월과 10월에 관찰한 새의 집합 `A = {딱새, 개똥지빠귀}`, `B = {딱새, 섬참새, 개똥지빠귀, 황조롱이}` → A의 모든 원소가 B에 속하는지 확인 (p.68)
- **부분집합**: 두 집합 A, B에 대하여 집합 A의 모든 원소가 집합 B에 속할 때, A를 B의 부분집합이라 하고 `A ⊂ B` 로 나타낸다. (p.68)
  - 읽는 법: "집합 A는 집합 B에 포함된다" 또는 "집합 B는 집합 A를 포함한다" (p.68)
  - 벤 다이어그램: B를 나타내는 원 안에 A를 나타내는 원이 들어 있다. (p.68)
- 모든 집합은 자기 자신의 부분집합이다: `A ⊂ A` (p.68)
- 공집합은 모든 집합의 부분집합으로 **정한다**: `∅ ⊂ A` (p.68)
- A가 B의 부분집합이 아닐 때 `A ⊄ B` 로 나타낸다. (p.68)
- 보기: `A = {8, 16}`, `B = {4, 8, 16}` (p.68)
  1. A의 모든 원소가 B에 속하므로 `A ⊂ B`
  2. `4 ∈ B` 이지만 `4 ∉ A` 이므로 `B ⊄ A`
- 기호 ⊂의 유래가 되는 영어 단어를 찾아보는 활동이 있다. (p.68)

### 6. 서로 같은 집합, 진부분집합
- **서로 같다**: `A ⊂ B` 이고 `B ⊂ A` 일 때 두 집합 A, B는 서로 같다고 하며 `A = B` 로 나타낸다. (p.68)
- 두 집합이 서로 같지 않을 때 `A ≠ B` 로 나타낸다. (p.68)
- **진부분집합**: `A ⊂ B` 이고 `A ≠ B` 일 때, A를 B의 진부분집합이라고 한다. (p.68)

### 7. 예제 1 — 부분집합과 진부분집합 구하기 (p.68)
- 문제: 집합 `A = {1, 2}` 의 부분집합과 진부분집합을 모두 구하시오.
- 풀이 흐름: 원소의 개수에 따라 나누어 구하면 편리하다.
  - 원소 0개: ∅
  - 원소 1개: {1}, {2}
  - 원소 2개: {1, 2}
- 답: 부분집합은 ∅, {1}, {2}, {1, 2} / 진부분집합은 ∅, {1}, {2} (자기 자신 {1, 2}만 빠진다)

### 8. 역량 키우기 — 부분집합의 개수 탐구 (p.69)
- 집합 `A = {a, b}` 에서 각 원소의 포함 여부를 ○, ×로 표시하는 수형도를 그리면
  - a: ○ 또는 × (2개), b: ○ 또는 × (2²개) → 부분집합 {a, b}, {a}, {b}, ∅ 의 4개
- 이 방법으로 구해 볼 것
  1. 집합 {a, b, c}의 부분집합의 개수 (각 원소가 ○/× 두 가지 → 2×2×2)
  2. 원소의 개수가 k인 집합 {1, 2, 3, …, k}의 부분집합의 개수
  - 확장하기: `A = {1, 2, 3, 4}` 의 부분집합 중에서 원소 1이 속하지 않는 것의 개수

### 9. 스스로 익히기·역량 키우기 문제 유형
- p.67 스스로 익히기
  1. 집합인 것 찾고 원소 말하기: (1) 15보다 작은 소수의 모임 (2) 대한민국 광역시의 모임 (3) 원주율 π와 가까운 유리수의 모임 → '가까운'은 기준이 불분명
  2. 표현법 바꾸기: (1) `{x | x는 10 이상 20 이하의 짝수}` → 원소나열법 (2) `{5, 10, 15, …}` → 조건제시법
  3. 벤 다이어그램으로 나타내기: (1) `A = {x | x는 16의 약수}` (2) `B = {x | x² − 3x + 2 = 0}`
  4. n(A) 구하기: (1) `A = {x | x는 35의 약수}` (2) `A = {x | x는 x² + 1 ≤ 0인 실수}` → 만족하는 실수가 없으므로 공집합
- p.67 역량 키우기(표현하기): '아시아에서 아름다운 산', '인기가 많은 스포츠 종목', '날씨가 추운 나라'의 밑줄 친 부분을 바꾸어 집합이 되게 하기 / 확장: 원소가 3개인 실생활 집합을 원소나열법과 조건제시법으로 표현
- p.69 스스로 익히기
  1. 포함 관계 기호(A ⊂ B, A ⊄ B, A = B, A ≠ B) 모두 연결: (1) `A = {1, 3, 5}`, `B = {x | x는 7 이하의 홀수}` (2) `A = {x | x² − 1 = 0}`, `B = {0, 1, 2}` (3) `A = {1, 2, 7, 14}`, `B = {x | x는 14의 약수}` (4) `A = {x | 2x + 3 = 0}`, `B = {x | x² − 4x < 0}`
  2. `A = {a, b, c}` 의 (1) 부분집합 (2) 진부분집합 모두 구하기 (예제 1 연계)
  3. `A = {4, 6, 2a}`, `B = {10, a+1, 2b}` 에서 A = B일 때 실수 a, b의 값 구하기 → 같은 집합은 원소가 완전히 같아야 한다.

## 비교·정리표

### 집합을 나타내는 세 가지 방법
| 방법 | 형태 | 예 (8의 약수) | 주의 |
|---|---|---|---|
| 원소나열법 | { } 안에 원소를 모두 나열 | `{1, 2, 4, 8}` | 순서 무관, 중복해서 쓰지 않음, 규칙 있으면 '…' 사용 |
| 조건제시법 | `{x \| x의 공통된 성질}` | `{x \| x는 8의 약수}` | x는 원소를 대표하는 문자 |
| 벤 다이어그램 | 원 안에 원소를 적은 그림 | 원 A 안에 1, 2, 4, 8 | 벤(영국 논리학자)이 고안 |

### 기호 비교: ∈ 와 ⊂
| 기호 | 관계 | 왼쪽 | 오른쪽 | 예 |
|---|---|---|---|---|
| ∈ / ∉ | 원소와 집합 | 원소 | 집합 | `3 ∈ A`(홀수의 집합), `4 ∉ A` |
| ⊂ / ⊄ | 집합과 집합 | 집합 | 집합 | `{8, 16} ⊂ {4, 8, 16}` |
| = / ≠ | 집합과 집합 | 집합 | 집합 | A ⊂ B 이고 B ⊂ A ⇔ A = B |

### 부분집합 vs 진부분집합 (A = {1, 2})
| 구분 | 조건 | 자기 자신 포함? | ∅ 포함? | 목록 |
|---|---|---|---|---|
| 부분집합 | A의 모든 원소가 B에 속함 | 포함 | 포함 | ∅, {1}, {2}, {1, 2} |
| 진부분집합 | A ⊂ B 이고 A ≠ B | 제외 | 포함 | ∅, {1}, {2} |

### 집합의 종류
| 종류 | 뜻 | 예 | n( ) |
|---|---|---|---|
| 유한집합 | 원소가 유한개 | {6, 7, 8, 9, 10} | 5 |
| 무한집합 | 원소가 무수히 많음 | 홀수의 집합 | 정의하지 않음(유한집합일 때만 n(A)) |
| 공집합 | 원소가 하나도 없음 | {x \| x는 2보다 작은 소수} | 0 |

## 시험 함정 포인트
- '큰 수의 모임', 'π와 가까운 유리수의 모임'처럼 기준이 분명하지 않은 모임은 집합이 **아니다**. 모임이면 다 집합인 것이 아니라 대상을 분명히 정할 수 있어야 집합이다. (p.65, p.67)
- 원소와 집합 사이에는 ∈, 집합과 집합 사이에는 ⊂를 쓴다. `3 ⊂ A` 가 아니라 `3 ∈ A`, `{3} ∈ A` 가 아니라 `{3} ⊂ A` 이다(A가 홀수의 집합일 때). (p.65, p.68)
- 원소나열법에서 원소의 순서가 바뀌어도 같은 집합이고, 같은 원소는 두 번 쓰지 않는다. {1, 2, 4, 8}과 {8, 4, 2, 1}은 같은 집합이다. (p.66)
- 공집합의 원소의 개수는 0이다. `n(∅) = 0` 이며, 2보다 작은 소수의 집합처럼 조건을 만족하는 원소가 없으면 공집합이다. 1은 소수가 아니다. (p.66)
- 공집합은 모든 집합의 부분집합이고, 진부분집합에도 들어간다. 진부분집합에서 빠지는 것은 ∅가 아니라 **자기 자신**이다. (p.68)
- `A ⊂ B` 라고 해서 `B ⊂ A` 인 것은 아니다. {8, 16} ⊂ {4, 8, 16} 이지만 4 ∈ B, 4 ∉ A 이므로 B ⊄ A. (p.68)
- A = B 는 "원소의 개수가 같다"가 아니라 A ⊂ B 이고 B ⊂ A 일 때이다. (p.68)
- `{x | x는 x² + 1 ≤ 0인 실수}` 처럼 겉보기에 원소가 있을 것 같은 조건도 실제로 만족하는 수가 없으면 공집합, n(A) = 0이다. (p.67)
- 모든 집합은 자기 자신의 부분집합이다(A ⊂ A). 자기 자신은 부분집합에서는 빠지지 않는다. (p.68)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 집합 | 주어진 기준에 의하여 대상을 분명하게 정할 수 있을 때, 그 대상들의 모임 |
| 원소 | 집합을 이루는 대상 하나하나 |
| a ∈ A | a는 집합 A에 속한다(a는 A의 원소) |
| b ∉ B | b는 집합 B에 속하지 않는다 |
| 원소나열법 | { } 안에 원소를 모두 나열하여 집합을 나타내는 방법 |
| 조건제시법 | 원소들이 가진 공통된 성질을 제시하여 `{x \| 성질}` 꼴로 나타내는 방법 |
| 벤 다이어그램 | 집합을 나타내는 그림 |
| 유한집합 | 원소가 유한개인 집합 |
| 무한집합 | 원소가 무수히 많은 집합 |
| n(A) | 유한집합 A의 원소의 개수 |
| 공집합 (∅) | 원소가 하나도 없는 집합, n(∅) = 0 |
| 부분집합 (A ⊂ B) | A의 모든 원소가 B에 속할 때 A는 B의 부분집합 |
| 포함된다 / 포함한다 | A ⊂ B일 때 A는 B에 포함된다, B는 A를 포함한다 |
| A ⊄ B | A가 B의 부분집합이 아님 |
| 서로 같다 (A = B) | A ⊂ B 이고 B ⊂ A |
| A ≠ B | 두 집합이 서로 같지 않음 |
| 진부분집합 | A ⊂ B 이고 A ≠ B 일 때 A는 B의 진부분집합 |

## 자기점검 질문
1. '10의 약수의 모임'은 집합인가? 원소는? — 집합이다. 원소는 1, 2, 5, 10
2. '큰 수의 모임'이 집합이 아닌 이유는? — '큰 수'의 기준이 명확하지 않아 대상을 분명하게 정할 수 없기 때문
3. 홀수의 집합 A에 대하여 3과 4를 기호로 나타내면? — 3 ∈ A, 4 ∉ A
4. 100 이하의 홀수의 집합을 두 가지 방법으로 나타내면? — {1, 3, 5, …, 99}, {x | x는 100 이하의 홀수}
5. `B = {x | x는 2보다 작은 소수}` 일 때 n(B)는? — B = ∅ 이므로 0
6. 공집합과 집합 A의 포함 관계는? — ∅ ⊂ A (공집합은 모든 집합의 부분집합으로 정한다)
7. A = {8, 16}, B = {4, 8, 16}에서 B ⊄ A인 이유는? — 4 ∈ B 이지만 4 ∉ A
