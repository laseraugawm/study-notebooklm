# 함수 퀴즈

## Question 1
집합 $X = \{1, 2, 3\}$에서 집합 $Y = \{a, b, c\}$로의 대응 중 '집합 $X$에서 집합 $Y$로의 함수'에 해당하는 것은?

- [x] 정의역 $X$의 원소 $1$은 $a$, $2$는 $b$, $3$은 $a$에 대응한다.
- [ ] 정의역 $X$의 원소 $1$은 $a$, $2$는 $b$에 대응하고, $3$에 대응하는 원소는 없다.
- [ ] 정의역 $X$의 원소 $1$은 $a$, $2$는 $a$와 $c$, $3$은 $b$에 대응한다.
- [ ] 정의역 $X$의 원소 $1$은 $b$, $3$은 $c$에 대응하고, $2$에 대응하는 원소는 없다.

**Hint:** 함수가 되려면 정의역의 모든 원소가 빠짐없이, 오직 하나의 공역 원소와 짝을 이루어야 합니다.

## Question 2
함수 $f: X \to Y$에 대한 설명 중 항상 옳은 것은?

- [x] 치역은 공역 $Y$의 부분집합이다.
- [ ] 치역의 원소 개수는 항상 정의역 $X$의 원소 개수보다 많아야 한다.
- [ ] 공역과 치역은 모든 함수에서 항상 완전히 일치해야 한다.
- [ ] 정의역의 서로 다른 두 원소는 절대로 공역의 같은 원소에 대응될 수 없다.

**Hint:** 함수의 기본 구조에서 정의역, 공역, 치역 사이의 포함 관계를 떠올려 보세요.

## Question 3
정의역이 $X = \{-1, 2\}$인 두 함수 $f(x) = x^2 + a$와 $g(x) = bx + 1$에 대하여 $f = g$가 성립할 때, 상수 $a$와 $b$의 값은?

- [x] $a = -1, b = 1$
- [ ] $a = 1, b = -1$
- [ ] $a = 0, b = 0$
- [ ] $a = -2, b = 2$

**Hint:** 두 함수가 서로 같으려면 정의역의 모든 원소 $x$에 대해 $f(x) = g(x)$가 성립해야 합니다.

## Question 4
좌표평면에 그려진 도형이나 곡선이 함수 $y = f(x)$의 그래프인지 판별하는 올바른 방법은?

- [x] 정의역의 각 원소 $a$에 대하여 $y$축에 평행한 직선 $x = a$를 그렸을 때, 그래프와 오직 한 점에서 만나는지 확인한다.
- [ ] 공역의 각 원소 $b$에 대하여 $x$축에 평행한 직선 $y = b$를 그렸을 때, 그래프와 오직 한 점에서 만나는지 확인한다.
- [ ] $y$축에 평행한 직선 $x = a$와 두 점 이상에서 만나는 구간이 존재하는지 확인한다.
- [ ] 그래프가 반드시 원점을 지나며 연속된 선으로 연결되어 있는지 확인한다.

**Hint:** 하나의 $x$값에 $y$값이 오직 하나만 대응하는지 확인하는 직선의 방향을 생각해 보세요.

## Question 5
일대일함수와 일대일대응에 대한 설명 중 옳지 않은 것은?

- [x] 모든 일대일함수는 공역과 치역이 같으므로 항상 일대일대응이다.
- [ ] 일대일함수는 정의역의 임의의 두 원소 $x_1, x_2$에 대하여 $x_1 \ne x_2$이면 $f(x_1) \ne f(x_2)$를 만족한다.
- [ ] 일대일대응은 일대일함수 조건인 $x_1 \ne x_2 \implies f(x_1) \ne f(x_2)$를 기본적으로 만족한다.
- [ ] 실수 전체의 집합에서 정의된 일차함수 $f(x) = 2x$는 일대일함수이자 일대일대응이다.

**Hint:** 일대일함수가 일대일대응이 되기 위해 추가로 필요한 조건(공역과 치역의 관계)을 떠올려 보세요.

## Question 6
항등함수와 상수함수에 대한 설명으로 옳은 것은?

- [x] 상수함수의 치역은 원소의 개수가 $1$인 집합이다.
- [ ] 항등함수는 정의역의 모든 원소가 공역의 하나의 원소에 몰려서 대응하므로 상수함수의 일종이다.
- [ ] 상수함수의 치역은 공역의 원소 개수와 상관없이 항상 공역과 완전히 일치한다.
- [ ] 항등함수의 치역은 원소가 하나도 없는 공집합이다.

**Hint:** 정의역의 원소들이 공역의 어디에 어떻게 대응하는지에 주목해 보세요.

## Question 7
실수 전체의 집합에서 정의된 다음 함수 중 '일대일대응'인 것은?

- [x] $f(x) = 5x + 7$
- [ ] $f(x) = -3$
- [ ] $f(x) = x^2$
- [ ] $f(x) = 2|x|$

**Hint:** 서로 다른 $x$값에 대해 함숫값이 모두 다르고, 치역이 실수 전체가 되는 함수를 찾으세요.

## Question 8
실수 전체의 집합에서 정의된 연산 규칙 $y = \begin{cases} x^2 - 2x + 2 & (x \ge 1) \\ -2x + 3 & (x < 1) \end{cases}$ 에 대한 설명으로 옳은 것은?

- [x] 모든 실수 $x$에 대하여 대응하는 $y$의 값이 오직 하나씩 존재하므로 함수이다.
- [ ] $x = 1$일 때 대응하는 $y$의 값이 $2$개이므로 함수가 아니다.
- [ ] 이 함수는 일대일함수 조건을 만족하므로 일대일대응이다.
- [ ] $x < 1$인 구간에서는 $y$의 값이 존재하지 않아 함수라 볼 수 없다.

**Hint:** 구간별로 나누어진 경계값 $x = 1$에서의 대응 상태와 서로 다른 $x$에 대한 $y$값 중복 여부를 점검해 보세요.
