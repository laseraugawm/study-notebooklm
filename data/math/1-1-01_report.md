# Ⅰ-1-01 평면좌표
교과서 13-17쪽 · 수학(공통수학2)

## 학습 목표
- 선분의 내분을 이해하고, 내분점의 좌표를 계산할 수 있다. (p.13)
- 중단원 도입 질문: 무게가 서로 다른 두 사람이 시소에서 평형을 이루는 위치에는 어떤 원리가 있을까? — "시소가 평형을 이루는 원리에 내분이 숨어 있어." (p.12, p.15)

## 핵심 개념

### 1. 두 점 사이의 거리
- **준비하기**: 빗변이 x, 두 변이 6, 3인 직각삼각형에서 피타고라스 정리로 `x² = 6² + 3²` → x = √45 = 3√5 (p.13)
- **생각 틔우기**: 경주 불국사 배치도를 좌표평면에 나타냄. 석가탑 (−9, 0), 다보탑 (9, 0), 대웅전 (0, 12). 석가탑–다보탑, 석가탑–대웅전 사이의 거리를 구하고 방법을 이야기해 보기 (p.13)
  - 석가탑–다보탑: 같은 x축 위이므로 9 − (−9) = 18
  - 석가탑–대웅전: `√(9² + 12²) = √225 = 15`
- **수직선 위의 두 점 사이의 거리**: 두 점 A(x₁), B(x₂)에 대하여 (p.13)
  - x₁ ≤ x₂ 이면 AB = x₂ − x₁
  - x₁ > x₂ 이면 AB = x₁ − x₂
  - 따라서 **AB = |x₂ − x₁|**
  - 보기: A(−6), B(−1) → AB = |−1 − (−6)| = 5
- **좌표평면 위의 두 점 사이의 거리**: 두 점 A(x₁, y₁), B(x₂, y₂) (p.13)
  - 유도: 점 A를 지나고 x축에 평행한 직선과 점 B를 지나고 y축에 평행한 직선의 교점을 C(x₂, y₁)라 하면 삼각형 ABC는 직각삼각형
  - 피타고라스 정리: `AB² = AC² + BC² = |x₂ − x₁|² + |y₂ − y₁|² = (x₂ − x₁)² + (y₂ − y₁)²`
  - 따라서 **`AB = √((x₂ − x₁)² + (y₂ − y₁)²)`**
  - 원점 O(0, 0)과 점 A(x₁, y₁) 사이의 거리: `OA = √(x₁² + y₁²)` (p.13 날개)
  - 보기: A(1, −2), B(−3, 2) → `AB = √((−3−1)² + {2−(−2)}²) = √32 = 4√2`
- 인물: **데카르트**(Descartes, R., 1596~1650) — 좌표계를 최초로 제안한 프랑스의 수학자 (p.13)

### 2. 예제 1 — 세 변의 길이로 삼각형의 모양 판정 (p.14)
- 문제: 세 점 A(−1, 2), B(−4, −2), C(3, −1)을 꼭짓점으로 하는 삼각형 ABC는 어떤 삼각형인가?
- 풀이 흐름
  1. `AB = √({−4−(−1)}² + (−2−2)²) = 5`
  2. `BC = √({3−(−4)}² + {−1−(−2)}²) = 5√2`
  3. `CA = √((−1−3)² + {2−(−1)}²) = 5`
  4. AB² + CA² = BC² (25 + 25 = 50) 이고 AB = CA
- 답: **∠A = 90°인 직각이등변삼각형**
- 판정 요령: 세 변의 길이를 모두 구한 뒤 ① 같은 길이가 있는지(이등변·정삼각형), ② 피타고라스 관계가 성립하는지(직각) 확인한다.

### 3. 스스로 익히기 (p.14)
1. 두 점 사이의 거리: ⑴ A(4), B(7) ⑵ A(−12), B(−4) ⑶ A(−2, −2), B(2, 1) ⑷ A(0, 0), B(−2, 3)
   - 계산하면 ⑴ 3 ⑵ 8 ⑶ 5 ⑷ √13
2. 세 점 A(2, 3√3), B(2, −√3), C(−4, √3)을 꼭짓점으로 하는 삼각형 ABC는 어떤 삼각형인가 (예제 1 유형)
   - 계산하면 AB = 4√3, BC = √(36 + 12) = 4√3, CA = √(36 + 12) = 4√3 → 정삼각형

### 4. 역량 키우기(추론·증명하기) — 중선 정리 (p.14)
- 삼각형 ABC에서 변 BC의 중점을 M이라 할 때 **`AB² + AC² = 2(AM² + BM²)`** 가 성립함을 단계별로 확인
  - 1단계: 직선 BC를 x축, 점 M을 원점으로 정하고 A(a, b), B(−c, 0)이라 하면 점 C의 좌표는 (c, 0)
  - 2단계: `AB² + AC² = {(a+c)² + b²} + {(a−c)² + b²} = 2(a² + b² + c²)`, `AM² + BM² = a² + b² + c²`
  - 3단계: 따라서 AB² + AC² = 2(AM² + BM²)
- 포인트: 계산이 쉬워지도록 **좌표축과 원점을 도형에 맞게 잡는다**.

### 5. 선분의 내분 (p.15)
- **준비하기**: 두 점 A(−2), B(8) 사이의 거리 → 10
- **내분**: 선분 AB 위의 점 P에 대하여 `AP : PB = m : n (m > 0, n > 0)` 일 때, 점 P는 선분 AB를 m : n으로 **내분**한다고 한다. 점 P를 선분 AB의 **내분점**이라고 한다. (p.15)
- **수직선 위의 내분점** 유도 (p.15)
  - (ⅰ) x₁ < x₂ 일 때 AP = x − x₁, PB = x₂ − x 이고 `(x − x₁) : (x₂ − x) = m : n` → `x = (mx₂ + nx₁)/(m + n)`
  - (ⅱ) x₁ > x₂ 일 때도 같은 방법으로 동일한 결과
  - 선분 AB의 중점 M의 좌표: `(x₁ + x₂)/2` (날개)
- **좌표평면 위의 내분점** 유도 (p.15)
  - 세 점 A, P, B에서 x축에 내린 수선의 발을 A′, P′, B′이라 하면 `AP : PB = A′P′ : P′B′ = m : n`
  - 근거: 이전에 배운 내용(중2) — 평행선 사이의 선분의 길이의 비. l ∥ m ∥ n 이면 a : b = a′ : b′
  - 점 P′은 선분 A′B′을 m : n으로 내분하므로 x좌표 `x = (mx₂ + nx₁)/(m + n)`, 같은 방법으로 `y = (my₂ + ny₁)/(m + n)`
  - 중점 M의 좌표: `((x₁ + x₂)/2, (y₁ + y₂)/2)` (날개)
- **선분의 내분점 정리** (p.16)
  1. 수직선: A(x₁), B(x₂)를 이은 선분 AB를 m : n으로 내분하는 점 P의 좌표는 `(mx₂ + nx₁)/(m + n)`
  2. 좌표평면: A(x₁, y₁), B(x₂, y₂)를 이은 선분 AB를 m : n으로 내분하는 점 P의 좌표는 `((mx₂ + nx₁)/(m + n), (my₂ + ny₁)/(m + n))`
- 보기 (p.16)
  - A(−4), B(6)을 3 : 2로 내분: `(3×6 + 2×(−4))/(3 + 2) = 2`
  - A(1, −1), B(4, 5)를 2 : 1로 내분: `((2×4 + 1×1)/(2+1), (2×5 + 1×(−1))/(2+1))`, 즉 (3, 3)

### 6. 예제 1 (p.16) — 삼각형의 무게중심
- 문제: 세 점 A(x₁, y₁), B(x₂, y₂), C(x₃, y₃)을 꼭짓점으로 하는 삼각형 ABC의 무게중심 G의 좌표
- 풀이 흐름
  1. 변 BC의 중점 M의 좌표: `((x₂ + x₃)/2, (y₂ + y₃)/2)`
  2. 무게중심 G(x, y)는 선분 **AM을 2 : 1로 내분**하는 점
  3. `x = (2 × (x₂ + x₃)/2 + 1 × x₁)/(2 + 1) = (x₁ + x₂ + x₃)/3`, y도 같은 방법으로 `(y₁ + y₂ + y₃)/3`
- 답: **`G((x₁ + x₂ + x₃)/3, (y₁ + y₂ + y₃)/3)`**

### 7. 스스로 익히기 (p.17)
1. A(−9), B(5): ⑴ 3 : 4로 내분하는 점 ⑵ 중점 → 계산하면 ⑴ (15 − 36)/7 = −3 ⑵ −2
2. A(1, −4), B(7, 8): ⑴ 1 : 5로 내분하는 점 ⑵ 중점 → 계산하면 ⑴ (2, −2) ⑵ (4, 2)
3. A(2, a), B(−2, 3)에 대하여 선분 AB를 1 : 3으로 내분하는 점이 x축 위에 있을 때 a의 값 → 내분점의 y좌표 `(1×3 + 3×a)/4 = 0` 에서 a = −1
4. 무게중심 G (예제 1 유형): ⑴ A(0, 0), B(−5, 2), C(−1, 1) ⑵ A(−2, 2), B(1, −7), C(4, −1) → 계산하면 ⑴ (−2, 1) ⑵ (1, −2)

### 8. 역량 키우기(의사소통·원리 설명하기) (p.17)
- 삼각형 ABC의 세 변 AB, BC, CA를 m : n으로 내분하는 점을 각각 D, E, F라 할 때, m : n = 1 : 1인 경우와 m : n = 2 : 1인 경우에 삼각형 ABC, DEF의 무게중심이 각각 일치함을 설명해 보기
- 만화 속 힌트: "1 : 1이면 삼각형의 성질을 이용해서 구할 수 있겠는데?", "2 : 1인 경우는 쉽지 않네.", "좌표평면을 이용해 볼까?"
  - 좌표로 D, E, F를 내분점 공식으로 나타낸 뒤 세 좌표의 합을 3으로 나누면 두 무게중심을 비교할 수 있다.

## 비교·정리표

### 표 1. 거리 공식 비교
| 구분 | 두 점 | 거리 공식 | 보기 |
|---|---|---|---|
| 수직선 | A(x₁), B(x₂) | `AB = \|x₂ − x₁\|` | A(−6), B(−1) → 5 |
| 좌표평면 | A(x₁, y₁), B(x₂, y₂) | `AB = √((x₂−x₁)² + (y₂−y₁)²)` | A(1, −2), B(−3, 2) → 4√2 |
| 원점과 한 점 | O(0, 0), A(x₁, y₁) | `OA = √(x₁² + y₁²)` | — |

### 표 2. 내분점·중점·무게중심
| 구하는 점 | 공식 | 핵심 |
|---|---|---|
| m : n 내분점(수직선) | `(mx₂ + nx₁)/(m + n)` | m은 B 쪽 좌표, n은 A 쪽 좌표에 곱함 |
| m : n 내분점(평면) | `((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n))` | x, y 따로 같은 공식 |
| 중점 | `((x₁+x₂)/2, (y₁+y₂)/2)` | 1 : 1 내분점 |
| 삼각형 무게중심 | `((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)` | 중선 AM을 2 : 1로 내분 |

### 표 3. 세 변의 길이로 삼각형 판정
| 조건 | 삼각형 | 교과서 예 |
|---|---|---|
| 두 변 길이 같고, 긴 변² = 나머지 두 변² 합 | 직각이등변삼각형 | A(−1, 2), B(−4, −2), C(3, −1): AB = CA = 5, BC = 5√2 (p.14) |
| 세 변 길이 모두 같음 | 정삼각형 | 스스로 익히기 2 (p.14) |

## 시험 함정 포인트
- 수직선 위 두 점 사이의 거리는 x₂ − x₁ 이 아니라 **|x₂ − x₁|** 이다. 순서에 따라 음수가 될 수 있으므로 절댓값을 붙인다. (p.13)
- 좌표평면 거리 공식에서 `(x₂ − x₁)² + (y₂ − y₁)²` 의 제곱근을 취해야 한다. 제곱합 자체(예: 32)를 거리로 쓰는 것이 아니라 √32 = 4√2 이다. (p.13)
- 음수 좌표를 뺄 때 괄호를 빠뜨리기 쉽다: 2 − (−2) = 4 이지 0 이 아니다. (p.13 보기)
- 내분점 공식은 `(mx₁ + nx₂)/(m+n)` 이 아니라 **`(mx₂ + nx₁)/(m+n)`** 이다. m(A 쪽 비)은 B의 좌표 x₂에, n은 A의 좌표 x₁에 곱한다(엇갈려 곱함). (p.15)
- 무게중심은 중선 AM을 1 : 2가 아니라 **꼭짓점 A 쪽에서 2 : 1** 로 내분하는 점이다. (p.16)
- 무게중심 좌표는 세 꼭짓점 좌표의 합을 2가 아니라 **3으로** 나눈다. (p.16)
- 삼각형 모양 판정에서 직각만 확인하고 끝내면 안 된다. 예제 1은 AB = CA 이므로 그냥 직각삼각형이 아니라 **직각이등변삼각형**이고, 직각인 꼭짓점은 빗변 BC의 맞은편 **∠A** 이다. (p.14)
- 내분은 m > 0, n > 0 인 경우이고, 내분점 P는 **선분 AB 위**에 있다. (p.15)
- "내분점이 x축 위에 있다"는 조건은 **y좌표 = 0** 이다(x좌표 = 0 은 y축 위). (p.17 스스로 익히기 3)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 두 점 사이의 거리 | 두 점을 잇는 선분의 길이. 좌표평면에서는 피타고라스 정리로 `√((x₂−x₁)² + (y₂−y₁)²)` (p.13) |
| 내분 | 선분 AB 위의 점 P가 `AP : PB = m : n (m > 0, n > 0)` 을 만족할 때, P가 선분 AB를 m : n으로 내분한다고 함 (p.15) |
| 내분점 | 선분 AB를 m : n으로 내분하는 점 P (p.15) |
| 중점 | 선분을 1 : 1로 내분하는 점, `((x₁+x₂)/2, (y₁+y₂)/2)` (p.15) |
| 무게중심 | 삼각형의 중선 AM을 2 : 1로 내분하는 점, 좌표는 세 꼭짓점 좌표의 평균 (p.16) |
| 수선의 발 | 점에서 직선(x축)에 수직으로 내린 선이 만나는 점, 내분점 유도에 사용 (p.15) |
| 직각이등변삼각형 | 두 변의 길이가 같고 한 각이 90°인 삼각형 (p.14) |
| 데카르트 | 좌표계를 최초로 제안한 프랑스 수학자(1596~1650) (p.13) |

## 자기점검 질문
1. 수직선 위의 두 점 A(−6), B(−1) 사이의 거리는? — |−1 − (−6)| = 5
2. 두 점 A(1, −2), B(−3, 2) 사이의 거리는? — √32 = 4√2
3. 좌표평면 거리 공식은 어떤 정리로 유도하는가? — 피타고라스 정리(점 C(x₂, y₁)를 잡아 직각삼각형을 만든다)
4. 세 점 A(−1, 2), B(−4, −2), C(3, −1)로 만든 삼각형은? — ∠A = 90°인 직각이등변삼각형
5. 두 점 A(x₁), B(x₂)를 m : n으로 내분하는 점의 좌표는? — `(mx₂ + nx₁)/(m + n)`
6. A(−4), B(6)을 3 : 2로 내분하는 점의 좌표는? — 2
7. A(1, −1), B(4, 5)를 2 : 1로 내분하는 점의 좌표는? — (3, 3)
8. 삼각형의 무게중심은 중선을 어떤 비로 내분하는가? — 꼭짓점에서부터 2 : 1
9. 세 꼭짓점이 A(x₁, y₁), B(x₂, y₂), C(x₃, y₃)인 삼각형의 무게중심은? — `((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)`
10. 중선 정리 AB² + AC² = 2(AM² + BM²)를 좌표로 확인할 때 좌표축은 어떻게 잡는가? — 직선 BC를 x축, 중점 M을 원점으로 잡는다
