# 평행이동 퀴즈

## Question 1
점 $(x, y)$를 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동할 때와 방정식 $f(x, y)=0$이 나타내는 도형을 동일하게 평행이동할 때의 관계에 대한 설명으로 옳은 것은?

- [x] 점은 좌표에 이동량을 직접 더한 $(x+a, y+b)$가 되고, 도형은 $x, y$ 대신 각각 $x-a, y-b$를 대입한 $f(x-a, y-b)=0$이 된다.
- [ ] 점과 도형 모두 이동량을 직접 더하여 점은 $(x+a, y+b)$, 도형은 $f(x+a, y+b)=0$이 된다.
- [ ] 점은 이동량을 뺀 $(x-a, y-b)$가 되고, 도형은 이동량을 더한 $f(x+a, y+b)=0$이 된다.
- [ ] 점은 $x$축 방향 이동량만 더하고, 도형은 $y$축 방향 이동량만 빼서 나타낸다.

**Hint:** 점의 좌표 이동과 도형 방정식에서의 변수 대입 시 부호 차이를 떠올려 보세요.

## Question 2
이차함수 $y=(x-1)^2-2$의 그래프는 이차함수 $y=x^2$의 그래프를 어떻게 평행이동한 것인가?

- [x] $x$축의 방향으로 $1$만큼, $y$축의 방향으로 $-2$만큼
- [ ] $x$축의 방향으로 $-1$만큼, $y$축의 방향으로 $-2$만큼
- [ ] $x$축의 방향으로 $1$만큼, $y$축의 방향으로 $2$만큼
- [ ] $x$축의 방향으로 $-1$만큼, $y$축의 방향으로 $2$만큼

**Hint:** $y+2=(x-1)^2$ 꼴로 변형하여 변수 대입 관계를 확인해 보세요.

## Question 3
점 $(5, -4)$를 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $2$만큼 평행이동하였더니 점 $(2, b)$로 옮겨졌다. 이때 $a+b$의 값은?

- [x] $-5$
- [ ] $-1$
- [ ] $1$
- [ ] $5$

**Hint:** 점의 평행이동 공식 $(x+a, y+b)$를 이용해 $a$와 $b$를 각각 구하세요.

## Question 4
방정식 $3x-y-5=0$이 나타내는 직선을 $x$축의 방향으로 $-2$만큼, $y$축의 방향으로 $1$만큼 평행이동한 도형의 방정식은?

- [x] $3x-y+2=0$
- [ ] $3x-y-12=0$
- [ ] $3x-y-6=0$
- [ ] $3x-y=0$

**Hint:** $x$ 대신 $(x+2)$, $y$ 대신 $(y-1)$을 식에 대입하여 정리하세요.

## Question 5
원 $x^2+y^2+6x-4y=3$을 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동하였더니 원 $x^2+y^2=r^2$ ($r>0$)과 일치하였다. 이때 $a+b+r$의 값은?

- [x] $5$
- [ ] $3$
- [ ] $9$
- [ ] $1$

**Hint:** 원의 방정식을 표준형으로 바꾸어 중심의 좌표 변화와 반지름 $r$을 구해 보세요.

## Question 6
방정식 $f(x, y)=0$이 나타내는 도형을 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동한 도형의 방정식이 $f(x-a, y-b)=0$이 됨을 유도하는 과정이다. 빈칸 (가), (나)에 들어갈 식으로 알맞게 짝지어진 것은?

「도형 $f(x, y)=0$ 위의 점 $P(x, y)$를 평행이동한 점을 $P'(x', y')$이라고 하면
$x'=x+a, y'=y+b$이므로
$x =$ (가), $y =$ (나)
이다. 이것을 $f(x, y)=0$에 대입하면 $f(x'-a, y'-b)=0$이다.」

- [x] (가) $x'-a$, (나) $y'-b$
- [ ] (가) $x'+a$, (나) $y'+b$
- [ ] (가) $x'-b$, (나) $y'-a$
- [ ] (가) $a-x'$, (나) $b-y'$

**Hint:** $x'=x+a$와 $y'=y+b$를 각각 $x$와 $y$에 관하여 이항하여 정리하세요.

## Question 7
방정식 $(x-1)^2+(y+2)^2=4$가 나타내는 원을 $x$축의 방향으로 $1$만큼, $y$축의 방향으로 $-2$만큼 평행이동한 도형의 방정식은?

- [x] $(x-2)^2+(y+4)^2=4$
- [ ] $x^2+y^2=4$
- [ ] $(x-2)^2+y^2=4$
- [ ] $(x+2)^2+(y-4)^2=4$

**Hint:** 기존 방정식의 $x$ 자리에 $(x-1)$을, $y$ 자리에 $(y+2)$를 각각 대입하세요.

## Question 8
좌표평면 위에서 점 $P(3, -2)$를 $x$축의 방향으로 $-1$만큼, $y$축의 방향으로 $5$만큼 평행이동한 점을 $P'$이라 하고, 점 $Q(-1, 3)$을 $x$축의 방향으로 $4$만큼, $y$축의 방향으로 $-3$만큼 평행이동한 점을 $Q'$이라 할 때, 두 점 $P'$과 $Q'$ 사이의 거리는?

- [x] $\sqrt{10}$
- [ ] $\sqrt{5}$
- [ ] $5$
- [ ] $10$

**Hint:** 두 옮겨진 점 $P'$과 $Q'$의 좌표를 각각 구한 뒤, 좌표평면 위의 두 점 사이의 거리 공식을 사용하세요.

## Question 9
좌표평면 위에 나타나는 도형과 그 방정식 및 변환에 대한 설명으로 옳지 않은 것은?

- [x] 방정식 $f(x, y)=0$이 나타내는 도형을 $x$축 방향으로 $a$만큼, $y$축 방향으로 $b$만큼 평행이동하면 $f(x+a, y+b)=0$이 된다.
- [ ] 방정식 $ax+by+c=0$ ($a \neq 0$ 또는 $b \neq 0$)은 좌표평면 위에서 직선을 나타낸다.
- [ ] 방정식 $x^2+y^2+Ax+By+C=0$ ($A^2+B^2-4C>0$)은 좌표평면 위에서 원을 나타낸다.
- [ ] 점 $(x, y)$를 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동한 점의 좌표는 $(x+a, y+b)$이다.

**Hint:** 도형을 평행이동할 때 방정식의 변수 $x, y$ 대신 대입해야 하는 식의 부호를 점검하세요.

- [ ] $\frac{\sqrt{5}}{5}$

- [ ] $\frac{4}{5}$
