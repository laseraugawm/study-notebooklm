# Ⅱ-2-02 명제 사이의 관계
교과서 88~91쪽 · 공통수학2

## 학습 목표
- 명제의 역과 대우를 이해하고 설명할 수 있다. (p.88)
- 충분조건과 필요조건을 이해하고 판단할 수 있다. (p.88)

## 핵심 개념

### 1. 명제의 역과 대우
- 준비하기: 명제 '모든 직사각형은 정사각형이다.'의 참, 거짓 판별 (p.88)
- 생각 틔우기(민주 시민): "대한민국 국민이 아니면 대한민국 국회의원 피선거권이 없다."와 의미가 같도록 "대한민국 국회의원 피선거권이 있으면 ( )."의 빈칸 채우기 → 대우의 생각(빈칸: 대한민국 국민이다) (p.88)
- 명제 p → q에 대하여 가정과 결론을 서로 바꾸거나, 가정과 결론의 부정을 이용하여 새로운 명제를 만들 수 있다. (p.88)
- **역**: 명제 p → q에 대하여 `q → p` (가정과 결론을 바꿈) (p.88)
- **대우**: 명제 p → q에 대하여 `~q → ~p` (바꾸고 둘 다 부정) (p.88)
- 역(逆)의 한자의 뜻을 찾아보는 활동이 있다. (p.88)
- 보기: 명제 'x = −2이면 |x| = 2이다.' (p.88)
  1. 역: |x| = 2이면 x = −2이다.
  2. 대우: |x| ≠ 2이면 x ≠ −2이다.

### 2. 명제와 그 대우의 참, 거짓 관계 (p.88)
- p, q의 진리집합을 P, Q라 하면 ~p, ~q의 진리집합은 Pᶜ, Qᶜ
- `P ⊂ Q` 이면 `Qᶜ ⊂ Pᶜ` 이므로 p → q가 참이면 ~q → ~p도 참
- 역으로 `Qᶜ ⊂ Pᶜ` 이면 `P ⊂ Q` 이므로 ~q → ~p가 참이면 p → q도 참
- 그림: 전체집합 U 안에서 원 Q 안에 원 P가 있으면, Q 바깥(Qᶜ)은 P 바깥(Pᶜ)에 들어간다. `P ⊂ Q ⇒ Qᶜ ⊂ Pᶜ`
- **결론: 명제 p → q와 그 대우 ~q → ~p의 참, 거짓은 일치한다.** (p.88)

### 3. 예제 1 (p.89) — 대우 만들고 판별
- 문제: 명제 'x = 3이면 x² − 3x = 0이다.'의 대우를 말하고, 참, 거짓을 판별
- 풀이 흐름
  1. 대우: 'x² − 3x ≠ 0이면 x ≠ 3이다.'
  2. p: x = 3, q: x² − 3x = 0 → `P = {3}`, `Q = {0, 3}`
  3. P ⊂ Q이므로 주어진 명제는 참이고, 그 대우도 참
- 답: x² − 3x ≠ 0이면 x ≠ 3이다. (참)

### 4. 스스로 익히기 (p.89)
1. 그림의 ㉠, ㉡, ㉢ 채우기: p → q와 역 관계인 ㉠(q → p), 대우 관계인 ㉢(~q → ~p), ㉠과 대우이자 ㉢과 역 관계인 ㉡(~p → ~q)
2. (예제 1 연계) 역과 대우를 말하고 참, 거짓 판별: (1) x² − 2x = 0이면 x = 2이다. (2) x² < 16이면 −4 < x < 4이다.
3. 명제 'x² + ax − 6 ≠ 0이면 x ≠ 2이다.'가 참일 때 상수 a의 값 → 대우 'x = 2이면 x² + ax − 6 = 0이다.'가 참이므로 x = 2를 대입
- 역량 키우기(수학적 사고와 전략 설명하기): 한 면엔 숫자, 다른 면엔 알파벳이 적힌 카드 D, 5, A, 8. 명제 '카드의 한 면에 알파벳 자음이 적혀 있으면 다른 쪽 면에는 짝수가 적혀 있다.'가 참인지 확인하려면 반드시 뒤집어 봐야 하는 카드를 고르고 까닭 설명 — 힌트: "명제의 대우를 생각해 보자!" (자음 D, 그리고 대우 '홀수이면 모음이다'를 확인할 5) (p.89)

### 5. 충분조건과 필요조건
- 준비하기: 명제 'a² > 0이면 a > 0이다.'의 참, 거짓 판별 (p.90)
- 명제 p → q가 참일 때 기호로 `p ⇒ q` 로 나타낸다. 이때 (p.90)
  - **p는 q이기 위한 충분조건**
  - **q는 p이기 위한 필요조건**
- 보기: 'p: x는 4의 배수이다.', 'q: x는 2의 배수이다.' → p ⇒ q이므로 p는 q이기 위한 충분조건, q는 p이기 위한 필요조건 (p.90)
- `p ⇒ q` 이고 `q ⇒ p` 일 때 `p ⇔ q` 로 나타내고 **p는 q이기 위한 필요충분조건**이라 한다. 이때 q도 p이기 위한 필요충분조건이다. (p.90)
- 보기: 'p: x는 2의 배수이다.', 'q: x는 짝수이다.' → p ⇔ q이므로 p는 q이기 위한 필요충분조건 (p.90)

### 6. 진리집합으로 판단하기 (p.90)
두 조건 p, q의 진리집합을 각각 P, Q라고 할 때
- `P ⊂ Q` 이면 p ⇒ q 이므로 p는 q이기 위한 충분조건
- `Q ⊂ P` 이면 q ⇒ p 이므로 p는 q이기 위한 필요조건
- `P = Q` 이면 p ⇔ q 이므로 p는 q이기 위한 필요충분조건
- 기억법(교과서 그림): `p ⇒ q` 에서 화살표 출발점 p는 'q이기 위한 충분조건', 도착점 q는 'p이기 위한 필요조건' (p.90)

### 7. 예제 1 (p.90) — 어떤 조건인지 판단
- 문제: 'p: |x| ≤ 2', 'q: −3 ≤ x ≤ 3'일 때 p는 q이기 위한 어떤 조건인가?
- 풀이 흐름
  1. `P = {x | −2 ≤ x ≤ 2}`, `Q = {x | −3 ≤ x ≤ 3}`
  2. 수직선에서 [−2, 2]는 [−3, 3] 안에 있으므로 P ⊂ Q이고 Q ⊄ P
  3. 따라서 p는 q이기 위한 충분조건이지만 필요조건은 아니다.
- 답: 충분조건

### 8. 스스로 익히기 (p.91)
1. (예제 1 연계) p는 q이기 위한 어떤 조건인가: (1) p: x = 1, q: x² + 2x − 3 = 0 (2) p: x < 1, q: x² < 1 (3) p: |x| = 2, q: x² = 4
2. 두 집합 A, B에 대하여 (1) p: A ∩ B = A, q: A ∪ B = B (2) p: A − B = ∅, q: A = B
3. 'p: (x + 1)² = 0', 'q: x² + 3x + a = 0'에서 p가 q이기 위한 충분조건일 때 상수 a → P ⊂ Q 이므로 x = −1이 q를 만족해야 한다.
- 역량 키우기(원리 탐구하기): **삼단논법** — 두 전제로부터 결론을 이끌어 내는 논리 전개 방법. 두 전제가 참이면 삼단논법에서 결론은 항상 참이다. (p.91)
  - 예: (전제 1) 고래는 포유류이다. (전제 2) 포유류는 동물이다. → (결론) 따라서 고래는 동물이다.
  - 문제: p는 r이기 위한 충분조건, q는 r이기 위한 필요조건일 때 (1) r → p (2) ~q → ~r (3) p → q (4) ~q → ~p 중 참인 것 찾기 (p ⇒ r, r ⇒ q 이므로 삼단논법으로 p ⇒ q, 그리고 대우 활용)

## 비교·정리표

### 명제 p → q 의 역·대우·이
| 이름 | 꼴 | 'x = −2이면 \|x\| = 2'의 경우 | 원래 명제와 참·거짓 |
|---|---|---|---|
| 원래 명제 | p → q | x = −2이면 \|x\| = 2 (참) | — |
| 역 | q → p | \|x\| = 2이면 x = −2 (거짓, x = 2) | 일치하지 않을 수 있음 |
| 대우 | ~q → ~p | \|x\| ≠ 2이면 x ≠ −2 (참) | 항상 일치 |
| ㉡ (역의 대우) | ~p → ~q | x ≠ −2이면 \|x\| ≠ 2 | 역과 참·거짓 일치 |

(㉡은 p.89 스스로 익히기 1의 그림 자리이며 교과서는 별도 이름을 쓰지 않는다.)

### 충분·필요·필요충분조건
| 진리집합 관계 | 기호 | p는 q이기 위한 | 교과서 예 |
|---|---|---|---|
| P ⊂ Q | p ⇒ q | 충분조건 | p: 4의 배수, q: 2의 배수 |
| Q ⊂ P | q ⇒ p | 필요조건 | (위에서 q는 p이기 위한 필요조건) |
| P = Q | p ⇔ q | 필요충분조건 | p: 2의 배수, q: 짝수 |
| P ⊂ Q, Q ⊄ P | p ⇒ q만 | 충분조건이지만 필요조건은 아님 | p: \|x\| ≤ 2, q: −3 ≤ x ≤ 3 |

### 화살표 기호 구분
| 기호 | 뜻 | 쓰는 때 |
|---|---|---|
| p → q | 명제 'p이면 q이다.' | 참·거짓과 관계없이 명제를 나타냄 |
| p ⇒ q | 명제 p → q가 참 | 참일 때만 |
| p ⇔ q | p ⇒ q 이고 q ⇒ p | 필요충분조건 |

## 시험 함정 포인트
- 명제가 참이라도 그 **역**은 참이라는 보장이 없다. 'x = −2이면 |x| = 2'는 참이지만 역 '|x| = 2이면 x = −2'는 x = 2가 반례라 거짓. 참·거짓이 항상 일치하는 것은 **대우**이다. (p.88)
- 대우는 가정과 결론을 바꾸기만 하는 것이 아니라 **바꾸고 둘 다 부정**한다. p → q의 대우는 ~p → ~q가 아니라 ~q → ~p이다. (p.88)
- 'p는 q이기 위한 충분조건'은 P ⊂ Q일 때다. 집합이 **작은 쪽이 충분조건**, 큰 쪽이 필요조건이다. P = [−2, 2], Q = [−3, 3]에서 p가 충분조건. (p.90)
- p ⇒ q일 때 "q는 p이기 위한 충분조건"이라고 거꾸로 말하면 틀린다. q는 p이기 위한 **필요조건**이다. (p.90)
- p → q 와 p ⇒ q 는 다르다. ⇒는 명제 p → q가 **참일 때만** 쓴다. (p.90)
- 필요충분조건은 한쪽 방향만이 아니라 p ⇒ q 이고 q ⇒ p 둘 다 성립해야 한다(P = Q). 이때 q도 p이기 위한 필요충분조건이다. (p.90)
- 명제가 참인지 직접 판단하기 어려우면 대우를 판별해도 된다. 'x² + ax − 6 ≠ 0이면 x ≠ 2'는 대우 'x = 2이면 x² + ax − 6 = 0'으로 바꾸어 푼다. (p.88, p.89)
- 카드 문제에서 뒤집어 볼 카드는 자음 카드만이 아니다. 대우 '짝수가 아니면(홀수이면) 자음이 아니다'를 확인하려면 홀수 카드도 뒤집어야 하고, 짝수 카드(8)나 모음 카드(A)는 뒤집을 필요가 없다. (p.89)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 역 | 명제 p → q에 대하여 q → p |
| 대우 | 명제 p → q에 대하여 ~q → ~p |
| 명제와 대우의 관계 | p → q와 ~q → ~p의 참, 거짓은 일치한다 |
| p ⇒ q | 명제 p → q가 참임을 나타내는 기호 |
| 충분조건 | p ⇒ q일 때 p는 q이기 위한 충분조건 |
| 필요조건 | p ⇒ q일 때 q는 p이기 위한 필요조건 |
| p ⇔ q | p ⇒ q 이고 q ⇒ p |
| 필요충분조건 | p ⇔ q일 때 p는 q이기 위한 필요충분조건(q도 p이기 위한 필요충분조건) |
| 삼단논법 | 두 전제로부터 결론을 이끌어 내는 논리 전개 방법, 두 전제가 참이면 결론은 항상 참 |

## 자기점검 질문
1. 명제 p → q의 역과 대우는? — 역: q → p, 대우: ~q → ~p
2. 'x = −2이면 |x| = 2이다.'의 대우는? — |x| ≠ 2이면 x ≠ −2이다.
3. 명제와 대우의 참, 거짓이 일치하는 이유를 진리집합으로 말하면? — P ⊂ Q ⇔ Qᶜ ⊂ Pᶜ
4. 'x = 3이면 x² − 3x = 0이다.'와 그 대우의 참, 거짓은? — P = {3} ⊂ Q = {0, 3} 이므로 둘 다 참
5. p ⇒ q일 때 p와 q는 각각 무엇인가? — p는 q이기 위한 충분조건, q는 p이기 위한 필요조건
6. Q ⊂ P일 때 p는 q이기 위한 어떤 조건? — 필요조건
7. 'p: x는 2의 배수', 'q: x는 짝수'의 관계는? — p ⇔ q, 필요충분조건
8. 'p: |x| ≤ 2', 'q: −3 ≤ x ≤ 3'에서 p는 q이기 위한? — 충분조건(필요조건은 아님)
9. 삼단논법에서 두 전제가 참이면 결론은? — 항상 참
10. 카드 D, 5, A, 8 문제에서 대우를 이용하는 까닭은? — '짝수가 아니면 자음이 아니다'가 원래 명제와 참·거짓이 같아, 홀수 카드도 확인해야 하기 때문
