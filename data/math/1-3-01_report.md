# Ⅰ-3-01 평행이동

## 학습 목표
- 평행이동을 탐구하고, 실생활과 연결하여 문제를 해결할 수 있다. (p.45)
- 중단원 도입(p.44): 이상 시인의 '오감도' 제4호처럼 좌우가 바뀐 숫자는 어떻게 인쇄했을까? — "글자와 활자는 좌우 대칭이니까 실제 글자 형태로 활자를 만들어서 인쇄하지 않았을까?"

## 핵심 개념

### 1. 점의 평행이동 (p.45)
- **준비하기**: 이차함수 y = (x − 1)² − 2 의 그래프는 y = x² 의 그래프를 x축의 방향으로 1만큼, y축의 방향으로 −2만큼 평행이동한 것
- **생각 틔우기**: 알지오매스에서 점 A(−1, 2)가 블록 코딩 명령어 "A를 x축으로 2, y축으로 1만큼 평행이동하기"에 의해 옮겨지는 점의 좌표 → (1, 3) ("블록에 있는 숫자의 의미를 생각해 보자.")
- 점 P(x, y)를 x축의 방향으로 a만큼, y축의 방향으로 b만큼 평행이동한 점을 P′(x′, y′)이라 하면 x′ = x + a, y′ = y + b
- **점의 평행이동**: 점 P(x, y)를 x축의 방향으로 a만큼, y축의 방향으로 b만큼 평행이동한 점 P′의 좌표는 **(x + a, y + b)** (p.45)
- 보기: 점 P(3, −2)를 x축의 방향으로 −1만큼, y축의 방향으로 5만큼 → (3 + (−1), −2 + 5), 즉 **(2, 3)**

### 2. 도형의 방정식 f(x, y) = 0 (p.45)
- 방정식 ax + by + c = 0 (a ≠ 0 또는 b ≠ 0)은 **직선**을 나타낸다.
- 방정식 x² + y² + Ax + By + C = 0 (A² + B² − 4C > 0)은 **원**을 나타낸다.
- 이처럼 방정식 **f(x, y) = 0** 은 일반적으로 좌표평면 위의 도형을 나타낸다.

### 3. 도형의 평행이동 (p.46)
- 유도
  1. f(x, y) = 0 위의 점 P(x, y)를 x축 방향 a, y축 방향 b만큼 평행이동한 점 P′(x′, y′): x′ = x + a, y′ = y + b
  2. 거꾸로 쓰면 x = x′ − a, y = y′ − b
  3. f(x, y) = 0 에 대입 → f(x′ − a, y′ − b) = 0
  4. 점 P′(x′, y′)은 방정식 f(x − a, y − b) = 0 이 나타내는 도형 위의 점
- 날개: 도형의 방정식은 일반적으로 문자 x, y를 사용하므로 x′, y′을 각각 x, y로 바꾸어 나타낸다.
- **도형의 평행이동**: 방정식 f(x, y) = 0 이 나타내는 도형을 x축의 방향으로 a만큼, y축의 방향으로 b만큼 평행이동한 도형의 방정식은 **`f(x − a, y − b) = 0`** (p.46)
  - 즉 **x 대신 x − a, y 대신 y − b** 를 대입한다.

### 4. 예제 1 (p.46)
- 문제: 다음 도형을 x축의 방향으로 1만큼, y축의 방향으로 −2만큼 평행이동한 도형의 방정식
- ⑴ x + 2y + 1 = 0
  - x 대신 x − 1, y 대신 y + 2 를 대입: `(x − 1) + 2(y + 2) + 1 = 0`
  - 답: **x + 2y + 4 = 0** (그림: x절편 −1, y절편 −1/2 인 직선이 x절편 −4, y절편 −2 인 직선으로)
- ⑵ (x − 1)² + (y + 2)² = 4
  - x 대신 x − 1, y 대신 y + 2 를 대입: `{(x − 1) − 1}² + {(y + 2) + 2}² = 4`
  - 답: **(x − 2)² + (y + 4)² = 4** (중심 (1, −2) → (2, −4), 반지름 2 그대로)
- 포인트: 원을 평행이동하면 **중심만 이동**하고 반지름은 변하지 않는다.

### 5. 스스로 익히기 (p.47)
1. x축 방향 4, y축 방향 −3만큼 평행이동한 점: ⑴ (2, 4) → (6, 1) ⑵ (−1, 3) → (3, 0)
2. 점 (5, −4)를 x축 방향 a, y축 방향 2만큼 평행이동 → (2, b): 5 + a = 2, −4 + 2 = b 에서 a = −3, b = −2
3. (예제 1 유형) x축 방향 −2, y축 방향 1만큼 평행이동: ⑴ 3x − y − 5 = 0 → 3(x + 2) − (y − 1) − 5 = 0, 즉 3x − y + 2 = 0 ⑵ x² + y² = 14 → (x + 2)² + (y − 1)² = 14
4. 원 x² + y² + 6x − 4y = 3 을 x축 방향 a, y축 방향 b만큼 평행이동 → x² + y² = r² 과 일치 (r > 0)
   - (x + 3)² + (y − 2)² = 16 → 중심 (−3, 2)가 원점으로 가야 하므로 a = 3, b = −2, r = 4
- 계산 결과는 교과서 해설 쪽(148쪽)이 소스에 없어 직접 계산한 값이다.

### 6. 역량 키우기(연결·실생활과 연결하기) — 장기의 상(象) (p.47)
- 서연이가 두고 있는 장기 게임의 한 장면을 좌표평면 위에 나타냄. 현재 상(象)의 좌표가 (3, 3)
- 규칙: 상(象)은 먼저 선을 타고 **한 칸** 이동한 뒤, 대각선 방향 중 한 방향으로 **두 칸** 이동한다. 이때 다른 기물이 이동 경로 사이에 자리하면 이동이 불가능하다.
- 날개: 이동 경로 사이에 다른 기물이 없을 때 상(象)이 이동할 수 있는 방법은 **8가지**이다.
- 평행이동으로 보면 상의 한 번 이동은 점 (3, 3)을 (±2, ±3) 또는 (±3, ±2)만큼 평행이동하는 것이다. 실제로 갈 수 있는 점은 그림 속 다른 기물이 경로를 막는지 확인해 고른다.

## 비교·정리표

### 표 1. 점의 평행이동 vs 도형의 평행이동
| 구분 | x축 방향 a, y축 방향 b만큼 평행이동 | 연산 | 보기 |
|---|---|---|---|
| 점 (x, y) | (x + a, y + b) | 좌표에 **더한다** | P(3, −2), a = −1, b = 5 → (2, 3) (p.45) |
| 도형 f(x, y) = 0 | f(x − a, y − b) = 0 | x, y 자리에 **빼서 대입** | x + 2y + 1 = 0, a = 1, b = −2 → x + 2y + 4 = 0 (p.46) |

### 표 2. 도형별 평행이동 결과 (예제 1, a = 1, b = −2)
| 원래 도형 | 대입 | 결과 | 변하는 것 / 안 변하는 것 |
|---|---|---|---|
| 직선 x + 2y + 1 = 0 | (x − 1) + 2(y + 2) + 1 = 0 | x + 2y + 4 = 0 | 기울기 −1/2 그대로, 절편 변화 |
| 원 (x − 1)² + (y + 2)² = 4 | {(x − 1) − 1}² + {(y + 2) + 2}² = 4 | (x − 2)² + (y + 4)² = 4 | 중심 (1, −2) → (2, −4), 반지름 2 그대로 |

### 표 3. 방정식과 도형 (p.45)
| 방정식 | 조건 | 도형 |
|---|---|---|
| ax + by + c = 0 | a ≠ 0 또는 b ≠ 0 | 직선 |
| x² + y² + Ax + By + C = 0 | A² + B² − 4C > 0 | 원 |
| f(x, y) = 0 | 일반적으로 | 좌표평면 위의 도형 |

## 시험 함정 포인트
- 도형을 평행이동할 때는 x 대신 x + a 가 아니라 **x − a** 를, y 대신 **y − b** 를 대입한다. 점은 더하고 도형은 뺀다. (p.46)
- y축의 방향으로 −2만큼 평행이동이면 y 대신 y − (−2) = **y + 2** 를 대입한다. (p.46 예제 1)
- 원 (x − 1)² + (y + 2)² = 4 에 x − 1 을 대입하면 (x − 2)² 이 된다. (x − 1 − 1)을 (x)로 잘못 정리하지 않는다. (p.46)
- 원을 평행이동해도 **반지름은 변하지 않는다**. 중심만 옮긴다. (p.46)
- 직선을 평행이동해도 **기울기는 변하지 않는다**. (p.46 예제 1 ⑴)
- "점 (5, −4)를 평행이동하여 (2, b)" 문제에서 이동량 a는 2 − 5 = **−3** (도착 − 출발)이다. (p.47 스스로 익히기 2)
- 일반형 원을 평행이동해 x² + y² = r² 과 일치시키는 문제는 먼저 표준형으로 고쳐 **중심이 원점으로** 가는 이동량을 구한다. (p.47 스스로 익히기 4)
- 장기의 상은 대각선 두 칸만이 아니라 **선을 따라 한 칸 + 대각선 두 칸** 이동이며, 경로 사이에 기물이 있으면 이동할 수 없다. (p.47)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 평행이동 | 점이나 도형을 일정한 방향으로 일정한 거리만큼 옮기는 것 (p.45) |
| 점의 평행이동 | (x, y) → (x + a, y + b) (p.45) |
| 도형의 방정식 | 좌표평면 위의 도형을 나타내는 방정식 f(x, y) = 0 (p.45) |
| 도형의 평행이동 | f(x, y) = 0 → f(x − a, y − b) = 0 (p.46) |
| x축의 방향으로 a만큼 | x좌표를 a만큼 바꿈(a < 0 이면 왼쪽으로) (p.45) |
| 상(象) | 장기 기물, 선을 따라 한 칸 + 대각선 두 칸 이동, 경로에 기물 있으면 불가 (p.47) |
