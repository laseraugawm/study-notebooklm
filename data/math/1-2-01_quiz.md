# 원의방정식 퀴즈

## Question 1
중심의 좌표가 $(2, -1)$이고 반지름의 길이가 $3$인 원의 방정식은 무엇인가요?

- [x] $(x-2)^2 + (y+1)^2 = 9$
- [ ] $(x+2)^2 + (y-1)^2 = 9$
- [ ] $(x-2)^2 + (y+1)^2 = 3$
- [ ] $(x+2)^2 + (y-1)^2 = 3$

**Hint:** 중심이 $(a, b)$이고 반지름이 $r$인 원의 방정식 표준형은 $(x-a)^2 + (y-b)^2 = r^2$입니다.

## Question 2
두 점 $A(3, 4)$와 $B(-1, 2)$를 지름의 양 끝점으로 하는 원의 방정식을 구하시오.

- [x] $(x-1)^2 + (y-3)^2 = 5$
- [ ] $(x-1)^2 + (y-3)^2 = 20$
- [ ] $(x+1)^2 + (y+3)^2 = 5$
- [ ] $(x-1)^2 + (y-3)^2 = \sqrt{5}$

**Hint:** 원 지름의 양 끝점이 주어지면 두 점의 중점이 원의 중심이 되며, 중심과 한 점 사이의 거리가 반지름입니다.

## Question 3
방정식 $x^2 + y^2 - 8x + 12y + 3 = 0$이 나타내는 원의 중심의 좌표와 반지름의 길이 $r$로 옳은 것은?

- [x] 중심 $(4, -6)$, 반지름 $7$
- [ ] 중심 $(-4, 6)$, 반지름 $7$
- [ ] 중심 $(4, -6)$, 반지름 $49$
- [ ] 중심 $(-8, 12)$, 반지름 $7$

**Hint:** 이차식 부분을 각각 완전제곱식 꼴 $(x-a)^2 + (y-b)^2 = r^2$으로 변형해 보세요.

## Question 4
방정식 $x^2 + y^2 - 5x + 3y + k = 0$이 나타내는 도형이 실제 원이 되도록 하는 실수 $k$의 값의 범위는?

- [x] $k < \frac{17}{2}$
- [ ] $k > \frac{17}{2}$
- [ ] $k \le \frac{17}{2}$
- [ ] $k < 17$

**Hint:** 일반형 $x^2 + y^2 + Ax + By + C = 0$이 원을 나타낼 조건은 $A^2 + B^2 - 4C > 0$입니다.

## Question 5
이차방정식 $x^2 + y^2 + Ax + By + C = 0$에서 $A^2 + B^2 - 4C = 0$일 때, 이 방정식이 좌표평면에서 나타내는 도형은 무엇인가요?

- [x] 한 점 $(-\frac{A}{2}, -\frac{B}{2})$
- [ ] 중심이 $(-\frac{A}{2}, -\frac{B}{2})$인 원
- [ ] 좌표평면 위에 존재하지 않는다.
- [ ] 원점을 지나는 직선

**Hint:** 표준형으로 바꿨을 때 우변(반지름의 제곱 자리)의 값이 $0$이 되는 경우를 생각해 보세요.

## Question 6
원점 $O(0, 0)$과 두 점 $P(2, 0)$, $Q(3, -3)$을 지나는 원의 방정식은 무엇인가요?

- [x] $x^2 + y^2 - 2x + 4y = 0$
- [ ] $x^2 + y^2 + 2x - 4y = 0$
- [ ] $x^2 + y^2 - 2x - 4y = 0$
- [ ] $x^2 + y^2 + 2x + 3y = 0$

**Hint:** 구하는 원의 방정식을 일반형 $x^2 + y^2 + Ax + By + C = 0$으로 놓고 세 점의 좌표를 대입해 보세요.

## Question 7
중심의 좌표가 $(-4, -4)$이고 점 $(0, -4)$를 지나는 원의 방정식은?

- [x] $(x+4)^2 + (y+4)^2 = 16$
- [ ] $(x-4)^2 + (y-4)^2 = 16$
- [ ] $(x+4)^2 + (y+4)^2 = 4$
- [ ] $(x-4)^2 + (y-4)^2 = 4$

**Hint:** 중심과 원 위의 한 점 사이의 거리를 구하면 원의 반지름의 길이를 알 수 있습니다.

## Question 8
이차방정식 $x^2 + y^2 + Ax + By + C = 0$에서 $A^2 + B^2 - 4C < 0$일 때의 설명으로 올바른 것은?

- [x] 방정식을 만족시키는 점 $P(x, y)$가 좌표평면 위에 존재하지 않는다.
- [ ] 반지름의 길이가 0인 원을 만든다.
- [ ] 좌표평면 위의 한 점을 나타낸다.
- [ ] 원점을 중심으로 하고 반지름이 음수인 원을 나타낸다.

**Hint:** 실수의 제곱의 합은 항상 $0$ 이상이어야 한다는 성질을 생각해 보세요.

## Question 9
중심이 원점이고 반지름의 길이가 $\sqrt{5}$인 원의 방정식은 무엇인가요?

- [x] $x^2 + y^2 = 5$
- [ ] $x^2 + y^2 = \sqrt{5}$
- [ ] $x^2 + y^2 = 25$
- [ ] $(x-\sqrt{5})^2 + (y-\sqrt{5})^2 = 5$

**Hint:** 중심이 원점인 원의 방정식 공식은 $x^2 + y^2 = r^2$입니다.

## Question 10
원의 방정식 $(x-3)^2 + (y+1)^2 = 9$를 전개하여 $x^2 + y^2 + Ax + By + C = 0$ 꼴로 정리했을 때, 계수의 합 $A + B + C$의 값은 얼마인가요?

- [x] $-3$
- [ ] $9$
- [ ] $-7$
- [ ] $3$

**Hint:** 표준형의 괄호를 풀고 우변의 상수를 좌변으로 이항하여 우변을 $0$으로 만들어 보세요.
