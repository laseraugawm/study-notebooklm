# Ⅱ-2-03 명제의 증명

## 학습 목표
- 대우를 이용한 증명법과 귀류법을 이해하고 관련된 명제를 증명할 수 있다. (p.92)
- 절대부등식의 뜻을 알고, 간단한 절대부등식을 증명할 수 있다. (p.92)

## 핵심 개념

### 1. 정의와 정리
- 준비하기: 유리수의 뜻을 말하시오. (p.92)
- 생각 틔우기: 두 고양이가 "엄청 닮았다"는 말에 "닮음이라는 건 말이야…"라고 답하는 만화 → 일상어 '닮았다'와 수학 용어 '닮음'의 차이에서 용어의 뜻을 명확하게 정하는 까닭을 생각해 보기 (p.92)
- **정의**: 용어의 뜻을 간결하고 명확하게 정한 문장 (p.92)
  - 예: '세 변의 길이가 같은 삼각형을 정삼각형이라고 한다.'
- **정리**: 참임이 증명된 명제 중에서 기본이 되는 것이나 다른 명제를 증명할 때 이용할 수 있는 명제 (p.92)
  - 예: '이등변삼각형의 두 밑각의 크기는 같다.'

### 2. 대우를 이용한 증명법
- 명제와 그 대우는 참, 거짓이 일치하므로, 명제 p → q가 참임을 증명할 때 그 대우 `~q → ~p` 가 참임을 증명하기도 한다. (p.92)
- 함께 완성하기: '자연수 n에 대하여 n²이 짝수이면 n은 짝수이다.' 증명 (p.92)
  1. 대우: '자연수 n에 대하여 **n이 홀수**이면 **n²은 홀수**이다.'
  2. n이 홀수이면 `n = 2k − 1` (k는 자연수)로 나타낼 수 있으므로
  3. `n² = (2k − 1)² = 4k² − 4k + 1 = 2(2k² − 2k) + 1`
  4. 이때 `2k² − 2k` 는 0 또는 자연수이므로 n²은 홀수
  5. 대우가 참이므로 주어진 명제도 참
  - (빈칸 정답: n이 홀수 / n²은 홀수 / 2k² − 2k / 2k² − 2k)

### 3. 귀류법
- **귀류법**: 명제가 참임을 증명할 때, 명제 또는 명제의 결론을 부정한 후 가정이나 이미 알려진 수학적 사실에 모순임을 보여 부정한 명제가 거짓, 즉 원래의 명제가 참임을 증명하는 방법 (p.93)

### 4. 예제 1 (p.93) — √2는 유리수가 아니다 (귀류법)
1. √2가 유리수라고 하면 `√2 = n/m` (m, n은 서로소인 자연수)로 나타낼 수 있다.
2. 즉 `√2·m = n`, 양변을 제곱하면 `2m² = n²`
3. n²이 짝수이므로 n은 짝수 (앞의 대우 증명 결과 이용)
4. `n = 2k` (k는 자연수)로 나타내면 `2m² = n² = (2k)²`, 즉 `m² = 2k²`
5. m²이 짝수이므로 m은 짝수
6. m, n이 모두 짝수이므로 m, n은 **서로소인 자연수라는 가정에 모순**
7. 따라서 √2는 유리수가 아니다.

### 5. 스스로 익히기·역량 키우기 (p.93)
1. '자연수 n에 대하여 n²이 홀수이면 n은 홀수이다.'를 대우를 이용하여 증명 (대우: n이 짝수이면 n²은 짝수)
2. (예제 1 연계) '1 + √2는 유리수가 아니다.'를 귀류법으로 증명
- 역량 키우기(다양한 방법으로 증명하기): x, y가 실수일 때 'xy ≠ 0이면 x ≠ 0이고 y ≠ 0이다.'를 ① 대우를 이용한 증명법 ② 귀류법 두 가지로 증명해 보기

### 6. 절대부등식
- 준비하기: 부등식 `x² − 4x + 4 ≥ 0` 을 푸시오. (p.94)
- **절대부등식**: 부등식 `x² + 1 ≥ 0` 과 같이 문자를 포함한 부등식에서 그 문자가 가질 수 있는 어떤 실수를 대입해도 항상 성립하는 부등식 (p.94)
- 절대부등식의 증명에 자주 이용되는 실수의 성질 (a, b가 실수일 때) (p.94)
  1. `a > b ⇔ a − b > 0`
  2. `a² ≥ 0`
  3. a ≥ 0, b ≥ 0일 때 `a ≥ b ⇔ a² ≥ b²`
  4. `|a| ≥ a`
  5. `a² + b² = 0 ⇔ a = 0, b = 0`
  6. `|a|² = a²`, `|ab| = |a||b|`

### 7. 함께 완성하기 (p.94) — a² + 5b² ≥ 4ab
- a, b가 실수일 때 `a² + 5b² − 4ab ≥ 0` 임을 보이면 된다.
- `a² + 5b² − 4ab = (a − 2b)² + b²`
- `(a − 2b)² ≥ 0`, `b² ≥ 0` 이므로 `(a − 2b)² + b² ≥ 0`
- 따라서 a² + 5b² ≥ 4ab 성립
- 등호는 a − 2b = 0 이고 b = 0, 즉 `a = b = 0` 일 때 성립
- (빈칸 정답: a − 2b / a − 2b / a − 2b / 0)

### 8. 예제 1 (p.94) — 산술평균과 기하평균
- 문제: a > 0, b > 0일 때 `(a + b)/2 ≥ √(ab)` 가 성립함을 증명하고, 등호가 성립하는 경우를 말하시오.
- 증명 흐름
  1. `(a + b)/2 − √(ab) ≥ 0` 임을 보이면 된다.
  2. `(a + b)/2 − √(ab) = (a + b − 2√(ab))/2 = ((√a)² + (√b)² − 2√a√b)/2 = (√a − √b)²/2 ≥ 0`
  3. 따라서 `(a + b)/2 ≥ √(ab)`
  4. 등호는 `√a − √b = 0`, 즉 **a = b**일 때 성립
- 두 양수 a, b에 대하여 `(a + b)/2` 를 **산술평균**, `√(ab)` 를 **기하평균**이라고 한다. (p.94)

### 9. 스스로 익히기 (p.95)
1. x가 실수일 때 절대부등식 고르기: (1) x + 1 > 0 (2) |x − 3| ≥ 0 (3) x² − x + 1 > 0 (4) x² − 4 ≥ 0 → 모든 실수에서 성립하는지 확인((1)은 x = −1, (4)는 x = 0에서 성립하지 않음)
2. a, b가 실수일 때 `|a| + |b| ≥ |a + b|` 증명 빈칸 채우기
   - |a| + |b| ≥ 0, |a + b| ≥ 0 이므로 `(|a| + |b|)² ≥ |a + b|²` 임을 보이면 된다(성질 3).
   - `(|a| + |b|)² − |a + b|² = (a² + 2|ab| + b²) − (a² + 2ab + b²) = 2(|ab| − ab)`
   - |ab| ≥ ab 이므로 2(|ab| − ab) ≥ 0 (성질 4)
   - 등호는 `|ab| = ab`, 즉 `ab ≥ 0` 일 때 성립
3. a > 0, b > 0일 때 증명하고 등호 조건 말하기: (1) `b/a + a/b ≥ 2` (2) `4a + 1/a ≥ 4`
- 역량 키우기(증명하기·오류 찾기): a > 0, b > 0일 때 `(a + b)(1/a + 9/b)` 의 최솟값 (p.95)
  - 학생 풀이: `a + b ≥ 2√(ab)`, `1/a + 9/b ≥ 2√(9/(ab))` 를 곱해 `≥ 2√(ab) × 2√(9/(ab)) = 12` → 최솟값 12라고 답함
  - 문제점: 첫 부등식의 등호는 a = b일 때, 둘째 부등식의 등호는 1/a = 9/b일 때인데, 두 조건을 동시에 만족시키는 양수 a, b가 없다("말이 안 되는걸?"). 즉 12는 실제로 나올 수 없는 값이다.
  - 바른 방향: 먼저 전개하여 `1 + 9 + b/a + 9a/b` 로 만든 뒤 한 번만 산술평균과 기하평균의 관계를 적용한다.

## 비교·정리표

### 정의 vs 정리
| 구분 | 뜻 | 예 |
|---|---|---|
| 정의 | 용어의 뜻을 간결하고 명확하게 정한 문장 | 세 변의 길이가 같은 삼각형을 정삼각형이라고 한다. |
| 정리 | 참임이 증명된 명제 중 기본이 되거나 다른 증명에 이용되는 명제 | 이등변삼각형의 두 밑각의 크기는 같다. |

### 대우를 이용한 증명법 vs 귀류법
| 구분 | 무엇을 하는가 | 근거 | 교과서 예 |
|---|---|---|---|
| 대우를 이용한 증명법 | p → q 대신 ~q → ~p가 참임을 보인다 | 명제와 대우의 참, 거짓이 일치 | n²이 짝수이면 n은 짝수 |
| 귀류법 | 명제(또는 결론)를 부정한 뒤 모순을 이끌어 낸다 | 가정이나 알려진 수학적 사실에 모순 | √2는 유리수가 아니다 |

### 절대부등식과 등호 조건
| 부등식 | 조건 | 핵심 변형 | 등호 성립 |
|---|---|---|---|
| (a + b)/2 ≥ √(ab) | a > 0, b > 0 | (√a − √b)²/2 ≥ 0 | a = b |
| a² + 5b² ≥ 4ab | a, b 실수 | (a − 2b)² + b² ≥ 0 | a = b = 0 |
| \|a\| + \|b\| ≥ \|a + b\| | a, b 실수 | 양변 제곱의 차 2(\|ab\| − ab) ≥ 0 | ab ≥ 0 |

## 시험 함정 포인트
- 대우를 이용한 증명은 ~p → ~q(이)가 아니라 **~q → ~p**를 증명한다. 'n²이 짝수이면 n은 짝수'의 대우는 'n이 홀수이면 n²은 홀수'이다. (p.92)
- 귀류법에서 모순은 아무 데서나 찾는 것이 아니라 **가정이나 이미 알려진 수학적 사실**과의 모순이다. √2 증명에서는 'm, n은 서로소'라는 가정과 모순된다. (p.93)
- √2 = n/m으로 놓을 때 m, n이 **서로소**라는 조건이 빠지면 모순이 생기지 않는다. 서로소 조건이 증명의 핵심이다. (p.93)
- 절대부등식은 "해가 있는 부등식"이 아니라 문자에 **어떤 실수**를 대입해도 항상 성립하는 부등식이다. x² − 4 ≥ 0은 x = 0에서 성립하지 않으므로 절대부등식이 아니다. (p.94, p.95)
- 산술평균과 기하평균의 관계는 a > 0, b > 0일 때의 부등식이다. 등호는 a = b일 때만 성립한다. (p.94)
- a² + 5b² ≥ 4ab의 등호 조건은 'a = 2b'가 아니라 (a − 2b)² = 0 이고 b² = 0, 즉 **a = b = 0**이다. 제곱 두 개의 합이 0이려면 둘 다 0이어야 한다(성질 5). (p.94)
- 부등식 두 개를 곱해 최솟값을 구할 때 **두 등호 조건이 동시에 성립하는지** 확인해야 한다. (a + b)(1/a + 9/b) ≥ 12는 등호가 동시에 성립할 수 없어 12는 최솟값이 아니다. (p.95)
- |a| + |b| ≥ |a + b|의 등호는 a = b일 때가 아니라 |ab| = ab, 즉 **ab ≥ 0**일 때이다. (p.95)
- 양변을 제곱해 비교하려면 양변이 모두 0 이상이어야 한다(성질 3: a ≥ 0, b ≥ 0일 때 a ≥ b ⇔ a² ≥ b²). (p.94, p.95)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 정의 | 용어의 뜻을 간결하고 명확하게 정한 문장 |
| 정리 | 참임이 증명된 명제 중 기본이 되는 것이나 다른 명제를 증명할 때 이용할 수 있는 명제 |
| 대우를 이용한 증명법 | p → q가 참임을 그 대우 ~q → ~p가 참임을 보여 증명하는 방법 |
| 귀류법 | 명제 또는 결론을 부정한 후 가정이나 알려진 사실에 모순임을 보여 원래 명제가 참임을 증명하는 방법 |
| 서로소 | (예제에서) 1 이외의 공약수가 없는 두 자연수 m, n — 모두 짝수이면 모순 |
| 절대부등식 | 문자에 어떤 실수를 대입해도 항상 성립하는 부등식 |
| 산술평균 | 두 양수 a, b에 대하여 (a + b)/2 |
| 기하평균 | 두 양수 a, b에 대하여 √(ab) |
| 등호 조건 | 절대부등식에서 등호가 성립하는 경우(예: 산술·기하평균은 a = b) |
