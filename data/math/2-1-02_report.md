# Ⅱ-1-02 집합의 연산
교과서 70~77쪽 · 공통수학2

## 학습 목표
- 집합의 연산을 수행하고, 벤 다이어그램을 이용하여 나타낼 수 있다. (p.70)

## 핵심 개념

### 1. 합집합과 교집합
- 생각 틔우기: 두 동아리 학생들이 희망하는 진로 (p.70)
  - 동아리 A = {경제학자, 인공지능 전문가, 수학 연구원, 빅 데이터 분석가}
  - 동아리 B = {웹 개발자, 인공지능 전문가, 수학 연구원, 공학 엔지니어}
  - ① A 또는 B에 속하는 진로 → 합집합의 생각 ② A와 B에 공통으로 속하는 진로(인공지능 전문가, 수학 연구원) → 교집합의 생각
- **합집합**: 집합 A에 속하거나 집합 B에 속하는 모든 원소로 이루어진 집합, 기호 `A ∪ B` (p.70)
  - `A ∪ B = {x | x ∈ A 또는 x ∈ B}`
  - 벤 다이어그램: 두 원 전체를 색칠
- **교집합**: 집합 A에도 속하고 집합 B에도 속하는 모든 원소로 이루어진 집합, 기호 `A ∩ B` (p.70)
  - `A ∩ B = {x | x ∈ A 그리고 x ∈ B}`
  - 벤 다이어그램: 두 원이 겹치는 부분만 색칠
- **서로소**: 두 집합 A, B에 공통인 원소가 하나도 없을 때, 즉 `A ∩ B = ∅` 일 때 A와 B는 서로소 (p.70)
- 보기: `A = {1, 2, 3}`, `B = {1, 3, 5}`, `C = {4, 5}` (p.70)
  1. `A ∪ B = {1, 2, 3, 5}`, `A ∩ B = {1, 3}`
  2. `A ∩ C = ∅` 이므로 A와 C는 서로소

### 2. 합집합의 원소의 개수
- 확인: `A = {1, 2, 3, 4, 5}`, `B = {2, 4, 6, 8}` 에서 n(A) = 5, n(B) = 4, n(A ∩ B) = 2, n(A ∪ B) = 7 → `7 = 5 + 4 − 2` (p.71)
- 공식: 두 유한집합 A, B에 대하여 (p.71)
  - `n(A ∪ B) = n(A) + n(B) − n(A ∩ B)`
  - 이유: n(A) + n(B)에는 A ∩ B의 원소의 개수가 두 번 더해지므로 n(A ∩ B)를 한 번 빼 주어야 한다. (p.71)
- 특히 `A ∩ B = ∅` 이면 n(A ∩ B) = 0 이므로 `n(A ∪ B) = n(A) + n(B)` (p.71)
- 역량 키우기(실생활과 연결하기): OTT 플랫폼 A 이용 가구 14, B 이용 가구 8, A 또는 B 이용 가구 20 → A와 B를 모두 이용하는 가구 수 구하기 (`20 = 14 + 8 − n(A ∩ B)`) (p.71)

### 3. 집합의 연산 법칙
- 준비하기: `A = {1, 3, 5}`, `B = {1, 3, 9}` 의 A ∪ B와 A ∩ B 구하기 (p.72)
- **교환법칙** (두 집합 A, B) (p.72)
  - `A ∪ B = B ∪ A`
  - `A ∩ B = B ∩ A`
- **결합법칙** (세 집합 A, B, C) (p.72)
  - `(A ∪ B) ∪ C = A ∪ (B ∪ C)`
  - `(A ∩ B) ∩ C = A ∩ (B ∩ C)`
  - 결합법칙이 성립하므로 괄호 없이 `A ∪ B ∪ C`, `A ∩ B ∩ C` 로 나타내기도 한다. (p.72)
- **분배법칙** (세 집합 A, B, C) (p.72)
  - `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`
  - `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`
- 함께 완성하기: 세 원 벤 다이어그램으로 분배법칙 확인 (p.72)
  1. A ∪ (B ∩ C): 원 A 전체 + B와 C가 겹친 부분을 색칠 → (A ∪ B) ∩ (A ∪ C)를 그려 같은 영역임을 확인
  2. A ∩ (B ∪ C)와 (A ∩ B) ∪ (A ∩ C)를 각각 그려 같은 영역임을 확인
- 스스로 익히기 (p.73)
  1. 결합법칙 두 식을 벤 다이어그램으로 확인
  2. `A ∪ B = {2, 3, 4}`, `C = {1, 3, 9}` 일 때 `A ∪ (B ∪ C)` → 결합법칙으로 (A ∪ B) ∪ C를 계산
  3. `A ∪ (A ∩ B) = A`, `B ∩ (A ∪ B) = B` 를 벤 다이어그램으로 확인
  4. `A ∪ B = {a, b, c}`, `A ∪ C = {b, c, d, e}` 일 때 `A ∪ (B ∩ C)` → 분배법칙으로 (A ∪ B) ∩ (A ∪ C)를 계산
- 역량 키우기(원리 탐구하기): `A_k = {x | x는 k의 배수인 100 이하의 자연수}` (예: `A_30 = {30, 60, 90}`) 일 때 ① n(A_2 ∩ A_3) ② n(A_2 ∩ (A_3 ∪ A_5)) 구하기 (p.73)

### 4. 전체집합과 여집합
- **전체집합**: 어떤 집합에 대하여 그 부분집합을 생각할 때 처음의 집합, 기호 U (p.74)
- **여집합**: 집합 A가 전체집합 U의 부분집합일 때, U의 원소 중에서 A에 속하지 않는 모든 원소로 이루어진 집합을 U에 대한 A의 여집합이라 하고 `Aᶜ` 로 나타낸다. (p.74)
  - `Aᶜ = {x | x ∈ U 그리고 x ∉ A}`
  - 벤 다이어그램: 직사각형 U 안에서 원 A 바깥 부분
- 보기: `U = {1, 2, 3, 4, 5}`, `A = {1, 3, 5}` → `Aᶜ = {2, 4}` (p.74)
- 기호 U와 Aᶜ에서 C의 유래가 되는 영어 단어를 찾아보는 활동이 있다. (p.74)

### 5. 차집합
- **차집합**: 집합 A에는 속하지만 집합 B에는 속하지 않는 모든 원소로 이루어진 집합을 A에 대한 B의 차집합이라 하고 `A − B` 로 나타낸다. (p.74)
  - `A − B = {x | x ∈ A 그리고 x ∉ B}`
  - 벤 다이어그램: 원 A에서 B와 겹친 부분을 뺀 영역
- 보기: `A = {2, 4, 6, 8, 10}`, `B = {1, 2, 5, 10}` → `A − B = {4, 6, 8}`, `B − A = {1, 5}` (p.74)
- 전체집합 U의 부분집합 A에 대하여 Aᶜ은 U에 대한 A의 차집합으로 생각할 수 있다. 즉 `Aᶜ = U − A` (p.74)

### 6. 예제 1 (p.74) — A − B = A ∩ Bᶜ 확인
- 문제: 전체집합 U의 두 부분집합 A, B에 대하여 `A − B = A ∩ Bᶜ` 이 성립함을 벤 다이어그램으로 확인
- 풀이 흐름: A − B를 색칠(A에서 B와 겹친 부분 제외) / A를 색칠, Bᶜ(B 바깥 전체)을 색칠 → 둘의 공통 부분 A ∩ Bᶜ은 A에서 B를 뺀 부분 → 두 그림이 같으므로 A − B = A ∩ Bᶜ. 답: 풀이 참조

### 7. 여집합과 차집합의 성질 (p.75)
전체집합 U의 두 부분집합 A, B에 대하여
1. `Uᶜ = ∅`, `∅ᶜ = U`
2. `(Aᶜ)ᶜ = A`
3. `A ∪ Aᶜ = U`, `A ∩ Aᶜ = ∅`
4. `A − B = A ∩ Bᶜ`
- 스스로 익히기 (p.75)
  1. (Aᶜ)ᶜ = A, A ∪ Aᶜ = U, A ∩ Aᶜ = ∅ 을 벤 다이어그램으로 확인
  2. `U = {x | x는 10 이하의 자연수}` 에서 (1) `A = {2, 3, 5, 7}` (2) `A = {x | x는 10의 약수}` 의 Aᶜ 구하기
  3. A − B 구하기: (1) `A = {1, 4, 5, 7, 8}`, `B = {x | x는 12의 약수}` (2) `A = {x | x는 x − 5 < 0인 자연수}`, `B = {x | x² − 5x + 6 = 0}`
- 역량 키우기(오류 찾기): `A = {2, 3, 6}`, `B = {1, 2, 4, 8}` 에서 n(A − B)를 "n(A) − n(B) = 3 − 4 = −1"로 계산한 대화 → 개수가 음수가 나온 것이 오류의 신호. A − B는 A에서 B와 공통인 원소를 뺀 집합이므로 원소를 직접 확인해야 한다(A − B = {3, 6}). (p.75)

### 8. 드모르간의 법칙
- 준비하기: 전체집합 U의 부분집합 A에 대하여 Aᶜ을 벤 다이어그램으로 나타내기 (p.76)
- 벤 다이어그램 확인: (A ∪ B)ᶜ은 두 원 바깥 부분 / Aᶜ과 Bᶜ을 각각 색칠한 뒤 공통 부분을 잡으면 Aᶜ ∩ Bᶜ도 두 원 바깥 부분 → `(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ`. 같은 방법으로 `(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ` 확인 (p.76)
- **드모르간의 법칙**: 전체집합 U의 두 부분집합 A, B에 대하여 (p.76)
  - `(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ`
  - `(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ`
- 드모르간(De Morgan, A., 1806~1871): 드모르간의 법칙을 발견하였고, 현대 기호 논리학의 토대를 마련한 영국의 수학자 (p.76)
- 보기: `U = {1, 2, 3, 4, 5}`, `A = {1, 3, 5}`, `B = {3, 4, 5}` (p.76)
  1. (A ∪ B)ᶜ = {2}, Aᶜ ∩ Bᶜ = {2} → 같다
  2. (A ∩ B)ᶜ = {1, 2, 4}, Aᶜ ∪ Bᶜ = {1, 2, 4} → 같다

### 9. 예제 1 (p.76) — 드모르간의 법칙과 원소의 개수
- 문제: n(U) = 50, n(A) = 7, n(B) = 16, n(A ∪ B) = 21 일 때 n(Aᶜ ∪ Bᶜ)
- 풀이 흐름
  1. `n(A ∪ B) = n(A) + n(B) − n(A ∩ B)` 에서 `21 = 7 + 16 − n(A ∩ B)`, 즉 n(A ∩ B) = 2
  2. 드모르간의 법칙에 의하여 `Aᶜ ∪ Bᶜ = (A ∩ B)ᶜ`
  3. `n(Aᶜ ∪ Bᶜ) = n((A ∩ B)ᶜ) = n(U) − n(A ∩ B) = 50 − 2 = 48`
- 답: 48

### 10. 스스로 익히기·역량 키우기 (p.77)
1. (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ 을 벤 다이어그램으로 확인
2. `U = {x | x는 18 이하의 자연수}`, `A = {x | x는 3의 배수}`, `B = {x | x는 10의 약수}` 에서 Aᶜ ∪ Bᶜ 구하기 → (A ∩ B)ᶜ로 바꾸면 쉽다.
3. (예제 1 연계) n(U) = 45, n(A) = 15, n(B) = 12, n(A ∩ B) = 5 일 때 n(Aᶜ ∩ Bᶜ) → (A ∪ B)ᶜ로 바꾸어 n(U) − n(A ∪ B)
- 역량 키우기(법칙 탐구하기): `(A − B) ∪ (A − C) = A − (B ∩ C)` 확인 (p.77)
  - 서연: 세 원 벤 다이어그램으로 양변을 그려 비교
  - 건우: 연산 법칙으로 `(A − B) ∪ (A − C) = (A ∩ Bᶜ) ∪ (A ∩ Cᶜ) = …` 이어서 완성(분배법칙, 드모르간의 법칙 활용)
- p.71 스스로 익히기: ① `A = {1, 3, 5, 7, 9}`, `B = {x | x는 18 미만의 3의 배수}` 를 벤 다이어그램에 나타내고 A ∪ B, A ∩ B 구하기 ② `A = {2, 3, 7}` 과 B가 서로소이고 `A ∪ B = {1, 2, 3, 4, 5, 6, 7}` 일 때 B 구하기 ③ `A = {1, 2, 2a + 5}`, `B = {3, a, 3b − 1}` 에서 `A ∩ B = {2, 3}` 일 때 실수 a, b 구하기

## 비교·정리표

### 네 가지 연산
| 연산 | 기호 | 조건제시법 | 벤 다이어그램 영역 | 보기 결과 |
|---|---|---|---|---|
| 합집합 | A ∪ B | {x \| x ∈ A 또는 x ∈ B} | 두 원 전체 | {1,2,3} ∪ {1,3,5} = {1,2,3,5} |
| 교집합 | A ∩ B | {x \| x ∈ A 그리고 x ∈ B} | 겹친 부분 | {1,2,3} ∩ {1,3,5} = {1,3} |
| 여집합 | Aᶜ | {x \| x ∈ U 그리고 x ∉ A} | U에서 A 바깥 | U={1,…,5}, A={1,3,5} → {2,4} |
| 차집합 | A − B | {x \| x ∈ A 그리고 x ∉ B} | A에서 B 부분 제외 | {2,4,6,8,10} − {1,2,5,10} = {4,6,8} |

### 연산 법칙 모음
| 법칙 | ∪ 쪽 | ∩ 쪽 |
|---|---|---|
| 교환법칙 | A ∪ B = B ∪ A | A ∩ B = B ∩ A |
| 결합법칙 | (A ∪ B) ∪ C = A ∪ (B ∪ C) | (A ∩ B) ∩ C = A ∩ (B ∩ C) |
| 분배법칙 | A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) | A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) |
| 드모르간의 법칙 | (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ | (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ |

### 원소의 개수 공식
| 상황 | 공식 | 교과서 수치 |
|---|---|---|
| 합집합 | n(A ∪ B) = n(A) + n(B) − n(A ∩ B) | 7 = 5 + 4 − 2 |
| 서로소일 때 | n(A ∪ B) = n(A) + n(B) | A ∩ B = ∅ |
| 여집합 | n(Aᶜ) = n(U) − n(A) (Aᶜ = U − A) | n((A ∩ B)ᶜ) = 50 − 2 = 48 |

### A − B 와 B − A
| 구분 | 뜻 | A={2,4,6,8,10}, B={1,2,5,10} |
|---|---|---|
| A − B | A에만 있는 원소 | {4, 6, 8} |
| B − A | B에만 있는 원소 | {1, 5} |

## 시험 함정 포인트
- n(A ∪ B)는 n(A) + n(B)가 아니다. 공통 부분이 두 번 더해지므로 n(A ∩ B)를 한 번 빼야 한다. 그냥 더해도 되는 것은 A ∩ B = ∅(서로소)일 때뿐이다. (p.71)
- n(A − B)는 n(A) − n(B)가 아니다. A = {2, 3, 6}, B = {1, 2, 4, 8}에서 n(A) − n(B) = −1이지만 A − B = {3, 6}이므로 n(A − B) = 2이다. (p.75)
- A − B와 B − A는 다르다. 차집합은 교환법칙이 성립하지 않는다({4, 6, 8} ≠ {1, 5}). (p.74)
- 드모르간의 법칙에서 여집합을 풀면 ∪와 ∩가 **바뀐다**. (A ∪ B)ᶜ은 Aᶜ ∪ Bᶜ이 아니라 Aᶜ ∩ Bᶜ이다. (p.76)
- 서로소는 "원소의 개수가 같지 않다"가 아니라 공통인 원소가 하나도 없다(A ∩ B = ∅)는 뜻이다. (p.70)
- 분배법칙은 ∪와 ∩ 양쪽 방향으로 모두 성립한다. A ∪ (B ∩ C)는 (A ∪ B) ∩ (A ∪ C)로, 괄호 밖 연산이 ∩로 바뀐다는 점에 주의. (p.72)
- 여집합은 전체집합 U가 정해져야 정해진다. Aᶜ은 U의 원소 중에서 A에 속하지 않는 것이다(Aᶜ = U − A). (p.74)
- n(Aᶜ ∪ Bᶜ)를 바로 구하기 어려우면 (A ∩ B)ᶜ으로 바꾸어 n(U) − n(A ∩ B)로 계산한다. n(Aᶜ) + n(Bᶜ)로 더하면 틀린다. (p.76)
- A − B = A ∩ Bᶜ 이지 A ∩ B가 아니다. (p.74, p.75)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 합집합 (A ∪ B) | A에 속하거나 B에 속하는 모든 원소로 이루어진 집합 |
| 교집합 (A ∩ B) | A에도 속하고 B에도 속하는 모든 원소로 이루어진 집합 |
| 서로소 | 공통인 원소가 하나도 없는 두 집합, A ∩ B = ∅ |
| 교환법칙 | A ∪ B = B ∪ A, A ∩ B = B ∩ A |
| 결합법칙 | (A ∪ B) ∪ C = A ∪ (B ∪ C), (A ∩ B) ∩ C = A ∩ (B ∩ C) |
| 분배법칙 | A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C), A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) |
| 전체집합 (U) | 부분집합을 생각할 때 처음의 집합 |
| 여집합 (Aᶜ) | U의 원소 중 A에 속하지 않는 모든 원소로 이루어진 집합 |
| 차집합 (A − B) | A에는 속하지만 B에는 속하지 않는 모든 원소로 이루어진 집합 |
| 드모르간의 법칙 | (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ |
| 드모르간 | 드모르간의 법칙을 발견하고 현대 기호 논리학의 토대를 마련한 영국의 수학자(1806~1871) |

## 자기점검 질문
1. A = {1, 2, 3}, C = {4, 5}의 관계는? — A ∩ C = ∅ 이므로 서로소
2. n(A ∪ B) 공식은? — n(A) + n(B) − n(A ∩ B)
3. A = {1, 2, 3, 4, 5}, B = {2, 4, 6, 8}에서 n(A ∪ B)는? — 5 + 4 − 2 = 7
4. U = {1, 2, 3, 4, 5}, A = {1, 3, 5}일 때 Aᶜ은? — {2, 4}
5. 차집합 A − B를 교집합과 여집합으로 나타내면? — A ∩ Bᶜ
6. (A ∩ B)ᶜ을 드모르간의 법칙으로 바꾸면? — Aᶜ ∪ Bᶜ
7. 여집합과 차집합의 성질 네 가지는? — Uᶜ = ∅, ∅ᶜ = U / (Aᶜ)ᶜ = A / A ∪ Aᶜ = U, A ∩ Aᶜ = ∅ / A − B = A ∩ Bᶜ
8. n(U) = 50, n(A) = 7, n(B) = 16, n(A ∪ B) = 21일 때 n(Aᶜ ∪ Bᶜ)는? — n(A ∩ B) = 2, 50 − 2 = 48
9. 결합법칙이 성립하면 어떤 표기가 가능한가? — 괄호 없이 A ∪ B ∪ C, A ∩ B ∩ C
10. A = {2, 3, 6}, B = {1, 2, 4, 8}일 때 n(A − B)는? — A − B = {3, 6} 이므로 2
