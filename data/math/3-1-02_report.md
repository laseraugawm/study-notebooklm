# Ⅲ-1-02 합성함수와 역함수
교과서 114-119쪽 · 공통수학2

## 학습 목표
- 함수의 합성을 설명하고, 합성함수를 구할 수 있다. (p.114)
- 역함수의 개념을 설명하고, 역함수를 구할 수 있다. (p.114)

## 핵심 개념

### 1. 합성함수의 뜻 (p.114)
- 준비하기: 함수 f(x)=⅓x−3에 대하여 (1) f(6) (2) f(−4)를 구하기 (p.114)
- 생각 틔우기: 원소 이름 → 원소 기호 → 원자 번호의 대응(마그네슘 → Mg → 12, 아이오딘 → I → 53, 칼슘 → Ca → 20)을 보고 마그네슘의 원자 번호 말하기 (p.114)
- 세 집합 X, Y, Z에 대하여 두 함수 f : X → Y, g : Y → Z가 주어졌을 때, X의 각 원소 x에 Y의 원소 f(x)를 대응시키고, 다시 이 f(x)에 Z의 원소 g(f(x))를 대응시키면 X를 정의역, Z를 공역으로 하는 새로운 함수를 정의할 수 있다. (p.114)
- **합성함수**: 이 함수를 f와 g의 합성함수라고 하며 기호로 `g∘f` 로 나타낸다. (p.114)
- 합성함수 g∘f : X → Z에서 x의 함숫값을 `(g∘f)(x)` 로 나타낸다. (p.114)
- 정의역 X의 원소 x에 공역 Z의 원소 g(f(x))가 대응하므로 `(g∘f)(x) = g(f(x))` 이다. 즉 f와 g의 합성함수를 y=g(f(x))로 나타낼 수 있다. (p.114)
- 함수 f의 치역이 함수 g의 정의역의 부분집합일 때 합성함수 g∘f를 정의할 수 있다. (p.114)
- 정리 상자 — 합성함수: 두 함수 f : X → Y, g : Y → Z의 합성함수는 `g∘f : X → Z,  (g∘f)(x) = g(f(x))` (p.115)

### 2. 합성함수의 값 구하기 — 보기 (p.115)
- f(x)=x−3, g(x)=2x²에 대하여
  - (g∘f)(2) = g(f(2)) = g(−1) = 2
  - (f∘f)(−3) = f(f(−3)) = f(−6) = −9
- 안쪽 함수(f)부터 먼저 계산하고, 그 결과를 바깥 함수에 넣는다.

### 3. 예제 1 — 합성함수 구하기 (p.115)
- 문제: f(x)=2x−3, g(x)=x²+5에 대하여 (1) (g∘f)(x) (2) (f∘g)(x)
- 풀이 흐름
  1. (g∘f)(x) = g(f(x)) = g(2x−3) = (2x−3)²+5 = 4x²−12x+14
  2. (f∘g)(x) = f(g(x)) = f(x²+5) = 2(x²+5)−3 = 2x²+7
- 답: (1) 4x²−12x+14 (2) 2x²+7
- 일반적으로 두 함수 f, g에 대하여 **g∘f ≠ f∘g**, 즉 함수의 합성에 대한 **교환법칙은 성립하지 않는다**. (p.115)

### 4. 함께 완성하기 — 결합법칙 확인 (p.115)
- f(x)=3x, g(x)=x², h(x)=x−1에 대하여 (f∘(g∘h))(x) = ((f∘g)∘h)(x) 확인
  1. (i) (g∘h)(x) = g(h(x)) = g(x−1) = (x−1)² 이므로 (f∘(g∘h))(x) = f((g∘h)(x)) = f((x−1)²) = 3(x−1)²
  2. (ii) (f∘g)(x) = f(g(x)) = f(x²) = 3x² 이므로 ((f∘g)∘h)(x) = (f∘g)(h(x)) = (f∘g)(x−1) = 3(x−1)²
  3. 따라서 (f∘(g∘h))(x) = ((f∘g)∘h)(x)
- 일반적으로 세 함수 f, g, h에 대하여 **결합법칙이 성립**하므로 f∘(g∘h), (f∘g)∘h를 괄호 없이 `f∘g∘h` 로 나타내기도 한다. (p.115)

### 5. 스스로 익히기·실생활 (p.116)
- 1. f(x)=|2x−5|, g(x)=x²−3x에 대하여 (g∘f)(2), (f∘g)(2), (f∘f)(3), (g∘g)(3)
- 2. 그림의 함수 f : X → X(X={1, 2, 3, 4})에서 f(2)+(f∘f)(2)+(f∘f∘f)(2)의 값
- 3. (예제 1 유형) f(x)=3x+1, g(x)=x²−2x에 대하여 (g∘f)(x), (f∘g)(x)
- 4. (g∘f)(x)=4x−3, h(x)=x²+x일 때 ((h∘g)∘f)(x) — 결합법칙으로 h((g∘f)(x))로 볼 수 있다.
- 실생활과 연결하기: 카페의 '천 원 할인' f(x)=x−1000, '포장 할인'(반값) g(x)=½x (단, x>2000)
  - (f∘g)(x) = f(½x) = ½x−1000 → 포장 할인을 먼저, 천 원 할인을 나중에 적용
  - (g∘f)(x) = g(x−1000) = ½x−500 → 천 원 할인을 먼저, 포장 할인을 나중에 적용
  - 두 결과를 비교하여 어떤 할인을 먼저 적용하는 것이 유리한지 설명해 보는 활동 (½x−1000 < ½x−500)

### 6. 역함수의 뜻 (p.117)
- 준비하기: 함수 f(x)=4x−3에 대하여 f(a)=9일 때 상수 a의 값 구하기 (p.117)
- 두 집합 X, Y에서 함수 f : X → Y가 **일대일대응**이면 Y의 각 원소 y에 대응하는 X의 원소 x는 오직 하나 존재한다. (p.117)
- 이때 Y의 각 원소 y에 f(x)=y인 X의 원소 x를 대응시키면 Y를 정의역, X를 공역으로 하는 새로운 함수를 정의할 수 있다. (p.117)
- **역함수**: 이 함수를 함수 f의 역함수라고 하며 기호로 `f⁻¹` 로 나타낸다. (p.117)
- 역함수의 정의에 의하여 `y=f(x) ⟺ x=f⁻¹(y)` (p.117)
  - (f⁻¹∘f)(x) = f⁻¹(f(x)) = f⁻¹(y) = x (x∈X)
  - (f∘f⁻¹)(y) = f(f⁻¹(y)) = f(x) = y (y∈Y)
  - 합성함수 f⁻¹∘f는 X에서의 항등함수이고, f∘f⁻¹는 Y에서의 항등함수이다. (p.117)
- 역함수의 정의에서 (f⁻¹)⁻¹ = f 임을 알 수 있다. (p.117)

### 7. 역함수의 성질 (정리 상자, p.117)
함수 f : X → Y가 일대일대응일 때
1. f의 역함수 f⁻¹ : Y → X가 존재한다.
2. y=f(x) ⟺ x=f⁻¹(y)
3. (f⁻¹∘f)(x)=x (x∈X), (f∘f⁻¹)(y)=y (y∈Y)
4. (f⁻¹)⁻¹(x)=f(x) (x∈X)

- 보기(p.117): 그림의 f(1→b, 2→c, 3→a)는 일대일대응이므로 역함수 f⁻¹가 존재한다.
  1. f(1)=b 이므로 f⁻¹(b)=1
  2. (f⁻¹∘f)(2)=2, (f∘f⁻¹)(a)=a
  3. (f⁻¹)⁻¹(3)=f(3)=a

### 8. 역함수 구하는 방법 (p.117~118)
- 함수를 나타낼 때는 보통 정의역의 원소를 x, 치역의 원소를 y로 나타내므로 y=f(x)의 역함수 x=f⁻¹(y)도 x와 y를 서로 바꾸어 `y=f⁻¹(x)` 로 나타낸다. (p.117)
- 일대일대응인 함수 y=f(x)의 역함수 구하는 순서 (p.118)
  1. y=f(x)에서 x를 y에 대한 식으로 나타낸다 → x=f⁻¹(y)
  2. x와 y를 서로 바꾼다 → y=f⁻¹(x)
- 예제 1(p.118): 함수 y=3x+1의 역함수
  1. y=3x+1은 일대일대응이므로 역함수가 존재한다.
  2. x를 y에 대한 식으로: x = ⅓y − ⅓
  3. x와 y를 바꾸면: y = ⅓x − ⅓
  - 답: y=⅓x−⅓

### 9. 함수와 그 역함수의 그래프 (p.118)
- 함수 y=f(x)의 역함수 y=f⁻¹(x)가 존재할 때, y=f(x)의 그래프 위의 점을 (a, b)라고 하면 `b=f(a) ⟺ a=f⁻¹(b)` 이다.
- 따라서 점 (b, a)는 역함수 y=f⁻¹(x)의 그래프 위의 점이다. 점 (a, b)와 점 (b, a)는 직선 y=x에 대하여 대칭이다.
- 정리 상자: 함수 y=f(x)의 그래프와 그 역함수 y=f⁻¹(x)의 그래프는 **직선 y=x에 대하여 대칭**이다. (p.118)
- 보기: 함수 y=2x−3의 역함수는 y=½x+3/2이다. 두 그래프는 직선 y=x에 대하여 대칭이다(y=2x−3은 y절편 −3, x절편 3/2 / y=½x+3/2은 y절편 3/2, x절편 −3). (p.118)

### 10. 스스로 익히기·원리 탐구 (p.119)
- 1. 그림의 f : X → Y(1→c, 2→a, 3→b)에 대하여 f⁻¹(b), (f⁻¹∘f)(2), (f∘f⁻¹)(c)
- 2. f(x)=3x+4, g(x)=2x−3에 대하여 f⁻¹(−2), (g⁻¹∘f)(3)
  - f⁻¹(−2)=k 이면 f(k)=−2 로 놓고 푼다(역함수의 성질 ②).
- 3. (예제 1 유형) y=−4x+2, y=⅓x−6의 역함수
- 4. y=3x−2, y=−½x+1의 역함수의 그래프 그리기 — 직선 y=x에 대하여 대칭이동
- 원리 탐구하기: f(x)=−x+2, g(x)=2x−1에 대하여 (g∘f)⁻¹(x)와 (f⁻¹∘g⁻¹)(x)를 구하고 비교
  - (g∘f)(x) = 2(−x+2)−1 = −2x+3 → 역함수 y = −½x + 3/2
  - f⁻¹(x) = −x+2, g⁻¹(x) = ½x+½ → (f⁻¹∘g⁻¹)(x) = −(½x+½)+2 = −½x + 3/2
  - 두 결과가 같다.
- 확장하기: f(x)=3x+4, g(x)=5x−2에 대하여 (g∘(f∘g)⁻¹∘g)(3)의 값 구하기

## 비교·정리표

### 표 1. g∘f 와 f∘g (예제 1, p.115)
| 구분 | 먼저 적용 | 나중 적용 | f(x)=2x−3, g(x)=x²+5 일 때 |
|---|---|---|---|
| (g∘f)(x)=g(f(x)) | f | g | 4x²−12x+14 |
| (f∘g)(x)=f(g(x)) | g | f | 2x²+7 |
| 결론 | 교환법칙 성립 안 함 (g∘f ≠ f∘g) | | |

### 표 2. 합성의 법칙 (p.115)
| 법칙 | 성립 여부 | 근거 |
|---|---|---|
| 교환법칙 g∘f = f∘g | 일반적으로 성립하지 않음 | 예제 1 |
| 결합법칙 f∘(g∘h) = (f∘g)∘h | 성립 → f∘g∘h로 씀 | 함께 완성하기, 둘 다 3(x−1)² |

### 표 3. 함수 f 와 역함수 f⁻¹ (p.117~118)
| 구분 | f | f⁻¹ |
|---|---|---|
| 방향 | X → Y | Y → X |
| 정의역 | X | Y |
| 공역 | Y | X |
| 존재 조건 | — | f가 일대일대응 |
| 관계 | y=f(x) | x=f⁻¹(y) |
| 그래프 | 점 (a, b) | 점 (b, a), y=x 대칭 |

### 표 4. 역함수와 합성 (p.117)
| 식 | 값 | 의미 |
|---|---|---|
| (f⁻¹∘f)(x) | x (x∈X) | X에서의 항등함수 |
| (f∘f⁻¹)(y) | y (y∈Y) | Y에서의 항등함수 |
| (f⁻¹)⁻¹ | f | 역함수의 역함수는 원래 함수 |

## 시험 함정 포인트
- g∘f 는 g 먼저가 **아니라** f를 먼저 적용한 뒤 g를 적용한다: (g∘f)(x)=g(f(x)). 기호의 오른쪽 함수가 안쪽이다. (p.114)
- 합성함수 g∘f의 정의역은 X, 공역은 Z이다. 중간 집합 Y가 **아니다**. (p.114)
- g∘f는 f의 치역이 g의 정의역의 부분집합일 때 정의된다. (p.114)
- 함수의 합성은 교환법칙이 **성립하지 않지만**, 결합법칙은 **성립한다**. 둘을 바꿔 외우지 말 것. (p.115)
- 역함수는 모든 함수에 있는 것이 **아니라** 일대일대응일 때만 존재한다. 일대일함수만으로는 부족(공역=치역 필요). (p.117)
- f⁻¹(x)는 1/f(x)가 **아니라** 역함수의 함숫값이다. f⁻¹(b)=1 은 f(1)=b 와 같은 뜻이다. (p.117)
- 역함수 구할 때 x를 y에 대한 식으로 푼 뒤 **x와 y를 바꾸는 단계**를 빠뜨리지 말 것. 예제 1: x=⅓y−⅓ 에서 끝내면 안 되고 y=⅓x−⅓. (p.118)
- 함수와 역함수의 그래프는 x축이나 y축이 **아니라** 직선 y=x에 대하여 대칭이다. (p.118)
- f⁻¹∘f는 X에서의 항등함수, f∘f⁻¹는 Y에서의 항등함수 — 정의역이 서로 다르다. (p.117)
- (f⁻¹)⁻¹(3)=f(3)이다. 역함수의 역함수는 원래 함수 f. (p.117)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 합성함수 g∘f | f : X → Y, g : Y → Z에서 x에 g(f(x))를 대응시키는 함수, g∘f : X → Z (p.114) |
| (g∘f)(x) | 합성함수 g∘f에서 x의 함숫값, g(f(x))와 같다 (p.114) |
| 교환법칙(합성) | g∘f=f∘g — 일반적으로 성립하지 않음 (p.115) |
| 결합법칙(합성) | f∘(g∘h)=(f∘g)∘h — 성립, f∘g∘h로 표기 (p.115) |
| 역함수 f⁻¹ | 일대일대응 f : X → Y에서 Y의 각 원소 y에 f(x)=y인 x를 대응시킨 함수 f⁻¹ : Y → X (p.117) |
| y=f⁻¹(x) | x=f⁻¹(y)에서 x와 y를 바꾸어 나타낸 역함수 (p.117) |
| 항등함수 | f⁻¹∘f는 X에서, f∘f⁻¹는 Y에서의 항등함수 (p.117) |
| 직선 y=x에 대한 대칭 | 함수와 역함수 그래프의 관계, 점 (a, b) ↔ (b, a) (p.118) |
