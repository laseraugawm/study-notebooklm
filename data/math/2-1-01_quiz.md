# 집합 퀴즈

## Question 1
다음 중 대상을 명확하게 정할 수 있어 집합인 것은 무엇인가요?

- [ ] 100에 가까운 자연수의 모임
- [ ] 우리 학교에서 키가 큰 학생들의 모임
- [x] 15보다 작은 소수의 모임
- [ ] 아름다운 꽃들의 모임

**Hint:** 누가 선택하더라도 그 모임에 속하는 대상이 동일하게 구별되어야 집합입니다.

## Question 2
집합 $A = \{x \mid x\text{는 } 12\text{의 약수}\}$에 대한 설명으로 옳은 것은 무엇인가요?

- [ ] $5 \in A$
- [ ] $6 \notin A$
- [x] 원소나열법으로 나타내면 $A = \{1, 2, 3, 4, 6, 12\}$이다.
- [ ] $n(A) = 5$

**Hint:** $12$의 약수를 먼저 나열해 보고 원소의 포함 관계와 개수를 확인해 보세요.

## Question 3
다음 중 설명이 옳지 않은 것은 무엇인가요?

- [ ] $n(\emptyset) = 0$이다.
- [ ] 집합 $A = \{0\}$에 대하여 $n(A) = 1$이다.
- [x] 집합 $B = \{\emptyset\}$에 대하여 $n(B) = 0$이다.
- [ ] 집합 $C = \{x \mid x^2 + 1 = 0, x\text{는 실수}\}$이면 $C = \emptyset$이다.

**Hint:** 중괄호 안에 기호가 들어있으면 그 기호 자체가 하나의 원소로 취급됩니다.

## Question 4
집합 $A = \{a, b\}$에 대한 기호의 사용으로 옳은 것은 무엇인가요?

- [ ] $a \subseteq A$
- [ ] \{a\} \in A
- [ ] \emptyset \in A
- [x] \{a, b\} \subseteq A

**Hint:** 원소와 집합 사이에는 $\in$, 집합과 집합 사이에는 $\subseteq$ 기호를 사용합니다.

## Question 5
두 집합 $A = \{4, 6, 2a\}$와 $B = \{10, a+1, 2b\}$에 대하여 $A = B$일 때, 실수 $a, b$의합 $a+b$의 값은 얼마인가요?

- [ ] 6
- [x] 7
- [ ] 8
- [ ] 9

**Hint:** 두 집합이 서로 같으려면 원소가 완전히 일치해야 하므로, $2a$가 $B$의 원소 $10$과 같은 경우를 생각해 보세요.

## Question 6
집합 $A = \{1, 2, 3, 4, 5\}$의 부분집합 중 원소 $1$을 포함하지 않는 부분집합의 개수는 몇 개인가요?

- [ ] 8
- [x] 16
- [ ] 31
- [ ] 32

**Hint:** 특정한 원소를 반드시 갖지 않는 부분집합의 개수는 해당 원소를 제외한나머지 원소들로 만든 부분집합의 개수와 같습니다.

## Question 7
집합 $A = \{a, b, c\}$의 진부분집합의 총개수는 몇 개인가요?

- [ ] 6
- [x] 7
- [ ] 8
- [ ] 9

**Hint:** 진부분집합은 부분집합 중에서 자기 자신을 제외한 집합입니다.

## Question 8
집합 $A = \{x \mid x\text{는 } 20 \text{ 이하의 } 4\text{의 배수}\}$를 원소나열법으로 바르게 나타낸 것은 무엇인가요?

- [ ] $A = \{4, 8, 12, 16\}$
- [x] $A = \{4, 8, 12, 16, 20\}$
- [ ] $A = \{1, 2, 4, 8, 12, 16, 20\}$
- [ ] $A = \{4, 8, 12, 16, 20, 24\}$

**Hint:** '이하'라는 조건은 해당 숫자를 포함함을 의미합니다.
