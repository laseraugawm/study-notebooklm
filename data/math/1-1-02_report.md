## 핵심 개념

### 1. 직선의 방정식 (p.18)
- **준비하기**: 일차방정식 x − 3y + 9 = 0 이 나타내는 직선의 기울기와 y절편 → `y = (1/3)x + 3` 이므로 기울기 1/3, y절편 3
- **생각 틔우기**: 점 A(0, 1)을 지나는 직선이 하나로 결정되려면 무엇을 더 알아야 할까? — 점 A를 지나는 직선은 무수히 많으므로 기울기(또는 다른 한 점)를 더 알아야 한다.
- 날개: 직선 y = ax + b (a, b는 상수)의 기울기 `a = (y의 값의 증가량)/(x의 값의 증가량)`
- **① 점 A(x₁, y₁)을 지나고 기울기가 m인 직선**
  - 구하는 직선을 y = mx + n ……① 이라 하면 점 A를 지나므로 y₁ = mx₁ + n, 즉 n = y₁ − mx₁
  - ①에 대입하여 정리 → **`y − y₁ = m(x − x₁)`**
  - 날개: 점 A(x₁, y₁)을 지나고 x축에 평행하거나 x축과 일치하는 직선은 기울기가 0이므로 **y = y₁**
- **② 서로 다른 두 점 A(x₁, y₁), B(x₂, y₂)를 지나는 직선**
  - (ⅰ) x₁ ≠ x₂ 일 때: 기울기 `(y₂ − y₁)/(x₂ − x₁)` 이고 점 A를 지나므로 **`y − y₁ = ((y₂ − y₁)/(x₂ − x₁))(x − x₁)`**
  - (ⅱ) x₁ = x₂ 일 때: y축에 평행하거나 y축과 일치하고, 모든 점의 x좌표가 항상 x₁ 이므로 **x = x₁**
- 보기
  - 점 (−3, 1)을 지나고 기울기가 4: `y − 1 = 4(x + 3)`, 즉 y = 4x + 13
  - 두 점 (3, 6), (5, 2)를 지남: `y − 6 = ((2 − 6)/(5 − 3))(x − 3)`, 즉 y = −2x + 12

### 2. 스스로 익히기 (p.19)
1. ⑴ 점 (1, −2)를 지나고 기울기 3 → y = 3x − 5 ⑵ 점 (10, 5)를 지나고 x축에 평행 → y = 5
2. ⑴ (−2, 3), (2, 7) → y = x + 5 ⑵ (5, −2), (5, 9) → x좌표가 같으므로 x = 5
3. x절편이 a, y절편이 b인 직선의 방정식이 **`x/a + y/b = 1`** 임을 설명(단, ab ≠ 0)
   - 두 점 (a, 0), (0, b)를 지나므로 기울기 −b/a, `y = −(b/a)(x − a)` → 양변을 정리하면 bx + ay = ab → 양변을 ab로 나누어 x/a + y/b = 1
4. 두 직선 y = 2x + 7, y = −(1/2)x + 2의 교점과 점 (2, 5)를 지나는 직선 → 교점 (−2, 3), 기울기 2/4 = 1/2 → y = (1/2)x + 4
- 계산 결과는 교과서 해설 쪽(144쪽)이 소스에 없어 직접 계산한 값이다.

### 3. 역량 키우기(정보처리·공학 도구 활용하기) (p.19)
- 알지오매스에서 일차방정식 `3x − y − 5 + k(x + y − 3) = 0` 이 나타내는 직선 그리기
  1. 슬라이더 k를 k = 1, −1, −3으로 움직여 각 직선의 방정식 구하기 → k = 1: 4x − 8 = 0 즉 x = 2, k = −1: 2x − 2y − 2 = 0 즉 y = x − 1, k = −3: −4y + 4 = 0 즉 y = 1
  2. 실수 k의 값에 관계없이 항상 지나는 점 → 3x − y − 5 = 0 과 x + y − 3 = 0 을 동시에 만족하는 점 (2, 1)
- 그림에서 세 직선(세로선·대각선·가로선)이 한 점에서 만난다.

### 4. 두 직선의 평행 조건 (p.20)
- **준비하기**: 두 점 (4, 2), (−1, 7)을 지나는 직선 → 기울기 −1, y = −x + 6
- **생각 틔우기**: 일정한 방향으로 기울어진 건물(피사의 사탑 사진)을 좌표평면에 나타냄. 직선 l은 O(0, 0)과 (2, 25), 직선 l′은 (12, 0)과 (14, 25)를 지남
  - 기울기: 둘 다 25/2 로 같다.
  - y절편: l은 0, l′은 −150 으로 다르다.
- 두 직선 l: y = mx + n, l′: y = m′x + n′ 이 서로 평행하면 기울기는 같고 y절편은 다르므로 **m = m′, n ≠ n′**. 거꾸로 m = m′, n ≠ n′ 이면 두 직선은 서로 평행하다.
- **두 직선의 평행 조건**: 두 직선 y = mx + n, y = m′x + n′ 에서
  1. 두 직선이 서로 평행하면 m = m′, n ≠ n′ 이다.
  2. m = m′, n ≠ n′ 이면 두 직선은 서로 평행하다.
- 날개: **m = m′, n = n′ 이면 두 직선은 일치한다.**
- **예제 1** (p.20): 점 (2, 2)를 지나고 직선 y = (1/2)x − 1에 평행한 직선
  - 기울기가 1/2이고 점 (2, 2)를 지나므로 `y − 2 = (1/2)(x − 2)`
  - 답: **y = (1/2)x + 1**

### 5. 스스로 익히기 (p.21)
1. 보기 ㄱ. x + 2y = 1 ㄴ. 2x − y + 2 = 0 ㄷ. y = −2x + 8 ㄹ. 2x + y − 3 = 0 중 서로 평행한 것
   - y = mx + n 꼴로 고치면 ㄱ: y = −(1/2)x + 1/2, ㄴ: y = 2x + 2, ㄷ: y = −2x + 8, ㄹ: y = −2x + 3 → **ㄷ과 ㄹ** (기울기 −2 같고 y절편 다름)
2. (예제 1 유형) ⑴ 점 (3, 1)을 지나고 y = 2x − 3에 평행 → y = 2x − 5 ⑵ 점 (−3, 5)를 지나고 3x + y − √2 = 0에 평행 → 기울기 −3, y = −3x − 4
3. 두 점 (3, −4), (−1, −2)를 지나는 직선에 평행하고 x절편이 −1 → 기울기 −1/2, 점 (−1, 0)을 지나므로 y = −(1/2)x − 1/2
4. 점 (a, 2)를 지나고 3x − y + 4 = 0에 평행한 직선이 점 (2, 5)를 지날 때 → 기울기 3, y = 3x − 1, 2 = 3a − 1 에서 a = 1
- **역량 키우기(의사소통·원리 설명하기)**: 두 직선 ax + by + c = 0, a′x + b′y + c′ = 0이 서로 평행할 때 a/a′, b/b′, c/c′의 관계 설명(단, abc ≠ 0, a′b′c′ ≠ 0)
  - 대화 힌트: "두 직선의 기울기가 서로 같아야 해.", "두 직선의 y절편은 달라야 해."
  - 기울기 −a/b = −a′/b′, y절편 −c/b ≠ −c′/b′ → **`a/a′ = b/b′ ≠ c/c′`**

### 6. 두 직선의 수직 조건 (p.22)
- **준비하기**: 점 (1, −2)를 지나고 y = 4x − 11에 평행한 직선 → y = 4x − 6
- 유도
  1. l: y = mx + n, l′: y = m′x + n′ 이 서로 수직이면, 각각에 평행하고 원점을 지나는 y = mx, y = m′x도 서로 수직
  2. 두 직선과 직선 x = 1의 교점 P(1, m), Q(1, m′). 삼각형 POQ는 직각삼각형
  3. 피타고라스 정리: `OP² + OQ² = PQ²` → `(1 + m²) + (1 + m′²) = (m − m′)²` ……①
  4. 정리하면 **mm′ = −1**
  5. 거꾸로 mm′ = −1 이면 ①이 성립하므로 삼각형 POQ는 직각삼각형 → 두 직선은 서로 수직
- **두 직선의 수직 조건**: 두 직선 y = mx + n, y = m′x + n′ 에서
  1. 두 직선이 서로 수직이면 mm′ = −1 이다.
  2. mm′ = −1 이면 두 직선은 서로 수직이다.
- 보기: y = −3x + 5, y = (1/3)x + 1 → 기울기의 곱 `−3 × 1/3 = −1` 이므로 서로 수직
- **예제 1** (p.22): 점 (3, −2)를 지나고 직선 y = x + 5에 수직인 직선
  - 구하는 기울기를 m이라 하면 1 × m = −1, 즉 m = −1
  - `y − (−2) = −(x − 3)`, 즉 **y = −x + 1**

### 7. 스스로 익히기 (p.23)
1. 보기 ㄱ. 2x + y = 1 ㄴ. x + 2y − 4 = 0 ㄷ. x − y + 2 = 0 ㄹ. y = 2x − 3 중 서로 수직인 것
   - 기울기 ㄱ: −2, ㄴ: −1/2, ㄷ: 1, ㄹ: 2 → 곱이 −1인 것은 **ㄴ과 ㄹ**
2. (예제 1 유형) ⑴ 점 (4, −1)을 지나고 y = 3x − 2에 수직 → y = −(1/3)x + 1/3 ⑵ 점 (1, 2)를 지나고 x − 5y − 1 = 0에 수직 → 기울기 −5, y = −5x + 7
3. 두 점 (1, 2), (4, −4)를 지나는 직선에 수직이고 점 (3, 5)를 지남 → 기울기 −2의 수직이므로 1/2, y = (1/2)x + 7/2
4. 점 (6, a)를 지나고 2x + y − 3 = 0에 수직인 직선이 점 (4, 1)을 지날 때 → 기울기 1/2, y = (1/2)x − 1, a = 2
- **역량 키우기(의사소통·원리 설명하기)**: 두 직선 ax + by + c = 0, a′x + b′y + c′ = 0이 서로 수직이면 **aa′ + bb′ = 0** 임을 설명(단, ab ≠ 0, a′b′ ≠ 0)
  - 힌트: "두 직선이 서로 수직이면 기울기의 곱이 −1이야!" → `(−a/b) × (−a′/b′) = −1` → aa′ = −bb′ → aa′ + bb′ = 0

### 8. 점과 직선 사이의 거리 (p.24)
- **준비하기**: y = 2x − 3을 ax + by + c = 0 꼴로 → 2x − y − 3 = 0
- 그림: 투호 놀이 — "내가 서 있는 자리가 투호의 항아리와 제일 가까워!"
- **점과 직선 사이의 거리**: 좌표평면 위의 한 점 P에서 점 P를 지나지 않는 직선 l에 내린 수선의 발을 H라고 할 때, **선분 PH의 길이** (p.24)
- 유도 (점 P(x₁, y₁), 직선 l: ax + by + c = 0, a ≠ 0, b ≠ 0)
  1. 수선의 발 H(x₂, y₂). 직선 PH의 기울기 `(y₂ − y₁)/(x₂ − x₁)`, 직선 l의 기울기 `−a/b`, 서로 수직이므로 곱이 −1 → `b(x₂ − x₁) − a(y₂ − y₁) = 0` ……①
  2. H가 l 위의 점이므로 ax₂ + by₂ + c = 0. 양변에서 ax₁ + by₁ + c를 빼면 `a(x₂ − x₁) + b(y₂ − y₁) = −(ax₁ + by₁ + c)` ……②
  3. ①, ②를 제곱하여 더하면 `(a² + b²)(x₂ − x₁)² + (a² + b²)(y₂ − y₁)² = (ax₁ + by₁ + c)²`
  4. `PH = √((x₂ − x₁)² + (y₂ − y₁)²) = |ax₁ + by₁ + c| / √(a² + b²)` ……③
  - 날개: a = 0, b ≠ 0 또는 a ≠ 0, b = 0일 때도 ③이 성립한다.
- **공식**: 점 (x₁, y₁)과 직선 ax + by + c = 0 사이의 거리는 **`|ax₁ + by₁ + c| / √(a² + b²)`**
- 날개: 원점과 직선 ax + by + c = 0 사이의 거리는 `|c| / √(a² + b²)`
- 보기: 점 (2, 1)과 직선 4x + 3y − 1 = 0 → `|4×2 + 3×1 − 1| / √(4² + 3²) = 10/√25 = 2`

### 9. 스스로 익히기 (p.25)
1. ⑴ 점 (2, −1), 12x − 5y − 3 = 0 → |24 + 5 − 3|/13 = 2 ⑵ 점 (−4, 2), y = −2x − 1 → 2x + y + 1 = 0 으로 고쳐 |−8 + 2 + 1|/√5 = √5 ⑶ 원점, x − 3y + 20 = 0 → 20/√10 = 2√10
2. 평행한 두 직선 2x − y + 3 = 0, 2x − y − 7 = 0 사이의 거리 → 한 직선 위의 점 (0, 3)과 다른 직선 사이의 거리 |−3 − 7|/√5 = 2√5
3. 기울기가 2이고 점 (4, 1)에서의 거리가 2√5인 직선 모두 → 2x − y + k = 0, |7 + k|/√5 = 2√5, k = 3 또는 −17 → y = 2x + 3, y = 2x − 17
4. 점 (1, 0)을 지나고 점 (−1, 1)에서의 거리가 2인 직선 모두 → x = 1 (거리 2), 그리고 기울기 m인 경우 |−2m − 1|/√(m² + 1) = 2 에서 m = 3/4 → y = (3/4)x − 3/4
   - 기울기가 없는 직선 x = 1을 빠뜨리지 않도록 주의
- **역량 키우기(문제해결·적절한 전략 사용하기)**: 세 점 O(0, 0), A(x₁, y₁), B(x₂, y₂)에서 삼각형 OAB의 넓이가 **`½|x₁y₂ − x₂y₁|`** 임을 확인
  - 1단계: 직선 OA의 방정식 → y₁x − x₁y = 0
  - 2단계: 점 B와 직선 OA 사이의 거리 `|x₂y₁ − x₁y₂| / √(x₁² + y₁²)` 와 `OA = √(x₁² + y₁²)`
  - 3단계: 넓이 = ½ × OA × (높이) = ½|x₁y₂ − x₂y₁|
  - 적용하기: O(0, 0), A(6, 4), B(2, 5) → ½|6×5 − 2×4| = 11

## 비교·정리표

### 표 1. 직선의 방정식 구하는 경우
| 주어진 조건 | 방정식 | 보기(p.18) |
|---|---|---|
| 한 점 (x₁, y₁)과 기울기 m | `y − y₁ = m(x − x₁)` | (−3, 1), 기울기 4 → y = 4x + 13 |
| 두 점, x₁ ≠ x₂ | `y − y₁ = ((y₂ − y₁)/(x₂ − x₁))(x − x₁)` | (3, 6), (5, 2) → y = −2x + 12 |
| 두 점, x₁ = x₂ | x = x₁ (y축에 평행) | (5, −2), (5, 9) → x = 5 |
| x축에 평행 | y = y₁ (기울기 0) | (10, 5) → y = 5 |
| x절편 a, y절편 b (ab ≠ 0) | `x/a + y/b = 1` | p.19 스스로 익히기 3 |

### 표 2. 두 직선의 위치 관계
| 관계 | y = mx + n, y = m′x + n′ | ax + by + c = 0, a′x + b′y + c′ = 0 |
|---|---|---|
| 평행 | m = m′, n ≠ n′ | `a/a′ = b/b′ ≠ c/c′` |
| 일치 | m = m′, n = n′ | — |
| 수직 | mm′ = −1 | aa′ + bb′ = 0 |

### 표 3. 거리 공식
| 거리 | 공식 | 보기 |
|---|---|---|
| 점 (x₁, y₁)과 직선 ax + by + c = 0 | `\|ax₁ + by₁ + c\| / √(a² + b²)` | (2, 1)과 4x + 3y − 1 = 0 → 2 |
| 원점과 직선 | `\|c\| / √(a² + b²)` | 원점과 x − 3y + 20 = 0 → 2√10 |
| 평행한 두 직선 | 한 직선 위의 점에서 다른 직선까지의 거리 | p.25 스스로 익히기 2 |

## 시험 함정 포인트
- 두 점의 x좌표가 같으면 기울기를 구할 수 없다. 이때 직선은 y = … 이 아니라 **x = x₁** 이다. (p.18)
- x축에 평행한 직선은 x = x₁ 이 아니라 **y = y₁** 이다(기울기 0). (p.18 날개)
- 평행 조건은 기울기만 같으면 되는 것이 아니라 **y절편이 달라야** 한다. y절편까지 같으면 평행이 아니라 **일치**이다. (p.20)
- 수직 조건은 기울기의 곱이 1이 아니라 **−1** 이다. 기울기 1인 직선에 수직인 직선의 기울기는 −1이다. (p.22 예제 1)
- 일반형 ax + by + c = 0 의 기울기는 a/b 가 아니라 **−a/b** 이다. 보기에서 평행·수직을 판단할 때는 먼저 y = mx + n 꼴로 고친다. (p.21, p.23)
- 점과 직선 사이의 거리 공식은 직선을 **ax + by + c = 0 꼴(우변 0)** 로 고친 뒤 써야 한다. y = −2x − 1 은 2x + y + 1 = 0 으로 바꾼다. (p.24~25)
- 거리 공식의 분자에는 **절댓값**을 붙인다. 부호 때문에 거리가 음수가 될 수 없다. (p.24)
- 평행 조건을 일반형으로 쓸 때 `a/a′ = b/b′ = c/c′` 이면 평행이 아니라 일치이므로, 평행은 **`a/a′ = b/b′ ≠ c/c′`** 이다. (p.21 역량 키우기)
- "한 점을 지나는 직선"을 y = m(x − 1) 로만 두면 **기울기가 없는 직선 x = 1** 을 놓친다. (p.25 스스로 익히기 4)
- k의 값에 관계없이 항상 지나는 점은 k에 대한 항등식으로 보아 **두 식이 동시에 0** 이 되는 점이다. (p.19 역량 키우기)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 기울기 | (y의 값의 증가량)/(x의 값의 증가량) (p.18) |
