# 무리식과무리함수 퀴즈

## Question 1
다음 중 무리식에 대한 개념 설명으로 가장 옳은 것은?

- [ ] 근호 안에 문자가 포함되어 있으면 항상 무리식이다.
- [x] 근호 안에 문자가 포함된 식 중에서 유리식으로 나타낼 수 없는 식을 무리식이라고 한다.
- [ ] 분모에 무리수가 들어있는 모든 분수식을 무리식이라고 한다.
- [ ] 무리함수에서 정의역이 주어지지 않은 경우 근호 안의 식의 값이 $0$ 초과가 되는 실수 집합을 정의역으로 한다.

**Hint:** 무리식의 정의에서 근호 안의 조건과 유리식 표현 가능 여부를 떠올려 보세요.

## Question 2
무리함수 $y=\sqrt{-3x-2}+1$의 정의역을 구하면 무엇입니까?

- [ ] $\left\{ x \;\middle|\; x \ge -\frac{2}{3} \right\}$
- [x] $\left\{ x \;\middle|\; x \le -\frac{2}{3} \right\}$
- [ ] $\left\{ x \;\middle|\; x \ge \frac{2}{3} \right\}$
- [ ] $\left\{ x \;\middle|\; x \le \frac{2}{3} \right\}$

**Hint:** 근호 안에 있는 식의 값이 $0$ 이상이 되는 $x$의 범위를 찾아보세요.

## Question 3
무리함수 $y=\sqrt{ax}$ ($a \neq 0$)의 역함수 식과 그 정의역으로 옳은 것은?

- [x] $y=\frac{x^2}{a}$ ($x \ge 0$)
- [ ] $y=ax^2$ ($x \ge 0$)
- [ ] $y=\frac{x^2}{a}$ (실수 전체)
- [ ] $y=-\frac{x^2}{a}$ ($x \le 0$)

**Hint:** $x$와 $y$의 위치를 바꾼 후 치역이 정의역으로 변하는 과정에 주의하세요.

## Question 4
무리함수 $y=\sqrt{ax}$ ($a \neq 0$)의 그래프 성질에 대한 설명으로 옳지 않은 것은?

- [ ] $a$의 절댓값이 커질수록 그래프는 $x$축으로부터 멀어진다.
- [x] $a < 0$일 때, 치역은 $\{y \mid y \le 0\}$이다.
- [ ] 무리함수 $y=-\sqrt{ax}$의 그래프는 $y=\sqrt{ax}$의 그래프와 $x$축에 대하여 대칭이다.
- [ ] $y=\sqrt{ax}$의 그래프와 그 역함수의 그래프는 직선 $y=x$에 대하여 대칭이다.

**Hint:** 근호 앞의 부호가 치역에 미치는 영향과 절댓값 $|a|$의 의미를 파악해 보세요.

## Question 5
무리함수 $y=\sqrt{a(x-p)}+q$ ($a \neq 0$)의 정의역과 치역에 대한 설명으로 옳은 것은?

- [x] $a > 0$일 때, 정의역은 $\{x \mid x \ge p\}$이고 치역은 $\{y \mid y \ge q\}$이다.
- [ ] $a < 0$일 때, 정의역은 $\{x \mid x \ge p\}$이고 치역은 $\{y \mid y \ge q\}$이다.
- [ ] $a > 0$일 때, 정의역은 $\{x \mid x \le p\}$이고 치역은 $\{y \mid y \le q\}$이다.
- [ ] $a < 0$일 때, 치역은 $\{y \mid y \le q\}$이다.

**Hint:** $a$의 부호가 $x$의 범위에 미치는 영향과 $q$가 $y$의 범위에 미치는 영향을 고려하세요.

## Question 6
함수 $y=\sqrt{ax}$의 그래프를 $x$축의 방향으로 $-3$만큼, $y$축의 방향으로 $1$만큼 평행이동하였더니 점 $(-1, 7)$을 지났다. 이때 상수 $a$의 값은?

- [ ] $a = 6$
- [ ] $a = 9$
- [x] $a = 18$
- [ ] $a = 36$

**Hint:** 평행이동한 무리함수식을 먼저 구한 뒤 해당 점의 좌표를 대입해 보세요.

## Question 7
무리함수 $y=\sqrt{2x+6}-2$의 정의역과 치역으로 바르게 짝지어진 것은?

- [x] 정의역: $\{x \mid x \ge -3\}$, 치역: $\{y \mid y \ge -2\}$
- [ ] 정의역: $\{x \mid x \ge 3\}$, 치역: $\{y \mid y \ge -2\}$
- [ ] 정의역: $\{x \mid x \le -3\}$, 치역: $\{y \mid y \ge 2\}$
- [ ] 정의역: $\{x \mid x \ge -3\}$, 치역: $\{y \mid y \le -2\}$

**Hint:** 근호 안의 식을 $2(x-p)$ 꼴로 묶어 평행이동의 기준점을 찾아보세요.

## Question 8
식 $\frac{2}{\sqrt{x+2}-\sqrt{x}}$를 간단히 한 것으로 옳은 것은? (단, $x > 0$)

- [x] $\sqrt{x+2} + \sqrt{x}$
- [ ] $\sqrt{x+2} - \sqrt{x}$
- [ ] $2(\sqrt{x+2} + \sqrt{x})$
- [ ] $\frac{\sqrt{x+2} + \sqrt{x}}{2}$

**Hint:** 분모의 근호를 없애기 위해 합차 공식을 이용해 분모와 분자에 같은 값을 곱해 보세요.

## Question 9
무리함수 $y=-\sqrt{ax}$ ($a \neq 0$)의 그래프와 정의역 및 치역에 대한 설명으로 옳은 것은?

- [x] $a < 0$일 때, 정의역은 $\{x \mid x \le 0\}$이다.
- [ ] $y=\sqrt{ax}$의 그래프를 $y$축에 대하여 대칭이동한 것이다.
- [ ] $a > 0$일 때, 치역은 $\{y \mid y \ge 0\}$이다.
- [ ] $a$의 값에 관계없이 항상 점 $(0, 1)$을 지난다.

**Hint:** 근호 안의 식 $ax \ge 0$ 조건과 근호 바깥의 마이너스 부호가 치역에 주는 영향을 살펴보세요.

## Question 10

- [x] $6.25$
- [ ] $4$
- [ ] $9$
- [ ] $25$

**Hint:** 그래프가 원점을 지난다는 사실을 이용해 먼저 $b$의 값을 결정해 보세요.
