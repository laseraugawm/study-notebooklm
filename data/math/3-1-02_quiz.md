# 합성함수 퀴즈

## Question 1
두 함수 $f: X \to Y$, $g: Y \to Z$에 대하여 합성함수 $g \circ f$가 정의되기 위해 반드시 만족해야 하는 조건으로 올바른 것은?

- [x] 함수 $f$의 치역이 함수 $g$의 정의역의 부분집합이어야 한다.
- [ ] 두 함수 $f$와 $g$가 모두 일대일대응이어야 한다.
- [ ] 함수 $f$의 정의역과 함수 $g$의 공역이 서로 같아야 한다.
- [ ] 함수 $g$의 치역이 함수 $f$의 정의역의 부분집합이어야 한다.

**Hint:** 합성함수 $g(f(x))$에서 먼저 적용되는 함수 $f$의 함숫값들이 다음 함수 $g$에 입력될 수 있어야 함을 생각해 보세요.

## Question 2
세 함수 $f, g, h$에 대한 합성함수의 성질 설명 중 옳지 않은 것은?

- [x] 두 함수 $f, g$에 대하여 일반적으로 교환법칙 $g \circ f = f \circ g$가 성립한다.
- [ ] 세 함수 $f, g, h$에 대하여 결합법칙 $(f \circ (g \circ h))(x) = ((f \circ g) \circ h)(x)$가 성립한다.
- [ ] 합성함수에서 결합법칙이 성립하므로 괄호 없이 $f \circ g \circ h$로 나타내기도 한다.
- [ ] 합성함수 $g \circ f: X \to Z$에서 $x$의 함숫값은 $(g \circ f)(x) = g(f(x))$이다.

**Hint:** 함수를 합성할 때 적용하는 순서를 바꾸어도 항상 같은 결과가 나오는지 생각해 보세요.

## Question 3
두 함수 $f(x) = |2x - 5|$, $g(x) = x^2 - 3x$에 대하여 $(g \circ f)(2)$의 값은?

- [x] $-2$
- [ ] $2$
- [ ] $0$
- [ ] $-3$

**Hint:** 먼저 $f(2)$의 값을 구한 뒤, 그 결과값을 함수 $g$의 $x$에 대입해 보세요.

## Question 4
세 함수 $f, g, h$에 대하여 $(g \circ f)(x) = 4x - 3$이고 $h(x) = x^2 + x$일 때, $((h \circ g) \circ f)(x)$를 구한 식으로 올바른 것은?

- [x] $16x^2 - 20x + 6$
- [ ] $16x^2 - 24x + 9$
- [ ] $4x^2 + 4x - 3$
- [ ] $16x^2 - 20x + 12$

**Hint:** 합성함수의 결합법칙 $((h \circ g) \circ f)(x) = (h \circ (g \circ f))(x)$를 이용해 보세요.

## Question 5
함수 $f: X \to Y$의 역함수 $f^{-1}: Y \to X$가 존재하기 위한 조건 및 성질에 대한 설명으로 옳은 것은?

- [x] 함수 $f$가 일대일대응일 때에만 역함수 $f^{-1}$가 존재한다.
- [ ] 합성함수 $(f^{-1} \circ f)(x) = x$는 공역 $Y$에서의 항등함수이다.
- [ ] 역함수의 역함수는 원함수와 부호가 반대인 $(f^{-1})^{-1}(x) = -f(x)$이다.
- [ ] $y = f(x)$이면 항상 $y = f^{-1}(x)$가 성립한다.

**Hint:** 역함수는 공역의 각 원소에 대하여 정의역의 원소가 일대일로 다시 대응될 수 있어야 함을 명심하세요.

## Question 6
함수 $f(x) = 3x + 4$에 대하여 역함수 $f^{-1}$가 존재할 때, $f^{-1}(-2)$의 값은?

- [x] $-2$
- [ ] $2$
- [ ] $-\frac{2}{3}$
- [ ] $-10$

**Hint:** $f^{-1}(b) = a \iff f(a) = b$ 관계를 활용해 보세요.

## Question 7
일대일대응인 함수 $y = -4x + 2$의 역함수를 구한 식은?

- [x] $y = -\frac{1}{4}x + \frac{1}{2}$
- [ ] $y = \frac{1}{4}x - \frac{1}{2}$
- [ ] $y = 4x - 2$
- [ ] $y = -\frac{1}{4}x + 2$

**Hint:** 먼저 주어진 식을 $x = f^{-1}(y)$ 형태로 정리한 후, $x$와 $y$를 서로 바꾸어 보세요.

## Question 8
일대일대응인 함수 $y = f(x)$의 그래프와 그 역함수 $y = f^{-1}(x)$의 그래프 사이의 기하학적 대칭 관계에 대한 설명으로 옳은 것은?

- [x] 두 함수의 그래프는 직선 $y = x$에 대하여 대칭이다.
- [ ] 두 함수의 그래프는 $x$축에 대하여 대칭이다.
- [ ] 두 함수의 그래프는 $y$축에 대하여 대칭이다.
- [ ] 두 함수의 그래프는 원점에 대하여 대칭이다.

**Hint:** 점 $(a, b)$와 좌표를 서로 바꾼 점 $(b, a)$가 어떤 직선을 기준으로 대칭되는지 떠올려 보세요.

## Question 9
두 함수 $f(x) = -x + 2$, $g(x) = 2x - 1$에 대하여 합성함수의 역함수인 $(g \circ f)^{-1}(x)$와 항상 같은 식은?

- [x] $(f^{-1} \circ g^{-1})(x)$
- [ ] $(g^{-1} \circ f^{-1})(x)$
- [ ] $(f \circ g)^{-1}(x)$
- [ ] $(g \circ f)(x)$

**Hint:** 합성함수 전체에 역함수를 취할 때 두 함수의 합성 순서가 어떻게 변화하는지 확인해 보세요.

## Question 10
어느 카페에서 음료를 주문할 때 1000원을 할인해 주는 '천 원 할인' $f(x) = x - 1000$과 포장 시 반값으로 할인해 주는 '포장 할인' $g(x) = \frac{1}{2}x$를 모두 운영한다. 정가가 $x > 2000$원인 음료를 구매할 때, 손님에게 금액적으로 더 유리한 할인의 합성함수 식과 설명으로 옳은 것은?

- [x] $(f \circ g)(x) = \frac{1}{2}x - 1000$으로, 포장 할인($g$)을 먼저 적용하는 것이 더 유리하다.
- [ ] $(g \circ f)(x) = \frac{1}{2}x - 500$으로, 천 원 할인($f$)을 먼저 적용하는 것이 더 유리하다.
- [ ] $(f \circ g)(x) = \frac{1}{2}x - 500$으로, 두 할인의 순서에 따른 금액 차이는 없다.
- [ ] $(g \circ f)(x) = \frac{1}{2}x - 1000$으로, 포장 할인($g$)을 나중에 적용하는 것이 더 유리하다.

**Hint:** 포장 할인을 먼저 한 후 천 원 할인을 하는 $(f \circ g)(x)$와 그 반대인 $(g \circ f)(x)$를 각각 구해 결과를 비교해 보세요.
