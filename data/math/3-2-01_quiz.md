# 유리식과유리함수 퀴즈

## Question 1
유리식과 다항식의 정의 및 포함 관계에 대한 설명으로 옳은 것은?

- [x] 다항식은 분모가 상수인 유리식이므로 모든 다항식은 유리식에 포함된다.
- [ ] 분모에 변수 $x$가 포함되어 있는 식만 유리식이라고 정의한다.
- [ ] 유리식 $\frac{A}{B}$에서 분자 $A$는 절대로 상수가 될 수 없다.
- [ ] 모든 유리식은 다항식이다.

**Hint:** 다항식에서 분모가 어떠한 형태(상수)를 가질 수 있는지 고려해 보세요.

## Question 2
유리함수 $y = \frac{2x+3}{3x-6}$의 정의역으로 옳은 것은?

- [x] $\{x \mid x \ne 2\text{인 실수}\}$
- [ ] $\{x \mid x \ne -2\text{인 실수}\}$
- [ ] $\{x \mid x \ne 0\text{인 실수}\}$
- [ ] 실수 전체의 집합

**Hint:** 유리함수에서 함숫값이 정의되지 않는 분모의 조건을 생각해 보세요.

## Question 3
유리식 $\frac{x}{x+2} + \frac{x-6}{x^2-4}$를 간단히 계산한 식은?

- [x] $\frac{x-3}{x-2}$
- [ ] $\frac{x+3}{x-2}$
- [ ] $\frac{x-3}{x+2}$
- [ ] $\frac{2x-6}{x^2-4}$

**Hint:** 두 분수의 분모를 인수분해한 뒤 공통분모로 통분하여 계산하세요.

## Question 4
유리함수 $y = \frac{k}{x} (k \ne 0)$의 그래프에 대한 설명으로 옳은 것은?

- [x] $k$의 절댓값이 커질수록 그래프는 원점으로부터 멀어진다.
- [ ] $k < 0$이면 그래프는 제1사분면과 제3사분면에 위치한다.
- [ ] 그래프의 점근선은 두 직선 $y=x$와 $y=-x$이다.
- [ ] 그래프는 $y$축에 대하여 대칭이다.

**Hint:** $k$의 값과 절댓값이 그래프의 위치와 원점과의 거리에 미치는 영향을 떠올려 보세요.

## Question 5
유리함수 $y = \frac{-2}{x+4} - 1$의 점근선의 방정식과 치역으로 올바르게 짝지어진 것은?

- [x] 점근선: $x = -4, y = -1$, 치역: $\{y \mid y \ne -1\text{인 실수}\}$
- [ ] 점근선: $x = 4, y = -1$, 치역: $\{y \mid y \ne -1\text{인 실수}\}$
- [ ] 점근선: $x = -4, y = 1$, 치역: $\{y \mid y \ne 1\text{인 실수}\}$
- [ ] 점근선: $x = 4, y = 1$, 치역: $\{y \mid y \ne 1\text{인 실수}\}$

**Hint:** 표준형 $y = \frac{k}{x-p} + q$에서 $p$와 $q$가 점근선 및 치역에 주는 영향을 파악하세요.

## Question 6
유리함수 $y = \frac{-3x-8}{x+2}$의 그래프의 점근선의 방정식으로 옳은 것은?

- [x] $x = -2, y = -3$
- [ ] $x = 2, y = -3$
- [ ] $x = -2, y = 3$
- [ ] $x = -8, y = -3$

**Hint:** 일반형 $y = \frac{ax+b}{cx+d}$를 $y = \frac{k}{x-p} + q$의 표준형 꼴로 변형하여 분석하세요.

## Question 7
이집트 분수의 성질 $\frac{1}{x} = \frac{1}{x+1} + \frac{1}{x(x+1)}$을 활용하여 분수 $\frac{1}{5}$을 두 이집트 분수의 합으로 나타낼 때, 빈칸에 들어갈 알맞은 분수는?
$$\frac{1}{5} = \frac{1}{6} + \text{___}$$

- [x] $\frac{1}{30}$
- [ ] $\frac{1}{25}$
- [ ] $\frac{1}{20}$
- [ ] $\frac{1}{15}$

**Hint:** 공식 $\frac{1}{x} = \frac{1}{x+1} + \frac{1}{x(x+1)}$에 $x=5$를 대입하여 계산해 보세요.

## Question 8
수심 $x\text{ m}$에서 권장되는 산소량의 백분율 $f(x)\%$가 $f(x) = \frac{1980}{x+99} (0 < x \le 200)$으로 구해질 때, 권장 산소량의 백분율이 $10\%$가 되기 위한 수심 $x$의 값은?

- [x] $99\text{ m}$
- [ ] $45\text{ m}$
- [ ] $90\text{ m}$
- [ ] $110\text{ m}$

**Hint:** $f(x) = 10$을 만족하는 일차방정식 $10(x+99) = 1980$을 풀어보세요.

## Question 9
유리함수 $y = \frac{2x-1}{x+1}$의 그래프는 유리함수 $y = -\frac{3}{x}$의 그래프를 $x$축의 방향으로 $p$만큼, $y$축의 방향으로 $q$만큼 평행이동한 것이다. 이때 상수 $p + q$의 값은?

- [x] $1$
- [ ] $3$
- [ ] $-1$
- [ ] $-3$

**Hint:** 함수를 $y = -\frac{3}{x-p} + q$ 꼴로 바꾸어 $p$와 $q$의 값을 찾아보세요.

## Question 10

- [x] $\frac{x+2}{x+1}$
- [ ] $\frac{x-2}{x+1}$
- [ ] $\frac{x+2}{x-1}$
- [ ] $\frac{x-6}{x+1}$

**Hint:** 두 번째 분수의 분모 $x^2-2x-3$을 먼저 인수분해하여 공통분모를 구하세요.
