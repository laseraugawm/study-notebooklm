## 핵심 개념

### 1. 대응과 함수
- 생각 틔우기: 멸종 위기 동물의 집합 X(파푸아화식조, 시베리아호랑이, 갈라파고스땅거북, 나일악어)와 대륙의 집합 Y(아시아, 아프리카, 오세아니아, 아메리카, 유럽)에서 각 동물을 주로 서식하는 대륙에 화살표로 연결해 보는 활동 (p.109)
- **대응**: 공집합이 아닌 두 집합 X, Y에 대하여 X의 원소에 Y의 원소를 짝 지은 것을 집합 X에서 집합 Y로의 대응이라고 한다. X의 원소 x에 Y의 원소 y가 대응하는 것을 기호로 `x → y` 로 나타낸다. (p.109)
- **함수**: X의 각 원소에 Y의 원소가 **오직 하나씩** 대응할 때, 이 대응을 집합 X에서 집합 Y로의 함수라고 한다. (p.109)
- 기호: 집합 X에서 집합 Y로의 함수를 f라고 할 때 `f : X → Y` 로 나타낸다. (p.109)
- 함수(function)는 일반적으로 알파벳 소문자 f, g, h 등으로 나타낸다. (p.109)
- 인물: 디리클레(Dirichlet, 1805~1859) — 집합 사이의 대응 관계로 함수의 개념을 설명한 독일의 수학자 (p.109) / 오일러(Euler, 1707~1783) — 함수의 기호 y=f(x)를 처음 사용한 스위스의 수학자 (p.110)

### 2. 정의역, 공역, 치역, 함숫값
- **정의역**: 함수 f : X → Y에서 집합 X (p.109)
- **공역**: 함수 f : X → Y에서 집합 Y (p.109)
- **함숫값**: 정의역 X의 원소 x에 공역 Y의 원소 y가 대응할 때 y=f(x)로 나타내고, f(x)를 x의 함숫값이라고 한다. (p.109)
- **치역**: 함숫값 전체의 집합 `{f(x) | x∈X}` (p.109)
- 함수 f : X → Y의 치역은 공역 Y의 **부분집합**이다. (p.109)

### 3. 보기 — 함수인지 판별 (X={1, 2, 3}에서 Y={a, b, c}로의 대응) (p.110)
1. ➊ X의 원소 3에 대응하는 Y의 원소가 **없으므로** 함수가 아니다.
2. ➋ X의 원소 2에 대응하는 Y의 원소가 a와 c **2개이므로** 함수가 아니다.
3. ➌ X의 각 원소에 Y의 원소가 오직 하나씩 대응하므로 함수이다. 정의역 {1, 2, 3}, 공역 {a, b, c}, 치역 {a, b}
   - 공역의 원소 c는 대응되는 원소가 없어도 괜찮다(치역에 들어가지 않을 뿐).

### 4. 정의역·공역을 생략하는 경우
- 정의역과 공역이 실수 전체의 집합의 부분집합인 함수 y=f(x)는 정의역이나 공역을 제시하지 않기도 한다. (p.110)
  - 이때 정의역은 **f(x)가 정의되는 실수 x의 값 전체의 집합**, 공역은 **실수 전체의 집합**으로 생각한다. (p.110)

### 5. 서로 같은 함수
- 정의역과 공역이 각각 같은 두 함수 f : X → Y, g : X → Y에서 정의역의 모든 원소 x에 대하여 f(x)=g(x)일 때, 두 함수 f와 g는 **서로 같다**고 하며 기호로 f=g로 나타낸다. (p.110)
- 예: 정의역이 {−1, 1}인 두 함수 f(x)=x, g(x)=x³에 대하여 f(−1)=g(−1)=−1, f(1)=g(1)=1이므로 f=g이다. (p.110)
  - 식의 모양이 달라도 정의역의 모든 원소에서 함숫값이 같으면 같은 함수이다.

### 6. 함수의 그래프
- **함수의 그래프**: 함수 f : X → Y에서 정의역 X의 각 원소 x와 이에 대응하는 함숫값 f(x)의 순서쌍 전체의 집합 `{(x, f(x)) | x∈X}` 를 함수 y=f(x)의 그래프라고 한다. (p.110)
- 정의역과 공역의 원소가 모두 실수일 때, 함수의 그래프는 순서쌍 (x, f(x))를 좌표로 하는 점을 좌표평면 위에 나타내어 그릴 수 있다. (p.110)
- 보기: 정의역이 {−1, 0, 1}인 함수 y=x²의 그래프는 {(−1, 1), (0, 0), (1, 1)} — 좌표평면 위에 **점 3개**로 나타난다. (p.110)
- **그래프 판별법**: 함수의 그래프는 정의역의 각 원소 a에 대하여 y축에 평행한 직선 x=a와 **오직 한 점**에서 만난다. (p.110)

### 7. 공학 도구 활용하기 — y=|x|가 함수인지 (p.111)
1. 알지오매스 입력창에 y=x를 입력 후 범위를 x≥0으로, y=−x를 입력 후 범위를 x<0으로 설정한다.
2. x=a를 입력한 후 슬라이더 a를 움직여 y=|x|가 함수인지 확인한다(직선 x=a와 한 점에서만 만나는지).
- 확장하기: `y = x²−2x+2 (x≥1), y = −2x+3 (x<1)` 의 그래프를 그리고 함수인지 알아보기

### 8. 여러 가지 함수 (p.112)
- **일대일함수**: 함수 f : X → Y에서 정의역 X의 임의의 두 원소 x₁, x₂에 대하여 `x₁≠x₂ 이면 f(x₁)≠f(x₂)` 를 만족시킬 때, f를 X에서 Y로의 일대일함수라고 한다. (p.112)
  - 그림 예: X={1, 2, 3}, Y={a, b, c, d}에서 서로 다른 원소가 서로 다른 원소로 대응(d처럼 남는 원소 있음) — 일대일함수이지만 공역≠치역 (p.112)
- **일대일대응**: 함수 f : X → Y가 일대일함수이고 **공역과 치역이 같을 때**, f를 X에서 Y로의 일대일대응이라고 한다. (p.112)
- 포함 관계: 함수 ⊃ 일대일함수 ⊃ 일대일대응 (p.112 벤 다이어그램)
- **항등함수**: 함수 f : X → X에서 정의역 X의 각 원소에 그 자신이 대응할 때, 즉 f(x)=x일 때, f를 X에서의 항등함수라고 한다. (p.112)
  - 항등함수는 일대일대응이다. (p.112)
- **상수함수**: 함수 g : X → Y에서 정의역 X의 모든 원소에 공역 Y의 단 하나의 원소가 대응할 때, 즉 g(x)=c (c는 상수)일 때, g를 상수함수라고 한다. (p.112)
  - 그림 예: X={1, 2, 3}의 모든 원소가 Y={2, 4, 6}의 4에 대응 (p.112)
  - 상수함수의 치역은 원소의 개수가 1인 집합이다. (p.112)

### 9. 보기 — 일대일함수 판별 (p.112)
1. ➊ f(x)=2x: 임의의 두 실수 x₁, x₂에 대하여 x₁≠x₂이면 2x₁≠2x₂, 즉 f(x₁)≠f(x₂)이므로 일대일함수. 또 공역과 치역이 모두 실수 전체의 집합으로 같으므로 **일대일대응**.
2. ➋ g(x)=x²: 정의역의 두 원소 −1, 1에 대하여 −1≠1이지만 (−1)²=1², 즉 g(−1)=g(1)이므로 일대일함수가 **아니다**.

### 10. 스스로 익히기 (p.111, p.113)
- p.111: 1. 대응 그림 중 함수를 찾고 정의역·공역·치역 구하기 / 2. y=−2x², y=4/x의 정의역과 치역 / 3. 정의역 {1, 3}인 f(x)=x²+a, g(x)=bx−8에서 f=g일 때 a, b / 4. 그래프 (1) 직선, (2) 위로 볼록한 포물선, (3) 원 중 함수의 그래프 찾기와 까닭
- p.113: 1. 일대일대응의 그래프 찾기 — (1) y=½x+1, (2) y=x²−1, (3) y=2|x| / 2. 항등함수와 상수함수의 그래프 찾기 — (1) y=x, (2) x=−1(세로 직선), (3) y=2 / 3. 보기 ㄱ. y=5x+7, ㄴ. y=−3, ㄷ. y=x, ㄹ. `y = x² (x≥0), 3x (x<0)` 에서 일대일함수, 일대일대응, 항등함수, 상수함수 찾기
- 실생활과 연결하기(p.113): 학생마다 가입하고 싶은 동아리를 한 명도 빠짐없이 1개씩 적는 것 = 학생의 집합에서 동아리의 집합으로의 함수. 실생활에서 일대일함수나 상수함수가 되는 경우 말해 보기

## 시험 함정 포인트
- 공역의 원소가 남아도 함수가 **될 수 있다**. 함수 조건은 X(정의역) 쪽 원소가 "빠짐없이, 하나씩" 대응하는 것이지 Y 쪽이 아니다. (p.110 ➌)
- 치역은 공역이 **아니라** 함숫값 전체의 집합이다. 치역 ⊂ 공역. (p.109)
- 정의역·공역이 생략된 함수에서 공역은 치역이 **아니라** 실수 전체의 집합으로 생각한다. (p.110)
- 같은 함수 판정은 식의 모양이 **아니라** 정의역의 모든 원소에서의 함숫값으로 한다. 정의역이 {−1, 1}이면 f(x)=x와 g(x)=x³은 같은 함수이다. (p.110) 단, 정의역과 공역이 각각 같아야 한다.
- 정의역이 {−1, 0, 1}인 y=x²의 그래프는 포물선이 **아니라** 점 3개이다. (p.110)
- 그래프 판별에서 쓰는 직선은 x축에 평행한 직선이 **아니라** y축에 평행한 직선 x=a이다. 원은 함수의 그래프가 아니다. (p.110, p.111)
- 일대일함수라고 해서 일대일대응인 것은 **아니다** — 공역=치역 조건이 추가로 필요하다. (p.112)
- y=x²은 일대일함수가 **아니다**: −1≠1인데 g(−1)=g(1)=1. (p.112)
- 항등함수는 정의역과 공역이 같은 집합 X(f : X → X)일 때 정의된다. 항등함수는 일대일대응이다. (p.112)
- 상수함수의 치역은 공역 전체가 **아니라** 원소가 1개인 집합이다. (p.112)

## 자기점검 질문
1. 대응이 함수가 되기 위한 조건은? — X의 각 원소에 Y의 원소가 오직 하나씩 대응해야 한다.
2. X={1, 2, 3}, Y={a, b, c}에서 1→a, 2→b, 3→b인 함수의 치역은? — {a, b}
3. 정의역·공역이 주어지지 않은 함수 y=f(x)의 정의역과 공역은? — 정의역은 f(x)가 정의되는 실수 x 전체, 공역은 실수 전체의 집합
4. 정의역이 {−1, 1}일 때 f(x)=x와 g(x)=x³이 같은 함수인 이유는? — f(−1)=g(−1)=−1, f(1)=g(1)=1로 정의역의 모든 원소에서 함숫값이 같기 때문
5. 어떤 그래프가 함수의 그래프인지 판별하는 방법은? — 정의역의 각 원소 a에 대하여 직선 x=a와 오직 한 점에서 만나는지 확인
6. 원 x²+y²=1의 그래프는 함수의 그래프인가? — 아니다. 직선 x=0과 두 점에서 만난다.
7. f(x)=2x가 일대일대응인 이유는? — x₁≠x₂이면 f(x₁)≠f(x₂)인 일대일함수이고, 공역과 치역이 모두 실수 전체로 같다.
8. g(x)=x²이 일대일함수가 아닌 이유는? — −1≠1이지만 g(−1)=g(1)=1
9. 항등함수와 상수함수의 식은? — 항등함수 f(x)=x, 상수함수 g(x)=c (c는 상수)
10. 함수, 일대일함수, 일대일대응의 포함 관계는? — 함수 ⊃ 일대일함수 ⊃ 일대일대응
