# Ⅰ-2-01 원의 방정식
교과서 31-33쪽 · 수학(공통수학2)

## 학습 목표
- 원의 방정식을 구하고, 그래프를 그릴 수 있다. (p.31)
- 중단원 도입(p.30): 원 안에 접하는 형태로 작은 원을 반복적으로 채워 넣은 그림 '아폴로니안 개스킷' — 모래 예술가 짐 데네반과 동료들이 15일 동안 미국 네바다주 블랙록 사막에 축구장 176개 정도의 크기로 그린, 세계에서 가장 큰 개스킷(기네스북 기록).

## 핵심 개념

### 1. 원의 방정식 — 표준형 (p.31)
- **준비하기**: 두 점 A(3, 5), B(−1, 3) 사이의 거리 → √(16 + 4) = 2√5
- **생각 틔우기**: 엘이디(LED) 쥐불놀이에서 손잡이를 잡고 빙빙 돌리면 엘이디 전구가 어떤 도형을 그리는가? → 원 (쥐불놀이: 정월 대보름 전날 밤에 줄에 불을 달고 빙빙 돌리며 노는 민속놀이)
- 유도
  1. 중심이 C(a, b), 반지름의 길이가 r인 원 위의 한 점을 P(x, y)라 하면 CP = r
  2. `√((x − a)² + (y − b)²) = r` → `(x − a)² + (y − b)² = r²` ……①
  3. 거꾸로 ①을 만족시키는 점 P(x, y)는 CP = r 이므로 점 C를 중심으로 하고 반지름의 길이가 r인 원 위의 점
- **원의 방정식**: 중심의 좌표가 (a, b)이고 반지름의 길이가 r인 원의 방정식은 **`(x − a)² + (y − b)² = r²`** (p.31)
- 날개: 중심이 원점이고 반지름의 길이가 r인 원의 방정식은 **x² + y² = r²**
- 보기: 중심 (2, −1), 반지름 3 → `(x − 2)² + (y + 1)² = 9`

### 2. 예제 1 — 지름의 양 끝점이 주어진 원 (p.31)
- 문제: 두 점 A(−2, 3), B(4, 7)을 지름의 양 끝점으로 하는 원의 방정식
- 풀이 흐름
  1. 중심 C(a, b)는 선분 AB의 **중점**: a = (−2 + 4)/2 = 1, b = (3 + 7)/2 = 5 → C(1, 5)
  2. 반지름 `AC = √({1 − (−2)}² + (5 − 3)²) = √13`
  3. 답: **`(x − 1)² + (y − 5)² = 13`**

### 3. 원의 방정식 — 일반형 x² + y² + Ax + By + C = 0 (p.32)
- 표준형을 전개하면 `x² + y² − 2ax − 2by + a² + b² − r² = 0` → 원의 방정식은 x, y에 대한 이차방정식 **`x² + y² + Ax + By + C = 0`** ……① 꼴로 나타낼 수 있다.
- 거꾸로 ①을 변형하면 `(x + A/2)² + (y + B/2)² = (A² + B² − 4C)/4`
- **A² + B² − 4C > 0** 이면 ①은
  - 중심의 좌표 `(−A/2, −B/2)`
  - 반지름의 길이 `√(A² + B² − 4C) / 2` 인 원을 나타낸다.
- 날개: ①이 나타내는 도형은 A² + B² − 4C = 0 이면 **한 점**, A² + B² − 4C < 0 이면 **존재하지 않는다**.
- 특징: x²과 y²의 계수가 같고(1), xy항이 없다.

### 4. 예제 2 — 일반형을 표준형으로 (p.32)
- 문제: x² + y² − 6x + 2y + 1 = 0 이 나타내는 원의 중심의 좌표와 반지름의 길이를 구하고 그래프 그리기
- 풀이 흐름
  1. 완전제곱식으로 변형: `x² − 6x + 9 + y² + 2y + 1 = 9`
  2. `(x − 3)² + (y + 1)² = 3²`
  3. 중심 **(3, −1)**, 반지름 **3**. 그래프는 중심 (3, −1)에서 반지름 3인 원(y축에 접한다)

### 5. 예제 3 — 세 점을 지나는 원 (p.32)
- 문제: 세 점 O(0, 0), P(2, 0), Q(3, −3)을 지나는 원의 방정식
- 풀이 흐름
  1. x² + y² + Ax + By + C = 0 으로 놓음
  2. O(0, 0)을 지나므로 C = 0 → x² + y² + Ax + By = 0
  3. P(2, 0): 4 + 2A = 0, Q(3, −3): 18 + 3A − 3B = 0
  4. 연립하여 A = −2, B = 4
  5. 답: **x² + y² − 2x + 4y = 0**
- 요령: 세 점이 주어지면 **일반형**으로 놓고 연립방정식을 푼다.

### 6. 스스로 익히기 (p.33)
1. ⑴ 중심이 원점, 반지름 √5 → x² + y² = 5 ⑵ 중심 (3, −2), 반지름 3 → (x − 3)² + (y + 2)² = 9 ⑶ 중심 (−4, −4), 점 (0, −4)를 지남 → 반지름 4, (x + 4)² + (y + 4)² = 16
2. (예제 1 유형) A(3, 4), B(−1, 2)를 지름의 양 끝점으로 → 중심 (1, 3), 반지름 √5, (x − 1)² + (y − 3)² = 5
3. (예제 2 유형) x² + y² − 8x + 12y + 3 = 0 → (x − 4)² + (y + 6)² = 49, 중심 (4, −6), 반지름 7
4. x² + y² − 5x + 3y + k = 0 이 원일 때 실수 k의 범위 → (−5)² + 3² − 4k > 0, 즉 k < 17/2
- 계산 결과는 교과서 해설 쪽(146쪽)이 소스에 없어 직접 계산한 값이다.

### 7. 역량 키우기(연결·실생활과 연결하기) (p.33)
- 원래 원 모양으로 추정되는 훼손된 유물(기와)을 복원하기 위해 사진을 좌표평면 위에 나타냄. 사진 둘레에 원점과 A(3, −2), B(7, 0)이 있을 때 세 점을 지나는 원의 방정식 (예제 3 유형)
  - x² + y² + Ax + By = 0 (원점을 지나므로 C = 0), B(7, 0): 49 + 7A = 0 → A = −7, A(3, −2): 13 + 3A − 2B = 0 → B = −4
  - 계산하면 x² + y² − 7x − 4y = 0

## 비교·정리표

### 표 1. 원의 방정식의 두 형태
| 구분 | 표준형 | 일반형 |
|---|---|---|
| 꼴 | `(x − a)² + (y − b)² = r²` | `x² + y² + Ax + By + C = 0` |
| 중심 | (a, b) | (−A/2, −B/2) |
| 반지름 | r | `√(A² + B² − 4C) / 2` |
| 쓰는 경우 | 중심·반지름을 알 때, 지름의 양 끝점을 알 때 | 지나는 세 점을 알 때 |
| 교과서 예 | 예제 1 (p.31) | 예제 3 (p.32) |

### 표 2. x² + y² + Ax + By + C = 0 이 나타내는 도형
| 조건 | 도형 | 근거 |
|---|---|---|
| A² + B² − 4C > 0 | 원 | p.32 본문 |
| A² + B² − 4C = 0 | 한 점 | p.32 날개 |
| A² + B² − 4C < 0 | 존재하지 않음 | p.32 날개 |

### 표 3. 조건별 원의 방정식 구하는 법
| 주어진 조건 | 방법 | 교과서 답 |
|---|---|---|
| 중심 (2, −1), 반지름 3 | 표준형에 대입 | (x − 2)² + (y + 1)² = 9 |
| 지름 양 끝점 A(−2, 3), B(4, 7) | 중점 = 중심, 중심~끝점 = 반지름 | (x − 1)² + (y − 5)² = 13 |
| 세 점 O, P(2, 0), Q(3, −3) | 일반형 놓고 연립 | x² + y² − 2x + 4y = 0 |

## 시험 함정 포인트
- `(x − a)² + (y − b)² = r²` 에서 중심은 (−a, −b)가 아니라 **(a, b)** 이다. (y + 1)² 은 b = −1 을 뜻한다. (p.31 보기)
- 우변은 반지름 r이 아니라 **r²** 이다. 반지름 3이면 우변은 9, 우변이 13이면 반지름은 √13 이다. (p.31)
- 지름의 양 끝점이 주어지면 반지름은 AB가 아니라 **AB의 절반**(= 중심과 끝점 사이의 거리)이다. (p.31 예제 1)
- 일반형의 중심은 (A/2, B/2)가 아니라 **(−A/2, −B/2)** 이다. (p.32)
- 일반형을 완전제곱식으로 고칠 때 더한 상수(9, 1)를 **우변에도** 더해야 한다: x² − 6x + 9 + y² + 2y + 1 = 9. (p.32 예제 2)
- x² + y² + Ax + By + C = 0 은 항상 원이 아니다. **A² + B² − 4C > 0** 일 때만 원이고, = 0 이면 한 점, < 0 이면 존재하지 않는다. (p.32)
- 원이 되는 조건은 A² + B² − 4C ≥ 0 이 아니라 **> 0** 이다(= 0 은 한 점). (p.32, p.33 스스로 익히기 4)
- 원점을 지나는 원은 일반형에서 **C = 0** 이다. 이를 먼저 쓰면 미지수가 둘로 줄어든다. (p.32 예제 3)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 원 | 한 점(중심)에서 일정한 거리(반지름)에 있는 점들로 이루어진 도형, CP = r (p.31) |
| 원의 방정식(표준형) | 중심 (a, b), 반지름 r인 원: (x − a)² + (y − b)² = r² (p.31) |
| 원의 방정식(일반형) | x² + y² + Ax + By + C = 0 (A² + B² − 4C > 0) (p.32) |
| 중심이 원점인 원 | x² + y² = r² (p.31 날개) |
| 지름의 양 끝점 | 지름 AB의 두 끝, 중점이 원의 중심 (p.31) |
| 완전제곱식 변형 | x² − 6x 에 9를 더해 (x − 3)² 으로 만드는 것 (p.32) |
| 아폴로니안 개스킷 | 원 안에 접하는 형태로 작은 원을 반복적으로 채워 넣은 그림 (p.30) |
