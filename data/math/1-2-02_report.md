## 학습 목표
- 좌표평면에서 원과 직선의 위치 관계를 판단하고, 이를 활용하여 문제를 해결할 수 있다. (p.34)

## 핵심 개념

### 1. 원과 직선의 위치 관계 ① — 중심과 직선 사이의 거리 d로 판단 (p.34)
- **준비하기**: 점 (2, −1)과 직선 5x − 12y + 4 = 0 사이의 거리 → |10 + 12 + 4|/13 = 2
- **생각 틔우기**: 알지오매스에서 x² + y² = 18 과 x − y = a 를 입력하고 슬라이더 a를 움직여 a의 범위에 따라 교점이 몇 개 생기는지 말해 보기 (그림은 a = 3)
  - 원의 중심 (0, 0)과 직선 사이의 거리 |a|/√2 와 반지름 3√2 를 비교하면 −6 < a < 6 일 때 2개, a = ±6 일 때 1개, a < −6 또는 a > 6 일 때 0개
- 이전에 배운 내용(중2): 직선 l이 원 O와 한 점에서 만날 때 직선 l은 원 O에 **접한다**고 하고, 직선 l을 원 O의 **접선**, 만나는 점 T를 **접점**이라고 한다. (p.34 날개)
- 원의 중심과 직선 사이의 거리를 d, 반지름의 길이를 r이라 하면
  1. **d < r** 이면 서로 다른 두 점에서 만난다.
  2. **d = r** 이면 한 점에서 만난다. (접한다.)
  3. **d > r** 이면 만나지 않는다.
- **예제 1** (p.34): 원 (x + 1)² + (y − 2)² = 8 과 직선 y = x − 1 의 위치 관계
  1. 중심 (−1, 2)와 직선 x − y − 1 = 0 사이의 거리 `d = |−1 − 2 − 1| / √(1² + (−1)²) = 2√2`
  2. 반지름 r = 2√2 이므로 d = r
  3. 답: **한 점에서 만난다. (접한다.)**

### 2. 원과 직선의 위치 관계 ② — 판별식 D로 판단 (p.35)
- 원 x² + y² = r² ……①, 직선 y = mx + n ……② 의 교점의 개수 = ①, ②를 모두 만족시키는 실수 순서쌍 (x, y)의 개수
- ②를 ①에 대입: x² + (mx + n)² = r², 즉 `(m² + 1)x² + 2mnx + n² − r² = 0` ……③
- 교점의 개수 = 이차방정식 ③의 **실근의 개수**
  1. **D > 0** 이면 서로 다른 두 점에서 만난다.
  2. **D = 0** 이면 한 점에서 만난다. (접한다.)
  3. **D < 0** 이면 만나지 않는다.
- **예제 2** (p.35): 원 x² + y² = 5 와 직선 y = 2x + k 가 서로 다른 두 점에서 만날 때 실수 k의 범위
  - 풀이 1(판별식): 대입하면 x² + (2x + k)² = 5, `5x² + 4kx + k² − 5 = 0`. `D = (4k)² − 4 × 5 × (k² − 5) = −4k² + 100 > 0` → k² < 25, 즉 −5 < k < 5
  - 풀이 2(거리): 원점과 2x − y + k = 0 사이의 거리가 반지름 √5 보다 작아야 하므로 `|k| / √(2² + (−1)²) = |k|/√5 < √5` → |k| < 5, 즉 −5 < k < 5
  - 답: **−5 < k < 5**

### 3. 스스로 익히기 (p.36)
1. (예제 1 유형) 위치 관계 판단
   - ⑴ x² + y² = 5, 2x + y = 4 → d = 4/√5 < √5 → 서로 다른 두 점
   - ⑵ x² + y² − 2y = 1 (즉 x² + (y − 1)² = 2), y = x + 3 → d = |0 − 1 + 3|/√2 = √2 = r → 접한다
   - ⑶ x² + y² + 2x − 4y − 4 = 0 (즉 (x + 1)² + (y − 2)² = 9), x − 3y − 3 = 0 → d = |−1 − 6 − 3|/√10 = √10 > 3 → 만나지 않는다
2. (예제 2 유형) 원 x² + y² = 8, 직선 y = −x + k → d = |k|/√2, r = 2√2 → ⑴ −4 < k < 4 ⑵ k = −4 또는 k = 4 ⑶ k < −4 또는 k > 4
3. 원 (x + 4)² + (y + 1)² = 5 와 직선 2x − 11y + k = 0 이 두 점에서 만날 때 → |−8 + 11 + k|/√125 < √5 → |k + 3| < 25, 즉 −28 < k < 22
4. 중심 (2, 3)이고 직선 x + 3y − 1 = 0 에 접하는 원 → 반지름 = |2 + 9 − 1|/√10 = √10 → (x − 2)² + (y − 3)² = 10
- 계산 결과는 교과서 해설 쪽(146쪽)이 소스에 없어 직접 계산한 값이다.

### 4. 역량 키우기(연결·실생활과 연결하기) — 원형 관개 농법 (p.36)
- **원형 관개 농법**: 사막과 같이 자연적인 방법으로 경작하지 못하는 땅에 인공적으로 물을 가져와 원형으로 경작지를 만들어 농사를 지을 수 있게 하는 것
- 두 원형 경작지(중심 (0, 0), 반지름 1 / 중심 (3, 0), 반지름 2 — 그림의 눈금 −1, 1, 5에서 읽음)에 모두 접하는 도로 ax + by = 3 의 a, b 구하기 (단, a < 0, b > 0)
  - 원점과의 거리 3/√(a² + b²) = 1 → a² + b² = 9
  - (3, 0)과의 거리 |3a − 3|/3 = 2 → |a − 1| = 2, a < 0 이므로 a = −1 → b² = 8, b = 2√2

### 5. 기울기가 주어진 원의 접선의 방정식 (p.37)
- **준비하기**: 원 x² + y² = 4 와 직선 2x + y − 5 = 0 → d = 5/√5 = √5 > 2 → 만나지 않는다
- 유도
  1. 접선을 y = mx + n, 즉 mx − y + n = 0 이라 하면 중심 O(0, 0)과의 거리 `d = |n| / √(m² + (−1)²) = |n| / √(m² + 1)`
  2. 접하려면 d = r → `|n| = r√(m² + 1)`, `n = ±r√(m² + 1)`
- **공식**: 원 x² + y² = r² 에 접하고 기울기가 m인 직선은 **`y = mx ± r√(m² + 1)`**
- 날개: 한 원에 대하여 **기울기가 같은 접선은 2개**이다.
- 보기: x² + y² = 4 에 접하고 기울기 −1 → `y = −x ± 2√((−1)² + 1)`, 즉 **y = −x ± 2√2**

### 6. 원 위의 점에서의 접선의 방정식 (p.37~38)
- ① 점 P(x₁, y₁)이 좌표축 위의 점이 아닌 경우 (x₁ ≠ 0, y₁ ≠ 0)
  1. 직선 OP의 기울기는 y₁/x₁, OP는 접선에 수직 → 접선의 기울기 **−x₁/y₁**
  2. `y − y₁ = −(x₁/y₁)(x − x₁)`, 즉 `x₁x + y₁y = x₁² + y₁²`
  3. P는 원 위의 점이므로 x₁² + y₁² = r² → **x₁x + y₁y = r²**
- ② 점 P가 좌표축 위의 점인 경우 (x₁ = 0 또는 y₁ = 0)
  - P(0, ±r) 또는 (±r, 0) → 접선 y = ±r 또는 x = ±r → 이 경우에도 x₁x + y₁y = r²
- **공식**: 원 x² + y² = r² 위의 점 P(x₁, y₁)에서의 접선은 **`x₁x + y₁y = r²`** (p.38)
- 보기: x² + y² = 25 위의 점 (3, 4) → 3 × x + 4 × y = 25, 즉 **3x + 4y = 25**

### 7. 원 밖의 한 점에서 그은 접선 — 예제 1 (p.38)
- 이전에 배운 내용(중3): 원 밖의 한 점에서 원에 그은 **접선은 항상 2개**이다.
- 문제: 점 (5, 0)에서 원 x² + y² = 5 에 그은 접선
- 풀이 1(접점을 미지수로)
  1. 접점 P(x₁, y₁) → 접선 x₁x + y₁y = 5
  2. (5, 0)을 지나므로 5x₁ = 5, x₁ = 1
  3. x₁² + y₁² = 5 에 대입 → 1 + y₁² = 5, y₁ = ±2
  4. 접선: x + 2y = 5 또는 x − 2y = 5
- 풀이 2(기울기를 미지수로)
  1. 기울기 m → y = m(x − 5), 즉 mx − y − 5m = 0
  2. 원점과의 거리 = √5: `|−5m| / √(m² + (−1)²) = √5`, `|−5m| = √5 × √(m² + 1)`
  3. 양변 제곱: 25m² = 5m² + 5, m = ±1/2
  4. 접선: x + 2y = 5 또는 x − 2y = 5
- 답: **x + 2y = 5 또는 x − 2y = 5**

### 8. 스스로 익히기 (p.39)
1. ⑴ x² + y² = 5, 기울기 2 → y = 2x ± 5 ⑵ x² + y² = 25, y = −3x + 2 에 평행 → y = −3x ± 5√10 ⑶ x² + y² = 1, x + 4y + 2 = 0 에 수직(기울기 4) → y = 4x ± √17
2. x² + y² = 25 위의 점에서의 접선: ⑴ (3, −4) → 3x − 4y = 25 ⑵ (−1, 2√6) → −x + 2√6y = 25 ⑶ (5, 0) → x = 5 ⑷ (0, −5) → y = −5
3. x² + y² = 10 에 접하고 기울기 −3인 두 직선 → y = −3x ± 10, 두 직선 사이의 거리 20/√10 = 2√10
4. (예제 1 유형) 점 (3, 1)에서 x² + y² = 5 에 그은 접선 → 3x₁ + y₁ = 5, x₁² + y₁² = 5 에서 접점 (1, 2), (2, −1) → x + 2y = 5 또는 2x − y = 5
- **역량 키우기(문제해결·다양한 전략 사용하기)**: 점 (0, 10)에서 원 x² + y² = 10 에 그은 접선의 x절편을 세 학생의 방법으로 구하기
  - 윤서: 원 위의 점에서의 접선의 방정식 이용 / 민준: 기울기가 주어진 원의 접선의 방정식 이용 / 민서: 삼각형의 닮음 이용
  - 윤서 방법으로 계산하면 접점 (±3, 1), 접선 ±3x + y = 10, x절편 ±10/3

## 비교·정리표

### 표 1. 원과 직선의 위치 관계 판정
| 위치 관계 | 거리 d와 반지름 r | 판별식 D | 교점 수 |
|---|---|---|---|
| 서로 다른 두 점에서 만난다 | d < r | D > 0 | 2 |
| 한 점에서 만난다(접한다) | d = r | D = 0 | 1 |
| 만나지 않는다 | d > r | D < 0 | 0 |

### 표 2. 원 x² + y² = r² 의 접선 공식
| 주어진 것 | 공식 | 교과서 보기 |
|---|---|---|
| 기울기 m | `y = mx ± r√(m² + 1)` | x² + y² = 4, 기울기 −1 → y = −x ± 2√2 (p.37) |
| 원 위의 접점 (x₁, y₁) | `x₁x + y₁y = r²` | x² + y² = 25, (3, 4) → 3x + 4y = 25 (p.38) |
| 원 밖의 한 점 | 접점을 (x₁, y₁)로 놓거나 기울기를 m으로 놓고 풀기 | (5, 0), x² + y² = 5 → x ± 2y = 5 (p.38) |

### 표 3. 예제 2의 두 풀이 비교 (p.35)
| 풀이 | 세우는 식 | 결과 |
|---|---|---|
| 판별식 | 5x² + 4kx + k² − 5 = 0, D = −4k² + 100 > 0 | −5 < k < 5 |
| 점과 직선 사이 거리 | \|k\|/√5 < √5 | −5 < k < 5 |

## 시험 함정 포인트
- 거리로 판단할 때 d < r 이 "만나지 않는다"가 아니라 **서로 다른 두 점에서 만난다** 이다. 원의 중심이 직선에 가까울수록 많이 만난다. (p.34)
- 거리 공식에 넣을 때는 원의 **중심**을 대입한다. 일반형 원은 먼저 표준형으로 고쳐 중심과 반지름을 구한다. (p.36 스스로 익히기 1)
- 판별식은 원 방정식에 직선을 대입해 만든 **x에 대한 이차방정식**의 판별식이다. 직선의 식만으로 D를 구하는 것이 아니다. (p.35)
- 기울기가 주어진 접선은 1개가 아니라 **2개**(± 부호)이다. (p.37 날개)
- 공식 y = mx ± r√(m² + 1) 에서 √ 안은 m² 이 아니라 **m² + 1** 이다. (p.37)
- 원 위의 점에서의 접선 x₁x + y₁y = r² 은 중심이 **원점**인 원 x² + y² = r² 에서 쓰는 공식이다. (p.38)
- 접점이 좌표축 위(예: (5, 0))이면 접선은 x = 5 처럼 **y축에 평행한 직선**이다. 기울기 공식으로는 나오지 않는다. (p.38, p.39 스스로 익히기 2)
- 원 밖의 한 점에서 그은 접선은 **2개**이다. 하나만 구하고 끝내지 않는다. (p.38 날개)
- 예제 1 풀이 1에서 x₁ = 1 을 구한 뒤 원의 방정식에 대입해야 y₁ = ±2 두 값이 나온다. (p.38)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 접한다 | 직선이 원과 한 점에서 만나는 것 (p.34 날개) |
| 접선 | 원과 한 점에서 만나는 직선 (p.34 날개) |
| 접점 | 원과 접선이 만나는 점 (p.34 날개) |
| 원의 중심과 직선 사이의 거리 d | 중심에서 직선에 내린 수선의 길이, 위치 관계 판정에 사용 (p.34) |
| 판별식 D | 원과 직선을 연립해 얻은 이차방정식의 판별식, 실근의 개수 = 교점의 개수 (p.35) |
| 기울기가 주어진 접선 | y = mx ± r√(m² + 1) (p.37) |
| 원 위의 점에서의 접선 | x₁x + y₁y = r² (p.38) |
| 원형 관개 농법 | 경작하지 못하는 땅에 인공적으로 물을 가져와 원형 경작지를 만드는 농법 (p.36) |
