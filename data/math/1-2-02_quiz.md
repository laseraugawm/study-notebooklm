# 원과직선 퀴즈

## Question 1
원의 중심과 직선 사이의 거리 $d$, 원의 반지름의 길이 $r$, 이차방정식의 판별식 $D$를 이용한 원과 직선의 위치 관계 설명으로 옳은 것은?

- [x] $d = r$ 이면 원과 직선은 한 점에서 만난다 (접한다).
- [ ] $d < r$ 이면 원과 직선은 만나지 않는다.
- [ ] $D = 0$ 이면 원과 직선은 서로 다른 두 점에서 만난다.
- [ ] $D < 0$ 이면 원과 직선은 한 점에서 만난다.

**Hint:** 원의 중심에서 직선까지의 거리가 반지름과 같을 때 교점의 개수가 몇 개가 되는지 생각해 보세요.

## Question 2
원 $(x-1)^2 + (y+2)^2 = 5$와 직선 $2x - y + 1 = 0$의 위치 관계를 판별하시오.

- [x] 한 점에서 만난다 (접한다).
- [ ] 서로 다른 두 점에서 만난다.
- [ ] 만나지 않는다.
- [ ] 세 점에서 만난다.

**Hint:** 원의 중심 $(1, -2)$에서 직선까지의 거리 $d$를 구하고 반지름 $\sqrt{5}$와 비교해 보세요.

## Question 3
원 $x^2 + y^2 = 9$에 접하고 기울기가 $2$인 직선의 방정식으로 올바른 것은?

- [x] $y = 2x \pm 3\sqrt{5}$
- [ ] $y = 2x \pm 9\sqrt{5}$
- [ ] $y = 2x \pm 3\sqrt{3}$
- [ ] $y = 2x \pm \sqrt{5}$

**Hint:** 기울기가 주어진 원의 접선 공식 $y = mx \pm r\sqrt{m^2+1}$을 적용해 보세요.

## Question 4
원 $x^2 + y^2 = 20$ 위의 점 $(-4, 2)$에서의 접선의 방정식으로 올바른 것은?

- [x] $2x - y + 10 = 0$
- [ ] $4x + 2y - 20 = 0$
- [ ] $-4x + 2y = 40$
- [ ] $2x + y - 10 = 0$

**Hint:** 원 $x^2 + y^2 = r^2$ 위의 점 $(x_1, y_1)$에서의 접선의 공식은 $x_1 x + y_1 y = r^2$입니다.

## Question 5
점 $(4, 0)$에서 원 $x^2 + y^2 = 4$에 그은 접선의 방정식 중 하나로 올바른 것은?

- [x] $x + \sqrt{3}y - 4 = 0$
- [ ] $x + 2y - 4 = 0$
- [ ] $x + \sqrt{5}y - 4 = 0$
- [ ] $\sqrt{3}x + y - 4 = 0$

**Hint:** 접점의 좌표를 $(x_1, y_1)$로 놓고 접선의 방정식 $x_1 x + y_1 y = 4$에 점 $(4, 0)$을 대입해 보세요.

## Question 6
중심의 좌표가 $(2, 3)$이고 직선 $x + 3y - 1 = 0$에 접하는 원의 방정식은?

- [x] $(x-2)^2 + (y-3)^2 = 10$
- [ ] $(x-2)^2 + (y-3)^2 = 100$
- [ ] $(x+2)^2 + (y+3)^2 = 10$
- [ ] $(x-2)^2 + (y-3)^2 = \sqrt{10}$

**Hint:** 원의 중심에서 직선까지의 거리가 바로 원의 반지름 $r$이 됩니다.
