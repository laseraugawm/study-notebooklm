## Question 1

## Question 2
명제 '자연수 $n$에 대하여 $n^2$이 홀수이면 $n$은 홀수이다.'가 참임을 대우를 이용하여 증명하려고 한다. 이때 서술해야 할 대우 명제로 옳은 것은?

- [x] 자연수 $n$에 대하여 $n$이 짝수이면 $n^2$은 짝수이다.
- [ ] 자연수 $n$에 대하여 $n$이 홀수이면 $n^2$은 홀수이다.
- [ ] 자연수 $n$에 대하여 $n^2$이 짝수이면 $n$은 짝수이다.
- [ ] 자연수 $n$에 대하여 $n$이 짝수이면 $n^2$은 홀수이다.

**Hint:** 명제 $p \rightarrow q$의 대우는 결론과 가정을 모두 부정하고 순서를 바꾼 $\sim q \rightarrow \sim p$입니다.

- [ ] 명제의 가정과 결론을 서로 바꾸어 새로운 명제가 참임을 입증하는 방법이다.

**Hint:** 결론을 반대로 가정했을 때 생기는 논리적 모순을 이용하는 증명 방식입니다.

## Question 6

## Question 7
$a, b$가 실수일 때 절대부등식 $a^2 + 5b^2 \ge 4ab$를 증명하는 과정이다. 빈칸 (가)와 (나)에 들어갈 식으로 바르게 짝지어진 것은?

$$a^2 + 5b^2 - 4ab = ( \text{가} )^2 + b^2 \ge 0$$
따라서 $a^2 + 5b^2 \ge 4ab$가 성립한다.
여기서 등호는 (나) 일 때 성립한다.

- [x] (가): $a - 2b$, (나): $a = b = 0$
- [ ] (가): $a + 2b$, (나): $a = b = 0$
- [ ] (가): $a - 2b$, (나): $a = 2b$
- [ ] (가): $a - 4b$, (나): $a = 4b$

**Hint:** $a$에 대한 완전제곱식 형태로 묶은 후, 두 제곱 항이 동시에 $0$이 되는 조건을 구합니다.

## Question 8

- [x] $a, b$가 음수인 실수일 때도 항상 성립한다.
- [ ] 등호가 성립하는 경우는 $a = b$ 일 때이다.
- [ ] $\frac{a+b}{2}$를 $a$와 $b$의 산술평균이라 한다.
- [ ] $\sqrt{ab}$를 $a$와 $b$의 기하평균이라 한다.

**Hint:** 산술평균과 기하평균의 관계가 성립하기 위한 변수의 범위(전제 조건)를 점검해 보세요.
