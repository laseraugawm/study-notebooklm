# Ⅲ-1-02 빅데이터와 과학기술사회
교과서 138-143쪽 · 통합과학

## 학습 목표
- 실시간 생활 데이터를 측정하여 문제 해결 방안을 도출할 수 있다. (p.138)
- 빅데이터를 사용하는 사례를 조사하고 빅데이터 활용의 장단점을 설명할 수 있다. (p.138)

## 핵심 개념

### 1. 데이터로 무엇을 할 수 있을까?
- **데이터**: 정보를 가지고 있는 값. (p.138)
  - 예: 시간대별 기온, 국가별 코로나 환자 수, 나의 하루 걸음 수, 스마트폰 사용 시간
- 데이터는 단순한 사실에 불과하지만, 필요한 데이터를 모으고 분석하기에 따라 많은 것을 알려 주는 **정보**가 되기도 한다. (p.138)
- 도입 그림: "우리는 일찍이 데이터의 중요성을 알고 있었지." — 옛 기록을 남기는 모습. (p.138)

### 2. [디지털 탐구] 디지털 탐구 도구를 활용하여 실시간 생활 데이터 측정하기 (p.138~139)
- 목표: 교실의 이산화 탄소 농도를 측정하여 학교 환경을 평가하고, 개선할 방법을 찾을 수 있다.
- 준비물: 노트북, 마이크로컨트롤러, 브레드보드, 점퍼 케이블, 이산화 탄소 센서
- 생각해 보기: 밀폐된 실내에서 이산화 탄소(CO₂) 농도가 높아지면 졸리거나 집중력이 떨어진다. 우리 교실의 CO₂ 농도를 알려면 데이터를 어떻게 수집해야 할까?
  - 학생들의 질문: 교실 내 위치에 따라 농도가 다를까? / 시간에 따라 달라질까? / 하루 동안의 변화를 측정하려면? / 정확하게 측정하려면?
- 탐구 과정 (p.139)
  1. 모둠별로 측정 **위치**, 측정 **시각**, 측정 **주기**를 정한다.
  2. 마이크로컨트롤러와 이산화 탄소 센서를 연결한다(브레드보드 사용).
  3. 완성된 측정기를 노트북과 연결한 뒤, 정한 측정 시각과 간격에 따라 측정하도록 **코딩**한다. (코딩이 어려우면 인터넷 검색이나 생성형 인공지능에서 코드를 얻어 본다.)
  4. 측정기가 정상 작동하는지 확인하기 위해 **운동장과 같이 개방된 환경**에서 측정한 뒤, 기상청 종합 기후 변화 감시 정보(climate.go.kr)의 우리나라 평균 CO₂ 농도와 비교한다.
  5. 정상 작동하면 정한 곳에 측정기를 놓고 데이터를 수집한다. 수집하는 동안 교실 환경의 변화도 함께 기록한다.
  6. 수집한 데이터를 **공유 플랫폼**에 올린다.
- 기준: **학교 보건 기준법**이 정한 교실의 이산화 탄소 농도 기준은 **1000 ppm 이하**, 환기를 할 경우 **1500 ppm 이하**. (p.139)
- 정리하기 (p.139)
  1. 반 전체 데이터를 종합하여 교실 환경 평가
  2. 데이터를 바탕으로 CO₂ 농도를 낮출 방법 제안
  3. 수집한 데이터의 양에 따라 얻을 수 있는 정보가 어떻게 달라질지 이야기
- 평가: 디지털 탐구 도구 제작 / 측정 결과로 학교 환경 평가 / 탐구 결과를 근거로 개선 방안 제시

### 3. 빅데이터의 뜻과 등장 (p.140)
- 측정 장소가 교실 → 전국의 모든 학교, 측정 기간이 하루 → 일 년으로 늘어나면 데이터의 양도 늘어난다.
- **빅데이터**: 방대하고 복잡한 데이터의 집합. 수치 자료뿐 아니라 **글, 영상, 음성** 등 형태가 매우 다양하다.
- 등장 배경: **센서의 개발**과 **정보 통신 기술의 발달**로 다양한 데이터를 실시간으로 수집하고 디지털로 전환할 수 있게 되면서 등장.
- 최근 의미 확장: 대용량의 데이터를 분석하여 가치 있는 정보를 추출하고, **변화를 예측하는 정보 기술**로까지 의미가 넓어지고 있다.
- 장점: 다양한 변수가 얽힌 복잡한 문제를 빠르게 분석할 수 있다. 정부의 정책 결정, 교육, 의료 등 다양한 분야에서 **합리적인 결정**을 내리는 데 유용하다.

### 4. 생활 속 빅데이터의 활용 (그림 Ⅲ-4) (p.140)
| 분야 | 활용 사례 |
|---|---|
| 농업 | 환경 정보 빅데이터로 식물 성장에 적절한 환경 제어 |
| 건강 | 건강 관련 내용 검색량에 따른 독감 유행 예측 |
| 기술 | 자동 번역 기술 향상 |
| 교육 | 학습 분석으로 개별화된 맞춤 교육 가능 |
| 교통 | 실시간 교통량 분석으로 교통 정보 제공 |
| 문화 | 개인별 맞춤 콘텐츠 제공 |
| 여행 | 여행지 선호도 빅데이터로 새로운 노선 개발 |
| 정부 기관 | 통화량 및 발신 지역, 교통 카드 데이터로 심야 유동 인구 분석 후 심야 버스 노선 결정 |
| 기업 | 소비자 행동 분석 후 개인별 관심 제품 추천 |

### 5. 과학 분야의 빅데이터 활용 (p.141)
- 거대 입자 가속기, 인공위성 같은 새로운 장비와 기술의 발달로 많은 양의 관측·실험 데이터를 얻고, 이를 디지털 형태로 전환하여 대량으로 축적할 수 있게 되었다.
- **과학 실험**: 입자 충돌 실험 같은 대규모 실험은 많은 자료를 생산한다. 방대한 자료를 분석하고 **이론적 모델과 비교**하여 새로운 과학 지식을 쌓는다.
- **신약 개발**: 이미 개발된 수많은 화학 물질의 구조와 성질을 빅데이터로 만들어 이용 → 신약을 더 빠른 시간에 개발. 유전자 데이터나 임상 시험 데이터도 활용.
- **유전체 분석**: 생물의 DNA 염기서열을 분석하면 방대한 자료를 얻는다. 인간 유전체 데이터를 분석하여 암이나 난치병 치료, **개인 맞춤형 의학**에 활용.
- **기상 관측**: 다양한 관측소와 인공위성으로 대량의 기상 데이터 수집 → 일기 예보의 정확도를 높이고 장기간의 기후 변화를 연구.

### 6. 빅데이터를 잘 활용하려면? — 데이터셋 (p.142)
- 빅데이터를 제대로 이용하려면 관련된 데이터를 모으는 것이 필요하다.
- **데이터셋**: 유사한 성질을 가진 데이터를 모아서 검색이나 사용이 편리하도록 정리한 것. 우리가 활용하는 빅데이터는 대부분 정리된 데이터셋이다.

### 7. [해 보기] 빅데이터 활용의 장점과 문제점 추론하기 (p.142)
- 준비물: 스마트 기기. 질문: 어떤 데이터를 분석하면 코로나19의 확산을 감시하고 예방할 수 있을까?
- 코로나 유행 시기에 활용한 데이터셋과 찾아낸 정보
  | 데이터셋 | 찾아낸 정보 |
  |---|---|
  | 전 세계 항공권 판매 데이터 | 감염병이 크게 퍼질 위험이 있는 나라를 항공권 판매량으로 예측 |
  | 지역별 코로나19 백신 접종 현황 | 어떤 지역이 감염병에 취약한지 파악하여 예방 |
  | 카드 이용 정보 | 카드 이용이 많은 지역 = 사람이 붐비는 곳 → 감염병이 퍼지기 쉬움 |
  | 지역별 인구 현황 | 어린이 등 감염에 취약한 사람이 많은 지역을 미리 점검 |
  | 지역별 코로나19 환자를 위한 병상 수 | 격리·치료할 병상이 부족하면 추가적인 대처 필요 |
  | 마스크 재고 현황 | 마스크가 부족한 지역에 집중 공급하여 확산 방지 |
- 질문: ① 빅데이터 활용의 장점 ② 이런 자료 활용 시 생길 수 있는 문제점 토의 ③ 다른 활용 사례를 찾아 장점과 문제점 분석
- 해석(교과서 본문 근거, p.140·143): 장점은 복잡한 문제를 빠르게 분석하고 예측하여 합리적 결정을 돕는 것, 문제점은 편향되거나 신뢰성 낮은 데이터로 잘못된 결론을 낼 수 있고 카드 이용 정보 같은 자료에 개인 정보가 포함될 수 있다는 것.

### 8. 공공 데이터 (p.143)
- **공공 데이터**: 모든 사람에게 공개되어 누구나 이용할 수 있는 데이터.
- 국가에서 수집한 데이터 → **공공 데이터 포털(data.go.kr)**
- 인공위성이나 전국 관측소에서 수집된 기상 자료 → 기상청 **기상 자료 개방 포털(data.kma.go.kr)**
- 그림 Ⅲ-5 기상청에서 제공하는 공공 데이터: 관측 자료, 기후 통계, 강수 일수, 폭염 일수, 지역별 날씨 예보, 지진·화산 활동 정보, 역사 기후 정보

### 9. 빅데이터 활용의 전망과 주의할 점 (p.143)
- 빅데이터의 활용은 점점 늘어날 것이다. 경제, 교통, 환경 등의 문제를 파악하고 앞으로 일어날 일을 예측하여 새로운 정책을 세우는 데 도움을 받을 수 있다.
- 주의할 점
  1. **편향되거나 신뢰성이 낮은 데이터**를 사용하면 오히려 잘못된 결론을 도출할 수 있다 → 데이터를 적절하게 **선별**하여 다루는 것이 매우 중요하다.
  2. 빅데이터에는 **개인 정보**가 포함될 수 있으므로 민감한 정보의 보호와 관리에 주의해야 한다.
- 스스로 확인: ① 빅데이터란? ② 빅데이터 이용 시 주의할 점. 과학과 나: 빅데이터로 우리 주변의 어떤 문제를 해결할 수 있을지 생각해 보기.

## 시험 함정 포인트
- 빅데이터는 수치 자료**만이 아니라** 글, 영상, 음성 등 형태가 매우 다양하다. (p.140)
- 데이터는 그 자체로는 단순한 사실이며, 모으고 분석해야 정보가 된다(데이터 = 정보가 **아님**). (p.138)
- 교실 CO₂ 기준은 **1000 ppm 이하**(환기할 경우 1500 ppm 이하)다. 숫자를 바꿔 내는 문제에 주의. (p.139)
- 측정기가 정상인지 확인할 때는 교실이 **아니라 운동장 같은 개방된 환경**에서 측정해 기상청 자료(climate.go.kr)와 비교한다. (p.139)
- 빅데이터 개념이 등장한 배경은 **센서의 개발과 정보 통신 기술의 발달**이다. (p.140)
- 최근 빅데이터는 데이터 집합뿐 **아니라** 분석해 가치 있는 정보를 추출하고 변화를 예측하는 **정보 기술**까지 뜻한다. (p.140)
- 심야 버스 노선 결정은 '기업'이 **아니라 '정부 기관'** 사례이고, 독감 유행 예측은 '건강' 분야(검색량 이용)다. (p.140)
- 데이터의 양이 많다고 무조건 옳은 결론이 나오는 것이 **아니다**. 편향되거나 신뢰성이 낮은 데이터는 잘못된 결론을 낳는다. (p.143)
- 공공 데이터는 누구나 이용할 수 있게 **공개된** 데이터다. 국가 데이터는 data.go.kr, 기상 자료는 data.kma.go.kr. (p.143)
- 우리가 활용하는 빅데이터는 대부분 **정리된 데이터셋**이다. (p.142)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|

| 데이터셋 | 유사한 성질의 데이터를 모아 검색·사용이 편리하도록 정리한 것 (p.142) |
| 공공 데이터 | 모든 사람에게 공개되어 누구나 이용할 수 있는 데이터 (p.143) |
| 공공 데이터 포털 | 국가에서 수집한 데이터를 공개하는 곳(data.go.kr) (p.143) |
| 기상 자료 개방 포털 | 기상청이 인공위성·관측소 기상 자료를 공개하는 곳(data.kma.go.kr) (p.143) |
| 마이크로컨트롤러 | 탐구에서 이산화 탄소 센서와 연결해 측정기를 만드는 장치 (p.139) |

| 학교 보건 기준법 | 교실 CO₂ 농도 기준(1000 ppm 이하, 환기 시 1500 ppm 이하)을 정한 법 (p.139) |
| 유전체 분석 | DNA 염기서열 분석, 암·난치병 치료·개인 맞춤형 의학에 활용 (p.141) |
| 개인 정보 | 빅데이터에 포함될 수 있어 보호·관리에 주의해야 하는 민감한 정보 (p.143) |

## 자기점검 질문
1. 데이터의 정의는? — 정보를 가지고 있는 값
2. 빅데이터란? — 방대하고 복잡한 데이터의 집합(수치·글·영상·음성 등 다양한 형태)
3. 빅데이터 개념이 등장한 배경은? — 센서 개발과 정보 통신 기술 발달로 실시간 수집·디지털 전환이 가능해짐
4. 교실 이산화 탄소 농도 기준은? — 1000 ppm 이하(환기 시 1500 ppm 이하)
5. 탐구에서 측정 전에 모둠이 정하는 세 가지는? — 측정 위치, 측정 시각, 측정 주기
6. 측정기의 정상 작동을 어떻게 확인하나? — 운동장 같은 개방된 곳에서 측정해 기상청 자료의 우리나라 평균 CO₂ 농도와 비교
7. 심야 버스 노선 결정에 쓰인 데이터는? — 통화량 및 발신 지역, 교통 카드 데이터(심야 유동 인구 분석)
8. 기상 관측 빅데이터의 활용 두 가지는? — 일기 예보 정확도 향상, 장기간 기후 변화 연구
9. 데이터셋이란? — 유사한 성질의 데이터를 모아 검색·사용이 편리하게 정리한 것
10. 항공권 판매 데이터로 알 수 있는 것은? — 감염병이 크게 퍼질 위험이 있는 나라 예측
11. 빅데이터 이용 시 주의할 점 두 가지는? — 편향·신뢰성 낮은 데이터를 선별해 잘못된 결론을 피할 것, 개인 정보 보호·관리
