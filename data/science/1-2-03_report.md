# Ⅰ-2-03 산과 염기의 종류와 성질
교과서 48-53쪽 · 통합과학

## 학습 목표
- 산과 염기의 특징을 설명할 수 있다. (p.48)
- 산과 염기의 특징이 나타나는 까닭을 설명할 수 있다. (p.48)
- 핵심 질문: 산과 염기는 어떤 성질이 있을까? / 우리 주변에는 어떤 산과 염기가 있을까? (p.48, p.52)

## 핵심 개념

### 1. 우리 주위의 산과 염기 (도입)
- 우리 몸의 **혈액은 약한 염기성**을 띤다. (p.48)
- 음식물을 소화하는 소화 효소 중에는 산성이나 염기성을 띠는 것들도 있다. (p.48)
- 산이 들어 있는 과일을 먹고, **염기성인 세제**로 빨래의 찌든 때를 세탁한다. (p.48)
- 도입 만화: 오렌지 주스(산)를 들고 오는 사람을 보고 대리석 조각상이 "산이잖아? 가까이 오지 마세요!"라고 함 → 산이 탄산 칼슘(대리석 성분)과 반응함을 암시. (p.48)

### 2. 탐구: 산과 염기의 성질
- **목표**: 산과 염기의 성질을 확인할 수 있다. (탐구 기능: 자료 분석, 결론 도출, 일반화) (p.48)
- **생각해 보기**: 실험실에서 쓰는 염산과 음식에 넣는 식초는 서로 다른 물질이지만 공통적인 성질도 가진다. 어떤 점이 비슷한지 알아보자. (p.48)
- **준비물**: 묽은 염산, 아세트산 수용액, 수산화 나트륨 수용액, 수산화 칼륨 수용액, 탄산 칼슘, 마그네슘 조각, 두부, 12홈판, 실험판, 간이 전기 전도계, 휴지, 스포이트, 핀셋, 약숟가락, 보안경, 실험용 장갑, 실험복 (p.48)
- **안전**: 물질이 피부나 옷에 직접 닿지 않게 하고 닿으면 즉시 흐르는 물에 씻는다. 실험 후 남은 용액은 폐수 통에 버린다. (p.48)
- **과정**: (p.48~49)
  1. 실험판 위에 12홈판을 놓고 묽은 염산, 아세트산 수용액, 수산화 나트륨 수용액, 수산화 칼륨 수용액을 각각 10방울씩 세 줄의 홈에 넣는다.
  2. 첫 번째 줄에 간이 전기 전도계의 전극을 각각 담가 전류가 흐르는지 알아본다.
  3. 첫 번째 줄에 탄산 칼슘, 두 번째 줄에 마그네슘 조각, 세 번째 줄에 작게 자른 두부를 각각 넣고 변화를 관찰한다.
- **정리하기**: 결과표를 채우고 각 물질을 산과 염기로 구분 → 산: 묽은 염산, 아세트산 수용액 / 염기: 수산화 나트륨 수용액, 수산화 칼륨 수용액. (p.49)
- **결과 해석(본문)**: (p.49)
  - **산**: 수용액 상태에서 전류가 흐르고, 탄산 칼슘과 반응하여 **이산화 탄소(CO₂) 기체**를, 마그네슘 등의 금속과 반응하여 **수소(H₂) 기체**를 발생시킨다.
  - **염기**: 수용액 상태에서 전류가 흐르고 **단백질을 녹이지만**, 탄산 칼슘이나 마그네슘 등의 금속과는 반응하지 않는다.
- **산성**: 산의 공통적인 성질. **염기성**: 염기의 공통적인 성질. (p.49)
- 참고(산과 금속의 반응): 모든 금속이 산과 반응하여 수소 기체를 발생시키는 것은 아니다. **구리, 은, 금, 백금** 등은 산과 반응하지 않는다. (p.49)
- 평가하고 성찰하기: 산과 염기를 옳게 구분하였는가? / 안전하게 실험하였는가? / 모둠원과 함께 적극적으로 참여하였는가? (p.49)

### 3. 산의 공통적인 성질이 나타나는 까닭
- **염화 수소(HCl)**는 물에 녹아 묽은 염산이 될 때 **수소 이온(H⁺)**과 **염화 이온(Cl⁻)**으로 이온화된다. (p.50)
- 묽은 염산에 전극을 넣고 전원 장치를 연결하면 **이온들이 전극으로 움직이며 전류가 흐른다**(사진: 전구에 불이 켜짐). (p.50)
- 그림 Ⅰ-16 염화 수소의 이온화 모형: 염화 수소 기체 + 물 → 염산(H⁺, Cl⁻가 흩어져 있음). (p.50)
- 염산, 질산, 황산, 탄산, 아세트산은 수용액 상태에서 수소 이온(H⁺)을 내놓는다. 산의 종류에 따라 **음이온의 종류는 달라지지만 양이온의 종류(H⁺)는 같다**. (p.50)
- 여러 산이 공통적인 성질을 나타내는 것은 **수소 이온 때문**이다. (p.50)
- **산**: 수용액 상태에서 수소 이온(H⁺)을 내놓는 물질. (p.50)
- 산의 이온화 (p.50):
  - 염화 수소 `HCl → H⁺ + Cl⁻` (염화 이온)
  - 질산 `HNO₃ → H⁺ + NO₃⁻` (질산 이온)
  - 황산 `H₂SO₄ → 2H⁺ + SO₄²⁻` (황산 이온)
  - 탄산 `H₂CO₃ → 2H⁺ + CO₃²⁻` (탄산 이온)
  - 아세트산 `CH₃COOH → H⁺ + CH₃COO⁻` (아세트산 이온)
- 꼼꼼 읽기: 산이 수용액 상태에서 이온화될 때의 반응식을 써 보며 읽는다. (p.50)

### 4. 염기의 공통적인 성질이 나타나는 까닭
- 수산화 나트륨 수용액에 전원 장치를 연결하면 묽은 염산과 마찬가지로 전류가 흐른다. 수산화 나트륨은 수용액에서 **나트륨 이온(Na⁺)**과 **수산화 이온(OH⁻)**으로 이온화되기 때문이다. (p.51)
- 그림 Ⅰ-17 수산화 나트륨의 이온화 모형: 고체 수산화 나트륨이 물에 녹아 수용액이 될 때 Na⁺과 OH⁻으로 나뉜다. (p.51)
- 수산화 나트륨, 수산화 칼슘 등은 수용액 상태에서 수산화 이온(OH⁻)을 내놓는다. 염기의 종류에 따라 **양이온의 종류는 달라지지만 음이온의 종류(OH⁻)는 같다**. (p.51)
- 여러 염기가 공통적인 성질을 나타내는 것은 **수산화 이온 때문**이다. (p.51)
- **염기**: 수용액 상태에서 수산화 이온(OH⁻)을 내놓는 물질. (p.51)
- 염기의 이온화 (p.51):
  - 수산화 나트륨 `NaOH → Na⁺ + OH⁻` (나트륨 이온)
  - 수산화 칼륨 `KOH → K⁺ + OH⁻` (칼륨 이온)
  - 수산화 칼슘 `Ca(OH)₂ → Ca²⁺ + 2OH⁻` (칼슘 이온)

### 5. 우리 주변의 산과 염기
- 일상생활에서 먹는 음식이나 사용하는 물질 중에는 산이나 염기가 들어 있는 것이 많다. (p.52)
- 집 안의 예: (p.52)
  - **유리 세정제**: 기름 성분을 제거하기 위한 **염기** 성분이 들어 있다.
  - **비누**: 수산화 나트륨은 세탁 비누를 만드는 데 사용된다(염기).
  - **해열제, 진통제**: 살리실산과 아세틸 살리실산은 해열제나 진통제로 사용된다(산).
  - **식초, 과일**: 식초에는 아세트산, 과일에는 비타민 C 등의 산이 들어 있다.
- 환경의 예: (p.53)
  - **해양 산성화**: 대기 중 이산화 탄소 농도가 높아지면서 바다에 녹는 이산화 탄소의 양이 많아져 해수 표면의 수소 이온(H⁺) 농도가 점점 높아지고 있다.
  - **산성비**: 화석 연료 연소 시 배출된 황 산화물, 질소 산화물로부터 생성된 황산, 질산에 의해 산성비가 만들어진다.
  - **수국**: 꽃잎이 **산성 토양에서는 푸른색**, **염기성 토양에서는 붉은색**으로 피어난다.
  - **염기성 호수**: 탄자니아의 **나트론 호수**는 염기성을 띤다.
- Q: 이 외에도 우리 주변에서 볼 수 있는 산과 염기의 예를 찾아 써 보자. (p.53)

### 6. 스스로 확인 · 과학과 나
- 1. 아세트산 수용액이 산성을 띠는 까닭 → 수용액에서 수소 이온(H⁺)을 내놓기 때문(CH₃COOH → H⁺ + CH₃COO⁻). (p.50, p.53)
- 2. 산의 수용액과 염기의 수용액에서 모두 전류가 흐르는 까닭 → 둘 다 수용액에서 이온화되어 생긴 이온들이 전극으로 움직이기 때문. (p.50~51, p.53)
- 과학과 나: 산과 염기의 성질을 이해하는 것은 우리 생활에 어떤 도움을 줄지 생각해 보자. (p.53)

## 시험 함정 포인트
- 전류가 흐르는 것은 산만의 성질이 **아니라** 산과 염기 **모두**의 성질이다(둘 다 수용액에서 이온화). (p.49~51)
- 탄산 칼슘과 반응해 나오는 기체는 수소가 **아니라 이산화 탄소(CO₂)**이고, 마그네슘과 반응해 나오는 기체가 **수소(H₂)**이다. (p.49)
- 단백질(두부)을 녹이는 것은 산이 **아니라 염기**이다. (p.49)
- 모든 금속이 산과 반응하는 것은 **아니다**. 구리, 은, 금, 백금은 산과 반응하지 않는다. (p.49)
- 산의 공통 성질은 **양이온 H⁺** 때문이고 산마다 다른 것은 **음이온**이다. 염기는 반대로 공통인 것이 **음이온 OH⁻**, 다른 것이 **양이온**이다. (p.50~51)
- 황산(H₂SO₄)과 탄산(H₂CO₃)은 H⁺를 **2개(2H⁺)** 내놓고, 음이온은 SO₄²⁻, CO₃²⁻ (전하 2−)이다. (p.50)
- 수산화 칼슘 Ca(OH)₂는 OH⁻를 **2개** 내놓고 양이온은 Ca²⁺이다. (p.51)
- 아세트산(CH₃COOH)은 H를 4개 가지지만 내놓는 H⁺는 **1개**이다(CH₃COO⁻ + H⁺). (p.50)
- 수국은 산성 토양에서 **푸른색**, 염기성 토양에서 **붉은색**이다(반대로 외우기 쉬움). (p.53)
- 해양 산성화는 바다에 녹는 CO₂가 많아져 해수 표면의 **H⁺ 농도가 높아지는** 현상이다. (p.53)
- 혈액은 약한 **염기성**이다(산성 아님). 유리 세정제는 기름 제거용 **염기** 성분이다. (p.48, p.52)
- 산성비의 원인 물질은 화석 연료 연소 때 나온 황 산화물·질소 산화물로부터 생긴 **황산·질산**이다. (p.53)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 산 | 수용액 상태에서 수소 이온(H⁺)을 내놓는 물질 (p.50) |
| 염기 | 수용액 상태에서 수산화 이온(OH⁻)을 내놓는 물질 (p.51) |
| 산성 | 산의 공통적인 성질(전류가 흐름, 탄산 칼슘과 반응해 CO₂, 금속과 반응해 H₂ 발생) (p.49) |
| 염기성 | 염기의 공통적인 성질(전류가 흐름, 단백질을 녹임, 탄산 칼슘·금속과 반응 안 함) (p.49) |
| 이온화 | 물질이 물에 녹아 양이온과 음이온으로 나뉘는 것 (예: HCl → H⁺ + Cl⁻) (p.50) |
| 수소 이온(H⁺) | 산이 공통적으로 내놓는 양이온. 산의 공통 성질의 원인 (p.50) |
| 수산화 이온(OH⁻) | 염기가 공통적으로 내놓는 음이온. 염기의 공통 성질의 원인 (p.51) |
| 염화 이온(Cl⁻) | 염화 수소가 이온화할 때 생기는 음이온 (p.50) |
| 간이 전기 전도계 | 수용액에 전류가 흐르는지 확인하는 기구 (p.48) |
| 염화 수소(HCl) | 물에 녹아 염산이 되는 산 (p.50) |
| 아세트산(CH₃COOH) | 식초에 들어 있는 산 (p.50, p.52) |
| 수산화 나트륨(NaOH) | 대표적인 염기, 세탁 비누 제조에 사용 (p.51~52) |
| 살리실산·아세틸 살리실산 | 해열제·진통제로 쓰이는 산 (p.52) |
| 해양 산성화 | 바다에 녹는 CO₂ 증가로 해수 표면 H⁺ 농도가 높아지는 현상 (p.53) |
| 산성비 | 황 산화물·질소 산화물로부터 생긴 황산·질산에 의해 만들어진 비 (p.53) |
| 나트론 호수 | 탄자니아에 있는 염기성 호수 (p.53) |

## 자기점검 질문
1. 산과 염기의 수용액에서 모두 전류가 흐르는 까닭은? — 수용액에서 이온화되어 생긴 이온들이 전극으로 움직이기 때문
2. 산이 탄산 칼슘, 마그네슘과 반응할 때 발생하는 기체는? — 탄산 칼슘: 이산화 탄소(CO₂), 마그네슘: 수소(H₂)
3. 탐구에서 두부를 녹인 용액은? — 염기(수산화 나트륨 수용액, 수산화 칼륨 수용액)
4. 산과 반응하지 않는 금속의 예는? — 구리, 은, 금, 백금
5. 여러 산이 공통적인 성질을 나타내는 까닭은? — 수용액에서 공통적으로 수소 이온(H⁺)을 내놓기 때문
6. 황산의 이온화 반응식은? — H₂SO₄ → 2H⁺ + SO₄²⁻
7. 수산화 칼슘의 이온화 반응식은? — Ca(OH)₂ → Ca²⁺ + 2OH⁻
8. 아세트산 수용액이 산성을 띠는 까닭은? — CH₃COOH가 수용액에서 H⁺를 내놓기 때문
9. 염기에서 종류에 따라 달라지는 이온은? — 양이온 (Na⁺, K⁺, Ca²⁺ 등)
10. 수국 꽃잎 색은 토양에 따라 어떻게 달라지나? — 산성 토양: 푸른색, 염기성 토양: 붉은색
11. 해양 산성화가 일어나는 까닭은? — 대기 중 CO₂ 농도가 높아져 바다에 녹는 CO₂가 많아지고 해수 표면 H⁺ 농도가 높아지기 때문
