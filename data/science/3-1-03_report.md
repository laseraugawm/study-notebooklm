# Ⅲ-1-03 과학기술의 발전과 우리 생활
교과서 144-147쪽 · 통합과학

## 학습 목표
- 인공지능 로봇, 사물 인터넷 등을 인간 삶과 환경 개선에 활용하는 사례를 찾을 수 있다. (p.144)
- 과학기술의 발전이 미래 사회에 미치는 유용성과 한계를 예측할 수 있다. (p.144)
- (중심 질문: 과학기술의 발전은 우리 생활을 어떻게 변화시켰을까?)

## 핵심 개념

### 1. 사물 인터넷(IoT)
- 도입 사례: 내 몸의 이상을 감지해 구조 신호를 보내는 **스마트워치**, 햇빛의 세기를 고려해 열고 닫히는 **블라인드**. 도입 그림: 냉장고가 "집에 올 때 우유 사 오는 거 잊지 마."라고 말함. (p.144)
- **사물 인터넷(IoT)**: 각종 물건에 **센서와 통신 기능**을 내장한 뒤 **인터넷에 연결**하는 기술. (p.144)
- 사물 인터넷에 연결된 물건들은 (p.144)
  1. 스스로 정보를 수집하고 교환하며,
  2. 스스로 작동하거나,
  3. 사용자가 원격으로 조절할 수도 있다.

### 2. 집 안에서 사용되는 사물 인터넷 — 미래 스마트 홈 (그림 Ⅲ-6) (p.144)
| 기기 | 기능 |
|---|---|
| 냉난방 장치 | 기온과 습도를 측정해 쾌적한 환경을 자동으로 관리 |
| 조명 | 사람의 수면 패턴을 학습해 자동으로 관리 |
| 에너지 관리 시스템 | 에너지 사용량을 분석해 에너지 절약을 도움 |
| 냉장고 | 식품의 신선도를 파악해 맞춤형 요리법 안내 |
| 인공지능 비서 | 사람의 목소리를 인식해 작업 수행 |
| 청소 로봇 | 공간의 형태를 인지하여 스스로 청소 |

### 3. 인공지능 기술과 인공지능 로봇 (p.145)
- **인공지능 기술**: 인간의 **추론**이나 **학습** 능력을 컴퓨터에 구현한 기술. 최근에는 사물 인터넷과 결합하여 수집한 데이터를 분석하여 문제를 해결한다.
- **인공지능 로봇**: 로봇과 인공지능 기술이 접목된 로봇. **정해진 동작만 수행한 과거의 로봇과 달리** 주변 환경을 인식하고 스스로 판단하여 움직일 수 있다.

### 4. 기술의 결합과 생활의 변화 (p.145)
- 과학기술 결합의 흐름: 사물이 **센서**로 상황을 인식 → **인터넷**으로 정보 공유 → **인공지능**으로 스스로 판단해 문제 해결 → **로봇**과 결합해 물리적인 행동 수행
- 생활 속 예
  - 인터넷에 연결된 차량: 교통 정보가 전송되어 운전자의 안전하고 편안한 운전을 돕는다.
  - 자동으로 측정되는 심장박동수나 운동량 정보: 개인의 건강을 증진한다.
  - 주거 환경을 모니터링하는 기술: 에너지를 더 효율적으로 사용하게 한다.
- **도시 관리 시스템**: 도시의 대기 상태, 쓰레기통의 포화 정도, 교통량, 실시간 주차 공간 등 다양한 도시 데이터를 통해 도시 전체의 사물과 시민이 효율적으로 상호작용하도록 구축한다.

### 5. 과학기술이 적용되는 도시 — 미래 과학 도시 (그림 Ⅲ-7) (p.145)
| 기술 | 기능 |
|---|---|
| 스마트 병원 | 환자의 상태를 모니터링하고 원격으로 진료 |
| 수술용 로봇 | 정밀한 의료 서비스 제공 |
| 배송 드론 | 주문한 즉시 물건을 전달 |
| 자율주행 자동차 | 환경 정보를 실시간으로 분석하여 최적의 경로 선택 |
| 산업 로봇 | 사람과 함께 협력 |
| 스마트팜 로봇 | 작물의 상태를 판단하여 수확 |

### 6. [탐구] 일상생활 속 로봇의 특징 분석 및 개선 방안 고안하기 (p.146~147)
- 목표: 일상생활에서 활용하는 로봇의 특징을 분석하고 더 편리하게 사용하도록 개선 방안을 고안할 수 있다. 준비물: 스마트 기기
- 생각해 보기: 우리 주변에는 어떤 로봇이 있을까? 다양한 로봇을 사용하게 되면서 생활은 어떻게 변했을까?
- 탐구하기
  1. 제시된 로봇(**반려 로봇, 의료용 수술 로봇, 바리스타 로봇, 서빙 로봇**)을 모둠원과 나누어 각 로봇의 **종류·용도·기능**을 조사한다.
  2. 제시된 로봇 이외의 다른 로봇을 찾아본다.
  3. 이런 로봇을 사용했을 때 생긴 변화를 토의하고, **유용한 점과 발생할 수 있는 문제점 및 한계**를 정리한다.
  4. 조사한 로봇의 장단점을 생각하며 기능 개선 방안을 고안한다.
     - 예시: 내가 조사한 로봇 = 음식을 나르는 로봇 / 불편한 점 = 다른 층으로 배달하기 어렵다 / 개선 방법 = 바퀴 대신 다리를 달아 줘야 할 것 같다 / 내가 생각한 모습(그리기)
- 평가: 로봇의 종류에 따라 용도와 기능 설명 / 신뢰할 만한 자료 조사 / 창의적인 개선 방안 고안

### 7. 인공지능 로봇의 유용성과 한계 (p.147)
- 유용성: 인공지능 로봇은 **언론, 교통, 물류, 안전, 환경** 등 각종 분야에 접목되어 빠르게 확산 → 생활이 편리해지고 **산업 생산성**이 높아지는 등 사회 전반에 큰 영향.
- 한계(우려): 인공지능 로봇 사용으로 인한 **일자리 감소**, 로봇의 **통제 불능** 문제 등 부정적 영향에 대한 우려가 커지고 있다.
- 대비: 부정적 효과를 예방하고 긍정적 효과를 극대화하려면 기술이 사회 전반에 미치는 영향을 **예측**하고 **기술적·제도적으로 대비**해야 한다.
- 스스로 확인: ① 사물 인터넷이란? ② 과학기술이 발달한 미래 사회의 모습 한 가지(예: 스마트 홈, 자율주행 자동차, 배송 드론, 스마트 병원). 과학과 나: 생활 주변에서 사물 인터넷·인공지능·로봇 기술이 적용된 곳 찾기.

## 시험 함정 포인트
- 사물 인터넷은 물건에 **센서와 통신 기능**을 내장해 인터넷에 연결하는 기술이다. 센서만 있거나 통신만 있는 것으로 정의하지 말 것. (p.144)
- 사물 인터넷 기기는 사용자가 원격으로 조절할 **뿐 아니라** 스스로 정보를 수집·교환하고 스스로 작동하기도 한다. (p.144)
- 인공지능은 인간의 **추론이나 학습** 능력을 컴퓨터에 구현한 기술이다(단순 계산 능력이 아님). (p.145)
- 정해진 동작만 수행하는 것은 **과거의 로봇**이고, 인공지능 로봇은 환경을 인식하고 **스스로 판단**한다. (p.145)
- 기술 결합 순서: 센서로 **인식** → 인터넷으로 **공유** → 인공지능으로 **판단** → 로봇으로 **행동**. 역할을 바꿔 섞은 선지에 주의. (p.145)
- 주거 환경 모니터링 기술의 효과는 에너지를 **더 효율적으로 사용**하게 하는 것, 심장박동수·운동량 측정은 **건강 증진**, 인터넷 연결 차량은 **안전하고 편안한 운전**이다. (p.145)
- 쓰레기통의 포화 정도·주차 공간 데이터는 집이 **아니라 도시 관리 시스템**의 데이터다. (p.145)
- 인공지능 로봇의 우려는 일자리 **감소**(증가 아님)와 **통제 불능** 문제다. (p.147)
- 부정적 효과에 대한 대비는 기술 개발 중단이 **아니라** 영향을 예측하고 **기술적·제도적으로 대비**하는 것이다. (p.147)

## 자기점검 질문
1. 사물 인터넷이란? — 물건에 센서와 통신 기능을 내장하고 인터넷에 연결하는 기술
2. 사물 인터넷에 연결된 물건이 할 수 있는 일 세 가지는? — 스스로 정보 수집·교환, 스스로 작동, 사용자의 원격 조절
3. 인공지능 기술의 정의는? — 인간의 추론이나 학습 능력을 컴퓨터에 구현한 기술
4. 인공지능 로봇이 과거의 로봇과 다른 점은? — 정해진 동작만이 아니라 주변 환경을 인식하고 스스로 판단해 움직인다
5. 스마트 홈에서 수면 패턴을 학습해 자동 관리되는 것은? — 조명
6. 도시 관리 시스템에 쓰이는 도시 데이터 예는? — 대기 상태, 쓰레기통 포화 정도, 교통량, 실시간 주차 공간
7. 작물의 상태를 판단해 수확하는 로봇은? — 스마트팜 로봇
8. 탐구에서 제시된 로봇 네 가지는? — 반려 로봇, 의료용 수술 로봇, 바리스타 로봇, 서빙 로봇
9. 인공지능 로봇의 부정적 영향 두 가지는? — 일자리 감소, 로봇의 통제 불능 문제
10. 부정적 효과를 예방하려면? — 기술이 사회 전반에 미치는 영향을 예측하고 기술적·제도적으로 대비
