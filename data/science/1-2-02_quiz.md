# 산화환원 퀴즈

## Question 1
식물의 엽록체에서 일어나는 광합성 반응($6CO_2 + 6H_2O \rightarrow C_6H_{12}O_6 + 6O_2$)에 대한 설명으로 옳은 것은?

- [ ] 이산화 탄소($CO_2$)는 산화되어 포도당이 된다.
- [ ] 물($H_2O$)은 환원되어 산소가 된다.
- [x] 이산화 탄소($CO_2$)는 환원되고, 물($H_2O$)은 산화된다.
- [ ] 포도당과 산소가 반응하여 이산화 탄소와 물을 생성한다.

**Hint:** 반응물인 이산화 탄소와 물이 각각 생성물로 변할 때 산화와 환원 중 어떤 변화를 겪는지 비교해 보세요.

## Question 2
세포의 마이토콘드리아에서 일어나는 세포호흡 반응에 대한 설명으로 옳은 것은?

- [ ] 포도당($C_6H_{12}O_6$)이 환원되어 이산화 탄소가 된다.
- [ ] 산소($O_2$)가 산화되어 물이 된다.
- [x] 포도당($C_6H_{12}O_6$)은 산화되고, 산소($O_2$)는 환원된다.
- [ ] 빛에너지를 화학 에너지로 전환하여 포도당에 저장한다.

**Hint:** 세포호흡은 영양소를 분해하여 생명 활동에 필요한 에너지를 얻는 과정입니다.

## Question 3
메테인($CH_4$)의 완전 연소 반응($CH_4 + 2O_2 \rightarrow CO_2 + 2H_2O$)에서 산화되는 물질과 환원되는 물질을 옳게 짝지은 것은?

- [x] 산화: $CH_4$, 환원: $O_2$
- [ ] 산화: $O_2$, 환원: $CH_4$
- [ ] 산화: $CO_2$, 환원: $H_2O$
- [ ] 산화: $CH_4$, 환원: $CO_2$

**Hint:** 연소 반응 시 공기 중의 산소와 결합하는 주체가 어느 것인지 확인해 보세요.

## Question 4
철의 제련 반응($Fe_2O_3 + 3CO \rightarrow 2Fe + 3CO_2$)에 대한 설명으로 옳지 않은 것은?

- [ ] 산화 철(III)($Fe_2O_3$)은 산소를 잃고 철($Fe$)로 환원된다.
- [ ] 일산화 탄소($CO$)는 산소와 결합하여 이산화 탄소($CO_2$)로 산화된다.
- [ ] 철광석에서 순수한 철을 얻기 위해 산화 환원 반응이 이용된다.
- [x] 산화 철(III)($Fe_2O_3$)이 산화되고 일산화 탄소($CO$)가 환원된다.

**Hint:** 각 반응물이 산소를 얻는지 잃는지에 따라 산화와 환원을 구분해 보세요.

## Question 5
고온의 용광로에서 코크스($C$)가 산소와 결합하여 일산화 탄소($CO$)가 되는 반응에 대한 설명으로 옳지 않은 것은?

- [ ] 코크스($C$)가 산소와 결합하는 산화 반응이다.
- [ ] 생성된 일산화 탄소($CO$)는 산화 철(III)을 환원시키는 데 쓰인다.
- [ ] 코크스는 철광석을 환원시키기 위한 반응물로 작용한다.
- [x] 코크스($C$)가 산소를 잃고 환원되어 일산화 탄소($CO$)가 된다.

**Hint:** 어떤 물질이 산소와 결합할 때 일어나는 산화·환원 정의를 적용해 보세요.

## Question 6

- [x] 철이 산소와 반응하여 산화 철(III)로 산화될 때 열이 방출된다.
- [ ] 산화 철(III)이 환원되어 순수한 철이 될 때 열을 흡수한다.
- [ ] 파라핀이 완전 연소하여 이산화 탄소와 수증기를 생성한다.
- [ ] 산화 질소가 환원되면서 주위의 열을 흡수하여 온도를 높인다.

**Hint:** 손난로 내부의 주요 성분인 철 가루가 공기 중의 물질과 어떤 반응을 하는지 생각해 보세요.

## Question 7

- [ ] 산화 질소가 더욱 산화되어 열에너지를 방출한다.
- [ ] 이산화 탄소가 환원되어 공기 중의 산소로 전환된다.
- [ ] 리튬이 산화되면서 배기가스를 흡수한다.

**Hint:** 자동차에서 배출되는 유해 가스 중 하나인 산화 질소가 촉매를 지날 때 어떻게 변하는지 확인해 보세요.

## Question 8

- [ ] 산소가 전자를 잃고 산화되어 전기를 저장한다.
