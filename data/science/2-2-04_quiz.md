# 에너지 전환 퀴즈

## Question 1
휴대 전화에서 일어나는 에너지 전환 과정에 대한 설명으로 옳은 것은?

- [x] 배터리를 충전할 때는 전기 에너지가 화학 에너지로 전환되어 저장된다.
- [ ] 스피커에서 소리가 나올 때는 열에너지가 소리 에너지로 전환된다.
- [ ] 화면에서 빛이 나올 때는 화학 에너지가 중간 과정 없이 직접 빛에너지로 전환된다.
- [ ] 휴대 전화가 진동할 때는 소리 에너지가 모터의 운동 에너지로 전환된다.

**Hint:** 배터리를 전원에 연결하여 에너지를 넣을 때 어떤 형태의 에너지로 보관되는지 생각해 보세요.

## Question 2
에너지 보존 법칙에 대한 설명으로 가장 적절한 것은?

- [x] 에너지가 여러 형태로 전환될 때 전체 에너지의 총량은 변하지 않고 일정하게 유지된다.
- [ ] 에너지가 전환되면 인간이 유용하게 사용할 수 있는 에너지의 양이 지속적으로 증가한다.
- [ ] 사용을 마친 에너지는 완전히 소멸하여 우주 공간에서 사라진다.
- [ ] 마찰이나 공기 저항이 있는 실제 자연에서는 에너지 총량이 점차 감소한다.

**Hint:** 에너지의 형태가 바뀌는 과정에서 전체 에너지 양에 어떤 변화가 생기는지 떠올려 보세요.

## Question 3
어떤 열기관이 고열원에서 $1000\text{ kJ}$의 열을 흡수하여 외부에 $300\text{ kJ}$의 일을 하였다. 이 열기관의 열효율과 저열원으로 방출한 열량($Q_2$)으로 바르게 짝지어진 것은?

- [x] 열효율: $0.3$ ($30\%$), 저열원 방출 열량: $700\text{ kJ}$
- [ ] 열효율: $0.7$ ($70\%$), 저열원 방출 열량: $300\text{ kJ}$
- [ ] 열효율: $0.3$ ($30\%$), 저열원 방출 열량: $300\text{ kJ}$
- [ ] 열효율: $0.7$ ($70\%$), 저열원 방출 열량: $700\text{ kJ}$

**Hint:** 공급된 전체 열량은 '외부에 한 일'과 '저열원으로 버려진 열량'의 합과 같습니다.

## Question 4
열기관의 열효율에 대한 설명으로 옳지 않은 것은?

- [x] 열기관의 구조를 정밀하게 개선하면 흡수한 열을 $100\%$ 일로 바꾸는 열효율 $1$의 열기관을 만들 수 있다.
- [ ] 열기관에 공급된 열에너지 중 외부에 유용하게 한 일의 비율을 열효율이라고 한다.
- [ ] 열기관에서도 에너지가 보존되므로 공급된 열량은 한 일과 방출된 열량의 합과 같다.
- [ ] 가솔린 자동차의 엔진은 공급된 에너지의 대부분이 열 등으로 버려져 열효율이 낮은 편이다.

**Hint:** 열기관이 작동할 때 저열원으로 빠져나가는 열량을 완전히 없애는 것이 가능한지 고려해 보세요.

## Question 5
가솔린 자동차의 에너지 사용 현황에 대한 설명으로 옳은 것은?

- [x] 휘발유의 화학 에너지 중 실제 자동차 바퀴를 움직이는 운동 에너지로 전환되는 것은 약 $20\%$이다.
- [ ] 연료에 포함된 에너지의 대부분은 소리 에너지로 전환되어 주로 소실된다.
- [ ] 기계적 마찰로 인해 발생하는 열은 유용하게 사용된 에너지 범주에 포함된다.
- [ ] 휘발유에 포함된 에너지는 약 $80\%$가 운동 에너지로 전환되어 에너지 효율이 높다.

**Hint:** 가솔린 자동차에 주입된 연료 에너지 중 실제로 이동에 사용되는 비율과 버려지는 비율을 떠올려 보세요.

## Question 6
하이브리드 자동차가 일반 가솔린 자동차보다 에너지 효율이 더 높은 이유로 가장 적절한 것은?

- [x] 감속이나 내리막 주행 시 전기 모터가 발전기로 작용하여 버려지던 에너지를 전기 에너지로 저장하기 때문이다.
- [ ] 화석 연료를 전혀 사용하지 않고 오직 태양광 에너지만으로 주행하기 때문이다.
- [ ] 고속 주행을 할 때 엔진을 완전히 끄고 전기 모터만 구동하기 때문이다.
- [ ] 열기관 내부에서 저열원으로 방출되는 열을 $100\%$ 흡수하여 다시 일로 바꾸기 때문이다.

**Hint:** 자동차의 속도를 줄이거나 언덕을 내려갈 때 운동 에너지가 어떻게 처리되는지 주목해 보세요.

## Question 7
열병합 발전 방식이 일반 발전 방식에 비해 에너지 이용 효율이 크게 높은 까닭은 무엇인가?

- [x] 전력 생산 과정에서 발생하는 폐열을 버리지 않고 난방 등에 함께 이용하기 때문이다.
- [ ] 연료의 화학 에너지를 열에너지를 거치지 않고 직접 전기 에너지로 전환하기 때문이다.
- [ ] 송전선에서 발생하는 저항에 의한 전력 손실을 완전히 차단하기 때문이다.
- [ ] 터빈을 돌리지 않고 소리 에너지만으로 전기를 생산하기 때문이다.

**Hint:** 발전소에서 전기를 만들 때 부산물로 나오는 버려지는 열을 어떻게 활용하는지 생각해 보세요.

## Question 8
자연계에서 에너지 총량이 보존됨에도 불구하고 일상생활에서 에너지를 아껴 써야 하는 이유로 가장 옳은 것은?

- [x] 에너지가 전환되는 과정에서 다시 유용하게 사용하기 어려운 열에너지 등으로 바뀌어 버려지기 때문이다.
- [ ] 에너지를 사용할 때마다 우주 전체의 에너지 총량이 감소하기 때문이다.
- [ ] 에너지는 한 번 사용하면 다른 형태의 에너지로 전환되지 않고 파괴되기 때문이다.
- [ ] 전기 에너지는 사용 시 질량을 가진 물질로 완전히 변환되기 때문이다.

**Hint:** 에너지가 사용되어 다른 형태로 바뀐 후, 그 에너지를 다시 모아서 사용할 수 있는지 고려해 보세요.

## Question 9
다음 자연 현상 및 일상 현상에서의 에너지 전환 과정 연결 중 옳은 것은?

- [x] 식물의 광합성: 태양의 빛에너지 $\rightarrow$ 식물의 화학 에너지
- [ ] 롤러코스터가 높은 곳에서 내려올 때: 운동 에너지 $\rightarrow$ 위치 에너지
- [ ] 새가 울며 지저귈 때: 새 몸의 소리 에너지 $\rightarrow$ 화학 에너지
- [ ] 컴퓨터를 켜서 자료를 조사할 때 화면: 열에너지 $\rightarrow$ 화학 에너지

**Hint:** 식물이 햇빛을 받아 유기물(영양분)을 합성할 때 시작되는 에너지와 저장되는 에너지 형태를 확인하세요.

- [x] 전기 제품의 에너지 소비 효율 등급 표시제와 스마트 플러그 활용
- [ ] 모든 가전제품의 스피커 기능을 제거하여 소리 손실 방지
