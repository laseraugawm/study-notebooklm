# 중화반응 퀴즈

## Question 1
묽은 염산($HCl$) 수용액과 수산화 나트륨($NaOH$) 수용액이 반응하는 중화 반응에 대한 설명으로 옳은 것은?

- [ ] 수소 이온($H^+$)과 수산화 이온($OH^-$)은 $2 : 1$의 개수 비로 반응하여 물을 만든다.
- [x] 혼합 전 수용액의 수소 이온 양이 수산화 이온 양보다 많으면 혼합 용액은 산성이 된다.
- [ ] 중화 반응이 진행되는 동안 염화 이온($Cl^-$)의 총 개수는 지속적으로 감소한다.
- [ ] 수소 이온이 모두 반응하여 중성이 된 후 수산화 나트륨 수용액을 더 넣어도 액성은 변하지 않는다.

**Hint:** 중화 반응 시 이온이 결합하는 비와 알짜 이온 반응 후 남아 있는 이온에 따른 액성을 떠올려 보세요.

## Question 2
농도와 온도가 같은 묽은 염산($HCl$) $10\text{ mL}$와 수산화 나트륨($NaOH$) 수용액 $2\text{ mL}$를 혼합한 용액에 BTB 용액을 $2\sim3$방울 떨어뜨렸을 때 관찰되는 색으로 알맞은 것은?

- [x] 노란색
- [ ] 초록색
- [ ] 파란색
- [ ] 무색

**Hint:** 두 수용액의 부피 비를 통해 남아 있는 이온을 확인하고, 액성에 따른 BTB 지시약의 색 변화를 생각해 보세요.

## Question 3
중화 반응이 일어날 때 혼합 용액의 온도 변화 및 중화열에 대한 설명으로 옳은 것은?

- [ ] 중화 반응은 열을 흡수하는 반응이므로 반응이 진행될수록 혼합 용액의 온도가 낮아진다.
- [x] 발생하는 중화열의 크기는 중화 반응에서 생성된 물 분자의 양에 비례한다.
- [ ] 농도와 온도가 같은 묽은 염산과 수산화 나트륨 수용액을 혼합할 때, 부피 비와 상관없이 항상 최고 온도는 일정하다.
- [ ] 산성 수용액의 부피가 염기성 수용액의 부피보다 클 때 항상 최고 온도가 가장 높다.

**Hint:** 중화 반응 시 발생하는 에너지를 중화열이라 부르며, 이것이 반응량과 어떤 관계가 있는지 생각해 보세요.

## Question 4
일정량의 묽은 염산 수용액에 수산화 나트륨 수용액을 조금씩 첨가할 때, 비커 속 이온 수의 변화에 대한 설명으로 옳지 않은 것은?

- [x] 수산화 이온($OH^-$)의 수는 처음부터 중화점에 도달할 때까지 계속 증가한다.
- [ ] 염화 이온($Cl^-$)의 수는 수산화 나트륨 수용액을 넣어도 변하지 않고 일정하게 유지된다.
- [ ] 수소 이온($H^+$)의 수는 수산화 나트륨 수용액을 첨가함에 따라 점차 감소한다.
- [ ] 나트륨 이온($Na^+$)의 수는 수산화 나트륨 수용액을 넣는 양에 비례하여 계속 증가한다.

**Hint:** 반응에 직접 참여하는 알짜 이온($H^+$, $OH^-$)과 참여하지 않는 구경꾼 이온($Na^+$, $Cl^-$)의 차이를 떠올려 보세요.

## Question 5

- [ ] 수영장을 염소로 소독하면 산성이 되므로 염기성 물질을 넣어 중화한다.
- [ ] 위액의 염산 때문에 속이 쓰릴 때 염기성 제산제를 복용하여 통증을 완화한다.
- [x] 생선 비린내를 제거하기 위해 염기성인 레몬즙을 생선에 뿌린다.
- [ ] 산성화된 토양이나 호수에 염기성인 석회 가루를 뿌려 중화한다.

**Hint:** 레몬즙의 액성이 산성인지 염기성인지 파악해 보세요.

## Question 6

- [ ] 이산화 탄소 기체는 물에 녹으면 염기성 물질인 탄산이 된다.

- [ ] 반응 결과 생성된 탄산 칼슘은 기체 상태로 대기 중에 배출된다.

## Question 7

- [x] 입속 박테리아가 만드는 산성 물질인 젖산을 치약의 염기성 성분이 중화하기 때문이다.
- [ ] 입속 박테리아가 만드는 염기성 물질을 치약의 산성 성분이 중화하기 때문이다.
- [ ] 치약의 산성 성분이 치아에 침착된 염기성 때를 녹여 제거하기 때문이다.
- [ ] 치약 속 수산화 나트륨이 치아 표면의 강산성 세균을 직접 사멸시키기 때문이다.

## Question 8

- [ ] 1번 홈 (묽은 염산 $10\text{ mL}$ + 수산화 나트륨 수용액 $2\text{ mL}$)
