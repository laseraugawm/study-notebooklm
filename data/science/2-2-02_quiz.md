# 전자기유도 퀴즈

## Question 1
코일을 통과하는 자기장이 변할 때 코일에 전류가 흐르는 현상을 무엇이라고 하는가?

- [x] 전자기 유도
- [ ] 정전기 유도
- [ ] 전류의 자기 작용
- [ ] 자화 현상

**Hint:** 자석의 운동에 의해 자기장이 변하면서 전기가 만들어지는 현상입니다.

## Question 2
코일과 막대자석을 이용해 유도 전류를 발생시키는 실험에서, 코일에 흐르는 유도 전류의 세기를 크게 만드는 방법으로 옳지 않은 것은?

- [x] 막대자석과 코일을 같은 속도와 같은 방향으로 이동시킨다.
- [ ] 막대자석을 더 빠르게 움직인다.
- [ ] 자기장이 더 센 자석을 사용한다.
- [ ] 코일의 감은 수를 늘린다.

**Hint:** 코일 내부를 통과하는 자기장의 변화율을 높이는 조건인지 생각해 보세요.

## Question 3
막대자석과 코일을 배치하고 검류계를 연결하였을 때, 검류계의 바늘이 움직이지 않는(유도 전류가 흐르지 않는) 경우는 언제인가?

- [x] 자석을 코일 중심에 넣은 상태로 정지해 있을 때
- [ ] 자석을 가만히 두고 코일을 자석을 향해 가까이 가져갈 때
- [ ] 코일을 가만히 두고 자석을 코일에서 멀리 떨어뜨릴 때
- [ ] 자석의 S극을 코일에 빠르게 가까이 가져갈 때

**Hint:** 코일 내부를 통과하는 자기장의 변화가 발생하는지 여부를 파악해 보세요.

## Question 4
자석의 N극을 코일에 가까이 가져갈 때와 멀리 떨어뜨릴 때 나타나는 현상에 대한 설명으로 옳은 것은?

- [x] 두 경우 유도 전류의 방향이 서로 반대이다.
- [ ] 두 경우 모두 유도 전류가 흐르지 않는다.
- [ ] 두 경우 유도 전류의 방향이 동일하다.
- [ ] N극을 가까이 할 때만 전류가 흐르고 멀리 할 때는 흐르지 않는다.

**Hint:** 자석의 이동 방향에 따른 코일 내부 자기장의 세기 변화를 고려해 보세요.

## Question 5
발전기에서 전기를 생산할 때 일어나는 주요 에너지 전환 과정으로 옳은 것은?

- [x] 운동 에너지 $\rightarrow$ 전기 에너지
- [ ] 화학 에너지 $\rightarrow$ 전기 에너지
- [ ] 빛 에너지 $\rightarrow$ 전기 에너지
- [ ] 전기 에너지 $\rightarrow$ 운동 에너지

**Hint:** 터빈이나 자석의 회전 움직임이 무엇으로 바뀌는지 생각해 보세요.

## Question 6
발전소의 발전기 구조와 전기 생산 과정에 대한 설명으로 옳지 않은 것은?

- [x] 코일 내부에서 자석이 회전하면 자석의 운동 에너지가 증가한다.
- [ ] 발전기의 바깥쪽에는 코일이 고정되어 있다.
- [ ] 터빈이 회전하면 터빈과 연결된 자석이 함께 회전한다.
- [ ] 물이나 증기의 흐름을 이용해 터빈을 회전시킨다.

**Hint:** 에너지 전환이 일어날 때 기존 에너지의 양이 어떻게 되는지 확인해 보세요.

## Question 7
발전소에서 지속적으로 전기 에너지를 생산하기 위해 자석을 계속 돌려주어야 하는 이유로 가장 적절한 것은?

- [x] 자석이 회전하면서 운동 에너지가 전기 에너지로 전환되어 운동 에너지가 감소하기 때문에
- [ ] 자석이 오래 회전하면 자석의 자기장 세기 자체가 소멸하기 때문에
- [ ] 코일의 저항이 시간에 따라 급격히 증가하기 때문에
- [ ] 자석이 정지해 있어야만 코일에 유도 전류가 일정하게 흐르기 때문에

**Hint:** 한 형태의 에너지가 다른 형태로 전환될 때 기존 에너지가 어떻게 변하는지 생각해 보세요.

## Question 8
테이프 통에 에나멜선을 감고 네오디뮴 자석을 회전시키는 간이 발전기 실험에 대한 설명으로 옳은 것은?

- [x] 자석을 빠르게 회전시키면 코일을 통과하는 자기장이 변하여 유도 전류가 흐른다.
- [ ] 자석을 천천히 돌릴수록 발광 다이오드(LED)의 불빛이 더 밝아진다.
- [ ] 에나멜선의 감은 수를 줄일수록 유도 전류의 세기가 세어진다.
- [ ] 에나멜선의 끝부분 피막을 사포로 벗기지 않아도 회로에 전류가 통한다.

**Hint:** 발광 다이오드(LED)에 불이 켜지기 위해 필요한 전자기 유도 조건과 실험 절차를 파악해 보세요.

## Question 9
자전거 바퀴에 연결된 발전기로 휴대 전화를 충전하거나 발광 킥보드가 빛을 내는 원리에 대한 설명으로 옳은 것은?

- [x] 바퀴의 회전 운동 에너지가 전자기 유도를 통해 전기 에너지로 전환된다.
- [ ] 외부 전원에 항상 연결되어 있어야만 작동한다.
- [ ] 바퀴가 멈추어 정지해 있을 때 전기가 가장 많이 발생한다.
- [ ] 바퀴 내부에 들어 있는 화학 배터리의 반응만으로 빛을 낸다.

**Hint:** 전원을 연결하지 않고도 작동되는 장치에서 움직임이 어떻게 전기가 되는지 떠올려 보세요.

## Question 10
다음 중 전자기 유도 현상이 일어나 유도 전류가 흐르는 조건에 대한 설명으로 옳은 것은?

- [x] 자석과 코일이 서로 상대적인 운동을 하여 코일을 통과하는 자기장이 변해야 한다.
- [ ] 코일 내부를 지나는 자기장의 세기가 시간에 따라 일정하게 유지되어야 한다.
- [ ] 자석의 세기가 매우 강하다면 자석과 코일이 정지해 있어도 전류가 흐른다.
- [ ] 코일 대신 인슐레이터(절연체) 물질을 사용해야 유도 전류가 유도된다.

**Hint:** 유도 전류가 생성되기 위해 magnetic field(자기장)에 어떤 변화가 필요한지 파악해 보세요.
