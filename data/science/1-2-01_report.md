# Ⅰ-2-01 산화·환원 반응의 규칙성
교과서 38-43쪽 · 통합과학

## 학습 목표
- 자연과 인류의 역사에 큰 변화를 가져온 화학 반응에서 공통점을 찾아 설명할 수 있다. (p.38)
- 산화·환원 반응을 산소와 전자의 이동으로 설명할 수 있다. (p.38)
- 중심 질문: 우리 주변의 화학 반응에는 어떤 공통점이 있을까? / 산화·환원 반응에서 산소는 어떻게 이동할까? / 산화·환원 반응을 전자의 이동으로 설명할 수 있을까?

## 핵심 개념

### 1. 우리 몸과 주변의 화학 반응 (p.38)
- 우리는 호흡으로 산소를 공급받고, 음식은 잘게 쪼개지고 분해되어 몸 구석구석으로 전달된다. 세포는 전달된 **영양분과 산소**를 이용한 화학 반응으로 **에너지**를 만든다.
- 우리 몸에서는 다양한 화학 반응이 끊임없이 일어난다.
- 도입 그림: 눈사람의 손난로는 "전혀 따뜻하지 않"고, 친구는 "네 것은 포장을 뜯지 않았거든"이라고 답한다 — 생활 속 화학 반응을 떠올리게 하는 도입 장면 (p.38)

### 2. 자연과 인류의 역사에 큰 변화를 가져온 화학 반응 (그림 Ⅰ-11) (p.38~39)
1. **광합성 생물의 등장**: 바다에 광합성을 하는 **남세균**이 생겨나면서 지구 대기에 산소가 쌓이기 시작
   - 광합성: 이산화 탄소와 물이 반응하여 **포도당과 산소**가 만들어지고, 생성된 산소는 대기의 성분이 됨 (p.39)
2. **산소 호흡을 하는 생물의 등장**: 대기 중 산소가 풍부해지면서 산소를 이용해 영양소를 분해하고 에너지를 얻는 생물 등장
   - 대기 중 산소로부터 **오존층** 형성 → 오존층이 태양 **자외선을 흡수** → 생물이 바다에서 육지로 올라올 수 있게 됨 (p.39)
3. **철의 제련**: 자연 상태의 철은 산소와 결합된 **산화 철** 형태로 존재 → 인류는 산화 철에서 **산소를 떼어 내는** 제련 기술을 개발하여 **철기 문명**을 일으킴. 대량 생산된 철이 산업과 건축 등에 이용되어 인류의 삶이 크게 향상 (p.39)
4. **화석 연료의 사용**: 석탄, 석유, 천연가스를 산소와 반응시키면 **연소**가 일어나고, 이때 발생하는 **열에너지**가 물품 생산, 전력 생산, 운송 수단, 난방 등에 사용 → 인류 문명이 한 단계 도약. 기차·자동차 등 운송 수단의 발명으로 먼 거리를 빠르게 이동 (p.39)
- **공통으로 관여한 원소 = 산소** (p.39)
- **산소의 이동에 의한 산화·환원 반응**: 이와 같이 산소가 관여하는 반응 (p.39)
- 산소는 대기에서는 **기체 상태**로, 지각에서는 다른 원소와 결합하여 **광물 형태**로 존재하는 흔한 원소 → 산화·환원 반응은 생활에서 쉽게 볼 수 있다. (p.39)

### 3. 산소의 이동과 산화·환원 (p.40~41)
- 도입: 페루의 **무지개 산** — 붉은색을 띠는 곳에 철 성분이 많다. 철로 된 물건은 광택 있는 은회색인데 철 성분이 많은 땅은 왜 붉을까? (p.40)

#### [해 보기] 산화 구리(Ⅱ)를 숯가루와 함께 가열할 때의 변화 관찰하기 (자료 분석·결론 도출) (p.40)
- 방법: 시험관에 산화 구리(Ⅱ) 가루와 **충분한 양의 숯가루**를 넣고, 고무관이 연결된 고무마개로 막은 뒤 가열. 고무관 끝은 **석회수**가 든 비커에 넣는다.
- 관찰 결과
  - **검은색**의 산화 구리(Ⅱ)(CuO) 가루 → **붉은색**의 구리(Cu) 가루로 변함
  - 시험관에는 반응하지 않은 숯가루가 남음
  - **이산화 탄소(CO₂)** 가 발생하여 **석회수가 뿌옇게** 됨
- 질문: ① CuO와 C가 반응하면 생기는 물질 ② 가열 시 산소의 이동 ③ 반응을 산소의 이동으로 설명
- 해석 (p.41)
  - 산화 구리(Ⅱ)에서 산소가 분리되어 **구리**가 생성되고, 동시에 분리된 산소가 숯가루의 **탄소**와 결합하여 **이산화 탄소**가 생성된다.
  - 반응식: `2CuO + C → 2Cu + CO₂`
    - CuO → Cu : 산소를 잃음 → **환원**
    - C → CO₂ : 산소를 얻음 → **산화**
- 그림 Ⅰ-12: 산화 구리(Ⅱ)(구리 원자 사이에 산소 원자) + 탄소 → 구리 + 이산화 탄소 분자 (p.41)

#### 산소의 이동으로 본 정의 (p.41)
- **산화**: 물질이 산소와 결합하여 **산소를 얻는** 반응
- **환원**: 물질이 산소와 분리되어 **산소를 잃는** 반응
- 위 반응에서 산화 구리(Ⅱ)는 산소와 분리되므로 **환원**되고, 탄소는 산소와 결합하므로 **산화**된다.
- **산화 반응과 환원 반응은 동시에 일어난다.**

#### 철의 녹 (p.41)
- 철은 공기 중에 오래 노출되면 녹이 슬어 붉은색으로 변한다.
- 철(Fe)이 산소와 만나면 서서히 산화되어 **산화 철(Ⅲ)(Fe₂O₃)** 이 되어 본래의 성질을 잃는다.
- 은회색 철과 달리 산화 철(Ⅲ)은 **붉은색**을 띠고 **광택이 없다**.
- 페루 무지개 산 일부가 붉게 보이는 까닭도 흙에 **산화 철** 성분이 많기 때문 (p.41)

### 4. 전자의 이동과 산화·환원 (p.42~43)
- 철이 녹슬 때: `4Fe + 3O₂ → 2Fe₂O₃` — 철은 산소를 얻어 산화된다. 그런데 이 반응에서 **환원 반응은 산소의 이동으로 설명할 수 없다**. (p.42)
- 전자의 이동으로 설명 (p.42)
  - 생성물 산화 철(Ⅲ)(Fe₂O₃)을 구성하는 이온: **철 이온(Fe³⁺)** 과 **산화 이온(O²⁻)**
  - 철은 전자를 잃어 Fe³⁺이 되고, 산소는 전자를 얻어 O²⁻이 된다.
  - 즉 **철에서 산소로 전자가 이동**하여 산화·환원 반응이 일어난다.

#### [탐구] 구리와 질산 은 수용액의 산화·환원 반응 관찰하기 (현장 설명·결론 도출) (p.42)
- 목표: 질산 은(AgNO₃) 수용액과 구리(Cu)의 산화·환원 반응을 관찰할 수 있다.
- 준비물: 질산 은 수용액, 구리줄, 페트리 접시, 사포, 핀셋, 보안경, 실험용 장갑, 보호 장갑, 실험복
- 과정
  1. 구리줄 표면을 **사포로 문지른** 뒤 원하는 모양(꽃 모양 등)을 만들어 페트리 접시에 넣는다.
  2. 질산 은 수용액을 구리줄이 잠기도록 넣는다.
  3. 수용액의 색과 구리줄 표면의 변화를 관찰한다.
- 안전: 실험 후 남은 용액은 **폐수 통**에 버린다.
- 정리하기: ① 수용액의 색 변화 ② 구리줄 표면의 변화
- 결과와 해석 (p.43)
  - 수용액: 무색 → 점점 **푸른색** — 구리가 전자를 잃고 **구리 이온(Cu²⁺)** 형태로 용액에 녹아 들어감
  - 구리줄 표면: **은(Ag)** 이 석출되어 달라붙음 — 은 이온(Ag⁺)이 전자를 얻어 금속 은으로 석출
  - 반응식: `Cu + 2Ag⁺ → Cu²⁺ + 2Ag`
    - Cu → Cu²⁺ : 전자를 잃음 → **산화**
    - Ag⁺ → Ag : 전자를 얻음 → **환원**
- 평가하고 성찰하기: 색이 변하는 까닭 이해, 색 변화 관찰, 모둠 활동 참여

#### 전자의 이동으로 본 정의 (p.43)
- **산화**: 전자를 **잃는** 반응
- **환원**: 전자를 **얻는** 반응
- 산화·환원 반응에서는 **전자를 주고받으므로** 산화와 환원은 **동시에** 일어난다.

#### 마그네슘의 산화·환원 반응 (그림 Ⅰ-14) (p.43)
- 마그네슘(Mg) 리본을 공기 중에서 가열하면 산소(O₂)와 반응하여 **산화 마그네슘(MgO)** 이 된다.
- 마그네슘이 산화되어 마그네슘 이온(Mg²⁺)이 되고, 산소가 환원되어 산화 이온(O²⁻)이 되며, 두 이온이 결합하여 산화 마그네슘이 생성된다.
- 반응식: `2Mg + O₂ → 2MgO (2Mg²⁺ + 2O²⁻)`
  - Mg → Mg²⁺ : 전자를 잃음 → **산화**
  - O₂ → O²⁻ : 전자를 얻음 → **환원**
  - 두 이온이 결합하여 산화 마그네슘 생성
- 스스로 확인: ① 구리와 산소가 반응하여 산화 구리(Ⅱ)가 생성될 때 산화·환원되는 물질 ② 질산 은 수용액에 구리줄을 넣을 때의 산화·환원 반응 / 과학과 나: 생명체가 살아가는 데 산화·환원 반응이 중요한 까닭

## 비교·정리표

### 표 1. 산화와 환원의 두 가지 정의

| 기준 | 산화 | 환원 | 대표 예 (교과서) |
|---|---|---|---|
| 산소의 이동 | 산소를 얻음(산소와 결합) | 산소를 잃음(산소와 분리) | `2CuO + C → 2Cu + CO₂` |
| 전자의 이동 | 전자를 잃음 | 전자를 얻음 | `Cu + 2Ag⁺ → Cu²⁺ + 2Ag`, `2Mg + O₂ → 2MgO` |
| 공통 | 산화와 환원은 항상 **동시에** 일어남 | | |

### 표 2. 교과서 반응별 산화·환원 물질

| 반응 | 산화되는 물질 | 환원되는 물질 | 근거 |
|---|---|---|---|
| `2CuO + C → 2Cu + CO₂` | 탄소(C → CO₂) | 산화 구리(Ⅱ)(CuO → Cu) | 산소의 이동 |
| `4Fe + 3O₂ → 2Fe₂O₃` | 철(Fe → Fe³⁺) | 산소(O₂ → O²⁻) | 전자의 이동(환원은 산소 이동으로 설명 불가) |
| `Cu + 2Ag⁺ → Cu²⁺ + 2Ag` | 구리(Cu → Cu²⁺) | 은 이온(Ag⁺ → Ag) | 전자의 이동 |
| `2Mg + O₂ → 2MgO` | 마그네슘(Mg → Mg²⁺) | 산소(O₂ → O²⁻) | 전자의 이동 |

### 표 3. 실험 관찰 결과 정리

| 실험 | 관찰 | 의미 |
|---|---|---|
| 산화 구리(Ⅱ) + 숯가루 가열 | 검은색 → 붉은색 가루 | CuO가 환원되어 Cu 생성 |
| 〃 | 석회수가 뿌옇게 됨 | C가 산화되어 CO₂ 발생 |
| 구리줄 + 질산 은 수용액 | 수용액이 점점 푸른색 | Cu가 산화되어 Cu²⁺로 녹아 들어감 |
| 〃 | 구리줄 표면에 은 석출 | Ag⁺가 환원되어 Ag 석출 |
| 철이 공기 중에 노출 | 은회색·광택 → 붉은색·광택 없음 | Fe가 산화되어 산화 철(Ⅲ)(Fe₂O₃) 생성 |

### 표 4. 역사 속 산소가 관여한 반응

| 사건 | 반응 | 산소와의 관계 | 결과 |
|---|---|---|---|
| 광합성 생물(남세균) 등장 | 이산화 탄소 + 물 → 포도당 + 산소 | 산소 생성 | 대기에 산소 축적, 오존층 형성 |
| 산소 호흡 생물 등장 | 산소로 영양소 분해 | 산소 이용 | 에너지 획득 |
| 철의 제련 | 산화 철에서 산소를 떼어 냄 | 산소 제거 | 철기 문명 |
| 화석 연료 사용 | 석탄·석유·천연가스 연소 | 산소와 반응 | 열에너지 이용, 문명 도약 |

## 시험 함정 포인트
- 산화 구리(Ⅱ)와 탄소 반응에서 **산화되는 것은 탄소**, **환원되는 것은 산화 구리(Ⅱ)** 다. 교과서는 "산화 구리(Ⅱ)는 산소와 분리되므로 환원되고"라고 직접 진술한다. 이름에 "산화"가 들어 있다고 산화되는 물질이 아니다. (p.41)
- 산화와 환원은 따로따로가 아니라 **항상 동시에** 일어난다. (p.41, p.43)
- 산소 기준: 산소를 **얻으면 산화**, 잃으면 환원 / 전자 기준: 전자를 **잃으면 산화**, 얻으면 환원 — 방향이 반대처럼 보이니 혼동 주의. (p.41, p.43)
- 철이 녹스는 반응 `4Fe + 3O₂ → 2Fe₂O₃` 에서 환원되는 것(산소)은 **산소의 이동으로 설명할 수 없어** 전자의 이동으로 설명한다. (p.42)
- 산화 철(Ⅲ)을 이루는 이온은 Fe²⁺가 아니라 **Fe³⁺** 와 **O²⁻** 이며, 전자는 **철에서 산소로** 이동한다. (p.42)
- 구리줄을 질산 은 수용액에 넣으면 수용액이 푸르게 되는 까닭은 은 때문이 아니라 **Cu²⁺** 가 녹아 들어갔기 때문이고, 표면에 붙는 물질은 구리가 아니라 **은(Ag)** 이다. (p.43)
- `Cu + 2Ag⁺ → Cu²⁺ + 2Ag` 에서 Cu 1개가 전자를 잃을 때 Ag⁺는 **2개**가 필요하다(계수 2). (p.43)
- 마그네슘 연소에서 산소(O₂)는 산화되는 것이 아니라 전자를 얻어 O²⁻가 되므로 **환원**된다. (p.43)
- 산화 구리(Ⅱ) 실험에서 석회수가 뿌옇게 되는 것은 산소가 아니라 **이산화 탄소(CO₂)** 가 발생했기 때문이다. (p.40)
- 철의 제련은 철을 산화시키는 것이 아니라 산화 철에서 **산소를 떼어 내는**(환원) 과정이다. (p.39)
- 자외선을 흡수하여 생물의 육지 진출을 가능하게 한 것은 산소 자체가 아니라 산소로부터 형성된 **오존층**이다. (p.39)
- 철의 녹(산화 철(Ⅲ))은 은회색이 아니라 **붉은색·광택 없음**이다. 무지개 산의 붉은 땅도 **산화 철** 때문이다. (p.41)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 산화·환원 반응 | 산소나 전자가 이동하며 산화와 환원이 동시에 일어나는 반응. 산소가 관여하는 경우 "산소의 이동에 의한 산화·환원 반응" (p.39) |
| 산화(산소 기준) | 물질이 산소와 결합하여 산소를 얻는 반응 (p.41) |
| 환원(산소 기준) | 물질이 산소와 분리되어 산소를 잃는 반응 (p.41) |
| 산화(전자 기준) | 전자를 잃는 반응 (p.43) |
| 환원(전자 기준) | 전자를 얻는 반응 (p.43) |
| 광합성 | 이산화 탄소와 물이 반응하여 포도당과 산소가 만들어지는 반응 (p.39) |
| 산소호흡 | 산소를 이용해 영양소를 분해하고 에너지를 얻는 것 (p.38, p.39) |
| 오존층 | 대기 중 산소로부터 형성되어 태양 자외선을 흡수하는 층 (p.39) |
| 제련 | 산화 철에서 산소를 떼어 내 철을 얻는 기술 (p.39) |
| 연소 | 화석 연료(석탄, 석유, 천연가스)가 산소와 반응하여 열에너지를 내는 반응 (p.39) |
| 산화 구리(Ⅱ) | CuO, 검은색 가루. 숯가루와 가열하면 환원되어 붉은색 구리가 됨 (p.40) |
| 산화 철(Ⅲ) | Fe₂O₃, 철이 산화된 붉은색·광택 없는 물질(녹). Fe³⁺와 O²⁻로 구성 (p.41, p.42) |
| 철 이온 | Fe³⁺, 철이 전자를 잃어 된 이온 (p.42) |
| 산화 이온 | O²⁻, 산소가 전자를 얻어 된 이온 (p.42) |
| 구리 이온 | Cu²⁺, 구리가 전자를 잃어 된 이온. 수용액을 푸른색으로 만듦 (p.43) |
| 은 이온 | Ag⁺, 전자를 얻어 금속 은으로 석출되는 이온 (p.43) |
| 석출 | 금속 이온이 전자를 얻어 금속 은(Ag) 등 고체로 되어 나오는 것 (p.43) |
| 산화 마그네슘 | MgO, 마그네슘을 공기 중에서 가열하여 생성. Mg²⁺와 O²⁻의 결합 (p.43) |
| 석회수 | 이산화 탄소와 만나면 뿌옇게 되는 용액. CO₂ 확인에 사용 (p.40) |

## 자기점검 질문
1. 광합성, 철의 제련, 화석 연료의 사용에 공통으로 관여하는 원소는? — 산소
2. 산소의 이동으로 산화와 환원을 정의하면? — 산화: 산소를 얻음, 환원: 산소를 잃음
3. `2CuO + C → 2Cu + CO₂` 에서 산화·환원되는 물질은? — 탄소가 산화, 산화 구리(Ⅱ)가 환원
4. 산화 구리(Ⅱ)와 숯가루를 가열할 때 관찰되는 변화 두 가지는? — 검은색 가루가 붉은색 구리로 변함, 석회수가 뿌옇게 됨(CO₂ 발생)
5. 철로 된 물건이 녹슬면 어떻게 변하나? — 산화되어 산화 철(Ⅲ)(Fe₂O₃)이 되며 붉은색을 띠고 광택이 없어짐
6. 철이 녹스는 반응을 전자의 이동으로 설명하면? — 철이 전자를 잃어 Fe³⁺(산화), 산소가 전자를 얻어 O²⁻(환원), 전자는 철에서 산소로 이동
7. 전자의 이동으로 산화와 환원을 정의하면? — 산화: 전자를 잃음, 환원: 전자를 얻음
8. 구리줄을 질산 은 수용액에 넣으면 나타나는 변화와 까닭은? — 수용액이 푸른색(Cu²⁺ 생성, 구리 산화), 구리줄 표면에 은 석출(Ag⁺ 환원). 반응식 `Cu + 2Ag⁺ → Cu²⁺ + 2Ag`
9. 마그네슘을 공기 중에서 가열할 때 산화·환원되는 물질은? — 마그네슘 산화(Mg²⁺), 산소 환원(O²⁻). 마그네슘이 산화되어 Mg²⁺가 되고, 산소가 환원되어 O²⁻가 되며, 두 이온이 결합하여 MgO 생성
10. 구리와 산소가 반응하여 산화 구리(Ⅱ)가 생길 때 산화·환원되는 물질은? — 구리가 산화, 산소가 환원
11. 산화와 환원이 동시에 일어나는 까닭은? — 산소나 전자를 한쪽이 잃으면 다른 쪽이 얻기(주고받기) 때문
12. 산화·환원 반응을 생활에서 쉽게 볼 수 있는 까닭은? — 산소가 대기(기체)와 지각(광물)에 흔하게 존재하기 때문
