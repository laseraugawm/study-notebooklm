# 화학 산화환원퀴즈

## Question 1
지구 역사에서 광합성 생물(남세균)이 등장한 이후 나타난 지구 환경 및 생물계의 변화로 옳은 것은?

- [ ] 대기 중 이산화 탄소의 농도가 급격히 증가하였다.
- [x] 대기 중 산소로부터 오존층이 형성되어 생물이 육지로 진출할 수 있게 되었다.
- [ ] 산소 호흡을 하는 생물이 사라지고 무산소 호흡 생물이 급증하였다.
- [ ] 대기 중의 산소가 지각의 광물과 반응하여 인류의 철기 문명이 자연적으로 시작되었다.

**Hint:** 광합성 결과 축적된 산소가 대기 상층에서 형성한 보호막의 역할을 생각해 보세요.

## Question 2
검은색 산화 구리(II) 가루($CuO$)와 숯가루($C$)를 함께 시험관에 넣고 가열할 때 일어나는 변화에 대한 설명으로 옳은 것은?

- [ ] 산화 구리(II)는 산소를 얻어 산화된다.
- [ ] 탄소($C$)는 산소를 잃어 환원된다.
- [x] 검은색의 산화 구리(II)가 붉은색의 구리($Cu$)로 변한다.
- [ ] 반응 결과 발생한 기체는 석회수를 변화시키지 않는다.

**Hint:** 산소를 잃은 물질의 색깔 변화와 발생하는 기체의 종류를 고려해 보세요.

## Question 3
철의 제련 반응에 대한 설명으로 옳은 것은?

- [ ] 자연 상태에 존재하는 순수한 철을 단순히 열로 용해하여 얻는 과정이다.
- [x] 산화 철에서 산소를 떼어 내어 순수한 철을 얻는 환원 과정이 포함된다.
- [ ] 철이 공기 중의 산소와 반응하여 산화 철(III)이 되는 산화 과정이다.
- [ ] 산소의 이동이 전혀 관여하지 않는 반응이다.

**Hint:** 자연 상태의 철광석 형태와 순수한 철을 얻기 위해 산소를 어떻게 처리해야 하는지 생각해 보세요.

## Question 4
산화·환원 반응의 중요한 특성인 '동시성'에 대한 설명으로 가장 적절한 것은?

- [x] 한 물질이 산소를 얻거나 전자를 잃으면, 다른 물질은 산소를 잃거나 전자를 얻는다.
- [ ] 화학 반응에서 산화 반응이 모두 끝난 후에 환원 반응이 진행된다.
- [ ] 조건에 따라 산화 반응만 단독으로 진행될 수 있다.
- [ ] 전자의 이동에 의한 반응에서는 동시성이 성립하지 않는다.

**Hint:** 산소나 전자를 주고받는 과정이 서로 연결되어 있음을 떠올려 보세요.

## Question 5
전자의 이동 관점에서 산화와 환원을 올바르게 정의한 것은?

- [x] 물질이 전자를 잃는 반응을 산화, 전자를 얻는 반응을 환원이라고 한다.
- [ ] 물질이 전자를 얻는 반응을 산화, 전자를 잃는 반응을 환원이라고 한다.
- [ ] 전자의 이동에 따른 정의는 산소가 결합하는 반응에는 적용할 수 없다.
- [ ] 금속 이온이 전자를 얻어 금속 원자로 석출되는 것은 산화 반응이다.

**Hint:** 구리가 구리 이온($Cu^{2+}$)이 될 때 전자를 어떻게 하는지 떠올려 보세요.

## Question 6
구리줄을 질산 은($AgNO_3$) 수용액에 넣었을 때 일어나는 변화로 옳은 것은?

- [x] 수용액 속에 구리 이온($Cu^{2+}$)이 늘어나면서 수용액이 점점 푸른색으로 변한다.
- [ ] 은 이온($Ag^+$)은 전자를 잃고 산화되어 구리줄 표면에 녹아든다.
- [ ] 구리줄 표면에는 아무런 물질도 석출되지 않고 수용액의 색만 변한다.
- [ ] 구리 원자는 전자를 얻어 환원된다.

**Hint:** 수용액의 색을 푸른색으로 변화시키는 이온이 생성되는 과정을 생각해 보세요.

## Question 7

- [x] $Cu$는 전자를 잃고 산화된다.
- [ ] $Cu$는 전자를 얻어 환원된다.
- [ ] $Ag^+$는 전자를 잃고 환원된다.
- [ ] $Ag^+$는 전자를 얻어 산화된다.

**Hint:** 반응 전후 구리 원자와 은 이온의 전하량 변화를 비교해 보세요.

## Question 8
마그네슘($Mg$) 리본을 공기 중에서 가열하여 산화 마그네슘($MgO$)이 생성되는 반응($2Mg + O_2 \rightarrow 2MgO$)을 전자의 이동으로 설명할 때 옳은 것은?

- [ ] 마그네슘 원자는 전자를 얻어 마그네슘 이온($Mg^{2+}$)이 된다.
- [x] 산소 분자는 전자를 얻어 산화 이온($O^{2-}$)으로 환원된다.
- [ ] 마그네슘은 환원되고 산소는 산화되는 반응이다.
- [ ] 마그네슘에서 산소로의 전자 이동은 일어나지 않는다.

**Hint:** 금속인 마그네슘과 비금속인 산소가 이온이 될 때 전자를 잃는지 얻는지 확인하세요.

## Question 9

- [x] 철에서 산소로 전자가 이동하면서 철은 산화되고 산소는 환원된다.
- [ ] 이 반응은 산소의 이동으로만 설명이 가능하고 전자의 이동으로는 설명할 수 없다.
