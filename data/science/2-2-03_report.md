# Ⅱ-2-03 화력·핵발전의 영향
교과서 108-111쪽 · 통합과학

## 학습 목표
- 화력 발전과 핵발전이 인간 생활에 미치는 영향을 조사하고 발표할 수 있다. (p.108)
- 화력 발전과 핵발전의 에너지 생성 과정과 장단점을 설명할 수 있다. (p.108)
- (교과서 소단원 제목: 화력 발전과 핵발전이 인간 생활에 미치는 영향) (p.108)

## 핵심 개념

### 1. [탐구] 화력 발전과 핵발전이 인간 생활에 미치는 영향 알아보기 (p.108~109)
- **목표**: 화력 발전과 핵발전이 인간 생활에 미치는 영향을 조사하여 발표할 수 있다. (정보 조사·과학적 의사 결정) / 준비물: 스마트 기기
- 도입 만화: 발전소 굴뚝과 냉각탑을 보며 "전기는 필요한데 발전소는 …." (p.108)
- **생각해 보기**: 우리나라는 화력 발전과 핵발전으로 전기 에너지를 공급하는 **비중이 높다**. 그러나 발전소를 건설·운영하는 과정에서 여러 문제도 발생한다. 발전소는 우리에게 어떤 영향을 줄까? 모두 없앤다면 어떻게 될까? (p.108)
- **2022년 에너지원별 발전량** (한국 전력 공사, 2022) (p.108)

| 에너지원 | 비율 |
|---|---|
| 석탄 | 32.5 % |
| 원자력(핵에너지) | 29.5 % |
| LNG | 27.5 % |
| 신재생 | 8.9 % |
| 유류·양수·기타 | 1.6 % |

  - → 석탄 + LNG(화력)와 원자력이 대부분을 차지한다.
- **자료: 국내 발전소 현황** (지도, 건설 중인 발전소 포함) (p.108)
  - **화력 발전**: 연료는 **석탄, 석유, 천연가스** 등. 화석 연료를 **연소**시켜 발전하며, 이때 **온실 기체와 대기 오염 물질**이 대기 중으로 방출된다.
  - **핵발전**: 원료는 주로 **우라늄**. **방사성 물질에서 발생하는 열에너지**로 발전하며, 발전 과정과 **핵폐기물 처리 과정에서 방사능 유출 위험**이 있다.
  - 지도: 화력 발전소는 서해안 중부 등 여러 해안에 밀집, 핵발전소는 주로 동해안 쪽과 서해안 남부에 위치하는 것으로 표시되어 있다.
- **탐구 과정** (p.109)
  1. 모둠별로 화력 발전소와 핵발전소 중 하나를 골라 우리 생활에 미치는 영향을 조사한다. 주제를 나누어 조사:
     - 안정적인 전기 에너지 공급
     - 발전소 주변 주민의 거주 환경
     - 발전 과정에서 생기는 환경 문제
     - 발전소가 주변 생태계에 미치는 영향
  2. 조사 내용을 바탕으로 발전소의 **긍정적·부정적 영향**, 발전소가 **없어진다면** 우리 생활의 변화(편해지는 점, 불편해지는 점 모두)를 이야기한다.
  3. 발전소의 부정적인 영향을 줄이는 방법을 토의한다.
  4. '◯◯ 발전소의 영향과 개선 방향 종합 보고서'를 만든다.
  5. 보고서를 발표하고 화력 발전소와 핵발전소의 개선 방향을 토의한다.
- 평가하고 성찰하기: 발전소가 생활에 미치는 영향을 설명할 수 있는가 / **공신력 있는 기관의 자료**를 수집하고 **출처를 명시**했는가 / 토의에서 자신의 생각을 정확히 표현했는가 (p.109)

### 2. 화력 발전 — 화력 발전소와 핵발전소는 우리에게 어떤 영향을 줄까?
- **화력 발전**: 석탄이나 석유 등 **화석 연료에 저장된 화학 에너지**를 이용하여 전기 에너지를 생산 (p.110)
- 에너지 생성 과정 (그림 Ⅱ-25) (p.110)
  1. **보일러**에서 화석 연료를 **연소** → 화학 에너지를 **열에너지**로 전환
  2. 열에너지로 **물을 끓여 증기**(수증기) 발생
  3. 증기로 발전기에 연결된 **터빈**을 돌림
  4. **발전기**에서 전기 에너지 생산 → 송전탑으로 송전
  - 그림 요소: 화석 연료 → 보일러로 물 가열 → 수증기 → 터빈 → 발전기, 냉각수가 증기를 식혀 물로 되돌림
  - `화학 에너지 → 열에너지 → (증기·터빈의) 운동 에너지 → 전기 에너지`
- **장점** (p.110)
  - 발전 효율이 **높은 편**
  - 발전량을 **조절하기 쉬움**
  - 비교적 **좁은 곳**에 발전소 건설 가능
- **단점** (p.110)
  - 화석 연료의 **매장량에 한계**가 있고 **매장 지역이 편중**됨
  - 연소 시 **이산화 탄소(CO₂)** 같은 **온실 기체**와 **미세 먼지** 같은 **대기 오염 물질**이 많이 배출됨
- 꼼꼼읽기: 화력 발전과 핵발전의 에너지 생성 과정과 장단점을 생각하며 읽어 보자. (p.110)

### 3. 핵발전
- 태양의 **핵융합** 반응(수소 원자핵 → 헬륨 원자핵)에서 에너지가 발생하듯이, 무거운 원자핵이 쪼개지는 **핵분열 반응**에서도 **질량이 감소**하면서 에너지가 발생한다. (p.111)
- **핵분열 반응**: 우라늄 원자핵과 같이 **질량이 큰 원자핵**이 **질량이 작은 원자핵**으로 쪼개지는 반응 (p.111)
- 에너지 생성 과정 (그림 Ⅱ-26) (p.111)
  1. **원자로**에서 **우라늄 원자핵에 중성자**를 충돌시킴 → 원자핵이 쪼개지며 **핵에너지가 열에너지**로 전환
  2. 함께 방출된 **중성자들**이 다른 우라늄 원자핵과 **연쇄적으로 충돌** → 막대한 양의 열에너지 발생
  3. 열에너지로 물을 끓여 **증기**를 만듦(증기 발생기)
  4. 증기로 **터빈**을 돌려 **발전기**에서 전기 에너지 생산
  - 그림 요소: 원자로, 증기 발생기, 터빈, 발전기, 냉각기, 바닷물
  - `핵에너지 → 열에너지 → (증기·터빈의) 운동 에너지 → 전기 에너지`
- **장점** (p.111)
  - 화력 발전보다 **이산화 탄소 배출량이 적음**
  - **원료 비용이 저렴**
  - **적은 양의 원료**로도 많은 전기 에너지 생산
- **단점** (p.111)
  - 발전 과정에서 발생하는 **방사선**과 **핵폐기물**이 인체와 환경에 위협이 됨

### 4. 화력 발전·핵발전과 인간 생활
- 우리나라는 **대부분의 전기 에너지**를 화력 발전소와 핵발전소에서 얻으며, 이 전기 에너지는 우리 삶에 편리하게 이용된다. (p.111)
- 그러나 **환경오염**, 발전소 건설에 따른 **주민 갈등** 등 여러 문제를 일으키기도 한다. (p.111)
- 따라서 이런 **문제를 줄이는 노력**과 함께 **새로운 에너지를 찾는 노력**이 필요하다. (p.111)
- 스스로 확인: ① 화력 발전과 핵발전에서 **공통**으로 일어나는 에너지 전환 과정 ② 화력 발전과 핵발전의 장단점. 과학과 나: 발전소 건설에 관한 논의에 참여한다면 어떤 태도로 토론하면 좋을지 이야기하기 (p.111)
  - 공통 과정(본문 근거): 발생한 **열에너지로 물을 끓여 증기**를 만들고, 증기로 **터빈을 돌려** 발전기에서 **전기 에너지**를 생산한다. (p.110~111)

## 비교·정리표

**표 1. 화력 발전 vs 핵발전**

| 구분 | 화력 발전 | 핵발전 |
|---|---|---|
| 연료·원료 | 석탄, 석유, 천연가스 (화석 연료) (p.108) | 주로 우라늄 (p.108) |

| 단점 | 매장량 한계·매장 지역 편중, 온실 기체·미세 먼지 배출 | 방사선·핵폐기물이 인체·환경 위협, 방사능 유출 위험 |

## 시험 함정 포인트
- 핵발전은 핵**융합**이 **아니라** 우라늄 원자핵이 쪼개지는 **핵분열** 반응을 이용한다. (p.111)
- 핵분열에서도 핵융합과 마찬가지로 **질량이 감소**하면서 에너지가 발생한다. 질량이 늘어나는 것이 **아니다**. (p.111)
- 핵분열의 연쇄 반응은 방출된 **중성자**가 다른 우라늄 원자핵과 충돌해서 일어난다. 양성자나 전자가 **아니다**. (p.111)
- 화력 발전에서 처음 에너지는 열에너지가 **아니라** 화석 연료에 저장된 **화학 에너지**이고, 핵발전은 **핵에너지**이다. (p.110~111)
- 화력 발전과 핵발전은 열을 얻는 방법만 다르고, **물을 끓여 증기로 터빈을 돌려 발전**하는 과정은 **공통**이다. (p.110~111)
- 핵발전의 장점은 "이산화 탄소를 전혀 배출하지 않는다"가 **아니라** 화력 발전보다 **배출량이 적다**는 것이다. (p.111)
- 발전량 조절이 쉽고 좁은 곳에 건설 가능한 것은 핵발전이 **아니라 화력 발전**의 장점이다. (p.110)
- 2022년 우리나라 발전량 1위는 원자력이 **아니라 석탄**(32.5 %)이며, 원자력은 29.5 %이다. (p.108)
- 화력 발전의 연료에는 석탄·석유뿐 **아니라 천연가스**(LNG)도 포함된다. (p.108)

| 용어 | 뜻 |
|---|---|
| 화력 발전 | 화석 연료에 저장된 화학 에너지를 연소로 열에너지로 바꾸어 증기로 터빈을 돌려 전기를 생산하는 발전 (p.110) |
| 화석 연료 | 석탄, 석유, 천연가스 등. 화력 발전의 연료 (p.108) |
| 보일러 | 화석 연료를 연소시켜 물을 가열하는 장치 (p.110) |
| 터빈 | 증기로 회전하여 발전기를 돌리는 장치 (p.110~111) |
| 냉각수 | 화력 발전소에서 증기를 식히는 물 (p.110) |
| 핵발전 | 핵분열에서 발생한 열에너지로 증기를 만들어 터빈을 돌려 전기를 생산하는 발전 (p.111) |
| 우라늄 | 핵발전소에서 주로 사용하는 원료 (p.108) |
| 핵분열 반응 | 우라늄 원자핵과 같이 질량이 큰 원자핵이 질량이 작은 원자핵으로 쪼개지는 반응 (p.111) |
| 중성자 | 우라늄 원자핵에 충돌해 핵분열을 일으키고, 분열 때 방출되어 연쇄 반응을 일으키는 입자 (p.111) |
| 원자로 | 핵분열이 일어나는 핵발전소의 장치 (p.111) |
| 증기 발생기 | 원자로의 열로 증기를 만드는 장치 (p.111) |
| 핵에너지 | 원자핵이 쪼개질 때 나와 열에너지로 전환되는 에너지 (p.111) |
| 핵폐기물 | 핵발전 과정에서 발생하여 인체와 환경에 위협이 되는 폐기물 (p.111) |
| 방사선 / 방사능 유출 | 핵발전 과정과 핵폐기물 처리 과정에서 생기는 위험 (p.108, 111) |
| 대기 오염 물질 | 미세 먼지 등, 화석 연료 연소 시 배출 (p.110) |

## 자기점검 질문
1. 화력 발전의 에너지 전환 과정은? — 화석 연료의 화학 에너지 → (보일러 연소) 열에너지 → 증기로 터빈 회전 → 발전기에서 전기 에너지.
2. 화력 발전의 장점 세 가지는? — 발전 효율이 높은 편, 발전량 조절이 쉬움, 비교적 좁은 곳에 건설 가능.
3. 화력 발전의 단점은? — 화석 연료 매장량 한계·매장 지역 편중, 온실 기체(CO₂)와 미세 먼지 같은 대기 오염 물질 배출.
4. 핵분열 반응이란? — 우라늄 원자핵처럼 질량이 큰 원자핵이 질량이 작은 원자핵으로 쪼개지는 반응.
5. 핵분열에서 막대한 열에너지가 생기는 까닭은? — 질량 감소로 에너지가 발생하고, 방출된 중성자가 다른 우라늄 원자핵과 연쇄적으로 충돌하기 때문.
6. 핵발전의 장점과 단점은? — 장점: CO₂ 배출 적음, 원료비 저렴, 적은 원료로 많은 전기 / 단점: 방사선과 핵폐기물이 인체·환경에 위협.
7. 화력 발전과 핵발전의 공통 에너지 전환 과정은? — 열에너지로 물을 끓여 증기를 만들고 증기로 터빈을 돌려 전기 에너지를 생산한다.
8. 2022년 우리나라 발전량 비율 상위 세 에너지원은? — 석탄 32.5 %, 원자력 29.5 %, LNG 27.5 %.
9. 화력 발전과 핵발전이 일으키는 사회적 문제와 필요한 노력은? — 환경오염, 발전소 건설에 따른 주민 갈등 / 문제를 줄이는 노력과 새로운 에너지를 찾는 노력.
10. 탐구에서 자료를 수집할 때 지켜야 할 점은? — 공신력 있는 기관의 자료를 수집하고 출처를 명시한다.
