# 화학 에너지 퀴즈

## Question 1
발열 용기에 사용되는 발열 팩의 주성분인 산화 칼슘($\text{CaO}$)이 물과 반응할 때 일어나는 현상에 대한 설명으로 옳은 것은?

- [ ] 주변에서 열에너지를 흡수하여 비커 안의 온도가 내려간다.
- [x] 화학 반응이 일어나면서 열을 방출하여 주변 온도가 높아진다.
- [ ] 상태 변화가 일어나면서 에너지의 출입이 전혀 발생하지 않는다.
- [ ] 기체가 다량 발생하면서 주변의 에너지를 빼앗아 차가워진다.

**Hint:** 발열 팩은 가열 장치 없이 음식을 데우거나 익힐 때 사용되는 도구입니다.

## Question 2
물과 산화 칼슘을 이용해 가열 장치 없이 음식을 조리하는 장치를 설계할 때 주의해야 할 사항으로 옳지 않은 것은?

- [ ] 산화 칼슘 가루가 많이 날릴 수 있으므로 마스크를 착용한다.
- [ ] 반응 시 열이 발생하므로 안전을 위해 보호 장갑을 착용한다.
- [x] 조리 용기로 알루미늄박을 사용하여 열전달 효율을 최대로 높인다.
- [ ] 실험 후 남은 수용액은 지정된 폐수 통에 버린다.

**Hint:** 특정 금속 재질은 산화 칼슘 수용액과 반응하여 부식되거나 손상될 수 있습니다.

## Question 3
다음 중 에너지를 방출하여 주변의 온도를 높이는 현상으로 옳지 않은 것은?

- [ ] 철 가루가 산소와 반응하여 따뜻해지는 손난로
- [ ] 산과 염기가 반응하는 중화 반응
- [x] 냉각 팩 속의 물질이 반응하여 시원해지는 현상
- [ ] 도시가스 등의 연료를 연소시켜 요리에 이용하는 현상

**Hint:** 제품의 사용 목적이 주변 온도를 차갑게 내리는 것인지 생각해보세요.

## Question 4
생물체 내에서 일어나는 세포호흡과 광합성에서의 에너지 출입에 대한 설명으로 옳은 것은?

- [ ] 세포호흡은 에너지를 흡수하는 반응이고, 광합성은 에너지를 방출하는 반응이다.
- [ ] 세포호흡과 광합성 모두 주변으로 에너지를 방출하여 체온을 유지한다.
- [x] 세포호흡은 에너지를 방출하는 반응이고, 광합성은 빛에너지를 흡수하는 반응이다.
- [ ] 광합성 시 방출된 에너지를 이용해 동물이 체온을 유지한다.

**Hint:** 식물이 양분을 만들기 위해 태양으로부터 어떤 에너지를 이용하는지 떠올려 보세요.

## Question 5
냉장고가 내부를 차갑게 유지하고 뒤쪽 방열판에서 열을 내보내는 원리로 옳은 것은?

- [x] 냉장고 내부에서 냉매가 기화하며 열을 흡수하고, 방열판에서 액화하며 열을 방출한다.
- [ ] 냉장고 내부에서 냉매가 액화하며 열을 흡수하고, 방열판에서 기화하며 열을 방출한다.
- [ ] 냉장고 내부에서 냉매가 융해되며 열을 방출하고, 방열판에서 응고되며 열을 흡수한다.
- [ ] 냉장고 내부와 방열판 모두에서 냉매가 승화하여 에너지를 연속 흡수한다.

**Hint:** 액체가 기체로 될 때와 기체가 액체로 될 때의 에너지 출입 관계를 생각해보세요.

## Question 6
지구 시스템에서 일어나는 물의 순환 과정과 에너지 출입에 대한 설명으로 옳은 것은?

- [ ] 물이 태양 에너지를 방출하여 수증기로 변한다.
- [ ] 기체 상태의 수증기가 에너지를 흡수하면 액화하여 구름이 된다.
- [x] 물은 에너지를 흡수하여 기화하고, 수증기는 에너지를 방출하며 액화한다.
- [ ] 물의 순환은 에너지 출입이 일어나지 않아도 지속될 수 있다.

**Hint:** 물이 수증기가 되는 과정과 수증기가 비나 구름이 되는 과정의 에너지 변화를 비교해 보세요.

## Question 7
겨울철 도로에 눈이 쌓였을 때 염화 칼슘($\text{CaCl}_2$)을 뿌려 눈을 녹이는 원리와 관련된 설명으로 옳은 것은?

- [ ] 염화 칼슘이 물에 용해될 때 에너지를 흡수하여 주변 온도가 낮아진다.
- [x] 염화 칼슘이 물에 용해될 때 열을 방출하여 주변 온도가 높아진다.
- [ ] 염화 칼슘이 승화하면서 주변의 열을 빼앗아 눈이 쉽게 녹는다.
- [ ] 염화 칼슘과 눈이 화학 반응하여 빛에너지를 대량 방출한다.

**Hint:** 염화 칼슘이 물과 만나 녹을 때 발생 또는 흡수되는 열에너지를 생각해 보세요.

## Question 8

- [ ] 불꽃에 닿은 액체가 연소하면서 주변에 산소를 공급한다.
- [x] 액체가 분해되면서 주변의 열을 흡수하여 온도를 낮춘다.
- [ ] 액체가 응고되면서 주변으로 많은 열에너지를 방출한다.

## Question 9
산화 칼슘과 물의 반응 실험에서 물 $100\text{ mL}$에 넣는 산화 칼슘의 질량을 $10\text{ g}$, $20\text{ g}$, $30\text{ g}$으로 늘릴 때 예상되는 측정 결과는?

- [x] 산화 칼슘의 질량이 증가할수록 최고 온도가 더 높아진다.
- [ ] 산화 칼슘의 질량이 증가할수록 최고 온도가 더 낮아진다.
- [ ] 물 100 mL의 양이 일정하므로 최고 온도는 모두 동일하다.
- [ ] 산화 칼슘 질량과 상관없이 처음 물의 온도보다 낮아진다.

**Hint:** 발열 반응에서 반응하는 물질의 양이 많아질 때 방출되는 열량의 변화를 고려하세요.
