# Ⅰ-2-02 생활 주변의 산화·환원 반응
교과서 44-47쪽 · 통합과학

## 학습 목표
- 생활 주변의 다양한 변화를 산화·환원 반응으로 이해할 수 있다. (p.44)
- 생활 주변의 산화·환원 반응을 찾을 수 있다. (p.44)
- 핵심 질문: 우리 주변의 산화·환원 반응에는 무엇이 있을까? / 우리 주변에서 일어나는 산화·환원 반응을 찾아볼까? (p.44, p.46)

## 핵심 개념

### 1. 산화·환원 반응과 우리 생활 (도입)
- 산화·환원 반응은 우리 주변에서 매우 다양하게 일어나며, 지구에 최초의 생명체가 나타났을 때부터 인류가 문명을 일으킨 현재까지 우리 생활에 관여해 왔다. (p.44)
- 도입 그림: 불꽃(폭죽)이 생길 때도, 휴대 전화 안에서도 산화·환원 반응이 일어난다. (p.44)
- 산화·환원 반응은 **생명을 유지하는 데에 필수적인 반응**이다. (p.45)
  - 식물은 광합성을 통해 스스로 영양소를 합성할 수 있게 되었다.
  - 인간을 포함한 대부분의 생물은 산소로 호흡하면서 영양소를 분해하고 에너지를 얻는다.

### 2. 광합성 — 빛에너지 → 화학 에너지
- **광합성**: 빛에너지가 화학 에너지로 전환되는 화학 반응. (p.44)
- 장소: 식물의 **엽록체**. 이산화 탄소와 물이 반응하여 포도당과 산소가 생성된다. (p.44)
- 반응식: `6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂` (이산화 탄소 + 물 → 포도당 + 산소) (p.44)
  - **이산화 탄소(CO₂)에서 환원**이 일어난다 → 포도당이 됨.
  - **물(H₂O)에서 산화**가 일어난다 → 산소가 됨.

### 3. 세포호흡 — 화학 에너지 이용
- **세포호흡**: 화학 에너지를 이용하여 생명 활동에 필요한 에너지를 얻는 화학 반응. (p.44)
- 장소: 세포의 **마이토콘드리아**. 포도당과 산소가 분해되어 이산화 탄소와 물이 생성된다. (p.44)
- 반응식: `C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O` (포도당 + 산소 → 이산화 탄소 + 물) (p.44)
  - **포도당(C₆H₁₂O₆)에서 산화**가 일어난다 → 이산화 탄소가 됨.
  - **산소(O₂)에서 환원**이 일어난다 → 물이 됨.
- 광합성과 세포호흡은 반응물과 생성물이 서로 뒤바뀐 관계이다. (p.44 두 반응식 비교)

### 4. 화석 연료의 연소 — 메테인의 연소
- 석유나 석탄 같은 **화석 연료**를 연소시키면 우리가 사용하는 에너지를 얻는다. 화석 연료는 공기 중에서 산소와 반응하여 **산화되면서 많은 양의 열에너지를 방출**한다. (p.45)
- 화석 연료인 액화천연가스의 주성분은 **메테인(CH₄)**이다. (p.45)
- 메테인을 완전 연소시키면 이산화 탄소(CO₂)와 물(H₂O)이 생성되면서 열에너지가 발생한다. (p.45)
- 반응식: `CH₄ + 2O₂ → CO₂ + 2H₂O` (p.45)
  - **메테인에서 산화**가 일어난다(산소와 결합하여 CO₂가 됨).
  - **산소에서 환원**이 일어난다.
- 그림: 가스레인지의 파란 불꽃. (p.45)

### 5. 철의 제련
- 철은 건축물이나 기계 장치에 많이 사용된다. 철은 자연에서 **산화 철의 형태**로 존재하므로 그대로 사용하기 어렵고, 산화·환원 반응을 포함한 **제련 과정**을 거쳐야 순수한 철을 얻을 수 있다. (p.45)
- 철광석과 코크스를 이용한 제련 과정의 발전으로 인류는 철을 이용해 문명을 발전시켰다. (p.45)
- 제련 과정(용광로): (p.45)
  1. 고온의 **용광로**에 철광석, **코크스(C)**, 석회석을 넣는다.
  2. 코크스가 산소와 결합하여 **일산화 탄소(CO)**가 된 후, 산화 철(Ⅲ)과 일산화 탄소가 반응하여 순수한 철이 얻어진다.
- 반응식: `Fe₂O₃ + 3CO → 2Fe + 3CO₂` (산화 철(Ⅲ) + 일산화 탄소 → 철 + 이산화 탄소) (p.45)
  - **산화 철(Ⅲ)(Fe₂O₃)에서 환원**: 산소가 분리되어 철로 환원된다.
  - **일산화 탄소(CO)에서 산화**: 산소와 결합하여 이산화 탄소로 산화된다.

### 6. 생활 주변에서 찾는 산화·환원 반응 (탐구 활동)
- 표백제로 빨래를 하거나 스마트폰 배터리를 충전할 때도 산화·환원 반응이 일어난다. (p.46)
- 자료를 찾을 때는 생성형 인공지능과 스마트 기기 검색 등 **두 가지 이상의 방법**을 이용하여 옳은 자료인지 검증한다. (p.46)
- **집에서**: (p.46)
  - **섬유 표백**: 누렇게 변한 옷을 세탁할 때 표백제를 넣으면 산화·환원 반응이 일어나 옷이 하얗게 된다.
  - **양초**: 불을 붙이면 주성분인 **파라핀**이 연소되어 이산화 탄소와 수증기로 변한다.
- **길에서**: (p.46)
  - **손난로**: 손난로에 들어 있는 철이 산소와 반응하여 **산화 철(Ⅲ)로 산화될 때 열이 발생**하여 따뜻해진다.
  - **자동차 배기관의 촉매 장치**: 촉매 장치에서 **산화 질소가 환원**되어 배기가스가 정화된다.
- **학교에서**: (p.47)
  - **리튬 배터리**: 리튬이 **전자를 잃고 산화**된 뒤 양극에서 음극으로 이동하면서 배터리가 충전된다.
  - **과일의 갈변**: 사과, 배, 바나나, 복숭아에 들어 있는 **폴리페놀** 성분이 산화되어 갈변 현상이 일어난다.
  - **반딧불이**: 반딧불이의 광세포에서는 **루시페린**이 산화되면서 빛에너지를 방출한다.
- 활동 과정: (p.47)
  1. 하루 동안 나의 주변에서 실제로 일어난 산화·환원 반응을 사진과 영상으로 촬영한다.
  2. 촬영한 사진과 영상에 설명을 붙여 공유 플랫폼에 올리고 친구들이 올린 사진과 영상을 감상한다.
- 평가 기준: 실생활에서 일어나는 산화·환원 반응인가, 사진과 영상이 산화·환원에 해당하는 까닭을 제시하였는가, 흥미롭게 구성되었는가를 기준으로 평가한다. (자기평가: 내가 잘한 점, 친구에게 배울 점) (p.47)

### 7. 스스로 확인 · 과학과 나
- 스스로 확인 1: 메테인이 연소될 때 산화되는 물질과 그 까닭 → 메테인(CH₄). 산소와 결합하여 이산화 탄소가 되기 때문. (p.45, p.47)
- 스스로 확인 2: 철이 제련되는 과정에서 환원되는 물질과 그 까닭 → 산화 철(Ⅲ)(Fe₂O₃). 산소가 분리되어 철이 되기 때문. (p.45, p.47)
- 과학과 나: 만약 지구에 5초 동안 산소가 사라진다면 우리 생활에 어떤 일이 일어날지 이야기해 보자. (p.47)

## 시험 함정 포인트
- 광합성에서 산화되는 것은 이산화 탄소가 **아니라 물**이다. 이산화 탄소는 **환원**되어 포도당이 된다. (p.44)
- 세포호흡에서 환원되는 것은 포도당이 **아니라 산소**이다. 포도당은 **산화**된다. (p.44)
- 광합성은 엽록체, 세포호흡은 **마이토콘드리아**에서 일어난다. 장소를 바꿔 내는 선지에 주의. (p.44)
- 광합성은 빛에너지를 화학 에너지로 전환하는 반응이고, 세포호흡은 화학 에너지를 **이용해** 에너지를 얻는 반응이다. 에너지 전환 방향을 바꾸면 틀린다. (p.44)
- 철의 제련에서 산화되는 물질은 산화 철(Ⅲ)이 **아니라 일산화 탄소(CO)**이다. 산화 철(Ⅲ)은 산소를 잃고 **환원**된다. (p.45)
- 메테인의 연소에서 산소는 **환원**된다(산화되는 것은 메테인). (p.45)
- 손난로는 철이 **산화**될 때 열이 발생하는 것이다(환원 아님). (p.46)
- 자동차 촉매 장치에서는 산화 질소가 **환원**되어 배기가스가 정화된다(산화 아님). (p.46)
- 리튬 배터리 충전 시 리튬은 전자를 **잃고 산화**된 뒤 **양극에서 음극으로** 이동한다. 이동 방향을 반대로 내는 선지 주의. (p.47)
- 과일 갈변은 폴리페놀, 반딧불이 발광은 루시페린이 **산화**되는 것이다. 물질 이름을 서로 바꾸는 선지 주의. (p.47)
- 철이 자연에서 그대로 쓰이지 못하는 까닭은 **산화 철의 형태**로 존재하기 때문이다. (p.45)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 광합성 | 빛에너지가 화학 에너지로 전환되는 화학 반응. 엽록체에서 CO₂와 H₂O가 반응해 포도당과 O₂ 생성 (p.44) |
| 세포호흡 | 화학 에너지를 이용해 생명 활동에 필요한 에너지를 얻는 반응. 마이토콘드리아에서 포도당과 O₂가 분해되어 CO₂와 H₂O 생성 (p.44) |
| 엽록체 | 광합성이 일어나는 식물 세포의 장소 (p.44) |
| 마이토콘드리아 | 세포호흡이 일어나는 세포의 장소 (p.44) |
| 화석 연료 | 석유·석탄·액화천연가스 등. 산소와 반응해 산화되며 많은 열에너지 방출 (p.45) |
| 메테인(CH₄) | 액화천연가스의 주성분. 완전 연소하면 CO₂와 H₂O 생성 (p.45) |
| 제련 | 산화 철 등에서 산화·환원 반응을 포함한 과정을 거쳐 순수한 금속(철)을 얻는 과정 (p.45) |
| 용광로 | 철광석·코크스·석회석을 넣어 고온에서 철을 제련하는 장치 (p.45) |
| 코크스(C) | 제련에 쓰이는 탄소. 산소와 결합해 일산화 탄소(CO)가 됨 (p.45) |
| 산화 철(Ⅲ)(Fe₂O₃) | 철광석 속 철의 형태. 제련에서 환원되어 철이 됨 (p.45) |
| 일산화 탄소(CO) | 제련에서 산화 철(Ⅲ)을 환원시키고 자신은 CO₂로 산화됨 (p.45) |
| 파라핀 | 양초의 주성분. 연소되어 이산화 탄소와 수증기가 됨 (p.46) |
| 촉매 장치 | 자동차 배기관에서 산화 질소를 환원시켜 배기가스를 정화하는 장치 (p.46) |
| 폴리페놀 | 사과·배·바나나·복숭아의 성분. 산화되어 갈변 일으킴 (p.47) |
| 루시페린 | 반딧불이 광세포의 물질. 산화되며 빛에너지 방출 (p.47) |
| 갈변 | 과일 속 폴리페놀이 산화되어 색이 갈색으로 변하는 현상 (p.47) |

## 자기점검 질문
1. 광합성에서 산화되는 물질과 환원되는 물질은? — 산화: 물(H₂O), 환원: 이산화 탄소(CO₂)
2. 세포호흡이 일어나는 장소와 반응식은? — 마이토콘드리아, C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O
3. 메테인이 연소될 때 산화되는 물질과 까닭은? — 메테인. 산소와 결합하여 이산화 탄소가 되므로
4. 철의 제련에서 환원되는 물질과 까닭은? — 산화 철(Ⅲ). 산소가 분리되어 철이 되므로
5. 용광로에 넣는 세 가지 물질은? — 철광석, 코크스(C), 석회석
6. 철이 자연 상태 그대로 쓰이기 어려운 까닭은? — 산화 철의 형태로 존재하기 때문
7. 손난로가 따뜻해지는 까닭은? — 철이 산소와 반응해 산화 철(Ⅲ)로 산화될 때 열이 발생하므로
8. 자동차 배기관 촉매 장치에서 일어나는 일은? — 산화 질소가 환원되어 배기가스가 정화됨
9. 리튬 배터리 충전 시 리튬의 변화는? — 전자를 잃고 산화된 뒤 양극에서 음극으로 이동
10. 과일의 갈변과 반딧불이의 빛에서 산화되는 물질은? — 각각 폴리페놀, 루시페린
11. 생활 속 산화·환원 자료를 찾을 때 지켜야 할 점은? — 생성형 인공지능, 스마트 기기 검색 등 두 가지 이상 방법으로 옳은 자료인지 검증
