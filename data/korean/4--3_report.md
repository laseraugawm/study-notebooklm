# 4-(3) 매체와 함께하는 생활
교과서 154~167쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 매체의 변천과 그에 따른 소통 문화의 변화를 이해할 수 있다. (p.154)
- 오늘날의 매체 소통 문화의 특성을 탐구하여 우리 국어생활을 성찰할 수 있다. (p.154)

## 핵심 개념

### 1. 매체의 변천 개관 (p.154)
- 우리는 매체를 사용하여 타인과 소통한다. 매체는 **구술 매체 → 문자 매체 → 영상 매체 → 디지털 매체**로 발전.
- 매체의 발전에 따라 **소통 방식과 문화도 변화**. 다양한 디지털 매체를 쓰는 오늘날의 소통은 과거와 많이 다름 → 탐구를 통해 우리 소통 문화를 이해·성찰.
- 생각 열기: (전단지 등) '강아지를 찾습니다!'와 온라인 게시물(댓글·쪽지·공유로 보호자와 연락이 닿음) → 매체와 소통 방식 비교.

### 2. 제재 「매체와 소통 문화의 변화」(윤여탁 외) (p.155~157)
- 글쓴이 윤여탁(1956~ ): 국어교육학자, 매체 및 **문식성** 교육 연구. 『문식성이란 무엇인가』, 『현대 시의 내포와 외연』. (p.157)
- 역사적 관점에서 매체의 변화가 소통 방식과 문화에 끼친 영향을 설명하는 글.

#### (1) 구술 매체 — 말하기 (p.155)
- 문자 이전의 주된 매체. 화자와 청자가 **직접 대면**하여 **상황과 맥락을 공유**.
- 한계: 다른 시간대·다른 공간의 사람과 소통이 어려움 → 지식·정보의 **기록, 보존, 유통**이 제대로 이루어지지 않음. **구전**되기도 하나 온전히 전하는 데 한계.

#### (2) 문자 매체 — 편지, 문서, 책 (p.155)
- **쓰기와 읽기** 중심 소통 문화 → 구술 매체의 **시공간적 한계 극복**.
- 지식을 기록·보존 → 글쓴이와 독자 간 시공간적 제약을 초월.
- 시공간을 공유하지 않으므로 글쓴이와 독자가 분리된 **탈상황적, 탈맥락적 소통**.
- **인쇄술의 발달**로 책이 대량 유통 → 쓰기·읽기 중심 소통이 더욱 발달, 지식·정보의 기록·축적·유통이 수월 → **지식의 대중화**.

#### (3) 영상 매체 — 영화, 텔레비전 (p.155~156)
- 글 중심 문자 매체는 **읽고 이해하는 능력에 따라** 이해 정도에 차이 ↔ **시청각 이미지** 중심 영상 매체는 **보편적으로 쉽게 이해**.
- 다수의 수용자가 **동시에** 정보를 수용하는 **대중 매체**의 특징 → 다수가 특정 정보를 공유하고 소통하는 문화, 대중에 대한 **영향력**이 매우 커짐.

#### (4) 디지털 매체 (p.156)
- 구술·문자·영상 매체의 특성을 **복합적으로** 지님.
- **복합양식성**: 음성, 문자, 그림, 동영상 등이 **혼합**되어 나타남 → 복합양식의 글·자료를 수용·생산하는 새로운 소통 방식 필요.
- **하이퍼텍스트**: 이용자가 다른 문서나 정보로 **바로 이동**할 수 있도록 제공되는 텍스트 → 자료를 손쉽게 넘나들며 원하는 정보 획득.
- **상호 작용성**: 이용자가 지식과 정보의 **소비자이면서 생산자** 역할을 겸함 → 생산자 → 수용자의 **일방적** 전달인 기존 대중 매체와 다름. 이용자가 정보를 능동적으로 선택·해석하며 문화를 생산·창조하는 **주체**.

#### (5) 오늘날의 디지털 소통 (p.157)
- 무선 인터넷·스마트폰 보편화 → 소통 방식이 더욱 다양.
- 인터넷: 정보 검색·공유, 다른 사람과 **수평적 관계에서 쌍방향** 소통.
- **SNS**: 자유로운 의사소통과 정보 공유, **인맥 확대**로 새로운 사회적 관계.
- **1인 미디어 방송**: 기존 영상 매체보다 폭넓은 콘텐츠를 직접 생산·소비.
- **댓글과 실시간 대화**로 시공간 제약 없이 쌍방향 소통 (1인 미디어와 SNS의 공통 소통 방식).
- 결론: 새로운 매체는 **새로운 문화**와 **새로운 언어**를 창조. 소통 기술의 변화 → 소통 문화의 발전 → 다시 기술의 진화를 요구. 매체 소통 문화를 이해·성찰하는 것은 변화를 **올바른 방향**으로 이끄는 데 중요.
- 생각 키우기: 어제 가장 많이 쓴 소통 매체, SNS 소통의 장단점. (p.157)

### 3. 학습 활동 1 — 매체별 특성 정리 (p.158)
| 매체 | 특성 |
|---|---|
| 구술 매체 | 음성 언어 중심, 대면하여 상황·맥락 공유, 시공간 제약 |
| 문자 매체 | 쓰기·읽기 중심, 기록·보존으로 시공간 한계 극복, 탈상황·탈맥락 |
| 영상 매체 | 문자 언어에 비해 쉽게 이해, 다수가 동시에 수용하는 대중 매체 |
| 디지털 매체 | 앞선 매체의 특성들이 복합, 복합양식성·하이퍼텍스트·상호 작용성 |

### 4. 학습 활동 2 — 매체 변천에 따른 소통 방식 탐구 (p.158~160)
- **(1) 가 vs 나**: 가 = 의원과 환자가 **대면**하여 말로 진료(어지럼 → 빈혈, 당귀 처방) → 구술 매체 / 나 = "후대의 사람들이 이 책을 통해 의학 지식을 잘 배워서…" → 책(문자 매체)으로 **기록·보존**, 시공간을 넘어 전달.
- **(2) 다 vs 라** (도움말: 영상 매체와 디지털 매체의 특성 비교)
  - 다: 『문화방송(MBC) 뉴스』(2023. 6. 4.) 「원동기 이상 운전면허 필요 … 사각지대 '여전'」(전동 킥보드) — **텔레비전 뉴스**
  - 라: 『한라일보』(2023. 3. 29.) 인터넷 기사 「청소년의 무분별한 개인형 이동 장치의 불법 운행 심각」 — 2021년 개정 도로 교통법: 만 16세 이상 원동기 면허 이상 취득자만 운행, 안전모 착용 의무화 / 최근 5년간 청소년 개인형 이동 장치 사고 **816건**, 전체의 **25%**. 입력·수정 시각, 공감 버튼, 공유하기, **관련 기사 링크**, **댓글**.
  | 구분 | 다(영상 매체) | 라(디지털 매체) |
  |---|---|---|
  | 공통점 | 뉴스의 핵심 내용을 제목으로 제시해 정보 전달 효과를 높임 | 같음 |
  | 차이점 | 영상·음성으로 다수에게 동시에, 일방적 전달 | 하이퍼텍스트로 관련 기사 읽기, 댓글·공유로 쌍방향 소통, 기사 수정 가능 |
- **(3) 기형도 문학관 SNS 게시물**: 엽서 쓰기 체험(느린 우편함, 시 구절을 첨부해 '느린 어느 날' 우편 배송) — **해시태그**(#기형도_문학관 등), 사진(복합양식성), **댓글·답글**(상호 작용성), **블로그 바로가기**(하이퍼텍스트), 쪽지 문의.
- **해시태그(Hashtag)**: 특정 핵심어 앞에 '#'을 붙여 게시물의 주제를 표시하는 방법, SNS 전반에서 사용. 같은 해시태그 게시물을 **한 번에 모아 볼 수 있음**. (p.160)

### 5. 학습 활동 3 — 디지털 매체의 소통 문화와 언어 (p.161~162)
- 가 **실시간 1인 미디어 방송** '반짝 식탁' — "실시간 함께 만들어요, 식혜 떡볶이!": 진행자가 실시간 댓글('떡사랑', '햇살' 님)을 읽고 질문(안 맵게 만드는 법)에 답함, 요리법을 댓글로 남김.
- 나 **온라인 단체 대화방**: 동아리 발표회에 전통 음식 요리법 소개 제안 → 영상 바로 가기 링크 공유 → 동의("좋아", "쵝오!!").
- **(1) 소통 방식**: 가의 진행자는 실시간으로 (시청자의 댓글에 반응하며 소통한다). 나에서는 제안에 다른 참여자가 동의 → 가와 나는 (**쌍방향**)으로 소통이 이루어지는 매체.
- **(2) 디지털 매체 언어의 특성**(p.162)
  | 경향 | 예 |
  |---|---|
  | 글자 입력에 드는 **시간과 노력을 줄이려는** 경향 | ㅎㅎㅎ, 넘넘 |
  | 의미를 더 **생생하게 표현·강조**하려는 경향 | 안녕하세요오오, 꼬옥, 또 만나용 |
  | 언어의 형식·의미를 바꾸어 **재미나 독특함**을 표현하려는 경향 | ㅎㅔㅎㅔ, 쵝오!! |
- 도움말: 실시간 1인 미디어 방송과 온라인 단체 대화방의 소통 문화에 주목하여 다양한 소통 양상과 언어 특징 탐구.

### 6. 학습 활동 4 — 매체 소통 문화 성찰 (p.163)
- 한국방송광고진흥공사 공익 광고 「**사회 관계망 서비스[SNS]는 또 하나의 미디어**」 → 광고가 말하는 디지털 매체 사용의 태도 생각하기(SNS도 영향력 있는 미디어이므로 책임 있게 사용).
- 자신의 디지털 매체 사용을 성찰하는 글을 SNS에 게시(개선이 필요한 소통 양상에 대해).

### 7. 대단원 마무리 (p.164~167)
- 내용 점검 요소: 중세 '어엿비' = **불쌍히** / '말ᄊᆞ미', '노미'는 표기상 **이어 적기** / 형태소 본래 모양을 밝혀 표기 = **표의주의** / 맞는 표기: **생각건대**, **꼼꼼히** / 읽기·쓰기 중심 = **문자 매체** / 복합양식성·하이퍼텍스트·상호 작용성 = **디지털 매체** / 주격 조사 '이/가'가 쓰이는 것은 **현대 국어**.
- 단원 통합 활동 「광고의 변화 탐구하기」(p.166~167)
  - 가(**1985년**) 인쇄 광고 "가는 말이 거칠어야 오는 말이 곱다?" — 속담 "말 한마디로 천 냥 빚을 갚는다", "가는 말이 고와야 오는 말이 곱다"를 인용, 거칠어진 언어 비판. 표기 "있**읍**니다"(현행 맞춤법은 '있습니다').
  - 나(**2017년**) 영상 공익 광고 — 온라인 댓글을 어떻게 쓸지 묻는 내용.
  - 비교 항목: 시기, 주제, 광고 매체, 국어 표현의 차이.
  - 조건에 맞는 광고 찾기: 국어 표현에 차이가 있는 과거와 현재의 광고 / 주제가 유사하지만 매체가 다른 두 광고 / 우리의 삶을 성찰할 수 있는 광고 → 과거 광고에만 있는 국어 표현(현행 맞춤법과 다르거나 요즘 잘 쓰지 않는 어휘) 찾기.
  - 평가: 구성 요소 비교, 시청각 자료와 매체의 관계, 매체 특성 비교, 국어 표현의 변화 이해.

## 시험 함정 포인트
- 매체 발전 순서는 구술 → **문자** → **영상** → 디지털이다. (p.154)
- '탈상황적·탈맥락적' 소통은 구술이 아니라 **문자 매체**의 특성이다. 구술은 상황·맥락을 **공유**한다. (p.155)
- **지식의 대중화**를 이룬 계기는 영상 매체가 아니라 **인쇄술의 발달**(문자 매체)이다. (p.155)
- 영상 매체는 읽기 능력에 따른 이해 차이가 적고 **보편적으로 쉽게** 이해된다 — 이해 차이가 생기는 것은 **문자 매체**. (p.155~156)
- 기존 대중 매체(영상)는 **일방적** 전달, 디지털 매체는 **상호 작용성**으로 쌍방향이다. (p.156)
- 하이퍼텍스트는 '여러 양식이 섞인 것'이 아니라 **다른 정보로 바로 이동**하게 하는 텍스트다. 섞인 것은 **복합양식성**. (p.156)
- 상호 작용성은 이용자가 **소비자이면서 생산자**가 됨을 뜻한다. (p.156)
- 해시태그는 '#'을 붙여 주제를 표시하고 **같은 해시태그 글을 모아 볼 수 있게** 한다. (p.160)
- 1985년 광고의 '있읍니다'는 **현행 맞춤법과 다른** 과거 표기다. (p.166)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 매체 | 소통을 위해 사용하는 수단 |
| 구술 | 입으로 말함 |
| 대면 | 서로 얼굴을 마주 보고 대함 |
| 구술 매체 | 말하기 중심 매체 |
| 문자 매체 | 편지·문서·책 등 쓰기·읽기 중심 매체 |
| 탈상황적·탈맥락적 소통 | 글쓴이와 독자가 상황·맥락을 공유하지 않는 소통 |
| 지식의 대중화 | 인쇄술로 책이 대량 유통되며 지식이 널리 퍼짐 |
| 영상 매체 | 영화·텔레비전 등 시청각 이미지 중심 매체 |
| 대중 매체 | 다수의 수용자가 동시에 정보를 수용하는 매체 |
| 디지털 매체 | 구술·문자·영상 매체의 특성을 복합적으로 지닌 매체 |
| 복합양식성 | 음성·문자·그림·동영상 등이 혼합되어 나타나는 성질 |
| 하이퍼텍스트 | 다른 문서나 정보로 바로 이동하도록 제공되는 텍스트 |
| 상호 작용성 | 이용자가 정보의 소비자이면서 생산자인 성질 |
| 1인 미디어 방송 | 개인이 직접 콘텐츠를 생산해 방송하는 매체 |
| 해시태그 | 핵심어 앞에 '#'을 붙여 게시물 주제를 표시하는 방법 |
| 문식성 | 글쓴이 윤여탁이 매체와 함께 연구하는 교육 분야 |

## 자기점검 질문
1. 매체의 발전 순서는? — 구술 → 문자 → 영상 → 디지털
2. 구술 매체의 한계는? — 다른 시공간의 사람과 소통이 어려워 지식·정보의 기록·보존·유통이 안 됨
3. 인쇄술의 발달이 가져온 결과는? — 쓰기·읽기 중심 소통 발달, 지식·정보 축적·유통 수월, 지식의 대중화
4. 영상 매체가 문자 매체보다 이해가 쉬운 이유는? — 시청각 이미지 중심이라 읽기 능력의 차이와 무관하게 보편적으로 이해
5. 디지털 매체의 세 특성은? — 복합양식성, 하이퍼텍스트, 상호 작용성
6. 상호 작용성으로 소통 방식이 어떻게 달라졌나? — 일방적 전달에서 이용자가 생산자 겸 소비자로 쌍방향 소통
7. 1인 미디어 방송과 SNS의 공통 소통 방식은? — 댓글·실시간 대화로 시공간 제약 없이 쌍방향 소통
8. 다(TV 뉴스)와 라(인터넷 기사)의 차이점은? — 라는 하이퍼텍스트로 관련 기사를 읽고 댓글로 소통 가능
9. '꼬옥', '안녕하세요오오'에 드러난 디지털 매체 언어의 경향은? — 의미를 생생하게 표현·강조하려는 경향
10. 해시태그의 기능은? — 게시물 주제 표시, 같은 해시태그 글을 한 번에 모아 보기
