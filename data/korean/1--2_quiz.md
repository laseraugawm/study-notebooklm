## Question 1
교과서에서 다루는 '주제 통합적 읽기'에 대한 설명으로 가장 적절하지 않은 것은?

- [ ] 동일한 화제나 주제를 다룬 다양한 관점과 형식의 글이나 자료를 읽는 독서 방법이다.
- [ ] 여러 글을 읽은 후 읽기 목적에 따라 내용을 재구성하여 자신의 견해를 세우는 것이 중요하다.
- [x] 주제와 관련된 단 하나의 정립된 관점만을 선택하여 객관적 진실을 도출하는 데 주안점을 둔다.
- [ ] 주제를 균형 있게 이해하고 창의적인 사고를 생성하는 데 기여한다.

**Hint:** 주제 통합적 읽기는 단 하나의 관점만을 취하는 것이 아니라, 다양한 자료를 비교하며 균형 있게 이해하는 방법임을 떠올려 보세요.

## Question 2
글 (가)에서 최재천 학자가 제시한 '지능'과 '지성'에 대한 설명으로 가장 적절한 것은?

- [ ] 지능은 자신의 행동을 투영하고 반성하는 능력이며, 지성은 단순 분석 능력이다.
- [ ] 생성형 인공지능은 인터넷 데이터를 활용하여 인간의 지성을 완전히 구현한 존재이다.
- [x] 지성은 어떤 상황에 자신을 투영해 보고 반성해 보는 능력까지 포함한다.
- [ ] 스티븐 핑커 교수는 인공지능이 인간의 지성을 뛰어넘어 위협이 될 것이라고 경고했다.

**Hint:** 글 (가)에서 '지성'이란 단순 분석 능력을 넘어 자신을 되돌아보는 반응과 관련이 있음을 생각해 보세요.

## Question 3
글 (나)에 제시된 생물학적 신경계의 구조와 인공 신경망의 구성 요소를 매칭한 것으로 가장 적절하지 않은 것은?

- [ ] 신경 세포의 가지 돌기 - 인공 신경망의 입력층
- [ ] 신경 세포 사이의 시냅스 - 인공 신경망의 화살표(전달 통로)
- [ ] 시냅스의 결합 강도 - 인공 신경망의 가중치
- [x] 시냅스에서 분비되는 화학 물질(아세틸콜린) - 인공 신경망의 임곗값

**Hint:** 임곗값은 신호 전달 여부를 결정하는 기준 한계값이며, 화학 물질은 전달 통로에서 분비되는 신호 매개체입니다.

## Question 4
글 (나)에서 설명하는 신경계와 인공 신경망의 '학습' 원리에 대한 이해로 옳지 않은 것은?

- [ ] 자주 사용하는 시냅스 연결이 강화되고 사용하지 않는 연결이 약화되는 현상을 '신경 가소성'이라고 한다.
- [ ] 인공 신경망은 반복적인 과정을 통해 원하는 값이 출력되도록 가중치를 조절하며 학습한다.
- [x] 신경 세포의 몸통에 모인 입력값의 합이 임곗값을 넘지 않더라도 항상 출력 신호가 내보내진다.
- [ ] 자전거 타기를 반복하여 관련 신경계의 연결 강도가 강화되는 것은 학습의 대표적 예시이다.

**Hint:** 신경 세포가 신호를 축삭 돌기(줄기)로 내보내기 위해 필요한 입력값 조건(임곗값)을 확인하세요.

## Question 5
글 (다)에서 인공지능 로봇의 도덕적 지위에 관한 입장(ㄱ~ㄹ)을 분석한 내용으로 적절하지 않은 것은?

- [ ] ㄱ과 ㄴ은 지능, 의식, 고통 감수성과 같은 사실적 속성의 유무에 따라 도덕적 지위를 결정해야 한다고 본다.
- [ ] ㄷ은 로봇이 고통을 느낄 수 있더라도 인간의 필요로 만들어진 도구이므로 도덕적 지위를 부여해서는 안 된다고 본다.
- [ ] ㄹ은 로봇이 의식이나 고통 감수성을 갖지 않아도 도덕적 지위를 부여할 수 있다고 본다.
- [x] 글쓴이는 ㄷ의 입장이 우리가 동물이나 다른 사람을 대우해 온 기존의 가치관과 가장 잘 부합한다고 평가한다.

**Hint:** 글쓴이는 ㄷ(고통을 느껴도 도구이므로 학대 가능)의 입장이 기존 가치관과 어떻게 관계를 맺는다고 평가했는지 떠올려 보세요.

## Question 6
글 (다)에 등장하는 철학자 마크 쿠헬버그의 '관계론적 접근'에 관한 설명으로 가장 적절한 것은?

- [ ] 도덕적 지위는 대상이 가진 객관적 생물학적/기술적 속성에 의해 물리적으로 결정된다.
- [x] 로봇이 실제로 감정을 지녔는지 여부보다 우리가 일상 경험 속에서 로봇과 어떻게 상호 작용하고 관계 맺는지가 중요하다.
- [ ] 소셜 로봇은 인간에게 해를 끼칠 수 있으므로 엄격하게 통제해야 한다는 기술 결정론적 입장이다.
- [ ] 인공지능 로봇은 인간이 만든 도구에 불과하므로 어떠한 정서적 태도도 가져서는 안 된다고 강조한다.

**Hint:** 관계론적 접근은 대상이 '진짜 감정이 있는지'보다 '우리가 대상과 어떻게 반응하고 상호 작용하는지'를 중시합니다.

## Question 7
논증하는 글을 쓸 때 활용되는 '논증 요소'에 대한 설명으로 옳은 것은?

- [ ] '이유'는 주장을 지지하기 위해 수집한 통계, 연구 결과 등의 객관적인 자료를 의미한다.
- [ ] '근거'는 주장을 가능하게 하는 글쓴이의 주관적인 생각이나 판단을 가리킨다.
- [x] '예상 반론'은 자신의 주장에 대해 반대하는 입장에서 제기할 수 있는 의견이나 견해를 의미한다.
- [ ] '반박'은 상대방의 예상 반론을 온전히 수용하여 자신의 주장을 철회하거나 취소하는 과정이다.

**Hint:** 주장, 이유, 근거, 예상 반론, 반론에 대한 반박의 개념 정의를 구분해 보세요.
