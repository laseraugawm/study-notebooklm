# 1-(2) 주제 통합적 읽기와 논증하는 글 쓰기
교과서 20~36쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 동일한 화제에 대해 다양한 관점과 형식으로 표현된 글이나 자료를 읽기 목적에 따라 주제 통합적으로 읽을 수 있다. (p.20)
- 논증 요소에 따른 분석을 바탕으로 효과적으로 내용을 조직하여 논증하는 글을 쓸 수 있다. (p.20)

## 핵심 개념

### 1. 주제 통합적 읽기
- **주제 통합적 읽기**: 동일한 화제나 주제를 다룬 여러 글이나 자료를 **읽기 목적에 따라** 읽고, 이를 바탕으로 **자신의 견해를 재구성**하는 읽기 방법. (p.20)
- 효과: 주제를 **균형 있게** 이해, 주제와 관련한 **새로운 관점이나 창의적 사고**를 생성. (p.20)
- **주제 통합적 읽기의 과정**(생각 열기 도식, p.20)
  1. 읽기 목적 구체화하기, 질문하기
  2. 화제와 관련된 다양한 글 찾기
  3. 여러 글을 비교하며 비판적으로 읽기
  4. 화제에 대한 자신의 견해 재구성하기
- 생각 열기 예: "어떻게 하면 행복할까?" → '자기 본래의 모습으로 살아가며 행복을 얻을 수 있다', '행복은 자신이 좋아하는 일을 하는 것' 등 다양한 관점의 자료를 보고 행복에 관해 종합적으로 생각함. (p.20)

### 2. 활동 1 도입 — 신문 기사 표제로 궁금증 만들기 (p.21)
- 「인공지능 서비스 1년 새 10배 - 인공지능, 일상이 되다」(『한국경제』, 2023. 9. 10.)
- 「인공지능의 윤리적 문제 - 우리는 올바른 방향으로 가고 있는가?」(『코리아아이티타임즈』, 2023. 10. 13.)
- 「인공지능의 시대, 문화·예술·교육도 변해야」(『서울경제』, 2023. 8. 23.)
- 궁금한 점 예: "인공지능은 인간과 똑같이 생각할까?", "인공지능은 어떤 원리로 인간을 따라 할 수 있지?" → 이를 해결할 글과 자료 찾기.

### 3. 가 「인공지능을 어떻게 봐야 할까」(최재천) — 동영상(인터뷰) 자료 (p.22)
- 형식: 질문("인공지능이 발달하면 인간의 지능을 지닐 수 있을까요?")에 답하는 **영상 자료**(출처: 에스비에스(SBS) 뉴스).
- 스티븐 핑커(하버드 대학) 인용: "인공지능은 지능이 아니다. 그냥 우리가 시키는 일을 할 뿐… 두려워할 것 없다."
- **지능(知能)**: 분석하고 해결책을 찾는 능력 = **인지 능력**.
- **지성(知性)**: 어떤 상황에 자신을 **투영해 보고 반성해 보는 것**까지 포함.
- 생성형 인공지능은 **집단 지능을 흉내 내는 수준** — 인간이 인터넷 공간에 쌓아 놓은 데이터를 모아 원하는 결과를 되돌려주기 때문.
- 인공지능의 미래: 지성적으로 보이는 인공지능은 가능하겠지만 **인간의 지성을 흉내 내는 수준**, 인간의 **감정**을 지니는 인공지능은 어렵다. 그 단계에 접근하면 "우리가 또 한 발짝 달아나겠죠."

### 4. 나 「인간의 뇌와 인공지능」(김상욱) — 과학 분야, 정보 중심의 글 (p.23~25)
- 글쓴이 김상욱: 물리학자·교수. 일반인도 이해할 수 있게 과학을 설명. 『김상욱의 양자 공부』, 『떨림과 울림』 (p.25)
- **신경 세포의 구조**(줄기 달린 양파에 비유, p.23)
  - **가지 돌기**(양파의 뿌리): 신호가 **입력**되는 곳
  - **몸통**(양파): 신호가 모이는 곳
  - **축삭 돌기**(줄기): 신호가 **출력**되는 곳
  - 신호 = **전류**(흐르거나 흐르지 않거나)
- **시냅스**: 신경 세포 사이의 좁은 간격. 전기 신호가 도달하면 화학 물질 **아세틸콜린** 분비 → 다른 신경 세포에 다시 전기 신호 생성(전기 신호 → 화학 신호 → 전기 신호). (p.23)
- 시냅스의 중요한 특징은 **유연하다**는 것: 자주 쓰는 연결은 강화, 안 쓰는 연결은 약화 → **신경 가소성**(기억과 학습의 근본 원리). (p.23)
- 자전거 타기 예: 처음엔 신호 전달이 느려 넘어짐 → 자주 타면 관련 시냅스 연결 강화 → 일부 근육이 움직이면 다른 근육이 자동으로 움직임 = '학습'. (p.24)
- **신경계의 학습 원리**: 달팽이부터 인간까지 같음. 가지 돌기로 들어온 입력이 몸통에서 합쳐지고 합이 **임곗값을 넘을 때만** 축삭 돌기로 출력. 같은 입력도 **시냅스 결합 강도**에 따라 출력이 달라짐. 기억은 결합 강도에 저장, 결합 강도가 강화되는 것이 '학습'. (p.24)
- **인공지능** = 결합 강도가 변하는 시냅스를 인공적으로 만든 것 → 신경계의 특성을 컴퓨터 프로그램으로 구현한 **인공 신경망**. (p.24)
- **인공 신경망의 구조**: 입력층 → 숨겨진 층 → 출력층. 원 = 신경 세포, 화살표 = 전달 통로이자 **시냅스**. 신호는 1(전류 흐름)·0(안 흐름). (p.24~25)
  - 화살표마다 **가중치**(시냅스 결합 강도에 해당)를 줌 → 원하는 값이 출력되도록 가중치 조절을 수없이 반복 = 가중치를 '학습'.
  - 숨겨진 층의 신경 세포는 입력 신호 × 가중치의 합이 임곗값을 넘을 때만 1을 출력. 입력·출력 모두 0과 1의 나열.
- 바둑 대결로 유명한 인공지능도 본질적으로 인공 신경망과 같음 — 연결 구조를 뇌와 유사하게 만들고 프로그램 기법을 추가해 개량했을 뿐. (p.25)

### 5. 다 「인공지능 로봇의 도덕적 지위」(신상규) — 철학 분야, 논증하는 글 (p.26~29)
- 글쓴이 신상규: 철학자·교수. 심리 철학, 인공지능의 철학 연구. 『호모 사피엔스의 미래』, 『푸른 요정을 찾아서』 (p.29)
- 문제 제기: **인공지능 로봇에게 도덕적 지위를 부여할 수 있는가?** (p.26)
- 우리는 보통 **지능, 의식, 고통 감수성** 같은 속성을 도덕적 지위 판단의 근거로 여김.
- **네 가지 입장** (p.26~28)
  - ㄱ. 지능·의식·고통 감수성을 **지니므로** 도덕적 지위를 **부여해야** 한다.
  - ㄴ. 지니지 **않으므로** 부여하지 **말아야** 한다.
  - ㄷ. 지닌다고 **해도** 부여하지 **말아야** 한다.(로봇은 인간의 필요로 만든 **도구**)
  - ㄹ. 지니지 **않아도** 부여할 **수 있다**.
- ㄱ·ㄴ(사실적 속성 기준)의 철학적 문제 (p.26~27)
  1. 의식·고통 감수성이 왜 핵심 기준인지 **정당화**가 필요 — 인간의 감수성이나 **종족적 편견**의 반영일 수 있음.
  2. 로봇이 그런 속성을 지니는지 **확인할 방법**이 없음 — 옆 사람의 울음이 슬픔인지 기쁨인지 거짓인지도 판단하기 어렵다.
- ㄷ·ㄹ = 사실적 속성과 무관하게 **가치 판단의 문제**로 접근하는 입장. (p.27)
- ㄷ의 문제: 과격함. 고통을 느끼는 존재를 학대해도 되는가? → 다른 사람이나 동물을 대우하는 **기존의 가치관과 충돌**. (p.27)
- ㄹ: 가장 **비직관적**, 상식과 거리가 멀어 보이지만 생각해 볼 여지가 상당. (p.27~28)
  - **소셜 로봇**: 사람이 동물·인간에게 감정을 이입하는 행동 양식을 이용해 정서적 반응을 인위적으로 이끌어 내려고 만든 로봇.
  - 예: 혼자 사는 사람이 5년, 10년 함께한 **로봇 강아지**가 고장 나 '죽으면' 슬프지 않겠는가? 소셜 로봇을 부수거나 괴롭히면 비난받지 않겠는가?
  - **마크 쿠헬버그**: 대상과 **어떻게 관계 맺고 있는지**가 중요. 로봇이 진짜 감정이 있는지보다 감정이 있는 존재로 **보이는지**, 우리와 어떻게 **상호 작용**하는지를 물어야 함 → **관계론적 접근**.
- **관계론적 접근**: 도덕적 지위는 객관적 속성의 문제가 아니라 인간과 인간·동물·자연이 맺는 일상적 관계 방식 속에서 정해지는 문제. (p.28~29)
  - 예: 전쟁터의 **군사 로봇** = 전우, 가정·요양원의 **감정 로봇** = 가족 같은 존재.
  - 반론 "로봇에게 느끼는 감정은 인위적 공감에서 비롯된 가짜 감정" → 반박: 가축·반려동물처럼 **인위적 공감도 거짓된 감정으로 볼 수 없다**.
- 결론: 도덕적 지위를 부여하는 **주체는 인간**. 이는 로봇 대우의 문제가 아니라 **기술적 존재들에 대한 우리의 심성과 가치관**의 문제. 과제 = 인간과 인공지능의 **새로운 관계 맺기**를 준비하는 것. (p.29)
- 생각 키우기: 생활 속 인공지능 활용 경험, 인공지능을 어떤 존재로 받아들여야 할지. (p.29)

### 6. 활동 1 학습 활동 — 주제 통합적으로 읽기 (p.30~32)
1. **글과 자료의 중심 내용 파악하기** — 가: 지능/지성 구별, 인공지능의 미래 / 나: 신경계 학습 원리(시냅스 결합 강도에 따라 학습 능력이 달라짐)와 인공 신경망 학습 원리(가중치에 따라 출력이 달라짐), 인공 신경망은 신경계를 **모방** / 다: 문제 제기 → 입장별 타당성 분석 → 견해 제시
2. **글과 자료를 비교하여 분석하기** — 분야와 성격, 화제에 관한 관점 비교(나 = 과학 분야, 정보 중심의 글). 자신의 **읽기 목적 구체화**
   - 읽기 목적 예: "미래의 인공지능이 인간의 능력을 뛰어넘을 수 있을지 궁금해." / "인공지능 시대를 살아가는 우리는 어떤 태도를 가져야 하는지 알고 싶어."
3. **읽기 목적을 고려하여 정보 선별하기** — 예: 가 "지능은 지니지만 아직 인간과 같은 지성·감정은 지니지 못한다." / 나 "인간의 뇌를 모방하여 만든 것이므로 인간의 능력을 뛰어넘는 인공지능은 만들지 못할 것이다." / 다 "누가 우월한지보다 새로운 관계 맺음이 필요하다."
4. **자신의 견해 재구성하기** — 예: 처음엔 곧 인간을 뛰어넘을 거라 생각 → 가·나를 보니 아직 인간 능력에 못 미침 → 다에서 능력과 별개로 새로운 관계 형성 가능함을 알게 됨.

### 7. 활동 2 — 논증하는 글 쓰기 (p.33~35)
- **논증 요소** (p.33)
  - **주장**: 자신이 굳게 내세우는 의견이나 견해
  - **이유**: 근거를 바탕으로 주장을 가능하게 하는 **주관적** 요인
  - **근거**: 주장을 지지하는 **객관적**인 자료
  - **반론에 대한 반박**: 주장에 반대하는 주장을 펼치는 것이 **반론**, 이에 다시 반대의 뜻을 밝히는 것이 **반박**
- 다의 ㄹ 입장 논증 분석: 주장 "인공지능 로봇에게 도덕적 지위를 부여할 수 있다." / 예상 반론 "로봇에게 느끼는 감정은 인위적 공감 행위에서 비롯된 가짜 감정일 뿐" / 반박 "반려동물처럼 인위적 공감도 거짓 감정으로 볼 수 없다." (p.33)
- **글쓰기 과정**: (1) 주장·이유·근거 정리 → (2) 예상 반론과 반박 준비 → (3) 뒷받침 자료 수집(주장 뒷받침 자료, 반박 뒷받침 자료) → (4) 논증 방법을 활용한 개요(서론·본론·결론) → (5) 글쓰기 → (6) 바꾸어 읽고 평가·고쳐 쓰기 (p.33~35)
- **논증 방법** (p.34)
  - **연역**: 일반적으로 받아들여지는 원칙·명제 → 개별 사실·특정 사례에 대한 구체적 주장을 끌어냄
  - **귀납**: 개별적·구체적 사례들 → 일반적·보편적 명제나 법칙 도출
- **평가 기준**(6개, p.35): 주장이 분명한가 / 타당한 이유와 근거 / 논증 방법을 효과적으로 활용해 조직 / 내용을 분명하게 전달하는 표현 / 사실 아닌 내용·과장 없음 / 표절하지 않고 인용 자료 출처를 정확히 밝힘

### 8. 대단원 내용 점검 (p.36)
- 사회적 독서 활동: **독서**로 얻은 지식·정보 공유 → 다양한 삶의 방식·가치관 이해, **사회적 문제** 인식·해결 방안 모색
- **주제 통합적** 읽기: 다양한 관점·형식의 글을 읽기 **목적**에 따라 비판적으로 견해를 **재구성**
- 논증 요소: **주장**, **근거**(객관적 자료), **이유**(주관적 요인), 반론에 대한 **반박**

### 표 1. 가·나·다 비교 (p.22~32)
| 구분 | 가 | 나 | 다 |
|---|---|---|---|
| 글쓴이 | 최재천 | 김상욱(물리학자) | 신상규(철학자) |
| 형식 | 동영상 인터뷰(SBS 뉴스) | 설명하는 글 | 논증하는 글 |
| 분야·성격 | 인공지능에 대한 견해 | 과학 분야, 정보 중심 | 철학 분야, 주장 중심 |
| 관점 | 지능은 흉내 내지만 지성·감정은 어려움 | 인공지능은 뇌의 학습 원리를 모방 | 새로운 관계 맺기 필요(관계론적 접근) |

### 표 2. 신경계 ↔ 인공 신경망 (p.23~25)
| 신경계 | 인공 신경망 |
|---|---|
| 신경 세포 | 원 |
| 시냅스 | 화살표(전달 통로) |
| 시냅스 결합 강도 | 가중치 |
| 전류가 흐름/안 흐름 | 1/0 |
| 입력 합이 임곗값을 넘을 때만 출력 | 입력×가중치의 합이 임곗값을 넘을 때만 1 출력 |
| 결합 강도 강화 = 학습 | 반복으로 적절한 가중치를 얻음 = 학습 |

### 표 3. 도덕적 지위에 대한 네 입장 (p.26~28)
| 입장 | 속성 유무 | 지위 부여 | 판단 기준 | 글쓴이 평가 |
|---|---|---|---|---|
| ㄱ | 있음 | 부여해야 함 | 사실적 속성 | 기준 정당화·확인 불가 문제 |
| ㄴ | 없음 | 부여하지 말아야 함 | 사실적 속성 | 같은 문제 |
| ㄷ | 있어도 | 부여하지 말아야 함 | 가치 판단(도구) | 기존 가치관과 충돌 → 타당하지 않음 |
| ㄹ | 없어도 | 부여할 수 있음 | 가치 판단(관계) | 비직관적이나 생각할 여지 → 지지 |

### 표 4. 이유 vs 근거 / 연역 vs 귀납
| 구분 | 내용 |
|---|---|
| 이유 | 주관적 요인, 근거를 바탕으로 주장을 가능하게 함 |
| 근거 | 객관적 자료, 주장을 지지 |
| 연역 | 일반 원칙 → 개별 사례의 구체적 주장 |
| 귀납 | 개별 사례 → 일반·보편적 명제 |

## 시험 함정 포인트
- **이유**는 주관적 요인, **근거**는 객관적 자료다. 둘을 뒤바꾸면 틀린다. (p.33)
- 지능은 **인지 능력**(분석·해결책 찾기)이고, 자신을 투영해 **반성**하는 것까지 포함하는 것은 **지성**이다. (p.22)
- 가에서 생성형 인공지능이 흉내 내는 것은 '지성'이 아니라 **집단 지능**이다. (p.22)
- 시냅스에서 분비되는 화학 물질은 **아세틸콜린**이며, 신호는 전기 → 화학 → 전기로 바뀐다. (p.23)
- 신호가 입력되는 곳은 **가지 돌기**, 출력되는 곳은 **축삭 돌기**다. (p.23)
- 인공 신경망에서 시냅스에 해당하는 것은 원이 아니라 **화살표**, 결합 강도에 해당하는 것은 **가중치**다. (p.25)
- ㄷ은 속성이 '있어도' 부여하지 말자는 입장, ㄹ은 속성이 '없어도' 부여할 수 있다는 입장이다. 글쓴이가 지지하는 것은 **ㄹ**. (p.27~28)
- ㄷ·ㄹ은 **사실적 속성**이 아니라 **가치 판단**의 문제로 보는 입장이다. (p.27)
- 관계론적 접근을 주장한 사람은 **마크 쿠헬버그**, 인공지능은 지능이 아니라고 한 사람은 **스티븐 핑커**. (p.22, p.28)
- 도덕적 지위를 부여하는 **주체는 인간**이다. (p.29)
- 주제 통합적 읽기는 여러 글을 단순 요약하는 것이 아니라 읽기 목적에 따라 **자신의 견해를 재구성**하는 것이다. (p.20)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 주제 통합적 읽기 | 동일 화제·주제의 여러 글·자료를 읽기 목적에 따라 읽고 자신의 견해를 재구성하는 읽기 |
| 지능 | 분석하고 해결책을 찾는 능력(인지 능력) |
| 지성 | 어떤 상황에 자신을 투영해 보고 반성해 보는 것까지 포함하는 능력 |
| 가지 돌기 | 신경 세포에서 신호가 입력되는 부분 |
| 축삭 돌기 | 신경 세포에서 신호가 출력되는 부분 |
| 시냅스 | 신경 세포 사이의 좁은 간격, 화학 물질로 신호를 전달 |
| 아세틸콜린 | 시냅스에서 분비되는 화학 물질 |
| 신경 가소성 | 자주 쓰는 시냅스 연결은 강화, 쓰지 않는 연결은 약화되는 성질(기억·학습의 근본 원리) |
| 임곗값 | 사물이 어떠한 기준에 의하여 분간되는 한계의 값 |
| 인공 신경망 | 신경계의 특성을 컴퓨터 프로그램으로 구현한 것 |
| 가중치 | 평균치를 산출할 때 개별치에 부여되는 중요도(인공 신경망에서 시냅스 결합 강도에 해당) |
| 감수성 | 외부 세계의 자극을 받아들이고 느끼는 성질 |
| 도덕적 지위 | 도덕적으로 대우받을 자격 |
| 소셜 로봇 | 감정 이입 행동 양식을 이용해 정서적 반응을 인위적으로 이끌어 내려고 만든 로봇 |
| 관계론적 접근 | 도덕적 지위를 대상과의 관계·상호 작용 속에서 정해지는 문제로 보는 입장 |
| 주장 | 자신이 굳게 내세우는 의견이나 견해 |
| 이유 | 근거를 바탕으로 주장을 가능하게 하는 주관적 요인 |
| 근거 | 주장을 지지하는 객관적인 자료 |
| 반론 / 반박 | 주장에 반대하는 주장 / 반론에 다시 반대의 뜻을 밝히는 것 |
| 연역 | 일반 원칙·명제에서 구체적 주장을 끌어내는 논증 |
| 귀납 | 구체적 사례들에서 일반 명제·법칙을 도출하는 논증 |

## 자기점검 질문
1. 주제 통합적 읽기의 과정 4단계는? — 읽기 목적 구체화·질문 → 다양한 글 찾기 → 비교하며 비판적 읽기 → 견해 재구성
2. 최재천이 구별한 지능과 지성의 차이는? — 지능은 분석·해결의 인지 능력, 지성은 자신을 투영해 반성하는 것까지 포함
3. 신경 가소성이란? — 자주 쓰는 시냅스 연결은 강화되고 쓰지 않는 연결은 약화되는 성질
4. 인공 신경망에서 '학습'이란? — 원하는 출력이 나오도록 가중치 조절을 반복해 적절한 가중치를 얻는 것
5. ㄱ·ㄴ 입장의 철학적 문제 두 가지는? — 기준의 정당화 문제, 로봇의 속성 유무 확인 불가 문제
6. ㄷ 입장이 타당하지 않은 이유는? — 사람·동물을 대우하는 기존 가치관과 충돌
7. 관계론적 접근의 핵심은? — 실제 속성보다 대상과 관계 맺고 상호 작용하는 방식이 도덕적 지위를 정함
8. '가짜 감정'이라는 반론에 대한 반박은? — 가축·반려동물처럼 인위적 공감도 거짓된 감정으로 볼 수 없다
9. 연역과 귀납의 차이는? — 연역은 일반 → 개별, 귀납은 개별 → 일반
10. 논증하는 글 평가 기준 중 자료 사용에 관한 것은? — 표절하지 않고 인용한 자료의 출처를 정확히 밝혔는가
