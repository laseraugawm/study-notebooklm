# 매체 소통 퀴즈

## Question 1
구술 매체를 활용한 소통의 특성과 한계에 대한 설명으로 가장 적절한 것은?

- [x] 화자와 청자가 직접 대면하여 소통하므로 당대의 상황과 맥락을 공유한다.
- [ ] 글쓴이와 독자의 시공간 상황이 분리되는 탈상황적, 탈맥락적 소통이 주를 이룬다.
- [ ] 지식과 정보가 문자로 기록되어 시공간의 제약 없이 멀리까지 안정적으로 전승된다.
- [ ] 음성, 문자, 이미지 등이 복합적으로 어우러진 하이퍼텍스트를 능동적으로 탐색한다.

**Hint:** 구술 매체는 문자가 발달하기 전, 화자와 청자가 직접 만나는 대면 상황을 전제로 합니다.

## Question 2
문자 매체의 등장과 발달이 가져온 소통 문화의 변화로 올바르지 않은 것은?

- [x] 화자와 청자가 직접 대면하여 실시간으로 상황과 맥락을 긴밀히 공유한다.
- [ ] 쓰기와 읽기를 중심으로 소통이 이루어지며 시공간적 한계를 극복하였다.
- [ ] 글쓴이와 독자가 서로 떨어져 있는 환경에서 소통하는 탈상황적, 탈맥락적 성격을 띤다.
- [ ] 인쇄술의 발달로 책이 대량 유통되면서 지식의 축적과 대중화에 기여하였다.

**Hint:** 문자로 기록된 글을 읽고 쓰는 소통 환경의 특징을 생각해 보세요.

## Question 3
영상 매체를 활용한 소통의 특징에 대한 설명으로 가장 적절한 것은?

- [x] 시청각 이미지 중심이어서 수용자가 보편적으로 내용을 쉽게 이해할 수 있다.
- [ ] 수용자의 독해 능력 차이에 따라 매체 내용의 이해 수준 차이가 크게 발생한다.
- [ ] 이용자가 정보의 소비자이자 생산자로서 실시간으로 적극 참여하는 상호 작용성이 핵심이다.
- [ ] 정보의 생산자와 수용자가 일대일 수평 관계에서 실시간 쌍방향 소통을 지속한다.

**Hint:** 영화나 텔레비전 등 시청각 이미지를 활용하는 매체의 수용 특성을 떠올려 보세요.

## Question 4
디지털 매체의 주요 특성 중 '복합양식성'에 대한 설명으로 가장 적절한 것은?

- [x] 음성, 문자, 그림, 동영상 등 다양한 양식이 혼합되어 나타나는 특성이다.
- [ ] 이용자가 링크 등을 이용해 다른 문서나 관련 정보로 바로 이동할 수 있는 특성이다.
- [ ] 수용자가 지식을 능동적으로 선택하고 생산자 역할을 겸하는 특성이다.
- [ ] 생산자가 전달하는 정보를 다수의 수용자가 동시에 시청각적으로 수용하는 특성이다.

**Hint:** 하나의 매체 표현물 안에 여러 양식(음성, 문자, 영상 등)이 어떻게 결합하는지 떠올려 보세요.

## Question 5
디지털 매체 환경에서 제공되는 '하이퍼텍스트'의 역할로 가장 적절한 것은?

- [x] 이용자가 다양한 문서나 정보로 바로 이동하며 필요한 정보를 손쉽게 얻도록 돕는다.
- [ ] 글쓴이와 독자가 동일한 대면 공간을 공유하도록 돕는 음성 소통 방식이다.
- [ ] 글을 읽고 이해하는 능력이 부족한 독자의 접근을 제한하는 보안 장치이다.
- [ ] 생산자가 정해 놓은 순서대로만 수용자가 글을 읽도록 강제하는 방식이다.

**Hint:** 인터넷 기사나 글에서 특정 문구를 눌러 관련 문서로 이동하는 방식을 생각해 보세요.

## Question 6
디지털 매체의 '상호 작용성'이 기존 대중매체의 소통 방식과 구분되는 가장 큰 특징은?

- [x] 이용자가 지식과 정보의 소비자인 동시에 생산자 역할을 겸하며 능동적으로 문화를 창조한다.
- [ ] 생산자로부터 수용자에게 정보가 일방적으로 전달되어 대중의 동시 수용을 유도한다.
- [ ] 문자 매체의 한계를 보완하기 위해 문자를 배제하고 동영상만 사용한다.
- [ ] 소통 당사자 간의 시공간적 제약이 심해져서 사전에 정해진 장소에서만 대화가 이루어진다.

**Hint:** 디지털 매체 이용자가 정보의 '생산자'이자 '소비자'로서 어떤 역할을 하는지 떠올려 보세요.

## Question 7

- [x] 구술 매체 → 문자 매체 → 영상 매체 → 디지털 매체
- [ ] 구술 매체 → 영상 매체 → 문자 매체 → 디지털 매체

## Question 8

- [x] 댓글과 실시간 대화를 활용하여 시공간의 제약을 받지 않고 쌍방향으로 소통한다.
- [ ] 생산자가 제작한 콘텐츠가 수용자에게 일방향으로만 전달되며 수용자의 피드백은 차단된다.
- [ ] 화자와 청자가 직접 얼굴을 마주보고 대면하는 구술 소통 형태를 필수로 요구한다.
- [ ] 텍스트만을 제공하여 이용자의 읽기 능력이 높은 집단에게만 유용한 정보를 제공한다.

**Hint:** 이용자들이 실시간으로 반응하고 의견을 나눌 수 있게 해 주는 기능을 생각해 보세요.

## Question 9
매체 기술의 변화와 인간의 소통 문화 사이의 관계에 대한 설명으로, 본문의 내용과 가장 잘 부합하는 것은?

- [x] 소통 기술의 변화는 소통 문화의 발전으로 이어지며, 발전된 소통 문화는 다시 기술의 진화를 요구한다.
- [ ] 새로운 매체가 등장을 하더라도 사람들이 소통하는 방식과 언어문화에는 변함이 없다.
- [ ] 매체 발전은 지식의 저장 능력에만 영향을 줄 뿐, 인간 상호 간의 관계 형성 방식과는 무관하다.
- [ ] 급속한 디지털 환경 변화 속에서는 매체 소통 문화를 성찰하기보다 오직 매체 기능 습득에 집중해야 한다.

**Hint:** 매체 기술과 소통 문화가 서로 어떻게 영향을 주 주고받는지 본문의 마지막 단락을 확인해 보세요.
