# 3-(1) 함께 만족하는 협상
교과서 100~111쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 협상에 대한 이해와 활동을 통해 개인 또는 집단의 갈등을 조정하여 문제를 해결할 수 있다. (p.100)
- 개인의 말이 사회에 미치는 영향력을 고려하여 책임감 있게 듣고 말할 수 있다. (p.100)

## 핵심 개념

### 1. 협상의 개념과 의의 (p.100)
- **협상**: 개인이나 집단 사이에서 **이익이나 주장이 달라** 발생하는 문제를 해결하기 위해 서로 **타협하고 조정**하면서 해결 방법을 찾아가는 **협력적 의사소통**의 방법.
- 협상 참여자는 **시작 단계 → 조정 단계 → 해결 단계**에 따라 다양한 전략을 마련.
- 태도: **말의 영향력**을 생각하며 **책임감 있게 듣고 말하기**.
- 의의: **양보와 협력**을 통해 **양측 모두가 만족**할 만한 결과를 얻을 수 있음.
- 생각 열기: 피자를 똑같이 나누려 할 때 "한 사람이 두 조각으로 자르고, 선택권은 자르지 않은 사람에게" → 두 사람 모두 만족할 방안인가?

### 2. 협상 시 고려해야 할 사회적 의사소통의 방법 (p.101)
1. 협상의 **목적과 상황**을 고려하여 **책임감 있게** 듣고 말한다.
2. 상대방의 이해가 부족할 경우 이해를 도울 수 있는 **정보를 추가로 제공**한다.
3. 상대방의 **처지와 입장을 이해**하며 **적극적이고 우호적인 자세**로 참여한다.
4. 말이 사회에 미치는 영향력을 고려하여 **거짓된 내용이나 왜곡된 사실**을 말하지 않는다.
- (평가 기준에 추가된 항목) 상대를 **존중하는 표현**을 사용하고 상대에게 **피해를 줄 수 있는 내용은 삼간다**. (p.108)

### 3. 협상 사례 — 풀빛고등학교 연극 동아리 ↔ 다빛아파트 주민 대표 (p.101~108)

#### (1) 협상의 배경과 준비 (p.101)
- 동아리 측(대표 **김선우**): 학교 **강당 지붕 공사** 때문에 공연·연습 장소가 필요 → 학교 인근 다빛아파트 **주민 문화 센터 소극장**이 최적.
- 주민 측: 주민을 위한 시설을 대여하면 **관리 비용**과 **주민 불편** 발생 → **상응하는 혜택**이 있어야 함.
- **준비 단계 전략**: 협상의 목적·상황·대상을 고려해 말할 내용 준비 / 얻고자 하는 바, 예상되는 상대측 요구와 대안, **양보할 수 있는 지점** 생각.

#### (2) 시작하기 (p.102)
- 동아리 측 이유: 강당 공사로 정기 공연 장소가 마땅치 않음, 문화 센터가 학교와 **인접**, 소극장의 **무대 시설**이 잘 갖추어짐. 학교 학생의 **절반가량이 다빛아파트 거주**.
- 주민 측 입장: 주민을 위한 문화 시설로 **외부 기관에 대여한 적이 없음**, 비용과 불편 → 주민 대표 회의 의견: **상응하는 이익**이 있어야 함.
- **시작 단계 전략**: 양측의 **입장을 확인**한다 / **입장 차이의 원인**을 분석하고 문제 해결의 **필요성과 가능성**을 확인한다.

#### (3) 조정하기 ① — 대여의 대가 (p.103)
- 동아리 제안: 주민들도 공연을 **관람**할 수 있게 함(한 아파트 주민들 사이의 이야기를 다룬 연극).
- 주민 측: 더 **실질적인 이익**을 원함 → 65세 이상 대상 **노인 학교**의 내년 연극 공연 기획에 **도움**을 요청.
- 동아리: "수용하기 쉬운 내용이 아니네요." → 주민 대표가 학업·동아리 병행의 어려움을 **이해**해 줌 → 동아리가 시간을 내 보겠다고 **양보** → 주민 측 소극장 대여 수락.
- 주민 측이 얻은 이익: **공연 관람** + **어르신 연극 활동 지원**.
- 사회적 의사소통: "저희의 입장을 이해해 주셔서 고맙습니다." / "어려운 상황에서도 그렇게 해 주신다니 고맙습니다." → 상대의 처지·입장을 이해하는 **우호적인 자세**.

#### (4) 조정하기 ② — 연습 시간과 민원·청소 (p.104~105)
- 연습 시간
  - 제안: 공연 **일주일 전**부터 매일 **오후 4시~9시** 연습.
  - 주민 측 사정: 관리 직원이 **7시에 퇴근** → 이후 사용 곤란.
  - 조정: 7시까지 연습, 단 **공연 전날만 9시까지** 사용.
- 민원·안전
  - 주민 측 우려: 출입자 증가로 **소음·쓰레기 민원**, **안전사고**.
  - 동아리 대책: 학생회 도움으로 **안내 요원 배치**(공연 안내·질서 유지), **쓰레기 캠페인**.
- 청소
  - 주민 요구: 공연 후 **소극장 안팎 청소**.
  - 동아리 사정: 분장 지우기·소품 정리로 전부는 어려움.
  - 조정: 학생은 **무대 정리와 무대 주변 청소**, 주민 측은 **객석과 문화 센터 주변 청소**.
- 동아리 대표: "제가 동아리 대표인 만큼 **책임감**을 가지고 … 잘 이행되도록 노력하겠습니다." → 말의 영향력을 고려한 **책임감 있는 말하기**, 상대를 안심시킴.
- **조정 단계 전략**: 문제를 파악하고 상대측의 **처지와 관점**을 파악 / 서로의 제안을 검토하여 **입장 차이를 좁힘** / **양보할 수 있는 지점**을 찾아 **합의를 유도**.
- 도움말: 모두가 만족하려면 얻고자 하는 바를 **분명히 표현**하면서도 상대방의 처지를 이해하고 협력하며 합의점을 찾아야 함. (p.105)

#### (5) 해결하기 (p.106~107)
- 공연 일정
  - 동아리 계획: 다음 달 첫째 주 **목·금 오후 1시**.
  - 주민 측 아쉬움: 평일 낮엔 **직장인 주민**이 관람 어려움 → 저녁 공연 요청.
  - 동아리 사정: 저녁 공연은 학생 **귀가 시간**이 늦어짐 → 대안: **토요일 오후 3시** 공연 1회 추가.
- 어르신 연극 지원
  - 동아리 제안: **대본 작성**과 **연기 기초 훈련**(자세 훈련, 호흡 훈련, 발성 및 발음 훈련) — '연기 기초 훈련'의 뜻을 묻자 설명 → **이해를 돕는 정보 추가 제공**.
  - 시기: 학기 중·여름 방학은 어려움 → **겨울 방학 때 한 달** 제안.
  - 주민 측: **매주 정기적** 도움 원함.
  - 조정: **2~3명씩 당번**을 정해 **한 달에 두 번** 방문.
  - 주민 대표: "저희의 요구가 좀 무리였던 것 같습니다… 많이 양보해 주셔서 고맙습니다."
- **해결 단계 전략**: **타협하고 조정**하여 남아 있는 문제 해결 / 모두가 만족할 수 있는 **최선의 대안**을 마련하여 **합의**.
- **의사소통 과정의 점검과 조정**: 듣기·말하기는 화자와 청자의 **상호 작용**으로 의미를 구성하는 과정 → 목적·대상·상황·맥락을 고려해 자신의 듣고 말하는 행위를 **지속적으로 점검**하고, 문제가 있으면 **적절히 조정**. (p.107)

#### (6) 합의안 (p.108)
1. 다빛아파트 문화 센터 내 소극장을 풀빛고 연극 동아리의 공연 및 연습 장소로 대여한다.
2. 공연은 다음 달 첫째 주 **목요일부터 토요일까지 총 3회**(목·금 오후 1시 / 토 오후 3시).
3. 공연 일주일 전부터 소극장 연습에 협조, 연습은 **19:00까지**(단, 공연 하루 전에는 **21:00까지**).
4. (정리 예) 동아리는 안내 요원 배치와 쓰레기 캠페인으로 민원·안전사고를 예방한다.
5. (정리 예) 공연 후 무대 정리·무대 주변 청소는 동아리가, 객석·문화 센터 주변 청소는 주민 측이 한다.
6. (정리 예) 동아리는 2~3명씩 당번을 정해 한 달에 두 번 어르신 연극 활동(대본 작성, 연기 기초 훈련)을 돕는다.

### 4. 활동 2 — 과정을 적용하며 협상하기 (p.109~111)
- 주제 예: 과학 동아리 지원금을 서로 받기 원하는 **과학 실험반과 천체 관측반** / 도서관 **난방기 사용**을 둘러싼 학생 대표와 행정실 시설 담당자.
- 준비: 협상 목표, 예상되는 상대측 요구 사항과 대응 방안, **양보 가능한 지점**.
  - 점검: 얻고자 하는 바를 분명히 정했는가 / 설득할 대안을 미리 마련했는가 / 양측이 만족할 **협상 가능한 범위**를 정했는가.
  - 도움말: 함께 만족하는 결과를 얻으려면 **협상 가능한 범위 설정**이 중요 — 얻고 싶은 것, 어디까지 양보할 수 있는지를 생각하면 상대측 요구에 적절한 대안 마련 가능. (p.109)
- 시작하기 점검: 상대측의 입장과 의도 파악 / 입장 차이 원인 분석, 문제 해결의 필요성·가능성 확인.
- 조정하기 점검: 상대 처지·관점, 해결할 문제 확인 / 입장 차이를 좁히는 노력 / 양보 지점을 찾아 합의 유도. (최초 요구 사항 → 상대측 제안 검토 → 타협하고 조정한 내용)
- 해결하기 점검: 타협과 조정으로 해결 / 최선의 해결책으로 합의 / 양측 모두 만족.
- 평가 기준: 목적과 상대측 요구 사항 파악 / 요구 수용하며 적절한 대안 / 거짓·왜곡 없음 / 경청하며 존중하는 표현 / 협력적 태도로 서로 만족하는 결과.
- 생각 키우기: 매체에서 접한 협상 상황과 참여자 태도, 자신의 갈등 상황 중 협상이 필요한 문제. (p.111)

## 비교·정리표

### 표 1. 협상의 단계별 전략 (p.101~106)
| 단계 | 전략 |
|---|---|
| 준비 | 목적·상황·대상 고려, 얻고자 하는 바·예상 요구·대안·양보 지점 생각 |
| 시작 | 양측 입장 확인, 입장 차이 원인 분석, 해결 필요성·가능성 확인 |
| 조정 | 상대 처지·관점 파악, 제안 검토로 입장 차이 좁히기, 양보 지점 찾아 합의 유도 |
| 해결 | 타협·조정으로 남은 문제 해결, 최선의 대안 마련·합의 |

| 연습 시간 | 일주일 전부터 매일 16~21시 | 19시까지, 공연 전날만 21시까지 |

|---|---|
| 책임감 있게 말하기 | "동아리 대표인 만큼 책임감을 가지고 … 이행되도록 노력" |
| 정보 추가 제공 | '연기 기초 훈련'(자세·호흡·발성 및 발음 훈련) 설명 |
| 처지 이해·우호적 자세 | "입장을 이해해 주셔서 고맙습니다", "요구가 좀 무리였던 것 같습니다" |
| 거짓·왜곡 금지 | 사실(공사, 직원 퇴근 시간 등)에 근거한 설명 |

## 시험 함정 포인트
- 협상은 한쪽이 이기는 것이 아니라 **양보와 협력으로 양측 모두 만족**하는 데 의의가 있다. (p.100)
- 입장 차이의 **원인 분석**과 해결의 필요성·가능성 확인은 '조정'이 아니라 **시작 단계**에서 한다. (p.102)
- '양보할 수 있는 지점을 찾아 합의를 유도'하는 것은 **조정 단계**, '최선의 대안을 마련하여 합의'하는 것은 **해결 단계**다. (p.103, p.106)
- 연습은 19시까지이며 **공연 하루 전만** 21시까지다. 이유는 관리 직원이 **7시에 퇴근**하기 때문. (p.104, p.108)
- 공연은 총 **3회**(목·금 오후 1시, 토 오후 3시)다. 저녁 공연을 하지 않은 이유는 학생들의 **귀가 시간** 문제. (p.106, p.108)
- 청소는 동아리가 전부 하지 않는다 — 무대·무대 주변은 학생, **객석·센터 주변은 주민 측**. (p.105)
- 어르신 지원은 겨울 방학 한 달도, 매주도 아닌 **2~3명 당번이 한 달에 두 번**으로 조정됐다. (p.106)
- 연극 동아리가 소극장을 고른 이유는 학교와의 **인접성**과 **무대 시설**이며, 학생 절반가량이 아파트 주민이라는 점을 근거로 들었다. (p.102)
- 협상 가능한 범위 설정은 **준비 단계**의 핵심이다. (p.109)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 협상 | 이익·주장이 달라 생긴 문제를 타협·조정으로 해결하는 협력적 의사소통 방법 |
| 타협 | 서로 양보하여 협의함 |
| 조정 | 서로의 제안을 검토하여 입장 차이를 좁혀 감 |
| 양보 | 자기 요구를 일부 거두어 상대에게 맞춤 |
| 시작 단계 | 입장 확인, 차이의 원인 분석, 해결 필요성·가능성 확인 |
| 조정 단계 | 처지·관점 파악, 입장 차이 좁히기, 양보 지점 찾아 합의 유도 |
| 해결 단계 | 남은 문제 해결, 최선의 대안으로 합의 |
| 협상 가능한 범위 | 얻고 싶은 것과 양보할 수 있는 한계 사이의 범위 |
| 사회적 의사소통 | 말의 사회적 영향력을 고려한 책임감 있는 의사소통 |
| 합의안 | 협상으로 합의한 내용을 정리한 문서 |
| 연기 기초 훈련 | 배우가 갖춰야 할 기본기를 익히는 훈련(자세·호흡·발성 및 발음) |
| 의사소통 과정의 점검과 조정 | 목적·대상·상황·맥락을 고려해 듣기·말하기를 계속 점검하고 고침 |

## 자기점검 질문
1. 협상의 정의는? — 이익·주장이 달라 생긴 문제를 타협·조정하며 해결하는 협력적 의사소통 방법
2. 협상의 세 단계는? — 시작 – 조정 – 해결
3. 시작 단계에서 할 일은? — 양측 입장 확인, 입장 차이 원인 분석, 해결 필요성·가능성 확인
4. 협상 시 고려할 사회적 의사소통 방법 네 가지는? — 책임감 있게 듣고 말하기, 정보 추가 제공, 처지 이해와 우호적 자세, 거짓·왜곡 금지
5. 주민 측이 소극장 대여로 얻은 이익은? — 공연 관람, 어르신 연극 활동(대본·연기 기초 훈련) 지원
6. 연습 시간이 조정된 이유는? — 관리 직원이 7시에 퇴근하기 때문
7. 토요일 공연을 추가한 이유는? — 직장인 주민도 관람할 수 있게, 저녁 공연은 학생 귀가 문제
8. '연기 기초 훈련' 설명은 어떤 의사소통 방법에 해당하나? — 상대 이해가 부족할 때 정보를 추가로 제공
9. 협상 준비에서 협상 가능한 범위를 정하는 이유는? — 얻고 싶은 것과 양보 한계를 알아야 상대 요구에 적절한 대안을 마련할 수 있어서
10. 의사소통 과정의 점검과 조정이란? — 목적·대상·상황·맥락을 고려해 자신의 듣기·말하기를 계속 점검하고 문제가 있으면 조정하는 것
