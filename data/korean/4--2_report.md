# 4-(2) 바르고 정확한 국어생활
교과서 140~153쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 한글 맞춤법의 원리를 이해하고 적용하여 바르게 표기할 수 있다. (p.140)
- 한글 맞춤법을 지키며 자신의 국어생활의 모습을 성찰하고 개선할 수 있다. (p.140)

## 핵심 개념

### 1. 한글 맞춤법이란 (p.140)
- 언어는 같은 언어를 쓰는 이들 사이의 **사회적 약속**. 저마다 다르게 적으면 뜻을 제대로 파악하지 못함.
- **한글 맞춤법**: 혼란을 피하고 효율적으로 소통하기 위해 정한, 우리말을 한글로 표기할 때 지켜야 할 원칙을 정해 놓은 **어문 규범**.
- 구성(총 **6장**): 제1장 **총칙** / 제2장 **자모** / 제3장 **소리에 관한 것** / 제4장 **형태에 관한 것** / 제5장 **띄어쓰기** / 제6장 **그 밖의 것**.
- 생각 열기: "어떻해", "빨리 낳으려면(→ 나으려면)", "안대(→ 안 돼)" 같은 맞춤법 오류로 뜻이 엉뚱하게 전달된 대화.

### 2. 제1장 총칙 — 제1항의 원리 (p.141)
- **제1항**: 한글 맞춤법은 **표준어를 소리대로 적되, 어법에 맞도록 함**을 원칙으로 한다.
- **표음주의**(#소리대로 적되): 발음하는 대로 적음. **표기하기가 용이**. 예: [밥], [꿈] → '밥', '꿈' / [아름다워]를 '아름답어'로 적지 않음('아름답어'는 [아름다버]로 소리 나므로).
- **표의주의**(#어법에 맞도록 함): **형태소의 본래 모양을 밝혀** 적음. 읽으면서 **의미를 파악하기 편함**. 예: '늙-'은 [늘거], [늑찌], [능는]으로 소리 나지만 어간을 고정해 '늙어, 늙지, 늙는'.
- 확인 문제(소 = 소리대로 / 어 = 어법에 맞게): 꽃밭(어), 맏이(어), 가려워(소), 웃으니(어), 더워(소), 젊음(어)

### 3. 제3장 소리에 관한 것 (p.142~143)

#### (1) 된소리 — 제5항: '깍두기'인가 '깍뚜기'인가?
- **제5항**: 한 단어 안에서 **뚜렷한 까닭 없이** 나는 된소리는 다음 음절의 첫소리를 된소리로 적는다.
  - 한 형태소 안의 두 모음 사이, 'ㄴ, ㄹ, ㅁ, ㅇ' 뒤의 된소리 → 된소리로 적음. 예: 소쩍새, 산뜻하다
- **다만**, **'ㄱ, ㅂ' 받침 뒤**에서 나는 된소리는(언제나 된소리되기가 일어나므로) 된소리로 적지 않는다. 예: 국밥, 갑자기, **깍두기**
- **예외**: 같거나 비슷한 음절이 **반복**되면 된소리로 적음. 예: 똑똑하다, 쓱싹쓱싹, 쌉쌀하다
- **된소리되기**: 예사소리 'ㄱ, ㄷ, ㅂ, ㅅ, ㅈ'이 일정한 환경에서 [ㄲ, ㄸ, ㅃ, ㅆ, ㅉ]으로 바뀌는 현상.

#### (2) 'ㄷ' 소리 받침 — 제7항: '돗자리'인가 '돋자리'인가?
- **'ㄷ' 소리로 나는 받침**: 음절 종성에서 [ㄷ]으로 소리 나는 ㄷ, ㅅ, ㅆ, ㅈ, ㅊ, ㅌ, ㅎ 등.
- **제7항**: 'ㄷ' 소리로 나는 받침 중 **'ㄷ'으로 적을 근거가 없는 것은 'ㅅ'**으로 적는다.
  - 근거가 있으면 'ㄷ': '얻-'(얻어[어더], 얻으니)
  - 근거가 없으면 'ㅅ': **돗자리, 덧저고리, 웃어른, 무릇** → 'ㅅ' 받침을 써 오던 **전통적 표기 관습**.
- **제29항**: 끝소리가 'ㄹ'인 말과 딴 말이 어울릴 때 'ㄹ' 소리가 'ㄷ' 소리로 나는 것은 'ㄷ'으로 적는다. 예: 반짇고리, 사흗날, 숟가락, 이튿날

#### (3) 두음 법칙 — 제10항: '생산 연도'인가 '생산 년도'인가?
- **두음 법칙**: 특정 소리가 **단어 첫머리**에 나타나는 것을 꺼려 발생하는 음운 현상. 예: 경로(敬老) – 노인(老人)
- **제10항**: 한자음 '녀, 뇨, 뉴, 니'가 단어 첫머리에 올 때는 '여, 요, 유, 이'로 적는다. 예: 여자(×녀자), 익명(×닉명)
- **다만**, **의존 명사**에는 두음 법칙이 적용되지 않음(앞말과 연결되어 하나의 단위를 이루므로). 예: 금 한 **냥**, 삼 **년**
- '생산 **연도**', '제작 연도'의 '연도'는 명사 → 두음 법칙 적용 / '2025**년도**'의 '년도'는 의존 명사 → 소리대로.
- 확인 문제: **몹시**, **놋그릇**, 십 **년**, **낟알**, **남녀**

### 4. 제4장 형태에 관한 것 (p.144~145)

#### (1) 어간과 어미 — 제15항: '드러나다'인가 '들어나다'인가?
- **제15항**: 용언의 **어간과 어미는 구별**하여 적는다 → 표의주의, 의미·기능 부분이 고정되어 뜻 파악이 쉬움.
- **[붙임 1]**: 두 용언이 어울려 한 용언이 될 때, 앞말의 **본뜻이 유지**되면 원형을 밝혀 적고, **본뜻에서 멀어지면** 밝혀 적지 않는다. → 표음주의와 표의주의의 **공존**.
  - **늘어나다**: '늘다'의 뜻 유지 → 원형 밝힘(×느러나다)
  - **드러나다**: '들다'의 본뜻 유지 안 됨 → 소리대로(×들어나다)
- **불규칙 용언 활용형**: 교체 양상을 규칙적으로 표기하기 어려워 교체가 일어나는 대로 적음 → 표의주의보다 **표음주의에 더 가까움**.

#### (2) 접미사 파생어 — 제19항: '너머'인가 '넘어'인가?
- **제19항**: 어간에 **'-이'나 '-음/-ㅁ'**이 붙어 명사가 된 것, **'-이'나 '-히'**가 붙어 부사가 된 것은 어간의 원형을 밝혀 적는다. (이 접미사들은 어간의 본뜻을 유지하며 여러 어간에 결합 가능)
- '-이', '-음' **이외의 모음으로 시작하는 접미사**가 붙어 품사가 바뀐 말은 원형을 밝히지 않음(결합 어간이 제약되고 새 말을 만들지 못함). 예: 저 산 **너머**(명사) ↔ 언덕을 **넘어야겠네**(동사 활용)

#### (3) 준말 — 제40항: '생각건대'인가 '생각컨대'인가?
- **제40항**: 어간 끝음절 '하'의 'ㅏ'가 줄고 'ㅎ'이 다음 음절 첫소리와 어울려 거센소리가 되면 **거센소리로** 적는다.
  - [붙임 1] 'ㅎ'이 어간 끝소리로 굳어진 것은 받침으로 적는다.
  - [붙임 2] 어간 끝음절 '하'가 **아주 줄** 적에는 준 대로 적는다.
- **기준**: '하' 앞 받침의 소리가 **[ㄱ, ㄷ, ㅂ]이면 '하'가 통째로 줄고**, 그 외에는 **'ㅎ'이 남아** 거센소리가 됨. → 생각하건대 → **생각건대**
- **거센소리되기**: 'ㄱ, ㄷ, ㅂ, ㅈ'이 'ㅎ'과 만나 [ㅋ, ㅌ, ㅍ, ㅊ]으로 바뀌는 현상. 예: 놓고[노코], 입학[이팍]
- 확인 문제 1: **쓸어진다**, **깨끗지**, **그을음**, **좇아**, **베풂**
- 확인 문제 2(준말): 달성하게 → **달성케** / 어떠하다 → **어떻다** / 연구하도록 → **연구토록** / 회상하건대 → **회상컨대**

### 5. 제5장 띄어쓰기 (p.146~147)
- **제2항**(제1장): 문장의 각 **단어는 띄어 씀**을 원칙으로 한다.
- 띄어쓰기는 읽는 이가 **의미를 분명하게 파악**하도록 해 줌. 예: '생선한마리만오천원' → '생선 한 마리 **만 오천 원**'(1마리 15,000원) / '생선 한 마리**만** 오천 원'(한 마리만 5,000원)
- **제41항**: **조사**는 앞말에 붙여 쓴다(단어이지만 자립성이 없어 다른 말에 의존).
- **제42항**: **의존 명사**는 띄어 쓴다(꾸미는 말이 반드시 있어야 하지만 명사 기능을 하므로 단어로 취급). 예: 한 **마리**
- 형태가 같은 말 구별: **'뿐'** — 체언 뒤(오늘뿐이다, 셋뿐이다) = **조사** → 붙임 / 용언 관형사형 뒤(먹을 뿐이다, 웃을 뿐이다) = **의존 명사** → 띄움.
- **제47항**: **보조 용언**은 띄어 씀이 원칙, 경우에 따라 붙여 씀도 **허용**.
  - 허용 구성: '**본용언 + -아/-어 + 보조 용언**'(깨뜨려 버렸다 / 깨뜨려버렸다, 읽어 보았다 / 읽어보았다), '**관형사형 + 보조 용언(의존 명사 + -하다/싶다)**'(할 만하다 / 할만하다)
  - **다만** 띄어 쓰는 경우: 앞말에 **조사**가 붙은 경우(책을 읽어도 본다), 앞말이 **합성 용언**인 경우(덤벼들어 보아라, 떠내려가 버렸다), 중간에 **조사**가 들어간 경우(잘난 체를 한다)
- 확인 문제 1: 여기서부터입니다(○) / 사과하기는∨커녕(×, '사과하기는커녕') / 약속대로(○) / 세∨번∨만에(○)
- 확인 문제 2: 아는 **척을 한다** / 비가 **올 듯하다** / 곶감을 **매달아 놓는다**(앞말이 합성 용언)

### 6. 제6장 그 밖의 것 — 제51항: '꼼꼼히'인가 '꼼꼼이'인가? (p.148)
- **제51항**: 부사의 끝음절이 분명히 **'이'로만** 나는 것은 '-이'로, **'히'로만** 나거나 **'이'나 '히'**로 나는 것은 '-히'로 적는다.
  1. '이'로만: 샅샅이, 반듯이
  2. '히'로만: 급히, 정확히
  3. '이, 히'로: 솔직히, 가만히
- **'-이'로 적는 경향**: 겹쳐 쓰인 명사 뒤(겹겹이), **'ㅅ' 받침** 뒤(반듯이), **'ㅂ' 불규칙** 어간 뒤(가벼이), **'하다'가 붙지 않는** 용언 어간 뒤(헛되이), 부사 뒤(곰곰이), 'ㄱ' 받침으로 끝난 일부 어근 뒤(깊숙이)
- **'-히'로 적는 경향**: **'하다'가 붙는 어근** 뒤('ㅅ' 받침 제외) — 급히, 정확히, **꼼꼼히**
- 이것만으로 구별 못하는 경우가 있으므로 정확히 하려면 **국어사전 확인**.
- 그림 예: 깨끗이, 반듯이, 꼼꼼히, 틈틈이

### 7. 학습 활동 (p.149~153)
- **활동 1(1)** [얼키고설키다]의 표기 탐구: '얽히다'는 '얽다' + 피동 접미사 '-히-' → 하나의 단어에 해당 → 어법에 맞게 '**얽히고**' / '섥다', '섥히다'라는 단어는 없음 → 소리대로 '**설키다**' → **얽히고설키다**. (p.149)
- **활동 1(2)** 오규원, 「한 잎의 여자 1」을 낭송하고 밑줄 친 표기를 표음주의·표의주의로 분류. (p.149)
- **활동 2(1)** 올바른 표기와 조항 연결 (p.150)
  | 단어 | 바른 표기 | 조항 |
  |---|---|---|
  | ① 해돋이/해도지 | 해돋이 | 제6항('ㄷ, ㅌ' 받침 뒤 '-이', '-히-'가 와서 'ㅈ, ㅊ'으로 소리 나도 'ㄷ, ㅌ'으로 적음) |
  | ② 법석/법썩 | 법석 | 제5항 다만('ㄱ, ㅂ' 받침 뒤 된소리는 적지 않음) |
  | ③ 오뚝이/오뚜기 | 오뚝이 | 제23항('-하다'·'-거리다'가 붙는 어근에 '-이'가 붙어 명사가 된 것은 원형을 밝힘) |
  | ④ 달달이/다달이 | 다달이 | 제28항(끝소리 'ㄹ'이 소리 나지 않으면 안 나는 대로 적음) |
- **활동 2(2)** 제19항 '다만': 어간 뜻과 **멀어진** 것은 원형을 밝히지 않음.
  - 목에 거는 물건 → **목걸이**(뜻 유지) / 목이 붓고 아픈 병 → **목거리**(뜻 멀어짐)
  - 여러 사람이 모여 즐겁게 노는 일 → **놀음**(뜻 유지) / 돈이나 재물을 걸고 내기를 하는 일 → **노름**(뜻 멀어짐)
- **활동 2(3)** 국어사전 활용 띄어쓰기: '만큼'은 용언 관형사형 뒤면 **의존 명사**(들릴 **만큼**), 체언 뒤면 **조사**(습관**만큼은**) / '버리다'는 본동사·**보조 동사**(행동이 이미 끝남) → ① 들릴 만큼 ② 던져 버리는(던져버리는도 허용), 습관만큼은 ③ 먹어 버리고는(먹어버리고는도 허용), 버리지 않았다. (p.151)
- **활동 3** 일기 고르기: **가만히**, **있다가**, **않았던**, **구매한 지**, **씁쓸한**, **고정한 채**, **되고**, **걷잡을**, **반드시**. (p.151)
- **활동 4** 실생활 오류 고치기: 매체(SNS 글, 단체 소통방, 방송 자막 등)에서 오류 찾기 → '나란이 → **나란히**', '섯부르게 → **섣부르게**'(제29항: '섣부르다'는 '설다'와 연관되어 '설부르다'에서 'ㄹ'이 'ㄷ'으로) → '올바른 표기 생활' **성찰 일지** 작성·공유(사례, 고친 표기와 까닭, 참고 자료 출처, 궁금한 내용). (p.152~153)

## 비교·정리표

### 표 1. 표음주의 vs 표의주의 (p.141)
| 구분 | 표음주의 | 표의주의 |
|---|---|---|
| 제1항 근거 | 소리대로 적되 | 어법에 맞도록 함 |
| 방식 | 발음하는 대로 | 형태소의 본래 모양을 밝힘 |
| 장점 | 표기하기 쉬움 | 읽으며 의미 파악이 편함 |
| 예 | 밥, 꿈, 아름다워, 드러나다, 너머, 불규칙 활용형 | 늙어·늙지·늙는, 늘어나다, 꽃밭, 젊음 |

### 표 2. 헷갈리는 표기 쌍 (p.142~148)
| 바른 표기 | 틀린 표기 | 근거 |
|---|---|---|
| 깍두기 | 깍뚜기 | 제5항 다만('ㄱ' 받침 뒤 된소리) |
| 돗자리 | 돋자리 | 제7항('ㄷ'으로 적을 근거 없음) |
| 생산 연도 / 2025년도 | 생산 년도 | 제10항(명사 vs 의존 명사) |
| 드러나다 / 늘어나다 | 들어나다 / 느러나다 | 제15항 [붙임 1] |
| 너머(명사) / 넘어(동사) | — | 제19항 |
| 생각건대 | 생각컨대 | 제40항 [붙임 2] |
| 꼼꼼히 | 꼼꼼이 | 제51항 |
| 숟가락, 섣부르다 | 숫가락, 섯부르다 | 제29항 |

### 표 3. 조사 vs 의존 명사 (p.146, p.151)
| 말 | 조사(붙여 씀) | 의존 명사(띄어 씀) |
|---|---|---|
| 뿐 | 오늘뿐이다, 셋뿐이다(체언 뒤) | 먹을 뿐이다(관형사형 뒤) |
| 만큼 | 습관만큼은(체언 뒤) | 들릴 만큼(관형사형 뒤) |
| 만 | 한 마리만(한정) | 세 번 만에(시간 경과) |

### 표 4. 보조 용언 띄어쓰기 (p.147)
| 경우 | 쓰기 | 예 |
|---|---|---|
| 원칙 | 띄어 씀 | 깨뜨려 버렸다 |
| 허용 | 붙여 씀 가능 | 깨뜨려버렸다, 할만하다 |
| 앞말에 조사 | 띄어 씀 | 읽어도 본다 |
| 앞말이 합성 용언 | 띄어 씀 | 떠내려가 버렸다, 매달아 놓는다 |
| 중간에 조사 | 띄어 씀 | 잘난 체를 한다 |

## 시험 함정 포인트
- 제1항은 '소리대로'만이 아니라 '**표준어를** 소리대로 적되, **어법에 맞도록**'이다. (p.141)
- '깍두기'는 'ㄱ' 받침 뒤 된소리라 된소리로 적지 **않지만**, '똑똑하다'처럼 같은 음절이 **반복**되면 된소리로 적는다. (p.142)
- '산뜻하다'는 'ㄴ' 뒤의 까닭 없는 된소리라 **된소리로 적는다**. (p.142)
- '돗자리, 웃어른, 무릇'의 'ㅅ'은 소리 때문이 아니라 **'ㄷ'으로 적을 근거가 없어서**다. '숟가락'의 'ㄷ'은 **제29항**('ㄹ'이 'ㄷ'으로 소리 남). (p.142~143)
- 의존 명사에는 두음 법칙이 **적용되지 않는다** — '삼 년', '2025년도'. '생산 연도'의 '연도'는 명사. (p.143)
- '드러나다'는 '들다'의 본뜻이 유지되지 않아 소리대로 적고, '늘어나다'는 본뜻이 유지되어 원형을 밝힌다. (p.144)
- '하' 앞 받침이 [ㄱ, ㄷ, ㅂ]이면 '하'가 **통째로** 준다(생각건대, 깨끗지). 그 외에는 'ㅎ'이 남는다(회상컨대, 연구토록). (p.145)
- 불규칙 용언 활용형 표기는 표의주의가 아니라 **표음주의**에 더 가깝다. (p.144)
- '사과하기는커녕'의 '커녕'은 **조사**라 붙여 쓴다. (p.147)
- '매달아 놓는다'는 앞말 '매달다'가 **합성 용언**이라 붙여 쓸 수 없다. (p.147)
- 'ㅅ' 받침 뒤 부사는 '-이'(반듯이), '하다'가 붙는 어근 뒤는 '-히'(꼼꼼히). '반드시'(꼭)와 '반듯이'(반듯하게)는 다른 말이다. (p.148, p.151)

| 표의주의 | 형태소의 본래 모양을 밝혀 적는 방식 |
| 된소리되기 | 예사소리 ㄱ, ㄷ, ㅂ, ㅅ, ㅈ이 된소리 ㄲ, ㄸ, ㅃ, ㅆ, ㅉ으로 바뀌는 현상 |
| 'ㄷ' 소리로 나는 받침 | 종성에서 [ㄷ]으로 나는 ㄷ, ㅅ, ㅆ, ㅈ, ㅊ, ㅌ, ㅎ 등 |

| 보조 용언 | 본용언 뒤에서 뜻을 보태는 용언(띄어 씀 원칙, 붙여 씀 허용) |

## 자기점검 질문
1. 한글 맞춤법 제1항은? — 표준어를 소리대로 적되, 어법에 맞도록 함을 원칙으로 한다
2. 표음주의와 표의주의의 장점은? — 표기가 쉬움 / 의미 파악이 편함
3. '깍두기'를 '깍뚜기'로 적지 않는 이유는? — 'ㄱ' 받침 뒤의 된소리는 반복 음절이 아니면 된소리로 적지 않음(제5항 다만)
4. '돗자리'를 'ㅅ'으로 적는 이유는? — 'ㄷ'으로 적을 근거가 없어서(제7항)
5. '삼 년'에 두음 법칙이 적용되지 않는 이유는? — '년'이 의존 명사라서
6. '드러나다'와 '늘어나다'의 표기가 다른 이유는? — 앞말의 본뜻 유지 여부(제15항 [붙임 1])
7. '생각하건대'의 준말과 그 까닭은? — 생각건대, '하' 앞 받침 소리가 [ㄱ]이라 '하'가 통째로 줆
8. '먹을 뿐이다'를 띄어 쓰는 이유는? — 관형사형 뒤의 '뿐'은 의존 명사
9. 보조 용언을 반드시 띄어 써야 하는 세 경우는? — 앞말에 조사, 앞말이 합성 용언, 중간에 조사가 들어간 경우
10. '꼼꼼히'로 적는 근거는? — '하다'가 붙는 어근('꼼꼼하다') 뒤에서는 '-히'(제51항)
11. '목걸이'와 '목거리'의 차이는? — 목에 거는 물건(어간 뜻 유지) / 목이 붓고 아픈 병(뜻 멀어짐, 원형 안 밝힘)

- **바로잡기** ''사과하기는∨커녕'을 ×로 표시하며 ‘사과하기는커녕’으로 붙여 써야 한다고 단정함' → 교과서 제47항은 보조 용언의 띄어쓰기를 다루는 조항이고, ‘커녕’이 조사라는 설명은 교과서 본문에 직접 제시되어 있지 않으므로, 이 확인 문제의 정오 판단 근거를 교과서 원문만으로 단정할 수 없다. (p.147)
