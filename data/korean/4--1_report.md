# 4-(1) 국어가 걸어온 길
교과서 130~139쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 중세 국어와 현대 국어의 차이를 살펴 국어의 변화를 이해할 수 있다. (p.130)
- 국어의 변화 양상을 살펴 국어의 미래를 예측하고 바람직한 국어생활의 방향과 태도를 기를 수 있다. (p.130)

> 표기 안내: 옛 글자는 ㆍ(아래아), ㆁ(옛이응), ㆆ(여린히읗), ㅸ(순경음 비읍), ㅿ(반치음)로 적는다. 화면에 따라 옛 글자를 조합한 음절(예: ᄆᆞᆯ)이 풀어져 보일 수 있다.

## 핵심 개념

### 1. 국어는 변화하는 실체 (p.130)
- 언어는 **끊임없이 변화**한다. 오늘날 국어도 역사적으로 많은 변화를 거친 결과.
- 국어의 변화를 아는 것이 중요한 이유: 과거의 국어는 **현대 국어를 이해**하는 데, 그리고 **우리의 언어문화를 이해**하는 데 도움.
- **국어사의 시대 구분**(p.130)
  | 시기 | 범위 |
  |---|---|
  | 고대 국어 | ~고려 건국 이전 |
  | 전기 중세 국어 | 10~14세기 |
  | 후기 중세 국어 | 15~16세기(훈민정음 창제 시기) |
  | 근대 국어 | 17~19세기 말 |
  | 현대 국어 | 20세기~ |
- 생각 열기: 조선 시대 법의학 서적의 신체 부위 명칭 — 무릅(무릎), 오곰(오금), 복쇼아뼈(복사뼈), 뎡바기(정수리), 눈섭(눈썹), 입시울(입술), 콧구무(콧구멍), 귓구무(귓구멍) → 오늘날 명칭과 비교.

### 2. 중세 국어 자료 (p.131~133)

#### 가 「세종어제훈민정음(世宗御製訓民正音)」 — 『월인석보』 권1, 세조 5년(1459)
- **훈민정음 언해본**: 1446년(세종 28년) 간행된 한문본 『훈민정음』 중 **'예의'** 부분을 우리말로 풀어 쓴 것, 세조 5년(1459) 간행 『**월인석보**』 1권 책머리에 실림. (p.131)
- 원문 첫머리(짧은 인용): "나·랏:말ᄊᆞ·미 中듕國·귁·에 달·아 文문字·ᄍᆞᆼ·와·로 서르 ᄉᆞᄆᆞᆺ·디 아·니ᄒᆞᆯᄊᆡ…"
- 어휘 풀이: ᄉᆞᄆᆞᆺ디 = 통하지 / 젼ᄎᆞ로 = 까닭으로 / 어린 = 어리석은 / 시러 = 능히 / 어엿비 = 불쌍히 / ᄒᆡᅇᅧ = 하여금 / 수ᄫᅵ = 쉽게, 쉬이
- **현대어 풀이**: 우리나라 말이 중국과 달라 한자와는 서로 통하지 아니하여서, 이런 까닭으로 어리석은 백성이 말하고자 하는 바가 있어도 마침내 제 뜻을 능히 펴지 못하는 사람이 많다. 내가 이것을 위하여 불쌍히 여기어 새로 **스물여덟 글자**를 만드니, 사람들로 하여금 쉽게 익혀서 날마다 씀에 편하게 하고자 할 따름이다. (p.132)

#### 나 『용비어천가(龍飛御天歌)』 제34장 — 세종 29년(1447)
- 세종이 **정인지** 등에게 명하여 짓게 한 **악장**, 1447년 간행. 조선 선조들의 행적을 노래하는 **서사시**. (p.131)
- 원문 첫머리(짧은 인용): "·믈 깊·고 ·ᄇᆡ :업·건마·ᄅᆞᆫ 하·ᄂᆞᆯ·히 命·ᄒᆞ실·ᄊᆡ ᄆᆞᆯ ·톤자·히 :건·너시·니이·다"
- 어휘 풀이: ᄆᆞᆯ 톤 자히 = 말을 탄 채 / ᄃᆞ리 = 사다리 / 도ᄫᆞ실ᄊᆡ = 도우시므로
- **현대어 풀이**: 물 깊고 배 없건마는 하늘이 명하시므로 말 탄 채로 (강을) 건너십니다. / 성 높고 사다리 없건마는 하늘이 도우시므로 말 탄 채로 (성을 뛰어넘어) 내리십니다. (p.133)
- **관련 고사**: 금나라 태조가 거란을 공격할 때 말 탄 채 강을 건넘(재 보니 바닥이 닿지 않을 만큼 깊었음) / 태조 **이성계**가 송도를 습격한 **홍건적**과 싸우다 말 탄 채 성벽을 뛰어넘음. (p.133)
- 생각 키우기: 조선 시대로 간다면 대화할 수 있을까? 21세기 사람이 왜 15세기 국어를 배워야 할까? (p.133)

### 3. 중세 국어의 음운과 표기 (학습 활동 1-1, p.134~135)
1. **현대 국어에서 쓰지 않는 글자**: 'ᄒᆞᇙ', 'ᄆᆡᇰᄀᆞ노니', '도ᄫᆞ실ᄊᆡ', 'ᄃᆞ리'에서 → 자음자 **ㆆ, ㆁ, ㅸ**, 모음자 **ㆍ(아래아)**.
2. **어두 자음군**: 단어 첫머리에 오는 둘 이상의 자음 연속체. 중세 국어에는 어두에 **'ㅂ'계 자음군(ㅳ, ㅄ 등)**이 올 수 있었음. 예: ᄠᅳᆮ(뜻), ᄡᆞᆯ(쌀) / 'ᄠᅳ들 → 뜻을', 'ᄡᅮ메 → 씀에'. 현대 국어에는 어두 자음군이 없음.
3. **성조와 방점**: 15세기 국어는 소리의 **고저(높낮이)**로 단어의 뜻을 구분 = **성조**. 글자 **왼쪽**에 찍은 점 = **방점**.
   - **평성**(낮은 소리): 점 없음
   - **거성**(높은 소리): 점 1개
   - **상성**(처음은 낮고 나중이 높은 소리): 점 2개
   - 답변 완성: "음의 (높낮이)로 단어의 뜻을 구별… 이것을 (성조)라고 하고…"
4. **이어 적기**: 말ᄊᆞ미(말씀이), 노미(놈이), ᄯᆞᄅᆞ미니라(따름이니라) → 중세 국어는 앞말의 받침을 뒤 음절 첫소리로 **소리 나는 대로 이어** 적음, 현대 국어는 체언과 조사를 **구별해** 적음.
5. **팔종성법** (p.135)
   - 가의 'ᄉᆞᄆᆞᆺ디'는 동사 'ᄉᆞᄆᆞᆾ다'(통하다)의 어간 'ᄉᆞᄆᆞᆾ-'의 **'ㅊ'이 'ㅅ'으로** 바뀌어 표기됨.
   - 중세 국어는 종성으로 발음되는 **ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅅ, ㆁ의 8개** 자음을 받침으로 적음 = **팔종성법**.
   - 예외: 나의 '깊고', '높고'는 받침 **'ㅍ'**이 'ㅂ'으로 바뀌지 않고 그대로 표기됨 → 팔종성법을 따르지 않은 경우도 있음.
   - 현대 국어: 종성으로 소리 나는 자음이 **ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅇ의 7개**로 줄어듦.
6. **옛이응(ㆁ)**: 현재 종성 'ㅇ'이 나타내는 소리를 표기하던 글자. 훈민정음 창제 이후 'ㅇ'과 혼용되다가 **조선어학회의 「한글 맞춤법 통일안」** 발표 이후 완전히 'ㅇ'으로 통합. (p.135)

### 4. 중세 국어의 문법 (학습 활동 1-2, p.136~137)
- **현대어 풀이 속 조사 고르기**
  | 중세 국어 | 현대 국어 |
  |---|---|
  | 나랏 말ᄊᆞ미 | 나라**의** 말**이** |
  | 듕귁에 달아 | 중국**과** 달라 |
  | 니르고져 ᄒᆞᇙ 배 이셔도 | 이르고자 하는 바**가** 있어도 |
  | ᄇᆡ 업건마ᄅᆞᆫ | 배**가** 없건마는 |
  | 하ᄂᆞᆯ히 命ᄒᆞ실ᄊᆡ | 하늘**이** 명하시므로 |
- **중세 국어의 조사**(p.136)
  - **관형격 조사 'ㅅ'**: '나랏 말ᄊᆞ미'처럼 **사물**을 가리키는 명사 다음에 'ㅅ'.
  - **비교의 부사격 조사 '에'**: '中듕國귁에 달아'(중국과 달라). 현대 국어에서도 '에'가 제한적으로 비교의 의미로 쓰이기도 함.
- **주격 조사의 차이**
  - 현대 국어: 자음 뒤 **'이'**, 모음 뒤 **'가'**.
  - 중세 국어 탐구: '말ᄊᆞ미 / 하ᄂᆞᆯ히' → **'이'** / 'ᄒᆞᇙ 배'(바+ㅣ) → **'ㅣ'** / 'ᄇᆡ 업건마ᄅᆞᆫ' → 겉으로 나타나지 않음.
  - **결과**: 자음 뒤 **'이'**, 'ㅣ'나 반모음 'ㅣ̆[j]' 외의 모음 뒤 **'ㅣ'**, 'ㅣ'나 반모음 'ㅣ̆[j]' 뒤에서는 **나타나지 않음**. 주격 조사 '가'는 중세 국어 자료에 보이지 않음.
- **명사형 어미**: 'ᄡᅮ메' = ᄡᅳ- + **-움** + 에 → 현대 '씀에' = 쓰- + **-ㅁ** + 에. (p.137)

### 5. 단어 형태와 의미의 변화 (학습 활동 1-3·4, p.137)
- **형태 변화**
  | 중세 | 현대 | 변화 |
  |---|---|---|
  | 니르고져 | 이르고자 | 'ㅣ' 모음 앞에서 어두의 **'ㄴ'**이 탈락 |
  | 펴디 | 펴지 | 'ㅣ' 모음 앞에서 'ㄷ'이 **'ㅈ'**으로 바뀜 |
  | ᄒᆞᄂᆞᆯ히 | 하늘이 | 체언 끝의 **'ㅎ'**이 소멸 |
  | 도ᄫᆞ실ᄊᆡ | 도우시므로 | 활용형 어간이 **'도ᄫᆞ-'**에서 '도우-'로 변함 |
- **의미 변화**
  | 어휘 | 중세 의미 | 현대 의미 |
  |---|---|---|
  | 말ᄊᆞᆷ | 말 | 말씀(높이거나 낮추는 말) |
  | 어리다 | 어리석다 | (나이가) 어리다 |
  | 놈 | 사람 | 남자를 낮잡아 이르는 말 |
  | 하다 | 많다 | (어떤 일을) 하다 |
  | 어엿브다 | 불쌍하다 | 예쁘다 |

### 6. 국어의 역사성 이해 (학습 활동 2, p.138)
- **'사흘' 소동**: '총 사흘 연휴' 보도 → '사흘'을 4일로 잘못 알아 검색어 1위, "휴일이 3일인데 웬 사흘이냐" 댓글.
- '사흘'은 날이 세 번 지나간 시간, 즉 **3일**을 뜻하는 **순우리말**. 옛말 '사ᄋᆞᆯ'은 **15세기** 문헌부터 나타나고, **16세기**부터 '사흘' — **'ㅎ'이 첨가**되고 **'ㆍ'가 'ㅡ'로** 바뀜.
- 활동: 살코기, 숟가락, 안팎, 좁쌀 중 하나를 국립국어원 「**우리말샘**」에서 찾아 '**역사 정보**' 항목으로 표기 변천 확인.
- 국어의 역사를 이해해야 하는 이유: 현재의 국어생활(단어 뜻·표기)을 바르게 이해하기 위해.

### 7. 국어의 역동성 — 지금도 계속되는 변화 (학습 활동 3, p.139)
| 영역 | 변화 모습 | 예 |
|---|---|---|
| 음운 및 표기 | 의미 강조를 위해 어두를 세게 발음 | 작다[짝따], 세다[쎄다], 저기[쩌기] |
| 음운 및 표기 | 키보드 입력 오타가 유행어가 됨 | 스빈다(습니다), 고나리자(관리자) |
| 단어/어휘 | 줄임말 형태의 신조어 | 혼밥, 남사친, 엄빠, 먹방 |
| 문장/문법 요소 | 문장 길이가 짧아짐 | 오늘 집 감. |
| 문장/문법 요소 | 사물을 높이는 간접 높임 | 커피 나오셨습니다. |
- 되돌아본 국어생활을 바탕으로 **바람직한 국어생활의 태도** 의견 나누기.

## 비교·정리표

### 표 1. 중세 국어 vs 현대 국어 (p.134~137)
| 항목 | 중세 국어 | 현대 국어 |
|---|---|---|
| 글자 | ㆍ, ㆁ, ㆆ, ㅸ 등 사용 | 사용하지 않음 |
| 어두 자음군 | 있음(ㅳ, ㅄ: ᄠᅳᆮ, ᄡᆞᆯ) | 없음 |
| 성조 | 있음(방점: 평성 0, 거성 1, 상성 2) | 없음 |
| 표기 | 이어 적기(말ᄊᆞ미) | 끊어 적기(말씀이) |
| 받침 | 팔종성법(8개) | 7개 대표음 |
| 주격 조사 | 이 / ㅣ / Ø | 이 / 가 |
| 관형격 조사 | ㅅ(사물 명사 뒤) | 의 |
| 명사형 어미 | -옴/-움 | -(으)ㅁ |

### 표 2. 방점과 성조 (p.134)
| 성조 | 소리 | 방점 |
|---|---|---|
| 평성 | 낮은 소리 | 없음 |
| 거성 | 높은 소리 | 1개 |
| 상성 | 처음 낮고 나중 높은 소리 | 2개 |

### 표 3. 두 중세 국어 자료 (p.131)
| 구분 | 세종어제훈민정음 | 용비어천가 |
|---|---|---|
| 성격 | 훈민정음 '예의' 부분 언해 | 악장(서사시) |
| 간행 | 『월인석보』 권1, 1459년(세조 5년) | 1447년(세종 29년) |
| 내용 | 훈민정음 창제 동기·목적 | 조선 선조들의 행적(제34장: 하늘의 도움) |

## 시험 함정 포인트
- 훈민정음 창제 시기는 **후기 중세 국어**(15~16세기)다. 전기 중세 국어는 10~14세기. (p.130)
- 언해본은 1446년 한문본 『훈민정음』의 **'예의'** 부분을 풀어 쓴 것이고, 실린 책은 **『월인석보』(1459)**다. (p.131)
- 방점은 글자 **왼쪽**에 찍는다. 점 1개는 **거성**, 2개는 **상성**, 평성은 점이 **없다**. (p.134)
- 팔종성법의 8개에는 **ㅅ과 ㆁ**이 있고 ㅇ이 아니다. 현대의 7개 받침에는 ㅅ 대신 **ㄷ**과 **ㅇ**이 들어간다. (p.135)
- '깊고', '높고'는 팔종성법의 **예외**(받침 ㅍ을 그대로 표기)다. (p.135)
- 중세 국어에는 주격 조사 **'가'가 없다**. 모음 뒤에서는 'ㅣ', 'ㅣ' 뒤에서는 생략. (p.136)
- '中듕國귁에 달아'의 '에'는 **비교**의 부사격 조사로, 현대어로는 '중국**과**'다. (p.136)
- '어엿브다'는 중세에 '**불쌍하다**', '어리다'는 '**어리석다**', '하다'는 '**많다**'라는 뜻이었다. (p.132, p.137)
- '사흘'은 **3일**이며 '사ᄋᆞᆯ'에서 **ㅎ 첨가, ㆍ→ㅡ** 변화를 겪었다. (p.138)
- 옛이응(ㆁ)이 'ㅇ'으로 완전히 통합된 것은 조선어학회의 「**한글 맞춤법 통일안**」 이후다. (p.135)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|

## 자기점검 질문
1. 국어사 시대 구분에서 후기 중세 국어의 시기는? — 15~16세기
2. 「세종어제훈민정음」이 실린 책과 간행 연도는? — 『월인석보』 권1, 1459년(세조 5년)
3. 현대 국어에서 쓰지 않는 중세 글자 예는? — ㆍ, ㆁ, ㆆ, ㅸ
4. 방점 2개가 나타내는 성조는? — 상성(처음 낮고 나중 높은 소리)
5. 'ᄉᆞᄆᆞᆺ디'에서 'ㅊ'이 'ㅅ'으로 적힌 이유는? — 팔종성법(종성에 8개 자음만 적음)
6. 중세 국어의 주격 조사 규칙은? — 자음 뒤 '이', ㅣ 외 모음 뒤 'ㅣ', ㅣ 뒤에서는 나타나지 않음
7. '나랏 말ᄊᆞ미'의 'ㅅ'은 어떤 조사인가? — 사물 명사 뒤에 쓰인 관형격 조사
8. '어엿브다'의 의미 변화는? — 불쌍하다 → 예쁘다
9. '펴디 → 펴지'는 어떤 변화인가? — 'ㅣ' 모음 앞에서 'ㄷ'이 'ㅈ'으로 바뀜
10. '사흘'의 변천은? — 15세기 '사ᄋᆞᆯ' → 16세기 '사흘'(ㅎ 첨가, ㆍ→ㅡ)
11. 오늘날 계속되는 국어 변화의 예 두 가지는? — 어두 된소리 발음(짝따), 줄임말 신조어(혼밥)
