# 3-(2) 작문 관습을 고려한 글쓰기
교과서 112~124쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 언어 공동체의 작문 관습을 이해하고, 자신의 글쓰기 과정에서 이를 고려할 수 있다. (p.112)
- 자신의 쓰기 과정과 전략을 점검하며 책임감 있는 태도로 글을 쓸 수 있다. (p.112)

## 핵심 개념

### 1. 글쓰기에서 고려할 사항 — 작문 관습과 작문 윤리 (p.112)
- **작문 관습**: 언어 공동체가 공유하는, 글의 종류에 따른 **전형적 구조·전개 방식·표현 방식**. 이를 따라야 효과적으로 소통 가능.
  - 해당 종류의 글에 일반적으로 활용되는 **형식과 표현**을 고려해야 함.
  - **예절을 중시하는 언어문화**를 반영하여 **독자를 존중·배려하는 표현**을 써야 함.
- **작문 윤리**: 책임감 있게 글을 쓰는 것.
  - **개인적 차원**: 생각·느낌·경험·의견 등을 **거짓으로 꾸미지 않고 진실(진솔)하게** 써야 함.
  - **사회적 차원**: 타인의 생각이나 자료를 **허락 없이 이용하지 않고 출처를 명확히** 밝혀야 함(**저작권 존중**).
- 오늘날 인터넷 매체에 글을 쓸 기회가 많고 **사회적 파급력**도 커져 책임감 있게 쓰는 태도가 꼭 필요.
- 생각 열기(요리 비유)
  - "많은 사람들이 모두 인정하는 김치찌개 맛있게 끓이는 방법을 따라 하면 실패하지 않지." → **작문 관습**
  - "파가 이렇게 많으니까 몰래 가져다 써도 눈치채지 못할 거야." → **작문 윤리** 위반(남의 것을 허락 없이 사용)

### 2. 제재 「양곡 창고, 예술의 산실로 변신하다」(이호준) — 기행문 (p.113~116)
- **글쓴이**: 이호준(1968~ ), 여행 작가이자 시인. 사라져 가는 것들의 뒷모습을 기록하려 전국을 떠돌며 씀. 『자작나무 숲으로 간 당신에게』, 『세상의 끝, 오로라』. (p.116)
- **갈래**: 기행문 — 삼례의 문화 예술촌을 다녀온 후 쓴 글. 작문 관습과 글쓰기 전략을 추론하며 읽기.
- **글의 흐름(여정)**
  1. **만경강**(도입, p.113): 계절이 깊어 가 푸른 강으로 가고 싶어짐("강은 세상 모든 푸른 것들의 고향"). 전북특별자치도 완주군 동상면 율치의 밤샘에서 발원, 새만금을 지나 바다로, 총 길이 **74km**, 김제·익산·군산을 지나 하천을 모음. 강과 길을 연인에 비유. → 삼례에서 멈춤: 꼭 가 보리라 벼르던 **문화 예술촌**이 있기 때문.
  2. **첫인상**(p.113~114): 무뚝뚝한 목재 창고 몇 동, 벽에 '협동 생산 공동 판매', '삼례 ≈≈ 창고' 글씨. 100년 가까이 **창고**로 쓰임.
  3. **역사**(p.114): 삼례는 토지가 비옥·기후 온화 → **일제 강점기 양곡 수탈 기지**의 수모. 삼례역은 군산으로 양곡을 나르는 **거점**. 주민들은 밤마다 "한 말 한 섬" 쌀 세는 소리를 들으며 잠듦.
  4. 양곡 창고를 개조한 **문화 복합 공간**, **원형 보전**에 역점 → 겉모습이 창고 그대로. **여섯 곳**의 문화 예술 공간이 독립 운영, 삼례역 이전 자리의 막사발 미술관을 합하면 **일곱 곳**.
  5. **미디어 아트 미술관**(p.114~115): 아날로그에서 디지털 세계로 떨어진 느낌, 창고 외관을 '배신'하듯 첨단 예술. **정크 아트**(일회용 빨대·링거 줄 등 쓰레기로 만든 작품), **인터랙티브 아트** 물속 체험(물고기가 되어 천으로 된 물속을 유영). 벽·천장 원형 그대로, 통나무 배열 자체가 예술, 바람이 잘 통하고 여름에 서늘하다고 함.
  6. **책 공방**(p.115): 책 읽기·나만의 책 만들기 체험 센터, 보기 어려운 인쇄 장비, 100년도 더 돼 보이는 **목궤선**은 국가유산급.
  7. **책 박물관**(p.115): '전라도 여자' 기획전, 프랑스어로 번역된 손바닥만 한 『춘향전』, 상설 전시 '**한국 북 디자인 100년**'(1883~1983). 화가들이 그린 표지 — 윤동주 『하늘과 바람과 별과 시』는 **김환기** 디자인, 1948년부터 30년간 교과서 삽화를 그린 **김태형** 코너의 '철수와 영희'.
  8. **목공소**(p.115): 조선 목수들의 철학이 스민 나무 가구 재현, 연장 전시. 짙은 나무 향 → 고향 소식을 들은 듯 반가움. 깔끔·조용, 담백해 마음이 편안.
  9. **디자인 박물관**(p.115~116): 한국산업디자인협회 공모전 수상작 갤러리(디자인·기능·경제성·기술 우수 제품), 젊은 방문객이 좋아함.
  10. **문화 카페**(p.116): 휴식 공간 + 커피 교육, 통유리 풍경이 매혹적.
  11. **마무리**(p.116): 다시 아날로그로, 삼례 성당·마당 조형물이 어우러짐. "오래된 것들은 누가 시키지 않아도 스스로 소통해서 친구가 된다." → **과거·현재·미래는 남남이 아니라 하나로 이어져 강물처럼 흘러간다**. 고통의 시대가 남긴 유산과 이 시대의 문화 예술이 **공존**.
- **표현상 특징**: 비유(동과 동 사이를 나비처럼 / 색다른 음식을 집어 먹는 기분 / 나무 향이 우르르 달려 나온다), 독자에게 말 건네듯한 표현("무슨 문화 예술촌이 이렇게 생겼어?"), 사진 자료 활용.
- 날개 질문: 삼례에 간 이유, 여행 경로 중심 정리, 미디어 아트 미술관에서 놀란 이유(창고 외관과 대비되는 첨단 예술), 문화 예술촌을 보고 느낀 점.
- 생각 키우기: 기행문으로 소개하고 싶은 여행지, 경험·느낌을 과장한 적과 그 이유. (p.116)

### 3. 학습 활동 1 — 작문 관습과 쓰기 과정 (p.117~118)
- 선생님 설명: 글쓰기의 **목적, 주제, 예상 독자, 글이 실릴 매체** 등을 고려해 **글의 종류**를 결정 → '**계획하기, 내용 생성하기, 내용 조직하기, 표현하기, 고쳐쓰기**'의 모든 과정에서 그 글의 종류와 관련된 작문 관습의 영향을 받음.
  - 예: 기행문은 **여정, 견문, 감상**의 구성 요소를 포함해 내용을 생성·조직하고, 여행에서 겪은 일과 감상을 **생생하고 솔직하게** 씀.
- **작문 계획서**: 글의 목적 — 완주 삼례의 문화 예술촌에서 보고 듣고 느끼고 생각한 바를 전달 / 예상 독자 — 역사와 문화 예술에 관심이 있는 사람, (여행을 계획하는 사람 등) / 글의 종류 — 기행문.
- **여정·견문·감상 정리**(p.118)
  | 여정 | 견문 | 감상 |
  |---|---|---|
  | 미디어 아트 미술관 | 정크 아트·인터랙티브 아트 체험, 바람이 잘 통하고 여름에 서늘하다는 이야기 | 디지털 세계로 떨어진 듯 놀라움 |
  | 책 공방 | 보기 어려운 인쇄 장비 | 목궤선은 국가유산 수준 |
  | 책 박물관 | 기획전, 북 디자인 100년 전시 | 화가들의 표지가 눈길을 끎 |
  | 목공소 | 나무 가구·연장 전시 | 고향 소식처럼 반가움, 마음이 편안 |
  | 디자인 박물관/문화 카페 | 수상작, 커피 교육 | 풍경이 매혹적 |
  | 마당 | 창고 건물·삼례 성당·조형물 | 과거·현재·미래가 하나로 이어짐 |

### 4. 학습 활동 2 — 작문 윤리 점검 (p.119)
- 보기: **작문 윤리는 책임감 있게 글을 쓰는 것** — 생각·경험을 거짓 없이 진실하게, **사실에 부합**하게 쓰기 / 타인의 자료를 **무단으로 베끼지 않고** 원저자의 **허락**을 받거나 **출처**를 명확히 밝히기.
- 작문 윤리 점검표 예: "만경강이나 삼례의 문화 예술촌을 보며 느낀 점을 과장해서 쓰지는 않았나?" + (만경강의 길이 등 사실 정보를 정확하게 썼는가? / 사진·자료를 가져왔다면 출처를 밝혔는가?)

### 5. 학습 활동 3 — 쓰기 과정과 전략 점검하며 인터넷 매체에 글쓰기 (p.119~121)
| 과정 | 하는 일 | 나의 작문 점검표 |
|---|---|---|
| **계획하기** | 글의 주제·목적·예상 독자 설정, 글의 종류와 관련된 작문 관습 고려 (예: 지역 축제 경험으로 시청 게시판에 건의문) | 목적에 맞는 예상 독자? 목적에 어울리는 주제문? 작문 관습·윤리 고려? |
| **내용 생성하기** | 주제 관련 여러 생각 떠올리기, 자료 수집 | 주제와 관련? 목적 달성에 도움? |
| **내용 조직하기** | 핵심 내용·자료를 체계적으로 배열해 전체 구조 정리(개요, 자료 활용 계획) | 작문 관습을 개요에 반영? 목적을 효과적으로 드러냄? 자료를 적절한 위치에 활용 계획? |
| **표현하기** | 초고 작성, 글의 종류에 따른 효과적 표현 전략과 작문 관습 고려 | 목적·개요 흐름 반영? 자료를 계획대로 활용? 독자와의 관계 고려한 표현? 표현 전략 활용? |
| **고쳐쓰기** | 문제점을 발견·개선해 완성도 높이기, 작문 관습·윤리 재점검 | 아래 평가 기준 |
- **고쳐쓰기 평가 기준**(p.121): 쓰임이 부적절한 단어 / 맞춤법·띄어쓰기 오류 / 문장 성분 간 호응·연결하는 말 / 문단 구분 / 주제에서 벗어난 문장 / 글의 종류와 관련된 작문 관습 위반 / **진솔하지 않게 쓴 부분이나 타인의 글을 베낀 부분**.

### 6. 대단원 내용 점검·통합 활동 (p.122~124)
- 협상: 쟁점과 **이해관계** 고려, **시작·조정·해결** 단계별 전략, 말의 **영향력**을 생각해 **책임감** 있게, **양보**와 **타협**으로 양쪽 모두 만족.
- 작문: 해당 종류 글의 **형식**과 **표현** 참고, **예절**을 중시하는 언어문화에 맞게 독자 존중, **진실**하게, 허락 없이 이용하거나 **표절**하면 안 됨.
- 공통: 말과 글의 영향력을 생각해 책임감을 갖고 언어생활 실천.
- 단원 통합 활동 '사회적 소통의 달인' 선발: 모범 사례(구단주와 협상에서 구단 입장까지 고려해 대안을 마련한 축구 선수 / 예의와 격식을 지키며 하고자 하는 말을 분명히 드러낸 편지 형식 건의문을 쓴 배우) → 선정 기준표(예: 상대를 존중하는 태도, 예의 바른 표현) 만들기.

## 비교·정리표

### 표 1. 작문 관습 vs 작문 윤리 (p.112, p.119)
| 구분 | 작문 관습 | 작문 윤리 |
|---|---|---|
| 뜻 | 언어 공동체가 공유하는 글 종류별 구조·전개·표현 방식 | 책임감 있게 글을 쓰는 것 |
| 내용 | 일반적 형식과 표현 따르기, 독자를 존중하는 표현 | 거짓 없이 진실하게, 사실에 부합, 출처 밝히기·무단 복제 금지 |
| 차원 | 소통의 효과성 | 개인적(진솔성)·사회적(저작권 존중) |
| 생각 열기 비유 | 검증된 김치찌개 조리법 따르기 | 남의 파를 몰래 가져다 쓰지 않기 |

### 표 2. 기행문의 구성 요소 (p.117~118)
| 요소 | 뜻 | 이 글의 예 |
|---|---|---|
| 여정 | 여행의 경로 | 만경강 → 삼례 → 미디어 아트 미술관 → 책 공방 → 책 박물관 → 목공소 → 디자인 박물관·문화 카페 → 마당 |
| 견문 | 보고 들은 것 | 정크 아트, 목궤선, 북 디자인 100년, 나무 가구 등 |
| 감상 | 느끼고 생각한 것 | 과거·현재·미래가 하나로 이어져 흐름 |

### 표 3. 쓰기 과정의 핵심 (p.119~121)
| 단계 | 핵심 |
|---|---|
| 계획하기 | 주제·목적·독자, 작문 관습 |
| 내용 생성하기 | 생각 떠올리기, 자료 수집 |
| 내용 조직하기 | 체계적 배열, 개요 |
| 표현하기 | 초고, 표현 전략 |
| 고쳐쓰기 | 문제 발견·개선, 관습·윤리 재점검 |

## 시험 함정 포인트
- 작문 관습은 개인의 습관이 아니라 **언어 공동체가 공유하는** 관습이다. 독자를 존중하는 표현도 작문 관습에 포함된다. (p.112)
- 진솔하게 쓰는 것은 작문 윤리의 **개인적 차원**, 저작권 존중은 **사회적 차원**이다. (p.112)
- 작문 관습은 계획하기 단계에만 적용되는 것이 아니라 **글쓰기의 모든 과정**에 영향을 준다. (p.117)
- 작문 관습·윤리 재점검은 **고쳐쓰기**에서도 다시 한다. (p.121)
- 감상을 **과장**해서 쓰는 것도 작문 윤리 위반이다(사실에 부합하지 않음). (p.119)
- 삼례의 창고는 일제 강점기 **양곡 수탈**과 관련된 아픈 역사를 지녔고, 삼례역은 **군산**으로 양곡을 나르는 거점이었다. (p.114)
- 문화 예술 공간은 **여섯 곳**이 독립 운영, 막사발 미술관을 더하면 **일곱 곳**이다. (p.114)
- 윤동주 시집 표지를 디자인한 사람은 **김환기**, '철수와 영희' 삽화 작가는 **김태형**이다. (p.115)
- 미디어 아트 미술관에서 놀란 이유는 **창고 그대로의 외관과 대비되는 첨단 예술** 때문이다. (p.114)
- 글의 주제는 '창고의 쓸모없음'이 아니라 **과거와 현재·미래가 하나로 이어져 공존**한다는 깨달음이다. (p.116)

| 여정 / 견문 / 감상 | 여행 경로 / 보고 들은 것 / 느끼고 생각한 것 |
| 거점 | 어떤 활동의 근거가 되는 중요한 지점 |
| 인터랙티브 아트 | 관객이 직접 참여할 수 있는 쌍방향 개념의 미술 |
| 정크 아트 | 쓰레기에서 건져 낸 재료로 만든 예술 |
| 유영 | 물속에서 헤엄치며 놂 |
| 목궤선 | 가계부 등에 줄을 긋는 기계 |
| 작문 계획서 | 글의 목적·주제·예상 독자·종류를 정리한 계획 |

| 개요 | 글의 전체 구조를 정리한 뼈대 |

## 자기점검 질문
1. 작문 관습이란? — 언어 공동체가 공유하는 글 종류별 구조·전개 방식·표현 방식
2. 작문 윤리의 개인적·사회적 차원은? — 거짓 없이 진솔하게 쓰기 / 타인의 저작권 존중
3. 기행문의 구성 요소 세 가지는? — 여정, 견문, 감상
4. 글쓴이가 삼례에 들른 이유는? — 꼭 한번 가 보리라 벼르던 문화 예술촌이 있어서
5. 삼례 창고에 얽힌 아픈 역사는? — 일제 강점기 양곡 수탈 기지, 삼례역은 군산으로 양곡을 나르는 거점
6. 글쓴이가 문화 예술촌에서 얻은 깨달음은? — 과거·현재·미래가 남남이 아니라 하나로 이어져 흘러간다
7. 글의 종류를 결정할 때 고려하는 것은? — 목적, 주제, 예상 독자, 글이 실릴 매체
8. 쓰기 과정 다섯 단계는? — 계획하기 → 내용 생성하기 → 내용 조직하기 → 표현하기 → 고쳐쓰기
9. 고쳐쓰기 평가 기준 중 작문 윤리와 관련된 것은? — 진솔하지 않게 쓴 부분이나 타인의 글을 베낀 부분은 없는가
10. 인터넷 매체 글쓰기에서 책임감이 특히 필요한 이유는? — 글을 쓸 기회가 많고 사회적 파급력이 커서
