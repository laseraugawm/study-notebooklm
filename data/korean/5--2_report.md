# 5-(2) 복합양식의 글 읽기와 쓰기
교과서 184~200쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 복합양식으로 구성된 글이나 자료에 담긴 글쓴이의 관점이나 의도, 표현 방법을 평가할 수 있다. (p.184)
- 신뢰할 수 있는 정보를 종합하여 복합양식 자료가 포함된 공동 보고서를 협동적으로 쓸 수 있다. (p.184)

## 핵심 개념

### 1. 복합양식과 공동 보고서 (p.184)
- **복합양식**: 문자, 그림, 표, 그래프, 사진, 동영상 등 **여러 양식이 복합적으로 작용하여 의미를 구성**하는 것.
- 글쓴이는 자신의 **관점이나 의도**를 바탕으로 다양한 양식의 자료를 활용해 복합양식의 글을 구성 → 독자는 글과 자료에 담긴 **관점, 의도, 표현 방법**을 평가해야 함.
- 다양한 글·자료에서 얻은 정보를 효과적으로 전달하려면 **보고서 형식** 활용. 협력적으로 공동 보고서를 쓸 때는 **신뢰할 수 있는 정보를 종합**하여 복합양식을 활용하는 것이 효과적.
- 생각 열기(학교 누리집 기사 취재): 우승까지의 과정을 시간 순서로 정리한 **표** / 우승 학생들의 심정을 인터뷰한 **글** / 기쁜 표정을 찍은 **영상과 사진** → 각 자료가 기사에서 하는 역할.

### 2. 활동 1 — 복합양식으로 구성된 글 읽기 (p.185~188)
#### 기획 기사 「해양 생물과 인류를 위협하는 독약 '미세 플라스틱'」(김≈≈ 기자)
- **1문단**(p.185): 플라스틱 쓰레기는 재활용보다 소각·투기되는 양이 훨씬 많고(동영상 「우리가 몰랐던 플라스틱 이야기」, 세계자연기금[WWF], 2021년), 처리되지 않은 쓰레기는 **바다**에 모임 → 자외선 노출·충돌로 부서져 **미세 플라스틱**이 됨. 세계자연보전연맹[IUCN] 보고서: 바다 유입 미세 플라스틱 **연간 100만 톤**, 그중 **합성 섬유**가 **35%**로 가장 높음.
  - **그래프**(IUCN, 2017년) 해양 유입 미세 플라스틱 요인: 합성 섬유(세탁물) **35.0%**, 타이어 **28.0%**, 도시 먼지 **24.0%**, 도로 도색 7.0%, 선박 코팅 3.7%, 개인 관리 용품 2.0%, 플라스틱 운반함 0.3%
- **2문단**(p.186): 미세 플라스틱은 물속 오염 물질(특히 **잔류성 유기 오염 물질**, **중금속**)을 빨아들임 → '**화학 물질의 혼합물**'. 제조 과정에서 첨가된 수천 종의 화학 물질이 쪼개지며 새어 나옴. 예: 식품 용기·비닐 랩의 **폴리염화 비닐**은 고온·빛에 오래 노출되면 **프탈레이트**(환경 호르몬의 일종, 생식 기관에 유해한 독성 물질) 유출 → 해양 생물의 **내분비 계통 교란**, 개체 수 감소 가능성. 2018년 야생 **병코돌고래 12마리** 소변에서 프탈레이트 검출.
- **3문단**(p.186): 해양 생물이 먹이로 착각해 섭취 → **먹이 사슬**을 거쳐 상위 포식자로 이동·잔류 → 생선·홍합·굴 등 해산물에서 검출 → 인체에 악영향.
  - **그림**(한국해양과학기술원[KMI], 2019년) 「플라스틱이 우리 식탁에 오르는 과정」: 바다에 버려진 플라스틱 쓰레기 → 잘게 부서진 미세 플라스틱 → 미세 플라스틱을 먹은 해양 생물 → 먹이 사슬을 통해 상위 포식자로 이동 → 사람이 섭취하는 해산물에서 검출
- **4문단**(p.187): WWF와 호주 뉴캐슬대학교 「플라스틱의 인체 섭취 평가 연구」: 한 사람이 **일주일에 약 5g**(신용 카드 한 장 크기) 섭취. 혈액·장기에서도 검출. 대부분 배출되지만 묻어 들어온 **독성 물질**과 **나노 플라스틱**은 몸 안에 잔류해 질병 유발 가능. (사진: 해변에서 발견된 미세 플라스틱)
- **5문단**(p.187): **2050년**에는 바닷속 플라스틱 무게가 전체 물고기 무게보다 더 나갈 것이라는 예측. 지구 표면의 **3/4**인 해양 생태계가 오염되면 인류는 안전할까? 방치하면 후폭풍이 훨씬 클 것.
- 댓글: 플라스틱 사용을 줄여야겠다 / 합성 섬유 비중이 크다는 게 충격 / 합성 섬유를 아예 안 쓸 수도 없어 난감.
- 날개 질문: 표제에서 '**독약**'이라 표현한 이유(해양 생물과 인류에 치명적 위협), '화학 물질의 혼합물'의 의미, 미세 플라스틱 섭취가 질병을 유발할 수 있다고 보는 이유(독성 물질·나노 플라스틱 잔류).

#### 학습 활동 (p.188)
1. **중심 내용과 관점 파악**: 문단별 정리 → 글쓴이의 관점: 미세 플라스틱이 해양 생태계를 교란하고 인간의 건강을 위협한다는 점에서 (심각한 문제이며 대책이 필요하다).
2. **복합양식 자료 분석**
   | 자료 | 주요 내용 | 글쓴이의 활용 의도 |
   |---|---|---|
   | 동영상 | 플라스틱 쓰레기는 재활용보다 소각·투기가 많음 | 문제의 심각성을 생생하게 제시 |
   | 그래프 | 해양 유입 미세 플라스틱 요인별 비중(합성 섬유 35%) | 요인을 수치로 객관적으로 제시 |
   | 그림 | 버려진 플라스틱이 바다를 거쳐 식탁에 오르는 과정 | 먹이 사슬 과정을 한눈에 이해 |
   | 사진 | 해변에서 발견된 미세 플라스틱 | 실제 모습을 보여 실감을 높임 |
3. **타당성과 신뢰성 평가 항목**
   - 글쓴이의 **주장과 근거는 타당**한가?
   - 활용된 자료는 글쓴이의 **의도나 관점을 효과적으로 표현**했는가?
   - 자료의 **출처가 명확**하며 **신뢰**할 수 있는가?

### 3. 활동 2 — 복합양식의 공동 보고서 쓰기 과정 (p.189~193)
- **공동 보고서**: 특정한 주제에 관심이 있는 사람들이 함께 모여 어떤 **목적**을 가지고 **관찰, 조사, 답사, 연구, 실험** 등을 수행한 뒤 그 **절차와 결과**를 정리하여 정보를 전달하는 글. (p.189)

#### (1) 주제와 목적 찾기 (p.189)
- 환경 동아리(상민, 지연, 민호, 수지)가 동아리 학술제 발표용 보고서 작성.
- 주제 후보: **합성 섬유 미세 플라스틱 배출의 문제점과 해결책** / 물티슈 사용에 대한 학생 인식과 실태 / 학급 페트병 쓰레기 양과 문제점.
- 선정 근거: 기사 자료에서 합성 섬유 세탁물 비중이 가장 높았음 → 다양한 자료 수집 후 복합양식 활용.
- 주제를 정할 때 고려할 점: 모둠원의 **공통 관심**, 관찰·조사 등으로 **수행 가능한지**, 목적이 분명한지.

#### (2) 주제에 따른 목차 구성 (p.190)
- 대화: 주제를 명확히 제시하고 **선정 이유**를 먼저 → 조사 방법 → 조사 결과 정리 → 해결 방안.
- **조사 방법**: **자료 조사**(상민), **설문 조사**(민호).
- **역할 분담**: 상민 — 자료 조사 / 민호 — 설문 조사 / 지연·수지 — 조사 결과 정리와 시각 자료 구성.
- **목차**: 1. 조사의 필요성과 목적 / 2. 조사 방법 / 3. 조사 결과 (1) 자료 조사 결과 (2) 설문 조사 결과 / 4. 결론 및 제언
- **조사 보고서의 구성 요소**(3부분)
  1. 기초적 사항: **조사의 필요성과 목적, 조사 방법**
  2. **조사 결과와 해석** — 보고서의 **핵심**
  3. **결론**: 조사 내용 요약 정리, **제언**

#### (3) 자료 수집하고 조직하기 (p.191)
| 자료 | 내용·출처 | 활용 위치 |
|---|---|---|
| 자료 ➊ | 세탁 시 발생하는 미세 플라스틱의 양 그래프(합성 섬유 의류 6kg 세탁 시 — 폴리에스테르+면 혼방 132,951개, 폴리에스테르 496,030개, 아크릴 728,789개), 영국 플리머스대학교, 2016년 | 조사 결과 (1) — 4쪽 |
| 자료 ➋ | 미세 플라스틱이 인체에 축적될 때의 악영향에 관한 **전문가 인터뷰 동영상**, 『한국방송공사(KBS) 뉴스』, 2019년 5월 21일 | 조사의 필요성 — 2쪽(건강 위협 강조) |
| 자료 ➌ | 우리 학교 학생 **설문 조사 결과** | 조사 결과 (2) — 5쪽(경각심) |
| 자료 ➍ | 해양 유입 미세 플라스틱 요인 그래프, IUCN, 2017년('활동 1' 기사에서 인용) | 조사의 필요성 — 2쪽 |
- 자료의 **신뢰성**을 **출처**를 고려해 평가(대학 연구, 공영 방송 뉴스, 국제기구).

#### (4) 완성된 공동 보고서 (p.192~193)
- 필자: 풀빛고등학교 환경 동아리(김상민, 박지연, 이민호, 최수지)
- **조사의 필요성**: 해양 유입 요인 중 합성 섬유(세탁물) 비중이 가장 큼 / 합성 섬유 미세 플라스틱에서 유해 물질 유출 → 해양 생물 개체 수 감소, 건강 위협.
- **조사의 목적**: 합성 섬유에서 발생하는 미세 플라스틱의 양과 문제점, 학생들의 인식 파악 → **의생활**과 관련해 미세 플라스틱 발생을 줄이는 방안 마련.
- **조사 방법**
  - 자료 조사: 20XX년 11월 1일~10일, **문헌 조사 및 인터넷 조사**, 합성 섬유 세탁 시 미세 플라스틱 양과 문제점 해결 방안
  - 설문 조사: 20XX년 11월 7일~11일, 풀빛고 **1학년 80명**, 합성 섬유 이용과 미세 플라스틱 배출에 대한 인식
- **조사 결과 (1) 자료 조사**
  - 6kg 세탁 시 미세 플라스틱: 폴리에스테르+면 혼방 137,951개(보고서 표기, 자료 ➊에는 132,951개로 표기) / 폴리에스테르 496,030개 / 아크릴 728,789개 → **천연 섬유가 섞인 의류**에서 배출량이 크게 줄어듦.
  - 40°C 물·85분 세탁 대비 **25°C 물·30분** 세탁 시 배출량 **52% 감소** → 낮은 온도, 짧은 세탁 시간에 크게 줄어듦.
- **조사 결과 (2) 설문 조사**
  - 합성 섬유 옷을 많이 입는가? 그렇다 22.5%, 아니다 12.5%, **모른다 65%** → 옷의 **소재를 확인하지 않음**.
  - 합성 섬유에서 미세 플라스틱이 배출되는 것을 아는가? 알고 있다 22.5%, **모른다 77.5%** → 알았다면 이용을 줄였을 것이라는 응답 많음 → **교육과 홍보** 필요.
- **결론 및 제언**: 천연 섬유가 섞인 상품 구입 / 낮은 물 온도에서 짧게 세탁 / 인식 개선을 위한 교육·홍보 → 결론: 합성 섬유 미세 플라스틱을 줄이려면 **우리들의 관심과 실천**이 필요.
- **평가 기준**(p.193): 내용 및 표현(주제·목적이 드러남, 방법·결과가 체계적, 보고서 형식에 맞는 조직, 복합양식 자료의 적절·효과적 제시) / **쓰기 윤리**(표절하지 않고 출처를 정확히, 사실 아닌 내용·과장 없음).

### 4. 활동 3 — 우리 모둠의 공동 보고서 쓰기 (p.194~197)
1. 주제와 목적 찾기: 각자 관심 분야 주제 → 모둠의 주제·목적 결정.
2. 목차 구성: 자료 조사 방법 계획과 **역할 분담**(보고서를 뒷받침할 다양한 복합양식 자료 탐색) → 목차 정리.
3. 자료 수집하고 조직하기: 자료별 수집 방법·내용·출처 정리 → **신뢰성 평가**(자료의 내용은 정확한가? 사실을 **과장, 왜곡, 축소**하지 않았는가? 출처가 명확한가?) → 불필요한 자료·추가 수집 자료 판단.
4. 공동 보고서 작성: **객관적 관점**을 유지하며 조사 결과를 과장·왜곡·축소하지 않기, 불필요한 수식어를 줄이고 **간결하고 명료하게**, 인용 자료의 **출처를 명확히**. (p.196)
5. 평가·보완: 내용 및 표현 / 쓰기 윤리 / **모둠원 평가**(각자 역할 수행, 의견 교환과 조율, 협력적 문제 해결).
- 생각 키우기: 일상에서 복합양식 글·자료를 접하는 상황, 공동 보고서 쓰기를 적용할 교과목. (p.197)

### 5. 대단원 마무리 (p.198~200)
- 내용 점검: 1 표현 방법의 효과와 적절성 평가 = **형식 측면**의 비평 / 2 여러 양식이 복합적으로 의미를 구성 = **복합양식** / 3 관찰·조사 등을 수행해 절차와 결과를 전달하는 글 = **공동 보고서** / 4 복합양식 글은 관점과 의도, **표현 방법**을 평가 / 5 자료 수집 시 정보의 **신뢰성** 판단.
- 단원 통합 활동: 복합양식을 활용한 **영화 인물 비평 보고서** — 탐구할 인물 선정(영화 제목, 인물 사진, 신상 정보, 선정 이유) → 인물의 특성이 드러난 장면 찾아 탐구.

## 시험 함정 포인트
- 해양 유입 미세 플라스틱 요인 1위는 타이어가 아니라 **합성 섬유(세탁물) 35%**, 2위 타이어 28%, 3위 도시 먼지 24%. (p.185)
- 프탈레이트는 **폴리염화 비닐**에서 고온·빛에 노출될 때 새어 나오는 **환경 호르몬**이다. (p.186)
- 몸 안에 잔류해 질병을 유발할 수 있는 것은 미세 플라스틱 알갱이 대부분이 아니라 **독성 물질과 나노 플라스틱**이다(대부분의 알갱이는 배출됨). (p.187)
- 공동 보고서의 **핵심** 부분은 서론이 아니라 **조사 결과와 해석**이다. (p.190)
- 자료 ➍(IUCN 그래프)는 조사 결과가 아니라 **조사의 필요성**에서 인용한다. (p.191)
- 설문 조사에서 배출 사실을 **모르는** 학생이 77.5%, 착용 여부를 **모르는** 학생이 65%다. (p.193)
- 미세 플라스틱 배출을 줄이는 조건은 **천연 섬유 혼방**, **낮은 물 온도**, **짧은 세탁 시간**이다. (p.193)
- 보고서 작성 시 조사 결과를 **과장·왜곡·축소**하지 말고 **간결·명료**하게, 출처를 밝혀야 한다. (p.196)
- 혼방 의류 수치가 자료 ➊(132,951개)과 완성 보고서(137,951개)에서 **다르게 표기**되어 있다 — 자료와 보고서 내용의 일치를 점검하는 것도 보고서 평가 요소다. (p.191, p.193)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 복합양식 | 문자·그림·표·그래프·사진·동영상 등이 복합적으로 의미를 구성하는 것 |
| 공동 보고서 | 여럿이 목적을 가지고 관찰·조사·답사·연구·실험 후 절차와 결과를 정리해 전달하는 글 |
| 미세 플라스틱 | 플라스틱이 잘게 쪼개진 미세한 알갱이 |
| 잔류성 유기 오염 물질 | 자연에서 분해되지 않고 먹이 사슬을 거쳐 동식물 체내에 축적되는 유해 물질 |
| 내분비 계통 | 호르몬을 만들어 분비하는 여러 특수한 샘으로 이루어진 동물체의 계통 |
| 프탈레이트 | 환경 호르몬의 일종, 생식 기관에 유해한 독성 물질 |
| 나노 플라스틱 | 미세 플라스틱보다 더 작게 분해된 입자 |
| 신뢰성 | 정보·자료를 믿을 수 있는 정도(출처, 정확성) |
| 타당성 | 주장과 근거가 이치에 맞는 정도 |
| 자료 조사 | 문헌·인터넷 등에서 자료를 찾는 조사 |
| 설문 조사 | 대상에게 질문지로 의견을 묻는 조사 |
| 제언 | 조사를 바탕으로 의견이나 방안을 내놓음 |
| 쓰기 윤리 | 표절하지 않고 출처를 밝히며, 사실이 아닌 내용·과장을 쓰지 않음 |

## 자기점검 질문
1. 복합양식이란? — 여러 양식이 복합적으로 작용하여 의미를 구성하는 것
2. 복합양식 글을 읽을 때 평가할 세 가지는? — 글쓴이의 관점, 의도, 표현 방법
3. 기사 표제에서 미세 플라스틱을 '독약'이라 한 이유는? — 해양 생물과 인류의 건강을 치명적으로 위협하기 때문
4. '화학 물질의 혼합물'이라는 표현의 의미는? — 오염 물질을 빨아들이고 첨가 화학 물질도 새어 나와 여러 화학 물질이 섞인 상태
5. 미세 플라스틱이 사람에게 돌아오는 과정은? — 바다 → 미세 플라스틱 → 해양 생물 섭취 → 먹이 사슬로 상위 포식자 → 해산물 → 사람
6. 복합양식 글의 타당성·신뢰성 평가 항목 세 가지는? — 주장과 근거의 타당성, 자료의 효과적 표현, 출처의 명확성과 신뢰성
7. 조사 보고서의 세 부분은? — 필요성·목적·방법 / 결과와 해석 / 결론(요약·제언)
8. 환경 동아리가 택한 조사 방법 두 가지는? — 자료 조사(문헌·인터넷), 설문 조사
9. 미세 플라스틱 배출을 줄이는 실천 방안은? — 천연 섬유 혼방 의류 구입, 낮은 온도·짧은 시간 세탁, 교육·홍보
10. 공동 보고서 작성 시 지켜야 할 점은? — 객관적 관점, 과장·왜곡·축소 금지, 간결·명료한 표현, 출처 명시
11. 모둠원 평가 항목은? — 역할 수행, 의견 교환과 조율, 협력적 문제 해결
