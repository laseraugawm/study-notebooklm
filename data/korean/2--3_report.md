# 2-(3) 현대 시의 시선
교과서 69~75쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 문학사와 시대적 상황의 관계에 대한 이해를 바탕으로 현대 시 작품을 감상할 수 있다. (p.69)
- 특정 요소를 중심으로 관련 있는 현대 시 작품들을 찾아 비교하며 감상하는 태도를 기를 수 있다. (p.69)

## 핵심 개념

### 1. 현대 시의 흐름 (p.69)
- 근대를 지나며 **노래와의 연관성이 사라지고 자유시가 형성** → 이름에서도 '가(歌)'가 떨어져 시가(詩歌) 문학이 **시(詩) 문학**이 됨.
- **1920년대**: 전통적인 **민요조의 운율에 개인적 정서**를 결합하는 흐름이 강함.
- **1930년대**: 한층 다양한 시적 경향 등장 → **현대 시 확립**.
- **해방 전까지**: **민족주의적 저항시**와 **자기 성찰적인 시**가 많이 창작.
- **해방 이후**: 전쟁·산업화·민주화를 겪으며 **현실 참여적·문명 비판적** 시와 **순수 서정**의 시가 공존.
- **오늘날**: 실험적이고 파격적인 작품을 비롯해 매우 다양한 형식과 내용.
- 생각 열기(시의 성격·역할에 관한 두 주장)
  - "시는 우리 시대의 아픔과 더 나은 세상의 모습을 노래하는 것이어야 한다." (현실 참여)
  - "시는 맑고 고운 내면의 아름다움과 순수한 이상을 노래하는 것이어야 한다." (순수 서정)
  - → "시는 ______." 자신의 생각 적기

### 2. 「자화상」 — 윤동주 (p.70~71)
- **시인**: 윤동주(1917~1945). 일제 강점기의 암울한 현실을 살아가는 **지식인의 고뇌**를 **순수한 감성과 성찰적 태도**로 표현. 「서시」, 「참회록」, 유고 시집 『하늘과 바람과 별과 시』. (p.71)
- **갈래·성격**: 현대 자유시, 산문시적 형태, 성찰적·고백적
- **화자**: 우물에 비친 자신(사나이)을 들여다보는 '나'
- **시적 대상**: 우물 속의 **사나이** = 화자 자신(자아)
- 교과서 안내: 우물을 통해 자신을 **성찰**하며 느낀 감정을 노래한 시. 일제 강점기의 암담한 시대 현실과 관련한 **시인의 자아 인식**에 주목. (p.70)
- **시상 전개**(행동과 심리의 변화, 학습 활동 1, p.72)
  | 화자의 행동 | 화자의 심리 |
  |---|---|
  | 외딴 우물을 찾아가 비친 사나이를 봄 | 그 사나이가 **미워짐** |
  | 우물 앞을 떠나 돌아감 | 그 사나이가 **가엾어짐** |
  | 도로 우물에 가서 들여다봄 | 다시 그 사나이가 **미워짐** |
  | 다시 떠나 돌아감 | 그 사나이가 **그리워짐** |
- 마지막 연: 우물 속 풍경이 다시 나오고 "**추억처럼** 사나이가 있습니다" → 미움·연민을 거쳐 자신을 **받아들이고 화해**하는 마음.
- **'우물'의 기능**: 자신의 모습을 비추어 보는 **성찰의 매개체**(거울 역할). (p.73)
- **우물 속 풍경**: "달이 밝고 구름이 흐르고 하늘이 펼치고 파아란 바람이 불고 가을이 있습니다" → 맑고 아름다운 **이상 세계**. 그 속의 사나이(현실의 자아)와 대비.
- **정서가 계속 변하는 까닭**(학습 활동 2, p.73 설명)
  - 윤동주는 순수하고 아름다운 이상 세계를 동경한 청년.
  - 그러나 민족의 고통 앞에서 그런 지향을 품는 것이 지식인으로서 **시대적 책임을 외면**하는 것 같아 **부끄러움**을 느낌.
  - 비극적 인식 → 치열한 **자기 성찰** → **자기혐오**(미움)와 **자기 연민**(가엾음) 사이의 **갈등**.
- **표현상 특징**(학습 활동 3, p.74)
  - 산문 같은 말투지만 **운율**이 있음
    - '**-ㅂ니다**'라는 종결 어미의 반복(경어체, 고백적 어조)
    - **2연의 내용이 6연에 거의 그대로 반복**(수미상관)
    - '**-고**'로 연결되는 구조의 반복(달이 밝고 구름이 흐르고…)
  - "**파아란 바람**": 바람(촉각)을 색채(**시각**)로 표현한 공감각적·시각화 표현. 표준어 '파란'이 아닌 **어법에 어긋나는 시어**지만 낭송하면 더 아름답고 우물 속 풍경의 **동화적인 분위기**를 부각.
  - 미워짐 ↔ 가엾어짐 ↔ 그리워짐의 반복 → 화자의 심리적 갈등.
- **주제**: 자기 성찰을 통한 자아 인식(자기혐오와 연민을 거쳐 자신을 받아들임)
- 생각 키우기: 거울 속 '나'에게 해 주고 싶은 말. (p.71)
- 학습 활동 4: 윤동주의 삶과 문학을 소재로 한 문화 콘텐츠를 경험하고 소감을 SNS에 올리기. (p.74)

### 3. 「저문 강에 삽을 씻고」 — 정희성 (학습 활동 5, p.75)
- **발표**: **1978년**. 근대화·산업화·도시화가 급속히 추진되던 **1970년대** 작품.
- **화자**: 하루의 고된 노동을 마친 저녁, 강가에서 삽을 씻으며 지나온 삶을 돌아보는 **중년 사내**(노동자).
- **시적 상황**: 저물녘 강변에 나가 삽을 씻고, 쭈그려 앉아 담배를 피우며 흐르는 강을 바라봄. (p.75)
- 교과서 해설: **소외된 민중의 아픔**을 **차분하고 정제된 어조**로 노래.
- 핵심 구절
  - "흐르는 것이 물뿐이랴" → 설의법, 흐르는 강물처럼 삶(세월)도 흘러감.
  - "**우리가 저와 같아서**"(반복) → 우리 삶이 저물어 가는 강물과 같다는 인식, 개인이 아닌 '**우리**'(민중) 전체의 삶으로 확장.
  - "거기 슬픔도 퍼다 버린다" → 삽으로 노동의 슬픔을 씻어 냄.
  - "삽자루에 맡긴 한 생애가 / 이렇게 저물고, 저물어서" → 노동으로 보낸 일생이 저물어 감(하루의 저묾 = 인생의 저묾).
  - "샛강 바닥 썩은 물에 / 달이 뜨는구나" → 어둡고 썩은 현실 속에서도 떠오르는 달(희미한 희망).
  - "먹을 것 없는 사람들의 마을로 / 다시 어두워 돌아가야 한다" → 가난한 현실로 돌아가야 하는 체념 섞인 의지.
- '우리가 저와 같아서'의 의미: 화자는 자신의 삶을 **흐르고 저물어 가는 강물**처럼 고달프고 덧없는 것으로 인식.

### 4. 두 작품 비교 — 화자의 자아 인식 (p.75)
- 「자화상」: 일제 강점기, 지식인의 **부끄러움과 자기 성찰** → 개인 내면의 자아 인식.
- 「저문 강에 삽을 씻고」: 1970년대 산업화 시기, **소외된 민중(노동자)**의 삶 → '우리'라는 공동체적 자아 인식.

## 비교·정리표

### 표 1. 「자화상」 vs 「저문 강에 삽을 씻고」 (p.70~75)
| 구분 | 자화상 | 저문 강에 삽을 씻고 |
|---|---|---|
| 시인 | 윤동주 | 정희성 |
| 시대 | 일제 강점기 | 1970년대(1978년 발표), 산업화 |
| 화자 | 우물을 들여다보는 '나'(지식인) | 강가에서 삽을 씻는 중년 사내(노동자) |
| 매개물 | 우물 | 강(흐르는 물) |
| 정서 | 미움·연민·그리움의 갈등 → 화해 | 슬픔, 체념, 차분함 |
| 자아 인식 | 개인적 자기 성찰 | 소외된 민중으로서의 '우리' |
| 어조 | 고백적('-ㅂ니다') | 차분하고 정제됨 |

### 표 2. 현대 시의 시기별 경향 (p.69)
| 시기 | 경향 |
|---|---|
| 1920년대 | 민요조 운율 + 개인적 정서 |
| 1930년대 | 다양한 시적 경향, 현대 시 확립 |
| 해방 전 | 민족주의적 저항시, 자기 성찰적 시 |
| 해방 이후 | 현실 참여·문명 비판 시와 순수 서정 시의 공존 |
| 오늘날 | 실험적·파격적, 다양한 형식과 내용 |

### 표 3. 「자화상」의 운율 형성 요소 (p.74)
| 요소 | 예 |
|---|---|
| 종결 어미 반복 | '-ㅂ니다' |
| 연의 반복 | 2연 ≒ 6연 |
| 연결 어미 반복 | '-고'(밝고, 흐르고, 펼치고, 불고) |
| 심리어 반복 | 미워져 / 가엾어집니다 / 그리워집니다 |

## 시험 함정 포인트
- 「자화상」의 '사나이'는 타인이 아니라 우물에 비친 **화자 자신**이다. (p.73)
- 화자의 심리는 미워짐 → **가엾어짐** → 미워짐 → **그리워짐** 순서다. '가엾어짐'과 '그리워짐'의 순서를 바꾸지 말 것. (p.71~72)
- 정서 변화의 원인은 **자기혐오와 자기 연민 사이의 갈등**이며, 그 바탕은 시대적 책임을 외면하는 것 같은 **부끄러움**이다. (p.73)
- 「자화상」은 산문 같은 말투지만 운율이 **없는 것이 아니다**. '-ㅂ니다', 2연·6연 반복, '-고' 반복으로 운율이 생긴다. (p.74)
- '파아란'은 표준어가 아닌 **어법에 어긋나는 시어**지만 오히려 아름다움과 동화적 분위기를 살린다. (p.74)
- 마지막 연에는 '**추억처럼**' 사나이가 있다 — 2연과 거의 같지만 이 부분이 달라 화해의 의미가 생긴다. (p.71)
- 「저문 강에 삽을 씻고」는 **1978년** 발표, 1970년대 **산업화** 시기 작품이다. 어조는 격앙이 아니라 **차분하고 정제된** 어조다. (p.75)
- '우리가 저와 같아서'의 '저'는 **흐르는 강물**을 가리킨다. (p.75)
- 시가가 '시'가 된 것은 근대를 지나며 **노래와의 연관성이 사라졌기** 때문이다. 현대 시 확립은 1920년대가 아니라 **1930년대**. (p.69)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 자유시 | 노래와의 연관성이 사라진 뒤 형성된 정형에 얽매이지 않는 시 |
| 민요조 운율 | 전통 민요의 운율(1920년대 시에 강하게 나타남) |
| 저항시 | 해방 전 민족주의적 성격의 시 |
| 자기 성찰 | 자신을 돌아보고 살핌(「자화상」의 핵심 태도) |
| 자기혐오 | 자신을 미워하는 감정 |
| 자기 연민 | 자신을 가엾게 여기는 감정 |
| 우물 | 「자화상」에서 자신을 비추어 보는 성찰의 매개체 |
| 사나이 | 우물에 비친 화자 자신 |
| 시적 상황 | 화자가 처한 장소·행동·처지 |
| 순수 서정 | 맑고 고운 내면과 순수한 이상을 노래하는 경향 |
| 현실 참여 | 시대의 아픔과 더 나은 세상을 노래하는 경향 |
| 소외된 민중 | 산업화 속에서 밀려난 노동하는 사람들(「저문 강에 삽을 씻고」) |

## 자기점검 질문
1. 시가 문학이 '시 문학'이 된 이유는? — 근대를 지나며 노래와의 연관성이 사라지고 자유시가 형성되어서
2. 현대 시가 확립된 시기는? — 1930년대
3. 「자화상」에서 우물의 기능은? — 자신을 비추어 성찰하게 하는 매개체
4. 「자화상」 화자의 심리 변화 순서는? — 미움 → 가엾음 → 미움 → 그리움
5. 화자의 정서가 계속 바뀌는 이유는? — 자기혐오와 자기 연민 사이의 갈등(시대적 책임을 외면하는 듯한 부끄러움)
6. 「자화상」의 운율을 만드는 요소 세 가지는? — '-ㅂ니다' 반복, 2연과 6연의 반복, '-고' 연결 구조 반복
7. '파아란 바람'의 표현 효과는? — 바람을 시각화해 우물 속 풍경의 동화적 분위기를 부각
8. 「저문 강에 삽을 씻고」 화자의 시적 상황은? — 하루 노동을 마친 저녁 강가에서 삽을 씻으며 삶을 돌아봄
9. '우리가 저와 같아서'에 담긴 화자의 삶에 대한 인식은? — 우리 삶이 흐르고 저물어 가는 강물처럼 고달프고 덧없다
10. 두 시의 창작 의도 차이는? — 「자화상」은 일제 강점기 지식인의 자기 성찰, 「저문 강…」은 산업화 시기 소외된 민중의 아픔

## 보완 노트 (외부 리뷰 1차 · deepseek)
- **빠진 내용** 「자화상」의 '우물'이 하는 기능에 대한 학습 활동 문항(설명하기) — 학습 활동 2-(2)에서 '우물'의 기능을 설명하는 문항이 제시되어 있으므로, 우물의 기능을 서술하는 활동이 포함되어야 한다. (p.73)
- **빠진 내용** 「자화상」 감상 평 쓰기 활동(학생 대화 참고 후 자신만의 해석·평가 담은 감상 평) — 학습 활동 3에서 학생들의 감상 대화를 참고하여 자신만의 해석과 평가를 담은 감상 평을 적는 활동이 제시되어 있다. (p.74)
- **빠진 내용** 「저문 강에 삽을 씻고」와 「자화상」의 창작 의도 비교 문항 — 학습 활동 5-(3)에서 두 작품이 창작된 각각의 시대적 상황과 관련지어 창작 의도를 비교하는 활동이 제시되어 있다. (p.75)
- **바로잡기** '「자화상」의 '우물 속 풍경'을 '맑고 아름다운 이상 세계'로 단정하고, 그 속의 사나이(현실의 자아)와 대비된다고 서술' → 교과서는 우물 속 풍경 자체를 '이상 세계'라고 규정하지 않고, 우물을 통해 자신을 성찰하며 느낀 감정을 노래한 시로 안내하며 일제 강점기의 암담한 시대 현실과 관련한 시인의 자아 인식에 주목하라고 제시한다. (p.70)
- **바로잡기** '「자화상」의 주제를 '자기 성찰을 통한 자아 인식(자기혐오와 연민을 거쳐 자신을 받아들임)'으로 확정 서술' → 교과서는 주제를 직접 제시하지 않고, 자기 성찰과 자기혐오·자기 연민 사이의 갈등이 드러나 있다고 설명할 뿐이므로, 화해·수용까지 단정하지 않는다. (p.73)
