# 1-(1) 사회적 독서 활동에 참여하기
교과서 12~19쪽 · 국어(공통국어2, 지학사)

## 학습 목표
- 의미 있는 사회적 독서 활동에 참여하여 타인과 교류하고 다양한 지식이나 정보, 삶의 가치관 등을 이해할 수 있다. (p.12)
- 독서를 통해 사회적 문제를 인식하고 구성원들과 협력하여 사회적 문제의 해결 방안을 마련할 수 있다. (p.12)

## 핵심 개념

### 1. 사회적 독서 활동이란
- **사회적 독서 활동**: 독서를 하고 얻게 된 지식이나 정보를 독서 모임 등을 통해 다른 사람과 공유하는 활동. 이를 통해 타인의 다양한 삶의 방식과 가치관을 이해할 수 있다. (p.12)
- 사회적 독서 활동의 효과 (p.12)
  1. 지식이나 정보를 교류하며 다양한 삶의 방식과 가치관을 이해함.
  2. 독서를 통해 우리 사회의 문제를 인식하고, 타인에 대한 이해의 폭을 넓힘.
  3. 구성원들이 연대하고 협력하면서 사회적 문제를 해결할 방안을 마련함.
  4. 독자 개인의 성장을 이끌고 사회 문화를 발전시키는 원동력이 됨.
- 사회적 독서 활동을 할 수 있는 곳: 수업, 교내 독서 동아리, 외부 독서 모임, 사회 관계망 서비스[SNS], 온라인 독서 모임 플랫폼 (p.17)
- 생각 열기: 혼자보다 여럿이 했을 때 더 효과적이라고 느꼈던 경험 떠올리기 (p.12)

### 2. 제재 글 「별점 제도, 집단 지성의 힘」(김성태)
- 갈래·성격: 별점 제도의 **문제점과 개선책**을 제시하는 글 (p.13)
- 글쓴이 김성태: 미디어 학자. 빅데이터·인공지능 기반 신기술로 복잡한 사회 문제의 해결 방안을 모색함. 저서 『빅데이터 시대의 커뮤니케이션 연구』, 『인터넷 커뮤니케이션 연구』 (p.16)

#### (1) 집단 지성과 별점 제도 (p.13)
- **집단 지성**: 여러 사람이 서로 협력하거나 경쟁하는 과정을 통해 얻게 된 집단의 지적 능력.
- 과거: 소수 집단이 정보를 독점 → 현대: 정보 생산·유통의 진입 장벽이 낮아져 누구나 참여 가능.
- 다수가 댓글·공유로 정보를 수정·보완 → 다수에 의해 검증된 정보는 **객관성**을 확보.
- 그늘: 가짜 뉴스나 출처 없는 정보가 파급력을 가지고 잘못된 집단 지성이나 집단 정서를 형성하기도 함.
- 별점 제도는 집단 지성의 **빛과 그늘을 모두** 보여 준다.
- **별점**: 별 개수로 매겨지는 점수. 맛집·카페, 웹툰·영화, 기업의 업무 평가, 학교의 강의 평가 등에 사용.
- 별점 제도의 장점: 상품 구매·서비스 이용 여부 판단의 **길잡이**, 판매자에게는 **미래 판매 전략의 근거**.

#### (2) 별점 제도의 문제점 3가지 (p.13~14)
1. **별점 조작·감정적 별점** → 판매자나 이용자에게 큰 피해. 근거: 2022년 8월 소상공인시장진흥공단 조사, 배달 플랫폼 이용 소상공인 사업체 300개 중 **78%가 피해 경험**.
2. **참여자의 범위가 전체 이용자를 대표하지 않음** → "1%의 생산자, 9%의 공유자, 90%는 한발 뒤에서 바라보는 사람" — 별점은 적극적인 **10%만의 의견**일 수 있음. 별점 참여자는 **무작위 표본이 아니다**.
3. **잘못된 추론을 이끌어 냄** → 같은 별점 3점이라도
   - <그림 1> **정상 분포**: 중간값 3점 근처에 이용자가 가장 많고 양극단(1점·5점)은 적음.
   - <그림 2> **엠(M)자형 분포**: 호불호가 뚜렷해 3점 근처는 거의 없고 양극단으로 치우침.
   - 분포를 모르는 이용자는 평균만 보고 '중간 정도'라 생각해 잘못된 선택을 하게 됨.

#### (3) 폐지가 아니라 보완 (p.15)
- 별점 제도는 문제가 있어도 **폐지하기 어렵다** — 이미 우리 사회의 **한 문화로 자리 잡았기** 때문.
- 따라서 대체 제도를 찾기보다 문제점을 보완하여 최선의 해결책을 마련해야 함. 제안은 **자료 수집과 분석 과정**에 대한 것.

#### (4) 개선책 3가지 (p.15~16)
1. 참여하는 **평가자의 수가 기준치를 넘을 때만** 별점 표시 → 극소수의 허위 댓글·극단적 평가로 전체 별점이 왜곡되지 않게.
2. 열람자에게 **추가 정보 제공** → 작성자 계정의 과거 평가 이력, 해당 상품 이용 횟수 등을 **시각화**하면 활용도가 높아지고 극단적 평가를 바로잡는 데 도움.
3. 허위·악성 평가를 줄이는 **기술적·제도적 장치** → 별점 평가·상품 평은 법령상 **저작물**이라 작성자 동의 없이 포털·플랫폼 사업자가 임의로 삭제 불가 → 제어 기술 보완, 작성자의 자격 조건 명확화.

#### (5) 결론 (p.16)
- 별점 제도는 쉽고 편리하며 소통의 즐거움을 주고, 집단 지성의 힘으로 여론의 흐름을 만들 수 있음.
- 그러나 그릇된 방식으로 쓰면 선량한 시민의 삶에 가하는 **폭력**이 될 수 있음.
- 기술 개발·제도적 장치도 필요하지만 **이용자들이 나서지 않으면 근본적 문제 해결이 어렵다** → 모든 이용자의 **진솔한 태도**가 핵심.

#### 날개 질문·어휘 (p.13~16)
- 별점 제도는 어디에 활용되고 있을까? / 평가자가 적으면 어떤 문제가 생길까? / 글쓴이는 왜 별점 제도를 폐지할 수 없다고 생각할까?
- 생각 키우기: 별점 제도로 도움·피해를 입은 경험, 집단 지성이 사회 문제 해결에 어떤 도움이 될지 (p.16)

### 3. 학습 활동 1 — 글을 읽고 사회적 문제 인식하기 (독서 일지) (p.17)
- 모둠별로 **독서 일지** 작성: 읽은 날짜, 제목, 내용 정리, 인상적인 부분과 그 이유, 더 알고 싶은 내용.
- 내용 정리 예시: 문제점 — "조작된 별점, 감정적으로 매긴 별점으로 판매자나 이용자에게 피해" / 개선책 — "평가자 수가 기준치를 넘는 경우에만 별점 표시"
- 인상적인 부분 예시: 진솔한 태도가 필요하다는 내용 — 재미로 별점을 매겼던 것을 반성하게 됨.
- 더 알고 싶은 내용 예시: 별점 제도 때문에 피해를 입은 이용자들의 사례.

### 4. 학습 활동 2 — 사회적 문제 공유하기 (p.18)
- (1) 별점 제도 관련 추가 자료를 찾아 공유
  - 자료 1(세정): 『문화방송(MBC) 뉴스』 2022년 6월 27일 — 별점 제도를 악용하는 평가자에 의해 피해를 본 사례('별점 테러·협박 전화'에 등골 휘는 자영업자들)
  - 자료 2(진호): 『경향신문』 2022년 7월 5일 — 별점 제도는 서비스 개선과 **소비자의 알권리 보장**이라는 긍정적 측면, 배달 앱 서비스 개선·합리적 선택·자영업자 마케팅 등 순기능 → 제도 자체보다 **운영 방법**의 관점에서 해결 방법을 찾아야 함.
- (2) 문제 인식·해결 방안에 대한 의견 나누기
  - 민수: 문제가 심각하고 개선책이 필요함 / 세정: 긍정적 측면도 있어 잘 사용하는 것이 중요
  - 서연: 제도적 해결책도 중요하지만 **이용자들의 인식 개선**이 중요 / 진호: **카드 뉴스**를 만들어 SNS에 올리자.
- 도움말: 공유 문서나 온라인 플랫폼으로 실시간 자료·의견 공유, 새 글·자료 올리기, 댓글로 의견 교류 가능.

### 5. 학습 활동 3 — 사회적 문제의 해결 방안 마련하기 (카드 뉴스 캠페인) (p.19)
- **카드 뉴스**: 이미지와 간단한 문구로 구성된 카드를 여러 장 활용하여 **이야기 형식**으로 뉴스를 전달하는 매체 자료. 한 화면에 카드 한 장 → **시각적 주목도**를 높여 정보 전달에 효과적.
- **카드 뉴스 제작 과정**: 주제와 목적 선정하기 → 수용자와 매체 특성 분석하기 → 내용 마련 및 구성하기 → 카드 뉴스 제작 및 공유하기
- 예시: 1쪽 "별점 제도란? 별의 개수로 이용 만족도를 표현하는 방법" / 2쪽 "별점 제도의 문제점 — 배달 플랫폼 업체 중 78% '별점 평가 관련 피해 경험이 있다'(소상공인시장진흥공단, 2022년)"
- 캠페인 결과 공유, 사회적 독서 활동 소감 나누기.

## 비교·정리표

### 표 1. 별점 제도의 문제점 ↔ 개선책
| 구분 | 문제점 | 관련 개선책 |
|---|---|---|
| ① | 조작·감정적 별점으로 피해(78%) | 허위·악성 평가를 거르는 기술적·제도적 장치, 작성자 자격 조건 명확화 |
| ② | 참여자가 전체 이용자를 대표하지 않음(적극적 10%) | 평가자 수가 기준치를 넘을 때만 별점 표시 |
| ③ | 잘못된 추론(평균만 보고 판단) | 작성자 평가 이력·이용 횟수 등 추가 정보 제공·시각화 |

### 표 2. 정상 분포 vs 엠(M)자형 분포 (p.14)
| 구분 | 정상 분포(그림 1) | 엠(M)자형 분포(그림 2) |
|---|---|---|
| 모양 | 평균값을 중앙으로 좌우 대칭, 종 모양 | 양극단이 높고 가운데가 낮음 |
| 이용자 분포 | 3점 근처에 가장 많음 | 1점·5점 양극단으로 치우침 |
| 의미 | 정말 '평균적인 맛집' | 호불호가 뚜렷함 |
| 평균 별점 | 3점 | 똑같이 3점 → 착각 유발 |

### 표 3. 집단 지성의 빛과 그늘 (p.13)
| 빛 | 그늘 |
|---|---|
| 누구나 정보 생산·유통에 참여 | 가짜 뉴스·출처 없는 정보의 파급력 |
| 다수의 수정·보완 → 객관성 확보 | 잘못된 집단 지성·집단 정서 형성 |
| 별점: 구매 길잡이, 판매 전략 근거 | 별점: 조작·대표성 부족·잘못된 추론 |

### 표 4. 학습 활동 흐름
| 단계 | 활동 | 결과물 |
|---|---|---|
| 1 문제 인식 | 글 읽기 | 독서 일지 |
| 2 문제 공유 | 추가 자료 찾기, 의견 나누기 | 모둠 공유방 글·댓글 |
| 3 해결 방안 마련 | 캠페인 | 카드 뉴스 |

## 시험 함정 포인트
- 글쓴이는 별점 제도를 **폐지**하자는 것이 아니라 **보완**하자고 한다. 이유는 이미 우리 사회의 한 문화로 자리 잡았기 때문. (p.15)
- 문제 있는 별점 평가도 법령상 **저작물**이라 플랫폼 사업자가 **임의로 삭제할 수 없다**. 그래서 '삭제'가 아니라 '제어 기술 보완'을 제안한다. (p.16)
- 78%는 '이용자'가 아니라 배달 플랫폼을 사용하는 **소상공인 사업체 300개** 중 피해 경험 비율이다(2022년 8월, 소상공인시장진흥공단). (p.14)
- 적극적으로 의견을 내는 쪽은 1%(생산자) + 9%(공유자) = **10%**이다. 90%는 바라보는 사람. (p.14)
- 같은 별점 3점이어도 **분포**가 다를 수 있다. 엠(M)자형은 '중간'이 아니라 호불호가 갈린 경우다. (p.14)
- 결론의 핵심은 기술·제도만이 아니라 **이용자의 진솔한 태도**다. 이용자가 나서지 않으면 근본적 해결이 어렵다. (p.16)
- 개선책은 별점을 대체할 제도를 찾는 것이 아니라 **자료 수집과 분석 과정**에서의 제안이다. (p.15)
- 경향신문 자료는 별점 제도의 **긍정적 측면**(알권리 보장·서비스 개선)을 다룬다. 피해 사례는 MBC 뉴스 자료. (p.18)
- 카드 뉴스 제작 과정에서 '수용자와 매체 특성 분석'은 '내용 마련 및 구성'보다 **먼저**다. (p.19)

## 핵심 용어 사전
| 용어 | 뜻 |
|---|---|
| 사회적 독서 활동 | 독서로 얻은 지식·정보를 독서 모임 등을 통해 다른 사람과 공유하는 활동 |
| 집단 지성 | 여러 사람이 협력하거나 경쟁하는 과정을 통해 얻게 된 집단의 지적 능력 |
| 별점 | 별 개수로 매겨지는 점수 |
| 파급력 | 어떤 일의 여파나 영향이 차차 다른 데로 미치는 힘 |
| 플랫폼 | 정보 시스템 환경을 구축·개방하여 누구나 방대한 정보를 쉽게 활용할 수 있도록 제공하는 기반 서비스 |
| 무작위 표본 | 임의 추출법에 의하여 뽑아낸 표본 |
| 정상 분포 | 분포 곡선이 평균값을 중앙으로 좌우 대칭의 종 모양을 이루는 분포 |
| 엠(M)자형 분포 | 값이 중간에는 거의 없고 양극단으로 치우친 분포 |
| 호불호 | 좋음과 좋지 않음 |
| 제어 | 기계·설비·화학 반응 따위가 목적에 알맞은 작용을 하도록 조절함 |
| 독서 일지 | 읽은 날짜·제목·내용 정리·인상적인 부분·더 알고 싶은 내용을 기록한 것 |

## 자기점검 질문
1. 사회적 독서 활동의 효과 세 가지는? — 다양한 삶의 방식·가치관 이해, 사회 문제 인식과 타인 이해의 폭 확대, 연대·협력으로 해결 방안 마련
2. 집단 지성의 뜻은? — 여러 사람이 협력·경쟁하는 과정에서 얻게 된 집단의 지적 능력
3. 별점 제도의 문제점 세 가지는? — 조작·감정적 별점의 피해, 참여자의 대표성 부족, 잘못된 추론
4. 별점 참여자가 대표성이 없는 이유를 보여 주는 말은? — "1%의 생산자, 9%의 공유자, 90%의 바라보는 사람"
5. 같은 3점인데 잘못된 선택을 하게 되는 경우는? — 엠(M)자형 분포인데 평균만 보고 '중간 정도'로 판단할 때
6. 글쓴이가 별점 제도를 폐지할 수 없다고 보는 이유는? — 이미 우리 사회의 한 문화로 자리 잡았기 때문
7. 악성 평가를 플랫폼이 마음대로 지울 수 없는 이유는? — 법령상 저작물이라 작성자 동의가 필요
8. 카드 뉴스 제작 과정 4단계는? — 주제와 목적 선정 → 수용자와 매체 특성 분석 → 내용 마련 및 구성 → 제작 및 공유
9. 글쓴이가 가장 근본적인 해결책으로 강조한 것은? — 모든 이용자의 진솔한 평가 태도
